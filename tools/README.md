## ★なぜ P形式にしたのか

`restyle` の `felt()`（布の粒）は1画素ごとの雑音で、PNG が圧縮できません。
そのまま保存すると **24KB → 942KB**、375枚で **320MB** になりました。

★ところが、画面で羊が出るのは いちばん大きくて 240px。
1024px を 240px に縮めると約18画素が1画素に平均され、★粒はそこで消えます。

測りました（0〜255のうちの差、見える画素だけ）。

```
942KB版 と P形式版の差   240px … 1.03 ／ 480px … 1.43
942KB版 と 粒なし版の差  240px … 1.40 ／ 480px … 2.36
```

★1%未満です。★見分けがつきません。

★透明は、しきい値（128）で2値にしています。
元の絵の半透明は 0.44% しかなく、★抜き取り10点で ずれた画素は 0 でした。

★荷物の README 自身も、同じ壁に当たって同じ結論に達しています。
