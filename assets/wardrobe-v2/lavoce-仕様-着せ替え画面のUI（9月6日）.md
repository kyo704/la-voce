# 仕様：着せ替え画面のUI ── アイテムが多くなったときの見せ方

全 276 行 / 末尾は「点数が増えたゲームは、例外なくここに行き着いています。」

作成 2026年9月6日 ／ 宛先：Sonnet ／ モックアップの画像あり

---

## §0 いまの問題

> **画面を見ながらアイテムを変えられない。**

原因は3つで、どれも点数が増えると必ず起きるものです。

```
① アイテムの一覧が、羊を隠している
② 全部が1つの平らな一覧に並んでいて、どこに何があるか分からない
③ 「もう一度あの組み合わせにする」ができない
```

**③がいちばん深刻です。** 166点あると、前に作った着せ方を手で再現するのは不可能です。

---

## §1 原則（着せ替えゲームに共通するもの）

実際に売れている着せ替えゲーム（あつまれ どうぶつの森、ポケ森、ミラクルニキ、
Fortnite のロッカー、Roblox のアバターエディタ）に共通する形は、この3つです。

```
★① 主役（キャラクター）を、絶対に隠さない
★② 探させない。「呼び出す」形にする
★③ 選んだ結果が、その場で見える（確定を待たない）
```

そして Woolsong の既存の決まりを2つ重ねます。

```
★④ 「これにする」を1回押させる（IKEA効果。押さないと愛着が生まれません）
★⑤ おすすめコーデを自動生成しない（自律性がいちばん強い動機なので、奪わない）
```

---

## §2 画面の組み立て（★下から出るシート）

一覧を「全画面」にしないでください。**下から出るシート**にして、
羊はいつも上に見えている状態を保ちます。

### 3段階の高さ（390×844 の端末を基準）

| 段 | シートの上端 | 何が見えるか | いつ |
|---|---|---|---|
| **少しだけ** | y700 | 羊が全部。よく着るもの4点 | 開いた直後 |
| **半分** | y470 | 羊の上半分。一覧が2行 | ★ふだんの高さ |
| **全部** | y250 | 一覧が4行 | 「ならべる」を押したとき |

```
・シートの上端を指で上下にドラッグして、3段階に吸い付く（スナップ）
・つまみ（横棒）を上に出す
・★下にスワイプで閉じる。閉じても着せ替えは消えない（プレビューのまま）
```

**「半分」を既定にしてください。** 羊の顔と胸が見えるので、
上を着替えたときの変化がその場で分かります。

## §3 スロットのレール（いちばん上・横一列）

```
帽子 ／ 目元 ／ 首元 ／ 上 ／ 下 ／ 羽織り ／ 靴 ／ 持ち物 ／ 背中
```

```
・アイコン40×40の角丸。選択中は色を反転（有料の色 #185C60 ではなく、選択の色）
・★スクロールさせない。9つを画面幅に入れる（1つ38px＋間隔で足ります）
・「全身もの」（既存の217点）は、★レールの外に別のタブとして置く
　　→ 全身ものを選ぶと、上と下が同時に置き換わることを、その場で見せる
```

---

## §4 絞り込みのチップ（レールの下）

```
すべて ／ もっている ／ ★（お気に入り）／ 新着 ／ 系統
```

```
・「系統」を押すと、下に第2列が出る
　　きれいめ／カジュアル／やわらかい／和風／季節もの／時代もの
・チップは1つだけ選べる（複数選択にしない。迷わせない）
・★「持っていないものを隠す」は既定オフ。持っていないものも見せます（§8）
```

---

## §5 一覧の見せ方

```
1行4列。1枚 80×88。角丸14
サムネイルは ★羊に着せた状態の切り抜き（服だけの絵にしない）
　　→ 服だけを並べると、着たときの想像がつきません。ここは手を抜かないでください
```

### 各枠に出すもの

```
左上の1枚目　★「はずす」（そのスロットを空にする）。必ず先頭に固定
選択中　　　 わくを2px→3px、選択の色。右下に●
新着　　　　 右上に赤い点（一度見たら消す）
未所持　　　 白を150かけて、右上に鍵。★暗くしすぎない（買う気が失せます）
```

---

## §6 ★コーデ（保存した着せ方）── これが本当の答え

**166点を毎回探させないでください。探すのではなく、呼び出させます。**

```
・いまの着せ方を「コーデ」として保存できる（★上限20）
・名前をつけられる（★アプリは読まない。表示だけ。自由記述の規則に触れません）
・レールのいちばん左に「コーデ」タブを置く
・1タップで、全スロットが一度に切り替わる
```

### 自動で作られるコーデ（保存枠を使わない）

```
「いま着ているもの」　開いた瞬間の状態。もどす用
「この前の着せ方」　　直前に確定したもの
```

**この機能がないと、点数が増えるほどアプリが使いにくくなります。**
点数を増やすなら、これは同時に入れてください。

---

## §7 よく着るもの・お気に入り

```
「少しだけ」の段には ★よく着るもの4点 だけを出す
　　＝ そのスロットで、直近30日に確定した回数が多い順
長押しで ★お気に入り（星）。星は一覧の先頭に集まる
```

**多くの人は、166点のうち10点くらいしか使いません。** その10点に、
1タップで届くようにするのが、いちばん効きます。

---

## §8 タップしたときの動き

```
1回タップ　　→　★その場で羊が着替える（プレビュー）。確定はしない
別のを押す　　→　差し替わる
「もどす」　　→　開いたときの状態に戻る
「これにする」→　★ここで確定。保存される
シートを閉じる→　プレビューのまま残る（確定はまだ）
画面を出る　　→　「決めていないものがあります」と1回だけ聞く
```

### ★「これにする」を必ず押させる理由

IKEA効果の研究で、**手をかけたものへの愛着は「完成したとき」にだけ生まれ、
完成しなかった場合は効果が消える**ことが分かっています。
自動保存にすると、この一手間がなくなり、愛着も生まれません。

```
確定したときの見せ方
　・ボタンが一瞬沈む
　・羊が1周期だけ歩く（★見せ場。歩行アニメをここで使ってください）
　・「かわいい」などの評価語は出さない（本人が決めることです）
```

---

## §9 持っていないものの見せ方

```
◯ 一覧に ★出す（隠さない）。白を150かけて、鍵のしるし
◯ タップすると、その羊に着せた姿を ★3秒だけ見せる（試着）
◯ そのあと「これは まだ です」とだけ出す
✕ 「購入する」「今だけ」「残り○点」は書かない
✕ 暗くしすぎない。買う気が失せます
```

**「まだ」以外の言葉を足さないでください。**急かす言葉は使わない、という決まりの中です。

---

## §10 色の選択（★次の段階）

色マスク（form.png ＋ mask.png）を入れたら、ここに足します。

```
・アイテムを選んだあと、シートの下に ★24色のパレットが1行出る
・色を変えるとその場で羊に反映
・「色ちがい」を別アイテムとして一覧に並べない（★数が4倍になって探せなくなります）
```

## §11 データの形

```ts
type Slot = 'hat'|'eyes'|'neck'|'top'|'bottom'|'outer'|'shoes'|'prop'|'back'|'fullbody'

interface Worn   { [slot in Slot]?: { key: string; color?: string } }
interface Outfit { id: string; label: string; worn: Worn; createdAt: string }  // 上限20

interface ItemMeta {
  key: string; category: Slot; name: string
  gender: 'm'|'f'|'u'
  layer: number          // 重ね順。manifest.json にあります
  owned: boolean
  seenAt?: string        // 新着の赤い点を消すため
  favorite?: boolean
  usedCount30d: number   // 「よく着るもの」の並べ替え用
}
```

```
・Worn は1つだけ。プレビュー中は ★別に draftWorn を持ち、確定で Worn に移す
・fullbody が入っているときは top と bottom を無効にする（UIでも押せなくする）
```

## §12 やってはいけないこと

```
✕ 一覧を全画面にする（羊が見えなくなります。いまの問題そのもの）
✕ 服だけの絵をサムネイルにする（着たときが想像できません）
✕ タップで即確定（IKEA効果が消えます）
✕ おすすめコーデを自動で作る（★いちばん強い動機＝自律性を削ります）
　　　※「さいころ（ランダム）」ボタンは可。★本人が押すので自律性は保たれます
✕ 色ちがいを別アイテムとして並べる
✕ 未所持を隠す／暗くしすぎる
✕ 「残り○点」「今だけ」などの急かす言葉
✕ 一覧に説明文を出す（名前だけでいいです）
```

---

## §13 実装の順番（★効く順）

```
1. ★シートの3段階（羊を隠さない）　　　　　いまの問題が直ります
2. ★スロットのレール（9つ）　　　　　　　　探す範囲が1/9になります
3. ★コーデの保存（上限20）　　　　　　　　166点問題の本当の答え
4. よく着るもの4点／お気に入り
5. 絞り込みのチップ
6. 未所持の試着（3秒）
7. 色のパレット（色マスクを入れてから）
```

**1〜3をやれば、いまの問題はほぼ解決します。**
4以降は、点数がさらに増えてから足しても間に合います。

## §14 参考にした形

```
あつまれ どうぶつの森　　部位のタブ＋グリッド、着た状態のサムネイル、確定してから着替え
ポケ森　　　　　　　　　 下から出るシート、キャラは常に上に見える
ミラクルニキ／シャイニングニキ　左の部位レール＋右のグリッド、コーデの保存
Fortnite ロッカー　　　　★保存した組み合わせが最上位。個別のアイテムはその下
Roblox アバターエディタ　カテゴリのタブ＋「いま着ているもの」の欄
```

共通しているのは、**どれも「保存した組み合わせ」を持っている**ことです。
点数が増えたゲームは、例外なくここに行き着いています。
