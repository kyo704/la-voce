
## 大きさの規約

```
家具・庭の置物・壁掛け・昭和の家具　320 × 320　★床に接する位置は y300 に揃えてあります
窓枠　　　　　　　　　　　　　　　  384 × 384　★中は抜いてあります（景色が透けます）
扉　　　　　　　　　　　　　　　　  320 × 512
窓の外の景色　　　　　　　　　　　  480 × 320
壁・床のタイル　　　　　　　　　　  256 × 256　★敷き詰め用（継ぎ目が出ません）
```

## ★窓は「枠」と「景色」が別レイヤーです

計画書の指示どおり、窓枠の中は抜いてあります。

```
重ね順　　景色（view）→ 窓枠（window）
```

枠を替えても景色はそのまま使えます。13枠 × 13景色 ＝ **169通り**の窓ができます。

## 床に接する位置

家具は **y300 が床の線**です。320の画像の下20pxは余白なので、
床のラインに y300 を合わせて置いてください。全点そろえてあります。

## ★縁側（showa_19）

計画書で「1点で昭和の家に見えるので最初に作る」としたものです。
床（板の間）と障子が一体になっています。**景色は `view_11 縁側から見た庭` と対で使ってください。**
