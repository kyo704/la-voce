# 声のカルテを、毎朝ひらく理由に

_La Voce ／ 分析レイヤー設計_

記録項目はもう十分に揃っています。足りないのは「今日それを見る理由」。
朝30秒で意味が立つ指標、週に一度の発見、本番から逆算する実務値——この三層に、記録が貯まるほど解放される仕掛けを重ねた10個の指標と、その計算方法をまとめました。

---

## 設計の骨格：3つの時間軸

_「毎日使いたくなる」は1種類の仕掛けでは作れません。開く頻度の違う3つの動機を、別々のレイヤーとして設計します。_

**今日の自分を言い当てる**（毎朝 30秒）  
予報・偏差値・立ち上がり。**入力する前に見たくなる**数字を置き、記録はその答え合わせにする。開く動機が「義務」から「答え合わせ」に変わります。

**自分だけの法則が出る**（週に 1回）  
ラグ相関・効いた習慣・症状の連鎖。一般論ではなく**「あなたの声は睡眠不足の2日後に落ちる」**という固有名詞の発見を返す。人に話したくなる層です。

**仕事の成果に直結する**（本番の前後）  
ピーキング曲線・発声負荷・環境の快適帯。次の本番日を入れると逆算プランが出る。ここが**プロが手放せなくなる**理由になります。

## 記録が貯まるほど、画面が増える

_現状6日分。少ないうちは「精度が足りないので非表示」ではなく、**次に何が開くかを見せる**ことで記録が続きます。件数の閾値は統計的に意味が立つ最小値から決めています。_

| Lv | 条件 | 解放されるもの | 予告の出し方 |
|---|---|---|---|
| Lv.1 | 1日 | 声の予報（一般知見のみ）、今日のサマリー | — |
| Lv.2 | 3日 | ウォームアップ効率、症状カレンダー、音域マップ | 初回は演出つきで開く |
| Lv.3 | 7日 | コンディション偏差値、週次カルテ、絶対湿度の1次元傾向 | 「あと◯日で偏差値が出ます」 |
| Lv.4 | 14日 | ラグ相関マップ（ラグ0-1）、効いた習慣ランキング（★1まで） | ロック画像＋残り日数バー |
| Lv.5 | 28日 | 発声負荷ACWR、環境ヒートマップ、予報の個人化、What-if | 「4週間そろいました」 |
| Lv.6 | 本番3件 | ピーキング曲線と本番逆算プラン | 本番を記録するたびに進捗 |

> **ロックの見せ方が肝心です**  
> 灰色の箱に「データ不足」と書くのは離脱の合図。**完成後のグラフをぼかして重ね、「あと3日」の進捗バーを添える**と、同じ状態が予告編になります。解放の瞬間は一度だけアニメーションを入れる価値があります。

## 指標カタログ

_10案。番号は実装の推奨順です（前半ほど少ないデータで成立し、効果が早く出ます）。_

### 01. 声の予報

`Voice Forecast — 朝30秒レイヤー`

いまの「声の状態の予測」は文章での注意喚起です。これを**数値の予報＋当たったかどうか**に変えると、記録が「答え合わせ」になります。予報が外れた日ほど新しい発見があるので、外れも歓迎できる設計にします。

> [図] 薄い帯は予測区間（±1標準誤差）。右の的中率は「予報と実測の差が±0.5以内だった日の割合」。数字が育つこと自体がゲームになります。

**計算**

```
前夜の行動 x から翌朝の喉スコア ŷ（1〜5）を予測する。
係数は「一般知見の事前値 β₀」と「その人の回帰係数 β̂」を件数で混ぜる（経験ベイズ縮約）。

  β = n/(n+k) · β̂ + k/(n+k) · β₀      k = 20（半分個人化される件数）
  ŷ = μ + Σ βⱼ (xⱼ − x̄ⱼ)            μ = その人の直近28日平均

事前値 β₀ の例（スコア1〜5換算・喉の生理から）
  睡眠時間        +0.25 / 時間      夕食→就寝    +0.10 / 時間
  水分量          +0.15 / L          心の余裕     +0.20 / 段階
  アルコール      −0.40（有無）      前日発声負荷 −0.15 / 正規化1単位
  絶対湿度        +0.02 / (g/m³)     前日の喉      +0.35（自己相関）

β̂ は L2正則化（リッジ、λ = 1.0、標準化後）。n < 14 のときは β̂ = 0 とみなし、
実質「一般知見だけの予報」から始めて、記録が増えるほどその人の式に寄っていく。

予測区間は直近の残差 e = y − ŷ の標準偏差から  ŷ ± SD(e)。
```

- **必要データ**：前日の睡眠・水分・食事・活動・メンタル・気象
- **解放条件**：Lv.1（一般知見のみ）→ Lv.5 で個人化
- **グラフ形式**：折れ線（予報）＋点（実測）＋予測区間の帯
- **ワクワクの源**：「当たった／外れた」が毎朝発生する。的中率が育つ
- **外れ値・欠損**：欠損した説明変数はその項を平均値で埋め、区間を1.2倍に広げて「自信なし」を表現

> **画面に出す言葉**  
> 今日の予報は **2.4／5**。前夜の睡眠5.5時間が効いています。  
> 直近30日の的中率は78%。外れたら理由を教えてください。

### 02. コンディション偏差値

`Self-relative Z — 朝30秒レイヤー`

100点満点の総合スコアは絶対評価なので、良い日も悪い日も70台に集まって動きが見えません。**自分の過去の分布のどこに今日がいるか**に変えると、同じデータで毎日ちゃんと針が振れます。

> [図] リングは自分比の偏差値。右のヒストグラムが「自分の分布のどこにいるか」を示すので、数字の意味が説明不要になります。

**計算**

```
直近28日（最低7日）の総合スコア x の平均 μ と標準偏差 σ を取り、

  z = (x − μ) / max(σ, 0.5)        σ の下限クリップで「安定しすぎた日」の暴発を防ぐ
  T = 50 + 10 z                    表示は 20〜80 にクリップ

順位表示は分布内のパーセンタイル  P = #{xᵢ ≤ x} / n × 100

【なぜ σ に下限を置くか】記録初期は分散が小さく、わずかな差で偏差値が90を超えます。
σ ≥ 0.5（5段階スケールで1目盛りの半分）を下限にすると、n が小さいうちも常識的な幅に収まります。
【σ の推定】n < 14 では標本SDの代わりに MAD ベースの頑健推定  σ̂ = 1.4826 · MAD  を使う。
```

- **必要データ**：既存の総合スコア（100点満点）のみ
- **解放条件**：Lv.3（7日）
- **グラフ形式**：ドーナツゲージ＋自分の分布ヒストグラム
- **ワクワクの源**：「自己ベスト更新」が毎日起こりうる。絶対値では動かない針が動く
- **外れ値・欠損**：σ の下限クリップと MAD 推定で少数件の暴れを抑制

> **画面に出す言葉**  
> 今日は **偏差値 62**。この4週間で上から12%、**4番目に良い日**です。

### 03. ウォームアップ効率

`Δ Semitone — 朝30秒レイヤー`

すでに「起き抜け」と「ルーティン後」の音名を取っているのに、いまは2本の折れ線として別々に見せています。**この2点の差そのものが、その日の声の立ち上がりの速さ**です。声のプロが最も体感的に納得する指標になります。

> [図] ダンベル図。棒の長さがそのままウォームアップで戻った半音数。長い日は「よく起きた声」、短い日は疲労の蓄積を疑います。

**計算**

```
音名を MIDI ノート番号に変換して差を取る（国際式・C4 = 60）。

  MIDI = 12 (オクターブ + 1) + 音階値     音階値: C=0, C#=1, … B=11
  ΔST = MIDI(ルーティン後) − MIDI(起き抜け)   単位は半音

平常値との比較は頑健統計で。m = 中央値(ΔST), MAD = 中央絶対偏差 として
  z = 0.6745 (ΔST − m) / MAD
  z ≤ −1.5 → 「立ち上がりが鈍い」、z ≥ +1.5 → 「よく起きている」

派生：ウォームアップ効率 = ΔST / m（平常を1.0とする割合表示。%で見せると直感的）
派生：起き抜けの絶対値 MIDI(起き抜け) の7日移動平均は「疲労の底」の指標。じわじわ下がっていたら要注意。
```

- **必要データ**：起き抜け／ルーティン後の音名（すでに記録あり）
- **解放条件**：Lv.2（3日）
- **グラフ形式**：ダンベル（2点＋接続線）
- **ワクワクの源**：「今日は半音5つ上がった、今週いちばん」——体感と一致するので毎朝確かめたくなる
- **外れ値・欠損**：どちらか片方だけの日は棒を描かず、点のみ表示して集計から除外

> **画面に出す言葉**  
> 今朝は **+2半音**。ふだんは +5 なので、声が起きるのに時間がかかる日です。  
> 本番前ならウォームアップを長めに。

### 04. 声の時差マップ

`Lagged correlation — 週次レイヤー`

この機能が、いちばん「人に話したくなる」発見を生みます。生活の変化は**当日ではなく数日後に声へ出る**ことが多い。その遅れ日数を可視化すると「自分の声には2日の時差がある」という固有の法則が手に入ります。

> [図] 行が生活の変数、列が「何日後に効くか」。色が濃いセルほど関係が強く、いちばん強いセルを文章にして返します。

**計算**

```
説明変数 x を k 日ずらして、目的変数 y（喉／声／響きスコア）とのスピアマン順位相関を取る。
順位相関を使うのは、5段階評価が順序尺度で、外れ値にも強いため。

  ρ(k) = Corr( rank x_{t−k} , rank y_t )      k = 0, 1, 2, 3

有意性は t 近似で  t = ρ √((n−2)/(1−ρ²)), 自由度 n−2。
変数7×ラグ4＝28通りを一度に見るので、Benjamini–Hochberg 法で FDR = 0.10 に補正。
補正後に残ったセルだけ枠線を付け、文章化の対象にする。

表示条件：ペアで揃っている日が n ≥ 14（Lv.4）。n < 14 のセルは灰色にして
「あと◯日でこのマスが埋まります」と出す。
```

- **必要データ**：生活変数7種 × 喉/声スコア、14日以上
- **解放条件**：Lv.4（14日・ラグ0-1）→ Lv.5（28日・ラグ0-3）
- **グラフ形式**：ヒートマップ（発散色：青＝正、赤＝負、中間はグレー）
- **ワクワクの源**：「自分の声の時差」という、他人には当てはまらない発見が出る
- **外れ値・欠損**：pairwise deletion（そのセルで揃っている日だけ使う）。補完はしない

> **画面に出す言葉**  
> 見つかりました。**あなたの声は、睡眠不足の「2日後」にいちばん落ちます**（ρ = 0.61）。  
> 本番の2日前の夜がいちばん大事、ということかもしれません。

### 05. 効いた習慣ランキング

`Effect size — 週次レイヤー`

いまの「食事では、喉の調子が良かった日に白米を食べていることが多いです／反対に悪かった日にも白米が多いです」という表示は、**件数の少なさが原因で矛盾したまま出てしまっています**。効果量と信頼区間で語り、確度を★で見せると、この問題は自然に解消します。

> [図] 点が効果量、横棒が95%信頼区間。棒がゼロ線をまたいでいる項目は★が付かず「まだ判断できない」扱いになります。

**計算**

```
二値の条件（あった日／なかった日）で翌日のスコアを比べ、標本サイズに強い効果量で表す。

  s_pooled = √( ((n₁−1)s₁² + (n₀−1)s₀²) / (n₁+n₀−2) )
  g = (x̄₁ − x̄₀) / s_pooled × J,   J = 1 − 3/(4(n₁+n₀) − 9)   ← 小標本バイアス補正
  SE(g) = √( (n₁+n₀)/(n₁n₀) + g²/(2(n₁+n₀)) )
  95%CI = g ± 1.96 · SE(g)

確度★の付け方（表示の門番）
  ★☆☆☆  n₁ ≥ 3 かつ n₀ ≥ 3（表示の最低ライン）
  ★★☆☆  CIがゼロをまたがない
  ★★★☆  上に加えて |g| ≥ 0.5
  ★★★★  上に加えて n₁ ≥ 10 かつ n₀ ≥ 10

方向は必ず「前日の行動 → 翌日のスコア」に固定する。同日で相関を取ると
「声が良かったからよく練習できた」という逆向きを拾ってしまう。
```

- **必要データ**：二値化できる習慣 × 翌日スコア
- **解放条件**：Lv.4（各群3日以上）
- **グラフ形式**：ドット＆ウィスカー（効果量＋CI）、効果の大きい順
- **ワクワクの源**：「自分だけの黄金律」が順位で出る。試したくなる
- **外れ値・欠損**：食品タグは**週の摂取頻度で層別**してから比較（毎日食べる主食は交絡するため既定で除外）

> **画面に出す言葉**  
> 今週わかったこと：**前夜7時間以上ねむれた日**は、翌日の声が平均で1段階近く良くなっています（★★★☆）。  
> 「水分2.0L以上」はまだ判断できません。あと4日ぶんで結論が出ます。

### 06. 症状カレンダーと連鎖

`Streak & conditional probability — 週次レイヤー`

症状は8種類も記録しているのに、いまはどこにも可視化されていません。**日付×症状の格子**にすると、連続日数と「症状が次の症状を呼ぶ」パターンが一目で出ます。医師やボイストレーナーに見せられる図でもあります。

> [図] 格子の1マスが1日1症状。連続している帯を自動で検出して警告に変えます。右は症状どうしの連鎖確率。

**計算**

```
① 連続日数（ストリーク）：症状 s が連続して記録された最長の直近区間。
   L ≥ 3 日で注意、L ≥ 7 日で受診の目安を案内（医療判断ではなく「記録上の事実」として提示）。

② 連鎖確率：症状 a の翌日に症状 b が出る確率と、b のふだんの出現率を比べる。
   P(b_t | a_{t−1}) = #(a_{t−1} ∧ b_t) / #(a_{t−1})
   lift = P(b_t | a_{t−1}) / P(b)       lift ≥ 1.5 かつ #(a) ≥ 5 のときだけ表示

③ 同時に出やすい組み合わせ：ジャッカード係数  J(a,b) = |a ∩ b| / |a ∪ b|
   上位3組を「よく一緒に出る症状」として並べる。

④ 月ごとの症状負荷：症状日数 / 記録日数。前月比の増減を矢印で。
```

- **必要データ**：症状8種のチェック（すでに記録あり）
- **解放条件**：Lv.2（3日）／連鎖確率は Lv.4
- **グラフ形式**：カレンダーヒートマップ（1色の濃淡）＋条件付き確率のカード
- **ワクワクの源**：「7日連続」に気づく瞬間の驚き。医師に見せられる資料が勝手にできる
- **外れ値・欠損**：記録のない日は「症状なし」ではなく空白として区別し、分母から除く

> **画面に出す言葉**  
> **乾燥が8日続いています。**ふだんより長い状態です。  
> あなたの記録では、乾燥の翌日に嗄れが出る確率は **71%**（ふだんは24%）。今日は加湿を優先しましょう。

### 07. 発声負荷バランス

`ACWR — 本番レイヤー`

スポーツ医学で故障予測に使われる**急性:慢性負荷比**を、発声時間に持ち込みます。「直近1週間の負荷が、この1か月の平均に対して何倍か」——歌い込みすぎと、逆に積み足りない状態の両方を1つの数字で管理できます。プロには即座に伝わる指標です。

> [図] 背景の帯が推奨ゾーン。1.5を超える急な増やし方は喉のトラブルと結びつくことが知られています。

**計算**

```
① 1日の発声負荷を、活動の種類で重み付けした分に換算する。

  L_d = 活動時間(分) × w
  w:  休養 0 ／ 自主練習 1.0 ／ レッスン 1.2 ／ リハーサル 1.3 ／ 本番 1.6
  （運動記録は 0.3 × 分 × 強度/3 を加算。呼吸支持のトレーニングも負荷の一部として扱う）

② 指数移動平均（EWMA）で急性・慢性の負荷を出す。単純移動平均より直近の変化に素直。

  A_t = λ_a L_t + (1−λ_a) A_{t−1},   λ_a = 2/(7+1)  = 0.250
  C_t = λ_c L_t + (1−λ_c) C_{t−1},   λ_c = 2/(28+1) = 0.069
  ACWR = A_t / C_t

③ ゾーン判定
  < 0.80  積み足りない（本番前なら仕上がり不足のサイン）
  0.80–1.30  ちょうどいい
  1.30–1.50  増やしすぎ注意
  > 1.50  喉を痛めやすい急増

④ 明日を休養にした場合の予測値も同じ式で1ステップ先まで回し、その場で提案する。
```

- **必要データ**：活動の種類と時間（すでに記録あり）
- **解放条件**：Lv.5（28日）
- **グラフ形式**：ゾーン帯つき折れ線＋今日の値の大きな数字
- **ワクワクの源**：「今日は歌っていいのか」に数字で答えが出る。予定を組む道具になる
- **外れ値・欠損**：記録のない日は L=0 とせず前日の EWMA を引き継ぐ（休んだのか未記録なのか区別できないため）

> **画面に出す言葉**  
> 今日の負荷比は **1.49**。この4週間の平均に対して、直近1週間で急に増えています。  
> 明日を休養にすると 1.20（ちょうどいい範囲）に戻ります。

### 08. 本番ピーキング曲線

`Event-aligned average — 本番レイヤー`

いまの分析は「本番3件で相関分析」止まりです。もう一歩進めて、**本番日をゼロ点にして過去の本番をすべて重ね合わせる**と、その人固有の仕上がり方の型が出ます。そして次の本番日を入れると、それが逆算プランになります。この機能が、La Voce を手放せなくします。

> [図] 過去の本番をすべて「当日＝0」にそろえて平均。帯は±1SD。谷の位置がその人の型で、次の本番の同じ日に手を打てます。

**計算**

```
① 本番日の集合 E = {e₁ … e_m} に対し、相対日 τ = d − eᵢ（−7 ≤ τ ≤ +3）で並べ替える。
   各 τ について平均と標準偏差を出す（重なった本番は τ ごとに件数が違うので n も持つ）。

  ȳ(τ) = (1/n_τ) Σᵢ y(eᵢ + τ),   SD(τ),   n_τ ≥ 2 の τ だけ描画

② 表示条件：本番 m ≥ 3 件。m < 3 のときは「あと◯回の本番でこの図が出ます」。

③ 逆算プラン：本番当日の声が良かった回（当日スコア ≥ 4）だけを取り出し、
   その回の τ 日目の行動（睡眠時間・発声負荷・水分）の中央値を「目標値」として提示する。

  目標(τ, 変数) = median{ x(eᵢ + τ) : y(eᵢ) ≥ 4 }

   良い回が2件未満なら、代わりに全体の中央値＋一般的な推奨を出す。

④ 公演の出来（既存項目）を y に差し替えれば、「出来」を目的変数にした同じ図も作れる。
```

- **必要データ**：本番の記録3件以上＋前後1週間の日次記録
- **解放条件**：Lv.6（本番3件）
- **グラフ形式**：イベント整列の折れ線＋SD帯＋当日の縦線
- **ワクワクの源**：「次の本番まであと12日、3日前が要注意」という、仕事のカレンダーに直結する助言が出る
- **外れ値・欠損**：本番が連日で重なる期間は τ の割り当てを最寄りの本番に限定し、二重計上しない

> **画面に出す言葉**  
> あなたは **本番の3日前にいちど沈み、前日に戻る型**です（過去5回の平均）。  
> 次の本番は9/6。**9/3は睡眠7.5時間・発声60分まで**を目標にしましょう。

### 09. 環境の快適帯

`Absolute humidity map — 本番レイヤー`

滞在地・気温・湿度をすでに取っているのに、いまは滞在地ごとの平均しか出していません。遠征の多い声のプロにとって、**自分の喉が快適な気温と湿度のゾーン**は実務的な武器になります。鍵は相対湿度ではなく**絶対湿度**で見ることです。

> [図] マスの色が喉のコンディション平均。件数2日未満のマスは灰色。枠で囲んだ範囲が快適帯です。

**計算**

```
① 相対湿度は気温が変わると同じ % でも空気中の水分量が変わってしまうので、
   絶対湿度 AH（g/m³）に直してから使う。Magnus 式＋理想気体の関係から：

  e_s = 6.112 · exp( 17.67 T / (T + 243.5) )   （飽和水蒸気圧 hPa、T は℃）
  AH = 216.7 · e_s · RH / 100 / (273.15 + T)

  検算：20℃/50% → 8.64 g/m³ ／ 25℃/60% → 13.81 g/m³ ／ 31℃/38% → 12.18 g/m³
  （冬の楽屋がなぜ乾くのかが、この数字で一目でわかります）

② 2次元マップ：気温を4℃刻み、相対湿度を10%刻みでビンに分け、各マスで喉スコアの平均。
   n ≥ 2 のマスだけ着色、n が増えるほど枠線を濃くして信頼度を表す。

③ 快適帯の抽出：AH を1次元でビン分け（2 g/m³ 刻み）し、
   喉スコア平均が全体平均 + 0.3 を超える連続したビン区間を快適帯とする。

④ 遠征先の予報（気温・湿度）を同じ式で AH に直せば、
   「明日の会場はあなたの快適帯より4.2 g/m³ 乾いています」と事前に言える。
```

- **必要データ**：気温・湿度・喉スコア。快適帯の抽出には20日程度
- **解放条件**：Lv.3（1次元）→ Lv.5（2次元マップ）
- **グラフ形式**：2次元ヒートマップ（1色の濃淡）＋今日の位置マーカー
- **ワクワクの源**：遠征前に「加湿器を持つか」が数字で決まる。旅の多い人ほど手放せなくなる
- **外れ値・欠損**：気温・湿度が未入力の日は除外。滞在地から気象APIで補完する場合は補完印を付ける

> **画面に出す言葉**  
> あなたの喉の快適帯は **絶対湿度 9.8〜14.2 g/m³**。  
> 今日の甲府（31℃/38%）は AH 12.2 で、ちょうど快適帯の中です。

### 10. 音域到達マップ

`Range tracker — 見せ場レイヤー`

音名を記録しているアプリは、そのまま**鍵盤の上に自分の到達点を置ける**という強い絵を持っています。折れ線より鍵盤のほうが、声のプロには一瞬で伝わります。「更新」という体験を毎日つくれる唯一の指標でもあります。

> [図] 記録された地声の到達音を鍵盤に置いたもの。上端が伸びた日は「更新」バッジ。声種の一般的な目安も薄く重ねます。

**計算**

```
記録された音名をすべて MIDI 番号に直し、期間ごとの最小値・最大値を取る。

  音域幅（半音） = max(MIDI) − min(MIDI)
  今週の充実度 = 今週の音域幅 / 自己ベストの音域幅 × 100 (%)

自己ベストの更新判定は外れ値に注意する。1日だけ突出した記録がベストになると、
以後ずっと更新できず意欲を削ぐ。そこで
  自己ベスト = 上位5%点（95パーセンタイル）を採用し、単発の記録では動かないようにする。
  それを超えた日は「更新」ではなく「新記録」として別扱いで祝う。

派生：起き抜けの最低音の30日移動平均が下がり続けている＝疲労の蓄積、というアラートに使える。
```

- **必要データ**：起き抜け／ルーティン後の音名
- **解放条件**：Lv.2（3日）
- **グラフ形式**：鍵盤ビジュアル＋範囲バー
- **ワクワクの源**：見た瞬間に意味がわかる。更新の瞬間が毎日起こりうる
- **外れ値・欠損**：95パーセンタイルを自己ベストとし、単発の外れ値でベストが動かないようにする

> **画面に出す言葉**  
> 今週の音域は **G#3 – E5**。自己ベスト（F3 – G5）の78%まで戻ってきました。

## 数字の作法

_どの指標にも共通して守るルール。ここを揃えておくと、記録が少ない時期でも「このアプリの数字は信用できる」という感触が保てます。_

1. **件数を必ず添える。**「平均4.5」ではなく「平均4.5（2日）」。件数を書くだけで、読み手が自分で割り引いて読めます。
2. **矛盾した結論を同時に出さない。**いまの「良かった日にも悪かった日にも白米が多い」という表示は、件数不足が原因です。**両方向に出た項目は結論を出さず「まだ判断できません」と表示する**ルールにします。効果量と信頼区間を使えば自動的にそうなります。
3. **5段階評価は順序尺度として扱う。**平均より中央値、ピアソンよりスピアマン。外れ値1件で結論が変わる事故が減ります。
4. **欠損は埋めない。**その指標に必要な項目が揃っている日だけを使う（pairwise deletion）。埋めた値で相関を出すと、実際にはない関係が生まれます。
5. **たくさん比べたら補正する。**変数×ラグで28通り試せば、偶然「有意」なものが1〜2個は出ます。Benjamini–Hochberg 法で FDR を 0.10 に抑えてから文章にします。
6. **因果の言い方を固定する。**「◯◯すると声が良くなります」ではなく**「◯◯した日の翌日は、平均して声が良く記録されています」**。テンプレートを1つ決めて、全画面で守ります。
7. **医療の言葉を使わない。**「炎症」「診断」は避け、「記録上◯日続いています」という事実提示に留めて、受診の判断は本人に返します。

## いまのグラフへの手直し

_新しい指標を足す前に、既存の画面で直したほうがよい点が4つあります。どれも小さな変更で効きます。_

### 1. 三重軸のグラフを分ける

「体重・摂取カロリー・タンパク質のまとめ」は、左軸にカロリー、右軸に体重、さらに軸のない線としてタンパク質——1枚に3つのスケールが同居しています。**2つ以上のy軸を持つグラフは、交点の位置が軸の取り方だけで変わる**ため、実際にはない相関を読ませてしまいます。「軸は非表示、ツールチップで確認可」という注記自体が、この形が無理をしているサインです。

解決は、すでに同じページの下にあります。「栄養摂取と体重の変化」の**上下2段・x軸共有**の形が正解で、これを3段に増やせば済みます。まとめグラフのほうは削除してよいでしょう。3つを1枚で比べたいなら、それぞれを「期間の初日＝100」に指数化すれば1本の軸に乗ります。

### 2. 1件しかない平均を出さない

「休養方法ごとの傾向」と「滞在地ごとの傾向」で、1件の記録が平均として並んでいます。**n ≥ 3 を表示の下限**にして、それ未満は「記録数」だけを並べた棒グラフにしておくと、貯める動機に変わります。

### 3. 総合スコアの内訳に、寄与を出す

76点という数字より、**「水分が50点で、ここが全体を7点押し下げています」**のほうが行動につながります。各サブスコアの重み × 満点との差を「押し下げ量」として並べ、いちばん効く1項目だけを提案にします。

### 4. 期間セレクタに「本番前後」を足す

1週間／1ヶ月／1年／全期間は暦の区切りですが、声のプロの実感は**本番を基準**に動いています。「直近の本番の前後2週間」というビューを1つ足すだけで、振り返りの精度が変わります。

## その先にある2つ

_上の10案が動いたあとに効いてくる、応用の2つ。どちらも既存の計算を使い回せます。_

### もしもスライダー（What-if）

予報（01）の回帰係数をそのまま使い、**「睡眠を+1時間したら」「アルコールをやめたら」を動かすと、明日の予測が動く**スライダー。数式は同じで、入力だけを仮の値に差し替えます。行動の重みが体感でわかるので、ここが一番「触っていて面白い」画面になります。

```
予報の式に仮の入力 x′ を入れて差分を取るだけ。

  Δŷ = Σ βⱼ (x′ⱼ − xⱼ)

係数 β は縮約後のものを使うので、記録が少ない人には一般知見寄りの、
多い人にはその人固有の答えが返る。効果の大きい順に3つだけスライダーを出すと迷いません。
```

### 週次ボイスカルテ

1週間ぶんを1枚のカードにまとめ、**先生・ボイストレーナー・耳鼻科に見せられる**形で書き出す機能。偏差値の推移、症状のカレンダー、発声負荷、今週わかったこと1つ。プロにとっては「人に見せられる」ことが継続の強い理由になります。画像として保存できると、そのまま共有されて広がります。
