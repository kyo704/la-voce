# 10　後援・協賛・助成 ― 3つは別のものです

## 読む前に

市役所から「後援」をもらうと、いちばん得られるものは。

```
・お金
・信用と、置ける場所
・会場費の割引
```

★当てなくて構いません。読み終わったあとに、もう一度考えてください。

## 本文

**この3つを混同している人が多いので、最初に分けます。**

```
後援（こうえん）  名義を貸してもらう。★お金は出ない。原則無料
協賛（きょうさん）企業や個人からの現金・現物。見返りに名前を載せる
助成（じょせい）  財団や自治体からの資金。★審査があり、事後精算が多い
```

### 後援は「お金」ではなく「扉」

**後援名義が付くと、できることが増えます。**

```
・市の公共施設に、チラシとポスターを置ける
・★教育委員会の後援があると、学校を通じてチラシを配れる
・市の広報紙の行事欄に載せてもらえる
・新聞社の後援があると、記事として扱われやすくなる
・放送局の後援があると、番組で紹介されることがある
```

**「無料で、チラシを置ける場所が増える」**——これが後援の本体です。

**後援は、積み上げれば51団体まで届きます。**
県、複数の市町村、教育委員会、新聞社、放送局、商工会、観光協会、
企業、そして個人。名義を貸してくれる先は、思っているより多くあります。

### 後援の取り方

```
① 開催の3か月前までに申請する（★2か月前だと間に合わない自治体があります）
② 申請書に「事業の趣旨」「対象」「入場料」「収支の見込み」を書く
③ 教育委員会は、市とは★別の申請です
④ 決定後、指定された名義の書き方をチラシに載せる
⑤ ★終了後に実績報告書を出す（これが次回に効きます）
```

**★注意：多ければ良いわけではありません。**

**51団体の後援は、51回の申請と、51回の実績報告**を意味します。
そして**チラシとプログラムに、51団体の名前を正確に載せる**必要があります。
名義の書き方は団体ごとに指定があり、重複や表記ゆれの誤植が起きやすい場所です。

**事務量が団体数に比例します。**最初は5〜10団体から始めてください。

### 協賛の頼み方

**金額を先に言わないでください。**

```
・何をする公演か
・誰に届くか（★動員の見込みと、その根拠）
・名前をどこに、どの大きさで載せるか
・当日、招待券を何枚お渡しするか
```

**そのうえで「1口◯円から」と言います。**

**★個人商店には、現物の協賛も頼めます。**
花、菓子、飲み物、印刷。**現金でなくても、支出が減ります。**

### 助成の申請書は、音楽家以外が読みます

**審査するのは音楽の専門家ではありません。**
だから、演奏の中身より**「誰に、どんな良いことがあるか」**を数字で書きます。

```
✗ 「質の高いクラシック音楽を届けます」
○ 「◯◯市の子ども◯名を無料招待し、生の演奏に触れる機会を作ります」
```

**★交付決定より前に使ったお金は、対象外になることが多いです。**
申請中に印刷を発注しないでください。

## 覚えておくこと

> **後援は、お金ではなく「置ける場所」をくれる。**

## 用語

**後援名義（こうえんめいぎ）** 団体の名前を使う許可。原則無料。

**実績報告書** 終了後に出す報告。★次回の審査で最初に見られます。

**現物協賛** お金の代わりに品物やサービスを提供してもらうこと。

## 自分の場合を書く

**Q1.** 次の公演で、後援を頼めそうな団体を三つ挙げるとしたら、どれですか。

**Q2.** そのうち、実績報告まで自分で回せるのは何団体ですか。

**※ 答え合わせはありません。採点もしません。**
**あなたの土地と、あなたの活動では、本文と違う答えが正しいことがあります。**
**書いたものは、あなたの記録に残ります。**

# 11　共演者への支払い ― 仲間を作りながら、資本主義に乗る

## 読む前に

遠方から呼んだ共演者に、まず確実に払うべきものは。

```
・高い最低保証
・交通費と宿泊費
・売れた枚数に応じた歩合
```

★当てなくて構いません。読み終わったあとに、もう一度考えてください。

## 本文

**まず、考え方を2つ並べます。どちらも要ります。**

### ① 仲間を作る

**共演者とは、この先も付き合います。**
向こうの演奏会に呼ばれ、こちらにも来てもらう。
**敵を作るより、仲間を作ったほうが、長い目で得です。**

そして**全員のやる気は、公演の質そのものに直結します。**
渋って払った金額は、舞台の上に出ます。

**だから、払えるだけ払ってください。**
動員が伸びたら、その分を上乗せする。**それが次の共演につながります。**

### ② それでも、これは資本主義です

**音楽家の主催者は、ここを忘れがちです。**

**チケットを売る努力を、報酬に反映させてください。**

```
最低保証        ★規模と、その人が呼べる人数から決める
10枚まで        1枚あたり  500円
11〜30枚        1枚あたり  700円
31枚以上        1枚あたり 1,000円
```

**売れば売るほど、1枚あたりの取り分が増える形にします。**

```
・売らなければ、働かなかったのと同じなので、報酬は低い
・売れば売るほど、率が上がる
・★ただし最低保証は必ず置く。ないと人は集まりません
```

**最低保証の分は、主催者のリスクです。**
それでいいのです。**誰よりも自分が売ればいい。**

### ★最低保証は、その人が呼べる人数から決める

**金額に決まった正解はありません。**
決めるときに見るのは、次の三つです。

```
① 公演の規模（会場の大きさ、チケット代、総予算）
② ★自分が確実に呼べる人数
③ ★その共演者が、その土地で呼べる見込みの人数
```

**③を、正直に見積もってください。**

たとえば山梨での公演に、関西や東北から音楽家を呼んだとします。
**その人が山梨で二十人、三十人を集めるのは、不可能です。**
土地に知り合いがいないのですから、当然です。

**呼べない人に、高い最低保証を置く必要はありません。**
それは相手の力の問題ではなく、**距離の問題**です。

### ★それより、必要経費を確実に払ってください

```
・交通費（★実費。遠方ほど、ここが効きます）
・宿泊費
・前日入りが必要なら、その分の食事
```

**この人の収支が、絶対にマイナスにならないようにする。**
**まず、そこです。**

自分の演奏会に出るために持ち出しになった——
これをやられた側は、二度と来ません。そして、その話は広まります。

```
必要経費（確実に払う）
   ＋
最低保証（呼べる人数と規模から決める）
   ＋
歩合（売った枚数に応じて積み上がる）
   ＝  その人のギャランティ
```

**まず沈まないようにして、そこからプラスを積み上げる。**
これが順番です。

### 「そのギャラでは出られない」と言われたら

**そう言う人はいます。それも当然の言い分です。**
ここで感情的にならず、**投資として計算してください。**

```
その人が来ることで
　□ 何人ぐらい、お客さまが増えそうか
　□ 話題になるか（新聞・地域の媒体が取り上げるか）
　□ 次につながるか（その人の周りの音楽家、次の共演）
```

**増える見込みがあるなら、多く払うのは良い投資です。**
高いギャラは、その分の集客と話題を買っているのですから、**払うべきです。**

**逆に、そうでないなら——一度、考えてください。**

```
・名前は大きいが、この土地では誰も知らない
・呼んでも、集客は自分の分だけ
・条件だけが重い
```

**この場合、その金額は投資ではなく、ただの支出です。**
断ることは、失礼ではありません。**次の機会に、条件を変えて頼めばいい。**

### 何枚で黒字になるかを、先に計算する

```
固定費（会場・印刷・必要経費・最低保証の合計） ÷ （チケット代 − 歩合の平均）
```

**この枚数を、企画の最初に出してください。**
そして**その数字を、共演者にも見せてください。**

「あと何枚で全員の取り分が増えるか」が見えると、**売る理由が生まれます。**

### お金以外で払えるもの

**経費を削りたいなら、自分の手間で埋めてください。**

```
・当日、自分でお茶をいれて振る舞う
・おむすびを握って、舞台裏で分け合う
・楽屋の飾りつけを自分でやる
```

**これは節約ではありません。**
**「大事にされている」と感じてもらうことが、次の共演を作ります。**

**お金と、心と、両方が要ります。**

## 覚えておくこと

> **まず沈ませない。必要経費が先で、ギャラはそのうえに積む。**

## 用語

**最低保証（さいていほしょう）** 動員に関係なく支払う下限の金額。
★その人がその土地で呼べる人数から決めます。距離が遠いほど、低くて構いません。

**必要経費** 交通費・宿泊費など、出演のために相手が実際に払うお金。
★最低保証とは別に、確実に払うもの。

**歩合（ぶあい）** 売れた枚数に応じて上乗せする報酬。
★段階的に率を上げると、売る動機になります。

**損益分岐点** 何枚売れば赤字が消えるかの枚数。★企画の最初に出すもの。

## 自分の場合を書く

**Q1.** 次の公演の損益分岐点は、何枚だと思いますか。ざっくりで構いません。

**Q2.** 呼びたい共演者を一人思い浮かべてください。
その人は、あなたの土地で何人呼べそうですか。
そして、その人が来ることで何が増えますか。

**※ 答え合わせはありません。採点もしません。**
**あなたの土地と、あなたの活動では、本文と違う答えが正しいことがあります。**
**書いたものは、あなたの記録に残ります。**

# 12　ホールは、お客さまの生活から逆算して選ぶ

## 読む前に

ホールを選ぶとき、最初に決めるべきことは。

```
・音響の良さ
・会場費
・誰に来てほしいか
```

★当てなくて構いません。読み終わったあとに、もう一度考えてください。

## 本文

**音響が良く、過ごしやすいホール。それは前提です。**
**そのうえで決め手になるのは、来てほしい人の生活です。**

```
土日も働いている人に来てほしい
　→ 平日夜。★駅から近い。19:00開演で21:00終演
　→ 終演後に電車がある場所かどうか

平日の昼間が空いている人に来てほしい
　→ 土日の昼。★駐車場が広い
　→ 14:00開演。暗くなる前に帰れる
```

**この2つは、両立しません。**どちらかを選んでください。

### 見るところ

```
□ 駐車場の台数（★地方では決定的。50台と200台では別の公演になります）
□ 最寄り駅からの距離と、終演後の交通
□ 階段の有無、エレベーター（★70代80代が主なお客さまなら必須）
□ トイレの数と場所（★休憩時間に行列ができると、後半の空気が変わります）
□ 客席の座り心地と、傾斜（前の人の頭で見えないホールがあります）
□ ロビーの広さ（★受付・物販・花の受け取りが同時に起きます）
□ 楽屋の数と、ピアノの状態
□ 音響（★空席のときと満席のときで別物です）
```

### キャパシティは、埋まるかどうかで選ぶ

**500席で3,000円より、80席で5,000円のほうが、手元に残ることがあります。**

```
500席に249名  → 半分が空席。写真も、空気も、寂しい
80席に80名    → 満席。★次も来たいと思われる
```

**空席は、来た人の満足度を下げます。**
**「席が埋まっている」こと自体が、公演の価値の一部です。**

### 下見でやること

```
・実際に客席に座る（★いちばん後ろと、いちばん端）
・声を出してみる、弾いてみる
・受付を置く場所に立ってみる
・トイレまで歩く
・★駐車場から入口まで歩く（雨の日を想像する）
```

## 覚えておくこと

> **ホールは音響で選ぶ前に、来てほしい人の生活で選ぶ。**

## 用語

**キャパシティ** 客席数。★埋まる見込みと合わせて考えるもの。

**動線（どうせん）** 人が歩く道すじ。★下見で実際に歩いて確かめます。

## 自分の場合を書く

**Q1.** 次の公演に来てほしい人は、平日の夜と土日の昼、どちらが来やすいですか。

**Q2.** その人たちは、何で会場まで来ますか。車ですか、電車ですか、歩きですか。

**※ 答え合わせはありません。採点もしません。**
**あなたの土地と、あなたの活動では、本文と違う答えが正しいことがあります。**
**書いたものは、あなたの記録に残ります。**

# 13　当日の運営は、動線と儀式でできている

## 読む前に

開演前の十分間に、お客さまの前に置くとよいものは。

```
・次回公演のチラシ
・CDやオリジナルの品
・練習風景や、曲の背景の展示
```

★当てなくて構いません。読み終わったあとに、もう一度考えてください。

## 本文

**お客さまは、会場に入ってから座るまでに、いくつかの動作をします。**
**これを「儀式」と呼びます。**

```
① 入口に着く
② チケットを渡す／当日券を買う
③ プログラムを受け取る
④ ★花やご祝儀を渡す人がいる
⑤ 席を探す
⑥ 開演までの時間を過ごす
```

**このうち④と⑥は、手が回りにくい場所です。**

### ④ 花とご祝儀

**必ず一定数の方が持ってきてくださいます。**
数は多くありませんが、**その場で止まると、列全体が止まります。**

```
・★受付とは別の机を用意する（列が混ざると、進まなくなります）
・花を置く場所（水、大きさ、直射日光）
・ご祝儀は★2人で確認して、記録し、その場で封筒に名前を書く
・お返しをどうするか、事前に決めておく
```

**記録がないと、あとで誰にお礼を言えばいいか分からなくなります。**

### ⑥ 開演までの時間

**受け取ったあと、開演まで10〜20分あります。**
**この時間、お客さまは手持ち無沙汰です。**

```
・★物販を置く
・パネル展示（★練習風景、会場の歴史、曲の背景）
・アンケートの記入台
```

**手持ち無沙汰の時間は、いちばん物が売れる時間です。**

### ★何を売るかを、考える

**「とりあえずCD」で終わらせないでください。**
お客さまが買うのは、音源ではなく**その日の記憶**です。

```
CD・音源        ★演奏を持ち帰りたい人に。定番だが、再生機を持たない人も増えています
ブロマイド・写真 舞台写真、練習中の写真。★サインを入れられるのが強い
ポストカード     いちばん買いやすい価格帯。★手紙を書く習慣のある層に効きます
プログラムの増補版 曲目解説を厚くしたもの。★その日にしか出ない
楽譜・自筆の一筆  子ども向けに強い
次回のチラシ      ★売り物ではないが、いちばん取ってもらえる場所
```

**選ぶときの基準は、三つです。**

```
① その日、その場でしか手に入らないか
② 持って帰るのが重くないか（★大きい物は売れません）
③ サインを入れられるか
```

**★「ここでしか買えない」が、いちばん効きます。**
同じCDでも、**その日の日付とサインが入るなら別の物**になります。
オリジナルの品——手ぬぐい、缶バッジ、栞、扇子——は、
原価が低く、**荷物にならず、人にあげられます。**
人にあげられる物は、**次の客を連れてきます。**

### 展示は、売り物の隣に置く

**買うかどうかを迷っている時間を、長くしてください。**

```
・練習風景の写真（★舞台の上と違う顔が見られると、人は近づきます）
・楽器の説明、実物（触れられるとなお良い）
・その日の曲の背景を、大きな紙に一枚
・過去の公演の写真（★続けていることが伝わります）
```

**展示の前に立ち止まった人が、その足で物販を見ます。**
だから**展示と物販は、必ず隣に置いてください。**

### 休憩時間の動線

```
・トイレまでの道に、物販とアンケート記入台を置く
・★行列の横を通れる幅があるか確認する
・水が飲める場所を用意する
```

**トイレの行列は避けられません。**
**その行列の横に、見るものと買うものを置いてください。**

### 下見でやること

```
・入口からトイレまで、実際に歩く
・受付を置く位置に立って、列がどこまで伸びるか想像する
・花の机を置く場所を決める
・★車椅子とベビーカーの通り道を確認する
```

### 当日のスタッフ

```
・仕事内容を、口頭ではなく★紙にして渡す
・机の位置、置くものを図にする
・★打ち合わせは最低2回（1回では伝わりません）
・受付のまとめ役を1人決める
```

**2回でも足りないことがあります。**
当日になって「聞いていない」が出る場所は、たいてい
花の受け取り、当日券の釣り銭、車椅子の誘導のどれかです。
**この3つは、紙に図で描いて渡してください。**

## 覚えておくこと

> **手持ち無沙汰の10分が、いちばん物が売れる時間。
> 売るのは音源ではなく、その日の記憶。**

## 用語

**動線** 人が歩く道すじ。★受付・物販・トイレは動線でつながります。

**物販（ぶっぱん）** 会場での商品販売。★開演前と休憩時間が勝負。
選ぶ基準は「その日しか買えない・重くない・サインを入れられる」。

**Q1.** 次の公演で、「その日、そこでしか手に入らないもの」を
一つ作るとしたら、何にしますか。

**Q2.** 当日、誰にも任せられていない仕事はどれですか。

**※ 答え合わせはありません。採点もしません。**
**あなたの土地と、あなたの活動では、本文と違う答えが正しいことがあります。**

# 14　確定申告と経費 ― 音楽で食べる人のための最低限

**※ 税理士による助言ではありません。一般的な制度の説明です。**
**個別の判断は、必ず税務署か税理士にご確認ください。制度は毎年変わります。**

## 読む前に

演奏の報酬から、あらかじめ引かれている税金があります。それは。

```
・消費税
・所得税（源泉徴収）
・住民税
```

★当てなくて構いません。読み終わったあとに、もう一度考えてください。

## 本文

### まず、どの所得になるか

音楽の収入は、多くの場合**事業所得**です。
**帳簿をつけて保存していれば、事業所得として扱われるのが基本**です。

**帳簿がないと、雑所得として扱われることがあります。**
雑所得だと、赤字を給与などと相殺できず、青色申告の特典も使えません。

**★つまり、帳簿をつけるかどうかが、最初の分かれ道です。**

### 開業届と青色申告

```
① 開業届（個人事業の開業・廃業等届出書）を税務署へ
② ★青色申告承認申請書を出す
   期限：開業から2か月以内、または適用したい年の3月15日まで
```

**この2枚目を出し忘れると、その年は青色になれません。**

**青色申告の特別控除**

```
65万円  複式簿記 ＋ e-Tax（または電子帳簿保存）
55万円  複式簿記 ＋ 書面提出
10万円  簡易な記帳
```

**65万円の控除は、所得税と住民税の両方に効きます。**
会計ソフトを使えば複式簿記は自動なので、**やらない理由がほぼありません。**

### 源泉徴収されている税金

**法人や団体から受け取る出演料は、原則として
所得税が差し引かれてから振り込まれます。**

```
100万円以下の部分   10.21%
100万円を超える部分 20.42%
```

**10万円の出演料なら、手取りは89,790円です。**

**★これは前払いです。**確定申告で、払いすぎた分は戻ってきます。
**経費が多い年ほど、戻る額が大きくなります。**

```
★申告しないと、戻りません。
```

**個人から個人への支払いでは、源泉徴収されないのが原則です。**

### 経費になるもの

```
楽譜・音源・書籍
レッスン代・コーチング代
交通費・宿泊費（★仕事のもの）
衣装（★演奏専用と言えるもの。私服と兼用は認められにくい）
メイク・美容（★舞台のためと説明できる範囲）
チラシ・プログラムの印刷
会場費・調律費・伴奏料
通信費・家賃・光熱費（★家事按分）
会計ソフト、名刺、封筒、切手
```

**家事按分**とは、生活と仕事で共用しているものを、
**割合で分けて経費にする**ことです。

```
例）家賃10万円のうち、練習に使う部屋が全体の25% → 2.5万円を経費に
```

**割合の根拠を、説明できるようにしておいてください。**

### 楽器は「買った年に全部」ではありません

```
10万円未満        その年に全額を経費に
10万〜20万円未満   3年で均等に（一括償却資産）
30万円未満        ★青色なら、その年に全額（年間300万円まで）
30万円以上        耐用年数で分けて経費に（減価償却）
```

### ★クレジットカードを分けてください

**仕事の買い物と、私生活の買い物を、同じカードで払わないでください。**

**明細を1行ずつ仕分ける作業に、何時間もかかります。**
公演が終わったあとの疲れた頭で、半年分のカード明細を
「これは仕事、これは私用」と分けていく——
この作業は、やった人でないと想像がつかないほど時間を食います。

```
・仕事用のカードを1枚作る
・仕事用の口座を1つ作る
・現金払いは、その場でレシートに用途を書く
```

**この3つだけで、確定申告の作業が半分以下になります。**

### 消費税とインボイス

**2年前の課税売上が1,000万円以下なら、消費税を納める義務はありません（免税事業者）。**

ただし**インボイス制度**により、免税のままだと、
**支払う側が仕入税額控除を満額できなくなります。**

現在の経過措置は、次のように縮小していく予定です。

```
2023年10月〜2026年9月   80%控除
2026年10月〜2028年9月   70%控除
2028年10月〜2030年9月   50%控除
2030年10月〜2031年9月   30%控除
2031年10月以降          0%
```

**★2026年10月から、80%が70%に下がります。**
支払う側の負担が増えるので、**免税事業者への発注を避ける動きが出やすくなります。**

**負担を軽くする特例**

```
2割特例  2026年9月30日を含む課税期間まで
3割特例  ★個人事業者は2027年分・2028年分に適用（法人は対象外）
```

**登録するかどうかは、取引先が法人中心かどうかで決まります。**

```
・法人・団体からの仕事が多い  → 登録を検討する
・個人・一般客が中心          → 登録しないほうが手取りが多いことも
```

**★この判断は、税務署か税理士に相談してください。**

### 保存するもの

```
・帳簿と決算書   7年
・領収書・請求書 7年（★消費税の関係で、5年ではなく7年で揃えるのが安全）
・支払調書       もらったら保管
```

## 覚えておくこと

> **帳簿をつけるかどうかが、事業所得か雑所得かを分ける。**

## 用語

**源泉徴収** 支払う側が、あらかじめ所得税を差し引いて納めること。★前払い。

**家事按分（かじあんぶん）** 生活と仕事で共用するものを、割合で分けること。

**減価償却** 高い物を、使う年数に分けて経費にすること。

**免税事業者** 消費税を納めなくてよい事業者。★2年前の課税売上1,000万円以下。
