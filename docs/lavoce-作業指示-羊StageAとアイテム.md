## A. 羊のおうち Stage A

**参照：羊のおうち仕様 §2**

### A-1 ｜ 柵と羊の重なりを直す（最優先・半日）

**現状の不具合**：お庭で、柵の線が羊の腰を横切っています。

**やること**

- 羊を `front` 層に固定する（`z-index: 30`）
- 柵は `back` 層（`z-index: 10`）

**完了の定義**：お庭の羊が、柵より完全に手前に描画されている。
どの位置にドラッグしても重なりが崩れない。

> **ここが崩れていると、一気に「作りかけ」に見えます。最初にやってください。**

---

### A-2 ｜ 接地の影（半日）

**現状の不具合**：家具も羊も床から浮いて見えます。

**やること**：全アイテムに楕円のソフトシャドウを1枚敷く。

```
形    : 楕円
幅    : アイテム幅 × 0.85
高さ  : 幅 × 0.22
位置  : アイテムの接地点（bottom）に中心を合わせ、y を +2px
色    : rgba(70, 45, 30, 0.18)
ぼかし : 6px
```

**`anchor: 'wall'` のアイテム（壁掛け・窓）には影を付けないこと。**

**完了の定義**：お部屋・お庭の全アイテムが「床に置いてある」ように見える。
壁掛けに影が付いていない。

> **この中でいちばん費用対効果が高い修正です。**

---

### A-3 ｜ 3層構造とスケール（1〜2日）

**現状の不具合**：全アイテムが同じ平面にあり、
お部屋の床にラグが4枚横一列に並んでいます。

**やること**

```ts
type Layer = 'back' | 'mid' | 'front'
```

| 層 | 内容 | スケール | z-index |
|---|---|---|---|
| `back` | 壁・窓・木立・柵・壁掛け | 0.85 | 10 |
| `mid` | 家具・噴水・ベッド・本棚 | 1.00 | 20 |
| `front` | ラグ・池・ベンチ・**羊** | 1.15 | 30 |

- 全アイテムに `layer` を持たせる
- **アイテムは自分の層の中でだけ左右に動かせる。** 層をまたぐドラッグは禁止

**完了の定義**：3層が視覚的に区別でき、
ドラッグしても層をまたがない。羊は常に最前面。

---

### A-4 ｜ 配置のスナップ（A-3 と同時）

**やること**：自由ドラッグをやめ、層ごとの横グリッドへスナップさせる。

```
グリッド：層の幅を 12 分割
同じマスに2つ置けない（押しのけるか、隣の空きマスへ）
```

**完了の定義**：ラグが重なって並ぶ状態が起きない。
ドラッグ中にスナップ位置が視覚的にわかる。

---

### A-5 ｜ 表示の階層を直す（半日）

**参照：羊のおうち仕様 §4.7**

**現状の不具合**：「72／6／6」が同じ大きさで並び、どれが主役かわからない。

```
所持ポイント     72        ← 32px、主役

連続 6日 ・ 最長 6日 ・ 累計 6日   ← 14px、muted、1行にまとめる
```

**`累計記録日数` を新たに追加してください**（A-6 の木と対応させるため）。

---

### A-6 ｜ 累計で育つ木（1日）

**参照：羊のおうち仕様 §4.5**

**お庭に木を1本。累計の記録日数で育ちます。**

| 累計記録日数 | 姿 |
|---|---|
| 0–6 | 芽 |
| 7–29 | 若木 |
| 30–99 | 花が咲く |
| 100–364 | 実がなる |
| 365– | 大樹 |

**必須の条件**

- **連続記録が途切れても、絶対に後退しない**（累計ベース）
- **購入不可・移動不可**の固定オブジェクト
- 段階が上がった初回だけ、控えめな演出（`prefers-reduced-motion` に対応）

**画像がまだ無い場合**：暫定のプレースホルダで実装し、
`render: '2d'` のまま差し替えられる形にしておくこと。

**完了の定義**：累計日数で姿が変わり、
連続記録をリセットしても木が後退しないことをテストで確認済み。

## B. アイテムシステム

**参照：アイテムカタログと素材調達 §6**

**目的は「アイテムを増やすのが、JSONに1行足すだけ」になることです。**
いま画像が揃っていなくても、この仕組みは先に作れます。

### B-1 ｜ ShopItem のデータモデル（1〜2日）

```ts
type ItemCategory =
  | 'hat' | 'clothes' | 'held'
  | 'floor' | 'wall' | 'windowFrame' | 'windowView'
  | 'gardenScene' | 'furniture' | 'gardenObject' | 'wallHanging'

interface ShopItem {
  key: string
  category: ItemCategory
  nameKey: string                  // i18n キー
  price: number | null             // null = 購入不可（達成解放）
  unlock?: UnlockCondition
  professions?: ProfessionKey[]    // ★並び順の優先のみ。購入制限に使わない
  season?: 'spring'|'summer'|'autumn'|'winter'|'event'
  layer: 'back' | 'mid' | 'front'
  anchor: 'floor' | 'wall' | 'sheep'
  render: '2d' | 'prerender3d'
  src: string
  width: number
  height: number
}
```

**アイテムの定義は1つのデータファイルに集約**し、
コード側は一切変更せずに追加できるようにしてください。

**完了の定義**：データファイルに1行足すだけで、
ショップに新アイテムが並び、購入・装備・配置ができる。

---

### B-2 ｜ ショップの並び順（半日）

```
1. 未購入かつ、いま買えるもの（所持ptが足りている）  ← いちばん上
2. 未購入で、あと少しで買えるもの
3. その他の未購入
4. 購入済み

同じ層の中では、profession が一致するものを優先
```

**「あと3ptで買える」ものを視覚的に目立たせてください。**

**完了の定義**：所持ポイントが変わると並び順が変わる。
職業を切り替えると、その職業のアイテムが上に来る。

---

### B-3 ｜ 価格を定数ファイルに（半日）

| 種別 | 価格 |
|---|---|
| 小物（持ち物・帽子） | 15〜30pt |
| 服 | 30〜50pt |
| 家具・庭の置物 | 40〜80pt |
| 床・壁・窓枠 | 60〜100pt |
| 窓の景色・庭の景観 | 80〜120pt |

**バランス調整が1ファイルで済む形**にしてください。

---

### B-4 ｜ 達成で解放されるアイテム（1日）

**参照：アイテムカタログ §5**

| 条件 | 解放されるもの |
|---|---|
| 累計 7日 / 30日 / 100日 / 365日 | 庭の木の各段階（A-6） |
| 初めて本番を記録 | 花束 |
| 本番の記録 10回 | 額入りの公演ポスター |
| 初めて弱声の最高音を記録 | 音叉 |
| 記録項目を10種類以上使った | 温湿度計 |
| 稽古ノートの目標を1つ達成 | 賞状 |

**必須の条件**

- **すべて累計ベース。** 「連続◯日」を条件にしない
- 一度解放されたら、**二度と失われない**
- 解放時に控えめな通知（プッシュではなく、次にアプリを開いたとき）

---

### B-5 ｜ 季節フラグ（半日）

`season` フィールドは、**「今月の新作」としてショップの先頭に出すためだけ**に使います。

- ❌ **入手期限を設けない。** 一度出したら常設
- ❌ カウントダウンや「あと◯日」を表示しない

**理由**：期間限定は「いま買わないと損」というプレッシャーを生み、
**羊のおうち仕様 §1 の「罰を作らない」原則に反します。**
体調が悪くて記録できなかった月に、二度と手に入らないものが流れていくのは、罰です。

## D. 禁止事項

- ❌ **WebGL / Three.js を導入しない**（羊のおうち仕様 §3.1）
- ❌ **ポイントを体調に連動させない。**
  「調子が良い日はボーナス」という変更を加えないこと（同 §1）
- ❌ **連続記録が途切れたときに、羊がしおれる・ポイントが減る・
  通知が出る、といった実装をしない**（同 §5）
- ❌ `professions` を購入制限に使わない（並び順の優先のみ）
- ❌ `season` を入手期限に使わない
- ❌ 3Dアセットの制作を試みない
- ❌ 羊のデザインを変更しない
