# La Voce ／ 名称・タグライン・商標の方針

アプリ名を「商標が取れる」かつ「4職種向けだとわかる」形に持っていくための方針と、
改名する場合の実装手順。

---

## 0. この文書について

### 2つのレーン

| レーン | 担当 | 内容 |
|---|---|---|
| **A** | Claude Sonnet 5 | §2 タグラインの反映／§5 改名の実装 |
| **B** | 坂本さん | §3 名前の決定／§4 商標の調査・出願 |

**Sonnet はレーンAだけを実行してください。** 商標の調査・判断・出願は代行できません。

### 進め方

```
1. §2 タグラインを反映する        ← 改名の有無に関わらず、今すぐできる
2. §4 の手順で名前を決める（坂本さん）
3. 商標を出願する（坂本さん）
4. 出願が済んでから §5 の実装と公表   ← 順序が重要（§4.4）
```

## 1. 前提：商標の強さと、わかりやすさは両立しない

商標法第3条1項3号は、**商品や役務の品質・用途・効能をそのまま表示するだけの商標**を
登録の対象から外しています。

つまり「ボイスケア」「声の健康手帳」のような、
**聞いた瞬間に中身がわかる名前ほど、登録できないか、極めて弱い。**

**だから二段構えにします。**

```
名前       識別力のある造語   → 商標を取る
タグライン   4職種を説明する    → 商標は取らない（取れない）が、常にセットで出す
```

**「4職種向けだとすぐわかる」という要件は、タグラインで解決します。**

## 2. タグライン（レーンA・今すぐ反映）

**改名するかどうかに関わらず、これは先に入れられます。**

### 2.1 2種類を使い分ける

| 用途 | 文言 | 使う場所 |
|---|---|---|
| **ブランド用** | **歌う人、話す人、演じる人のために** | ロゴの下、サイトのヒーロー、名刺、Instagram のプロフィール |
| **検索用** | **声楽・声優・アナウンサー・歌手のための、喉と体調の記録** | `<title>`、meta description、App Store のサブタイトル、OGP |

**ロゴの下に検索キーワードを並べると野暮になり、App Store に詩を書くと見つけてもらえません。**
必ず使い分けてください。

英語版：

| 用途 | 文言 |
|---|---|
| ブランド用 | **For those who sing, speak, and perform.** |
| 検索用 | Vocal health tracking for singers, voice actors, broadcasters, and performers |

### 2.2 なぜこの3つの動詞か

「歌う」「話す」「演じる」で、4職種すべてが自分事になります。

| 職業 | 該当する動詞 |
|---|---|
| 声楽家 / ポップス・ロック歌手 | 歌う |
| アナウンサー / ナレーター | 話す |
| 声優 | 演じる |
| ミュージカル俳優 | 歌う・演じる |

**職業名を並べずに全員を含められる**のが利点です。将来コールセンターや教員に広げても壊れません。

### 2.3 現行からの変更点

現行の「声のプロフェッショナルのための体調管理」は悪くありませんが、
**「プロフェッショナル」が抽象的で、声優やアナウンサーが自分事にしづらい。**
上の2種類に差し替えてください。

## 3. 名前の候補（レーンB・坂本さんが決定）

### 3.1 満たすべき条件

- **造語**（商標が取れる）
- **「声」を連想させるが、直接説明しない**（記述的にならない）
- 2〜4音節、母音で終わる
- 日本語話者も英語話者も発音できる
- La Voce からの移行が説明しやすい

### 3.2 候補と、既存使用の調査結果

| 候補 | 読み | 調査結果 |
|---|---|---|
| **Vocella** | ヴォチェッラ | **競合が薄い。** 見つかったのは英国の小規模店舗のみ。**最有力** |
| Vocanta | ヴォカンタ | voce＋canta。造語性が高い。**未調査** |
| Vocora | ヴォコーラ | voce＋coro（合唱）。**未調査** |
| Voceo | ヴォチェオ | 短い。造語性が高い。**未調査** |
| ~~Vocari~~ | — | **✗** vocari.dev、Vocari.io LLC、医療系求人サービスなど複数 |
| ~~Ovella~~ | — | **✗** App Store に生理管理アプリ、英国法人、人名 |
| ~~Vocera~~ | — | **✗** 医療通信の大手企業 |
| ~~Timbre~~ | — | **✗** App Store / Google Play に複数 |
| ~~Vellum~~ | — | **✗** Mac の書籍組版ソフトが著名 |
| ~~Koe~~ | — | **✗** koe.ai、Koe Recast ほか複数 |

**上記はウェブ検索の結果であり、商標調査ではありません。** 登録可能性の判断は §4 で。

### 3.3 Vocella を推す理由

1. **La Voce からの移行が自然。** 「voce」が残るので、既存ユーザーへの説明が1行で済む
2. **声を示唆するが、記述的ではない。** 説明が要るからこそ、商標が取れる
3. **4職種のどれも排除しない。** 「歌」に寄っていないので、アナウンサーも声優も自分事にできる
4. **羊と共存できる。** 名前が声側、キャラクターが羊側で役割が分かれる

## 4. 商標の手順（レーンB・坂本さん）

### 4.1 区分

| 区分 | 内容 | 要否 |
|---|---|---|
| **第9類** | アプリケーションソフトウェア | **必須** |
| **第42類** | SaaS の提供 | **必須** |
| 第44類 | 医療情報の提供 | **避けたほうが安全** |

**第44類を避ける理由**：医療機器該当性の議論と矛盾しかねません。
国際展開仕様 §5 で「診断・兆候の検知をしない」と線を引いているので、
医療分野での出願はその立場と食い違って見えます。

### 4.2 費用の目安（2026年時点・特許庁への法定費用）

| | 出願料 | 登録料（10年） | 合計 |
|---|---|---|---|
| 1区分 | 12,000円 | 32,900円 | **44,900円** |
| 2区分 | 20,600円 | 65,800円 | **86,400円** |

弁理士に依頼する場合、1区分で5〜10万円程度が加算され、**総額9〜15万円**が目安です。

### 4.3 手順

```
1. J-PlatPat で第9類・第42類を自分で検索（無料）  ← ここで大半が脱落
2. 残った候補で .com / .app のドメインと App Store を確認
3. 声に出す（電話で伝えられるか、聞いて綴れるか）
4. 弁理士に相談。最終的な登録可能性の判断はここ
5. 出願
6. 日本で登録後、マドリッド協定議定書で他国へ拡張
```

**国際展開を考えるなら、日本で先に取るのが正解です。**

### 4.4 順序の注意 ★重要

**出願より先に、新しい名前を公表しないでください。**

日本の商標制度は**先願主義**（先に出願した者が権利を得る）です。
Instagram や告知で新名称を先に出すと、第三者に先に出願されるリスクがあります。

```
✓ 出願 → 公表 → 実装（§5）
✗ 公表 → 出願
```

## 5. 改名が決まったときの実装（レーンA・Sonnet）

**新しい名前が確定し、出願が済んでから着手してください。**

### 5.1 まずブランド名を1箇所に集約する

```ts
// config/brand.ts
export const BRAND = {
  name: 'Vocella',
  nameJa: 'Vocella',
  taglineBrand: '歌う人、話す人、演じる人のために',
  taglineSearch: '声楽・声優・アナウンサー・歌手のための、喉と体調の記録',
  legacyName: 'La Voce',   // 移行期間中の併記に使う
} as const
```

**ハードコードされた「La Voce」を全部これに置き換える。**
国際展開仕様 §2.4 の文字列キー化が済んでいれば、この作業は大幅に楽になります。

### 5.2 差し替えの網羅チェックリスト

**見落としが起きやすい順に並べています。**

```
□ config/brand.ts の作成と、ハードコード文字列の置換
□ <title> / meta description / OGP（og:title, og:site_name, og:image）
□ manifest.json の name / short_name
□ <meta name="apple-mobile-web-app-title">
□ favicon / アイコン（差し替え不要。名前だけの変更なら現行アイコンのまま）
□ メールの差出人名・件名テンプレート（Resend の from）
□ LINE公式アカウントの表示名
□ 利用規約・プライバシーポリシー・特定商取引法に基づく表記の事業者名／サービス名
□ ★ Stripe の statement descriptor（カード明細に出る表記）
□ サポート用の問い合わせフォームの文言・自動返信
□ 週次メール・通知の本文
□ 管理画面・エラーページ・404
□ README、リポジトリ名（任意）
□ Instagram の表示名とハンドル
□ ドメイン移行（§5.3）
```

**★ Stripe の statement descriptor は特に見落とされます。**
カード明細に見慣れない名前が出ると、**「不明な請求」としてチャージバックが起きます。**
移行期間は `VOCELLA (LA VOCE)` のような併記を検討してください。

### 5.3 ドメイン移行

```
□ 新ドメインを取得し、旧ドメインから 301 リダイレクト
□ 全ページに canonical を新ドメインで設定
□ sitemap.xml / robots.txt を更新
□ Search Console にアドレス変更を申請
□ OAuth / Stripe / LINE の Webhook・リダイレクトURLをすべて更新  ← 壊れやすい
□ メールの送信ドメイン認証（SPF / DKIM / DMARC）を新ドメインで再設定
□ 旧ドメインは最低2年は維持する（リダイレクトのため）
```

**Webhook の URL 更新漏れは、課金が静かに壊れます。** 移行後に必ずテスト決済を1本通してください。

### 5.4 既存ユーザーへの告知

```
□ アプリ内バナー（初回ログイン時に1回だけ。閉じたら再表示しない）
□ メール／LINE で1回
□ 移行後3か月は、ロゴの下に「旧 La Voce」を小さく併記
```

**文面の要点**：名前が変わっただけで、**データもアカウントも料金も変わらない**ことを最初に書く。
ユーザーが最も不安になるのはそこです。

```
アプリの名前が「Vocella」に変わりました。
記録したデータ、アカウント、ご契約はそのままです。何もしていただく必要はありません。
```

**改名の理由は書かなくてよい。** 「商標のため」は運営の都合であり、ユーザーの関心事ではありません。

## 6. 改名しない場合（レーンA・今すぐ）

名前を変えない判断をした場合も、**§2 のタグラインだけは反映してください。**
4職種に開く効果は、タグラインだけでほぼ得られます。

あわせて、**ロゴを図形商標として出願する**選択肢があります。
「La Voce」という文字は一般名詞で弱いですが、
**Cormorant Garamond のイタリック＋羊の組み合わせ**には独自性があります。
ワードマークを諦め、図形商標で守る、という現実的な守り方です。

## 7. Sonnet 5 への依頼のコツ

- **レーンB（§3 §4）に手を出さない。** 商標の調査・判断・出願は坂本さんの担当です。
  候補名を勝手に増やしたり、登録可能性を判断したりしないこと
- **§2 のタグラインは今すぐ反映してよい。** 改名の決定を待たない
- **§5 は、坂本さんから「出願が済んだ」と伝えられてから着手する。**
  先に実装して公表されると、先願主義の下でリスクになります（§4.4）
- §5.1 の `config/brand.ts` を**必ず先に作る。** 個別ファイルを直接書き換えさせない
- §5.2 のチェックリストは**上から順に潰し、完了を1つずつ報告**させる。
  特に **Stripe の statement descriptor** と **Webhook の URL** を飛ばさせないこと
- ドメイン移行後は、**テスト決済を1本通して Webhook が届くことを確認**させる
