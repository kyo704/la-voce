# La Voce ／ 研究利用の同意（G3-15 に差し込む）

**Claude Sonnet 5 へ。これは G3-15（要配慮個人情報の同意画面）に足す1項目です。**

**★今週やらないと、二度とできません。**
あとから「研究に使わせてください」と全ユーザーに取り直すことは、事実上不可能です。

作業量は**半日**です。

---

## 0. なぜ今なのか

**声のプロの長期記録は、世界のどこにも存在しないデータです。**

声楽家・アナウンサー・声優が、毎日の声の状態と、睡眠・湿度・発声量・
レッスンと本番を、数年にわたって記録したもの。
**音声医学の研究者がずっと欲しがっていて、誰も持っていません。**

匿名化して研究に使えれば、**この分野に本当の貢献ができます。**
そして分かったことは、記録してくれた本人たちに返ります。

**ただし、要配慮個人情報の第三者提供にはオプトアウトが使えません。**
**本人の明示的な同意が、あらかじめ要ります。**
だから同意画面を作る今週が、唯一の機会です。

**使わないと決めるなら、それも今決めてください。保留だけが、選択肢を失う形の保留です。**

---

## 1. ★大原則

```
① 既定はオフ。
② ★同意しなくても、全機能がまったく同じに使える。
   同意を、機能や割引の条件にしない。
③ 用途を具体的に書く。書けないなら、聞かない。
④ ★未成年には出さない（保護者同意の設計が別途要るため）。
⑤ いつでも撤回できる。
```

**②を破らないでください。**「同意するとプレミアムが1か月無料」のような形にすると、
それは**同意ではなく取引**になり、法的にも倫理的にも成立しません。

## 2. 同意画面の文面（案）

```
┌──────────────────────────────────┐
│ 声の研究への協力（任意）                        │
│                                                  │
│ あなたの記録を、個人が分からない形にまとめて、  │
│ 「声の調子と生活習慣の関係」についての研究に    │
│ 使わせていただくことがあります。                │
│                                                  │
│ ・お名前・連絡先・生年月日は含めません          │
│ ・年齢は5歳のはば、地域は都道府県までにします   │
│ ・5人より少ない集まりの数字は出しません        │
│ ・★音声そのものは、そもそも保存していません    │
│ ・結果は公表されることがあります                │
│                                                  │
│ ★同意しなくても、アプリの機能はすべて          │
│   まったく同じように使えます。                  │
│                                                  │
│ いつでも設定から取り消せます。                  │
│ ※ 取り消したあとは新しく取り出しませんが、     │
│    すでに集計に含まれたものは戻せません。       │
│                                                  │
│           [ ] 研究への協力に同意する            │
└──────────────────────────────────┘
```

**最後の「戻せません」を省略しないでください。**
撤回すれば全部消えると誤解させると、そちらのほうが不誠実です。

## 3. 実装

### 3-1｜同意の記録

**EUへの道-いま埋め込むこと.md §3-2 の `ConsentRecord` を、そのまま使います。**
新しいテーブルを作らないでください。

```ts
{
  purposeKey: 'research.anonymized',
  policyVersion: 'ja-2026-09',
  textHash: '<表示した文面のハッシュ>',
  locale: 'ja',
  grantedAt: '...',
  withdrawnAt: undefined,   // ★撤回しても行を消さない
}
```

### 3-2｜抽出のときの規則

**いま抽出の機能を作る必要はありません。規則だけ決めておきます。**

```
・★同意が有効な人だけを対象にする（withdrawnAt が null）
・直接の識別子を落とす（userId は研究用の別IDに置き換える）
・年齢は5歳のはば、地域は都道府県まで
・★5人未満の集まりの数字を出さない（k匿名性。管理画面と同じ規則）
・★音声・録音は対象外（そもそも保存していない）
・自由記述（ノート・メモ・レッスンの振り返り）は★対象外
```

**自由記述を外す理由：**
本人しか読まない前提で書かれた文章です。匿名化しても、内容から人が特定されます。

### 3-3｜設定画面

```
設定 › プライバシー
├─ 研究への協力              [ オン / オフ ]
│   ※ オフでも、機能はすべて同じように使えます
└─ 同意の履歴を見る          いつ・どの文面に同意したか
```

---

## 4. ★禁止事項

```
1. ★既定でオンにしない
2. ★同意を、機能・割引・ポイントの条件にしない
3. ★未成年に、この同意欄を表示しない
4. 登録の必須項目にしない（飛ばして進めること）
5. 撤回した記録を削除しない（撤回の事実を残す）
6. ★自由記述を研究の対象に含めない
7. ★音声データを研究のために保存し始めない
8. 用途をあいまいに書かない（「サービス改善等」は不可）
9. 「同意すると、あなたにも結果が返ります」を、同意の見返りとして書かない
   （★事実として結果を公開するのはよい。取引にしない）
```

## 5. 確認

```
□ 既定でオフになっている
□ 同意せずに登録を完了できる
□ 同意していないユーザーが、全機能を使える（★プレミアムの範囲は変わらない）
□ 未成年として登録したユーザーに、この項目が表示されない
□ 撤回すると withdrawnAt が入り、行は残る
□ 同意の履歴に、日時と文面の版が表示される
□ 文面を改訂すると、textHash が変わる
```

## 6. Sonnet への依頼のコツ

**この機能は、実装が小さいわりに、間違えたときの被害が大きい領域です。**

**いちばん危ないのは、善意の「お得感」です。**

```
✗ 「研究に協力すると、プレミアムが1か月無料」
✗ 「協力者には、研究結果を先にお知らせします」
✗ 登録の流れの中で、飛ばしにくい位置に置く
```

**どれも同意を取引に変えます。取引になった同意は、同意ではありません。**

**判断の基準は1つです。**

```
★同意しない人が、少しでも損をしますか？
　→ するなら、その設計は間違っています。
```
