## 3. 問題なし（否定文・記事の本文）

### 否定として使われているもの（★直すと意味が壊れます）

```
「疑いの有無を判定するものではありません」
「数値そのものを論文の基準値と比べることはできません」×2
「基準値を超えた場合も、診断名ではなく…」
「点数を論文の基準値と厳密に比較できることは保証できません」
```

### 「改善」×3 — ★禁止の意味ではありません

§2-1 の「悪化／改善」は、**体調の言い表し方**の話です
（「低め」「高め」に置き換える）。実際にあるのは
「機能改善に役立てる」＝アプリを良くする、という意味で、
体調を指していません。

### 学ぶ・健康情報の記事の本文

```
lib/translations.js   「逆流のリスクも高まりやすく」（お酒の記事）
lib/healthInfoContent.js 「怪我のリスクも抑えやすい」（運動の記事）
lib/healthInfoContent.js 「器質的な異常がないのに生じる」（筋緊張性発声障害の定義）
```

★§2-1 は「アプリのどこにも」と書いていますが、
　§2-1 自身が「基準値は『学ぶ』の記事の中だけ」と例外を認めており、
　記事の本文は別扱いと読めます。とくに「器質的な異常がない」は
　医学的な定義そのもので、置き換えると意味が変わります。

**★ここも坂本さんのご判断が要ります。**
