# 実機テスト手順｜配信と更新の確認 §5（★坂本さんの作業）

対象 https://woolsong.app ／ 作成 2026-08-29 ／ 対応 a104ce3

---

## 用意するもの

**★端末を2台。1台は「古い版を開いたまま」にしておきます。**

| | 役割 |
|---|---|
| **端末A（古い側）** | いまの版を開いて、★そのまま置いておく。閉じない |
| **端末B（新しい側）** | 新しい版が配られたことを確かめる係 |

★iPad と iPhone、あるいは iPhone とパソコンでも構いません。
　**大事なのは「Aを先に開いておく」ことだけ**です。

★端末Aは、ホーム画面に追加したアプリからも試したいので、
　可能なら**先にホーム画面に追加**しておいてください。

## 準備（★いまやること）

- [ ] P-1. **端末A**で https://woolsong.app を開き、ログインする
- [ ] P-2. 下のタブ **「もっと」** を開き、いちばん下までスクロールする
- [ ] P-3. **バージョン a104ce3** と出ていることを確認し、★メモする
      （出ていなければ、一度アプリを閉じて開き直してください）
- [ ] P-4. ★端末Aを、そのまま置いておく。閉じないでください
- [ ] P-5. 私に「Aの準備ができた」とお知らせください
      → こちらで、新しい版を1つ配ります

## 本番（★新しい版を配ったあと）

### テスト1｜開き直したら、新しくなるか

- [ ] 1-1. **端末A**のアプリを、いったん閉じる（タスクから消す）
- [ ] 1-2. もう一度開く
- [ ] 1-3. **30秒以内**に、勝手に1回だけ画面が読み込み直されることを確認
- [ ] 1-4. 「もっと」の最下部を見る（★バージョンが a104ce3 から変わっている）

**★ここが変わらなければ、失敗です。** その時点で止めてお知らせください。

### テスト2｜★何度も読み込み直さないか（いちばん大事）

- [ ] 2-1. テスト1のあと、そのまま**1分ほど画面を見ている**
- [ ] 2-2. ★読み込み直しが**2回以上起きないこと**を確認する
- [ ] 2-3. タブを行き来する（今日の記録 → 分析 → もっと）
- [ ] 2-4. ★そのたびに読み込み直されないことを確認する

**★何度も読み込み直されると、操作できなくなります。**
**1回でも余計に起きたら、失敗です。すぐお知らせください。**

### テスト3｜ホーム画面のアイコンからでも同じか

- [ ] 3-1. **端末A**のホーム画面のアイコンから開く
- [ ] 3-2. 「もっと」の最下部のバージョンが、新しいことを確認

### テスト4｜オフラインで壊れないか

- [ ] 4-1. **端末B**で https://woolsong.app を開き、ログインする
- [ ] 4-2. 機内モードにする
- [ ] 4-3. アプリを閉じて、開き直す
- [ ] 4-4. ★アプリが起動すること（真っ白やエラー画面にならない）
- [ ] 4-5. 機内モードを解除する
- [ ] 4-6. 開き直して、新しいバージョンになることを確認

### テスト5｜利用者に「キャッシュを消して」と言わずに済んだか

- [ ] 5-1. ★ここまでで、一度も
      「設定からキャッシュを削除」「再インストール」を
      しなかったことを確認する

**★1回でも必要だったら、失敗です（同書 §6-1・§6-2）。**

## 合否の見かた

| | 合格 | 不合格 |
|---|---|---|
| テスト1 | 30秒以内に版が変わる | 変わらない・手動で消さないと変わらない |
| **テスト2** | 読み込み直しは**1回だけ** | **2回以上起きる（★最も重い失敗）** |
| テスト3 | アイコンからでも新しい | 古いまま |
| テスト4 | 機内モードでも起動する | 真っ白・エラー |
| テスト5 | 一度も手作業が要らない | 手作業が要った |

**★1つでも不合格なら、15〜20人への配布を行わないでください（同書 §8）。**

