# La Voce ／ 見やすさと「かんたん表示」

**Claude Sonnet 5 へ。文字の大きさと操作の設計です。**

読む順番：分析画面の表示規約.md §1（色）→ 本書。

---

## 0. 結論

```
① ★年齢で切り替えない。年齢を必須で聞かない。
② ★「シニアモード」と画面に書かない。名前は「見やすさ」。
③ 文字の大きさ（3段階）と「かんたん表示」は★別の設定にする。
④ ★画面を2つ作らない。CSS変数で1つの画面が伸び縮みする形にする。
⑤ ★OSの文字サイズ設定を尊重する（拡大を禁止しない）。
⑥ かんたん表示で減らすのは★選択肢であって、機能ではない。
⑦ ★金色と緑色を文字に使わない（実測でコントラストが足りません）。
```

---

## 1. なぜ年齢で切り替えないか

```
・40代でも老眼は始まります
・20代でも弱視の人がいます
・80代でも、スマホを速く使う人がいます
・そして「あなたは高齢者ですね」と機械に判定されるのは、不快です
```

**年齢は、必要な設定を推測するための代理変数にすぎません。**
**本人に直接、見え方を選んでもらえば足ります。**

### 1-1｜最初の画面で、一度だけ聞く

```
┌──────────────────────────────┐
│ 文字の大きさを選んでください                │
│                                            │
│  ┌────────┐ ┌────────┐ ┌────────┐        │
│  │ ふつう  │ │ 大きい │ │とても  │        │
│  │ あいう  │ │ あいう │ │大きい  │        │
│  │        │ │        │ │ あいう │        │
│  └────────┘ └────────┘ └────────┘        │
│                                            │
│  ★見本の文字が、そのまま大きくなります     │
│                                            │
│  あとから「もっと」で変えられます          │
└──────────────────────────────┘
```

**見本を実寸で出してください。**「大きい」という言葉では伝わりません。

**★年齢を聞いてよいのは、職業別項目の設定の中で、任意の欄としてだけです。**
そこでも必須にせず、見やすさの設定とは結びつけないでください。

## 2. 文字の大きさ（3段階）

### 2-1｜CSS変数だけで実現する

```css
:root { --base: 16px; --tap: 44px; --gap: 12px; }
[data-scale="large"]  { --base: 20px; --tap: 56px; --gap: 16px; }
[data-scale="xlarge"] { --base: 24px; --tap: 64px; --gap: 20px; }
```

```
・★すべての文字を rem または em で書く。px を直接書かない
・行間 1.7 以上（★大きい文字ほど、行間が要ります）
・1行の文字数を 30字前後に保つ（横に伸ばさない）
・★数字は本文より 1段階大きく（記録の数字がいちばん読まれます）
```

### 2-2｜★OSの設定を邪魔しない

```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```

```
✗ maximum-scale=1  user-scalable=no   ← ★絶対に書かない
```

**iPhone の「文字を大きく」を使っている人は、すでにそこで設定しています。**
それを打ち消す実装をしないでください。

### 2-3｜画面が壊れないこと

```
□ とても大きい で、ボタンの文字が枠から出ない（★折り返す）
□ 表が横に切れない（★横スクロールできる箱に入れる）
□ 羊が小さくならない
□ 下のタブの文字が消えない（★アイコンだけにしない）
```

## 3. かんたん表示

**文字の大きさとは別の設定です。**大きい文字だけ欲しい人がいます。

### 3-1｜ホーム

```
ふつう表示                    かんたん表示
┌──────────┐          ┌──────────┐
│ 羊  今日の状態    │          │      羊          │
│ ── ── ──  │          │                  │
│ [記録][分析][学ぶ]│          │ ┌──────────┐ │
│ 今週の推移 ▁▃▅▂ │          │ │ 今日を記録する │ │
│ お知らせ 3件      │          │ └──────────┘ │
│ 次のレッスン…     │          │                  │
└──────────┘          │  [ 見る ] [ 学ぶ ] │
                              └──────────┘
```

```
・★大きなボタンを1つだけ、真ん中に置く
・二番目に大事なものを2つまで
・推移・お知らせ・予定は、押した先に置く
・★消すのではなく、奥に置く
```

### 3-2｜記録の画面

```
✗ スライダー           → ★5つの大きなボタン
✗ トグルスイッチ       → ★「あり／なし」の2つのボタン（選んだ方に✓）
✗ 数値の直接入力だけ    → ★［−］［＋］と、大きな数字
✗ 長押しで削除         → ★「消す」ボタン
✗ 横スワイプで次へ      → ★「つぎへ」ボタン（スワイプも残してよい）
```

**★スライダーは、手が震える人には操作できません。**
**そして正確な値を入れたい人にも向きません。両方に悪い部品です。**

### 3-3｜1画面に1つのこと

```
ふつう表示    1画面で 睡眠・発話・水分・体調 を入れる
かんたん表示  ★1画面に1つ。「つぎへ」で進む。★残り何問かを出す
```

```
┌──────────────────────────────┐
│                              あと 3つ      │
│                                            │
│   昨日は、よく眠れましたか                  │
│                                            │
│   ┌──────────────────────┐  │
│   │        よく眠れた                  │  │
│   └──────────────────────┘  │
│   ┌──────────────────────┐  │
│   │        ふつう                      │  │
│   └──────────────────────┘  │
│   ┌──────────────────────┐  │
│   │        あまり眠れなかった          │  │
│   └──────────────────────┘  │
│                                            │
│   [ もどる ]                  [ とばす ]   │
└──────────────────────────────┘
```

**★「とばす」を必ず置いてください。**
答えられない項目で止まると、その日の記録が丸ごと消えます。

## 4. 押せること

```
・タップの的は ★56px 以上（かんたん表示は 64px）
・的と的の間を ★16px 以上あける
・★アイコンだけのボタンを作らない。必ず文字を添える
・★長押しだけ・スワイプだけの操作を作らない。必ずボタンの道を用意する
・押したことが分かるように、色と形を変える（0.1秒以内）
```

### 4-1｜★消える通知を使わない

```
✗ トースト（数秒で消える帯）
○ 画面の中に残す。★自分で閉じる
```

**読み終わる前に消えます。**そして「何か出たけど読めなかった」は不安を生みます。

### 4-2｜間違えても壊れない

```
・保存のあと、必ず「取り消す」を★30秒間出す
・削除は2段階（★「消しますか」＋「消す」）
・★エラーは、何をすればいいかを書く
    ✗「エラーが発生しました」
    ○「保存できませんでした。もう一度［保存］を押してください」
```

## 5. 色（★色は変えません。使い方だけ決めます）

**現在の配色で、実測したコントラスト比です。**

```
文字色          背景 #F7F2E6   カード #FFFDF8   判定
ink   #261913      15.27          16.78        ★どこでも使える
wine  #840C24       9.13          10.03        文字に使える
ink-2 #6D5D50        5.64           6.20        小さい文字には弱い
ink-3 #76665A        4.92           5.41        ★かんたん表示では使わない
s3    #447862        4.58           5.03        文字は避ける。線はよい
s2    #BF8722        2.80           3.08        ★文字に使わない
ok    #739E67        2.76           3.03        ★文字に使わない
```

```
★かんたん表示・大きい文字のときの規則

・本文も補足も、すべて ink #261913 にする（ink-2 / ink-3 を使わない）
・金 #BF8722 と 緑 #739E67 は、★塗りと線だけ。文字にしない
・グラフの線を 3px → ★4px にする
・★系列名を線のそばに直接書く（凡例だけに頼らない）
・点の形を変える（丸・四角・三角）。★色だけで区別しない
```

**色は1つも変えません。太さと置き方で読ませます。**

## 6. ★ホーム画面に追加できない問題

**これが、この層でいちばん脱落する場所です。**

PWA は、ブラウザの共有メニューから「ホーム画面に追加」を押さないと
アプリになりません。**この操作を知らない人が、大多数です。**

```
・初回に、★スクリーンショット付きの案内を1枚出す（文字は大きく）
・iPhone と Android で、案内を出し分ける
・★「あとで」を押せるようにする（ブラウザのままでも全部使えます）
・教室では、★先生が最初のレッスンで一緒にやる
```

**★印刷用の「はじめかた」1枚（A4・PDF）を作ってください。**
紙を渡せることが、この層では効きます。

```
1  この住所を開く（★QRコードを大きく）
2  下の [ ] を押す
3  「ホーム画面に追加」を押す
4  羊のマークができたら、それを押す
```

## 7. ★やらないこと

```
1.  ★年齢で自動的に表示を切り替えない
2.  ★「シニア」「高齢者」「かんたんモード（初心者向け）」と画面に書かない
3.  ★画面を2つに分けない（保守が2倍になり、片方が必ず古くなる）
4.  ★かんたん表示で機能を削らない（奥に置くだけ）
5.  ★user-scalable=no を書かない
6.  ★家族や先生による代理入力を作らない（本人の健康情報です）
7.  ★音声読み上げの自動再生をしない（本人が押したときだけ）
8.  ★点滅・自動で動くものを置かない
9.  ★「かんたん表示にしませんか」と、こちらから提案しない
      → 設定の中に、見つけやすく置いておくだけ
```

### なぜ ③ が重要か

**一人で作っているからです。**

画面を2つ持つと、片方の修正がもう片方に入りません。
**半年後、かんたん表示だけ古い分析画面のまま、という状態になります。**

```
★実装の形

・CSS変数（--base / --tap / --gap）で寸法を出す
・data-scale と data-simple を <html> に付ける
・分岐は、コンポーネントの中で最小限に
・★「SimpleHome.tsx」のような別ファイルを作らない
```

## 8. 誰のためか（★設計者の想定を書いておきます）

```
① 趣味で声楽・合唱をしている 60〜80代の生徒
   ★人数がいちばん多い層です。合唱人口の中心はここです
② 60代以上の先生
   ★教室そのものが、この人の手で動いています
③ 老眼が始まった 40〜50代（★自覚がなく、設定も変えません）
④ 暗い練習室・楽屋でスマホを見るすべての人
```

**②を落とすと、教室ごと落ちます。**
**「見やすさ」は、親切ではなく、流通経路を守る機能です。**

## 9. 受け入れ条件

```
□ とても大きい で、記録が最後まで終えられる
□ かんたん表示で、記録が★3タップ以内で終わる
□ すべてのタップ目標が 56px 以上
□ アイコンだけのボタンが1つもない
□ スワイプ・長押しだけの操作が1つもない
□ 金色と緑色が、文字に1か所も使われていない
□ OSの文字サイズを最大にしても、画面が壊れない
□ ★60代以上の人が、説明なしで1回目の記録を終えられる
```

**最後の1行だけは、コードでは確認できません。**
**テスター15〜20人のうち、★2人以上を60代以上にしてください。**
