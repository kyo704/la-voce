# La Voce「学ぶ」記事 執筆規定

## 前提

La Voce は声のプロフェッショナル向けのコンディション記録アプリ。
既存の「学ぶ」と「健康情報」を統合し、1つの学習セクションにする。その記事本文を書く。

読者は声を仕事にしている人。素人ではない。ただし解剖学や音声医学の専門教育は受けていない。

## 章立て（統合後・全職業共通）

1. この仕事の声      … 自分の声の仕組みと、この職業特有の声の使い方
2. 何が声を削るか    … 声を悪くする要因
3. アプリの数字の読み方 … La Voce の各指標が何を見ているか
4. 整える            … 日々のケアと回復の手段
5. 守る              … 本番・現場での予防
6. 続くときは        … 受診の目安と、その先
7. 用語              … 用語集

## トーン規定（最重要）

このアプリの最大の資産は「誠実さ」です。以下を厳守してください。

### 必ず守ること

- **断定しない。** 「〜と言われています」「〜とされています」「〜する人が多いようです」。
  生理学的に確立している事実（声帯が振動して音が出る等）だけは断定してよい。
- **医学的な診断・治療の助言をしない。** 対処法は「一般的に言われている工夫」として書く。
- **症状に触れる記事は、必ず受診を促す一文で終える。**
  例:「症状が続く場合は、耳鼻咽喉科（できれば音声を専門とする医師）にご相談ください。」
- **数値の基準値を断定しない。** 「◯◯以上は異常」という書き方をしない。
- **体重・体型に踏み込まない。** このアプリは「体重や体型ではなく、消費に対して摂取が足りているか」
  という立場を取っている。痩身を是とする表現、目標体重の提示、体型に関する価値判断は一切書かない。
  声楽家・ミュージカル俳優は摂食障害リスクが相対的に高い職種であることを念頭に置く。
- **不安を煽らない。** 「放置すると声が出なくなります」のような書き方はしない。
  「早めに気づけると対処しやすくなります」のように、行動に繋がる書き方をする。

### 絶対にやってはいけないこと

- **出典・論文名・著者名・発表年を捏造しない。** 具体的な研究を引用しない。
  「◯◯大学の研究で」「2019年の論文によると」といった書き方は、正確性を確認できないため一切禁止。
  一般に知られている知見として書く。
- 効果を保証する表現（「必ず良くなります」「治ります」）を書かない。
- サプリメント・特定商品・特定の医療機関を推奨しない。

## 文体

- です・ます調。
- 1文を短く。1文40字以内を目安。
- 見出しは使ってよいが、1記事に2〜3個まで。
- 箇条書きは有効。ただし箇条書きだけの記事にしない。地の文で理由を説明する。
- 専門用語を使うときは、初出時に短く説明を添える。
  例:「SOVTE（半閉鎖声道エクササイズ。ストロー発声などの総称）」
- 絵文字は使わない。
- 「あなた」を多用しない。主語を省いた自然な日本語にする。

## 分量

1記事 500〜900字。既存記事（逆流性食道炎の記事）が約700字なので、それが基準。
短くて役に立つほうが良い。埋めるために水増ししない。

## 出力形式

1記事ごとに以下の形式で書く。1つのファイルに複数記事を連ねてよい。

```
---
## [記事ID] 記事タイトル

- **章:** 2. 何が声を削るか
- **一覧表示用の1行:** （記事一覧に出す28字以内の説明）

本文をここに書く。
```

記事IDは、担当分の接頭辞に連番を付ける（例: V-1, V-2 / A-1 / S-1 / P-1 / C-1）。

## 既存記事の扱い

以下は既にアプリ内に存在する記事です。**書き直す必要はありません。**
担当分に含まれている場合は、記事IDと配置先だけを書き、本文は「※既存記事。移動のみ」と記載してください。

- 声区とパッサッジョ ― 通過点で何が起きているか（声楽家・ミュージカル / 第1章）
- 衣装と姿勢 ― コルセットが呼吸に与えるもの（声楽家・ミュージカル / 第2章）
- 声帯という器官のこと（共通 / 第1章）
- 逆流性食道炎と声（共通 / 第2章）※健康情報側の同名記事と重複しているので統合対象
- 声の衛生（ボーカルハイジーン）の基本（共通 / 第4章）
- 歌手に役立つ運動 — 目的別に整理（共通 / 第4章）
- 筋トレ回数の一般的な目安（共通 / 第4章）
- 身長からの参考体重レンジについて（**削除対象**。トーン規定に反するため）
- その他、歌手が注意すべき症状（共通 / 第2章）
