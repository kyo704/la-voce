SOVTE（半閉鎖声道エクササイズ）は、口の出口を狭くした状態で声を出す練習の総称です。ストローをくわえて発声する方法が最もよく知られています。リップロール（唇を震わせる）、ハミング、タングトリルなども同じ仲間です。

### なぜ楽に感じるのか

出口を狭めると、声道の中に圧力が保たれます。この圧力が声帯の振動を助け、**少ない力で振動が続く状態**を作ると言われています。強く息を送らなくても声が出る、という感覚です。

そのため、疲れている日や、声が重い日に負担をかけずに使えます。ウォームアップの入り口としても、歌い終わったあとのウォームダウンとしても使われています。

### やり方の一例

細めのストローを軽くくわえ、無理のない高さで「うー」と声を出します。頬が大きく膨らむほど強く吹く必要はありません。ゆっくり上下に音を動かしたり、曲の一節をストロー越しに歌ったりします。数分で十分だとされています。

ストローがなければ、唇を軽く閉じたハミングでも近い効果が得られると言われています。現場で目立たずにできるのが利点です。

### 注意すること

痛みがあるときに無理に続けないでください。楽に感じないなら、その日は合っていないということです。また、これは回復を助けるかもしれない手段であって、治療ではありません。声の不調が続く場合は耳鼻咽喉科にご相談ください。
