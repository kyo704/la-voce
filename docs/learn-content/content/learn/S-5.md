マイクの前では、声だけでなく体の位置も固定されます。この固定が、思っている以上に呼吸を変えることがあります。

台本を持つ姿勢は、その代表です。手元に紙があると視線が下がり、あごが引かれ、首の前側が縮みます。ページをめくる音を避けようとすれば、腕の位置も不自然になります。この状態では胸まわりが動きにくくなり、息が浅くなりやすいと言われています。息が浅いと、声を支えるぶんを喉のあたりで補おうとする形になりがちです。

### 距離と角度

マイクとの距離は音の設計で決まりますが、声の出し方にも影響します。近づけば小さな声で足りる一方、破裂音を避けるために角度をつけたり、顔をわずかにそらしたりします。その姿勢を何時間も保てば、首や肩に持続的な緊張が残ります。

叫びの場面でマイクから離れる、いわゆるオフ気味の処理をするときは、距離を取ったぶん声量で埋めようとして、かえって強く出してしまうことがあります。距離が変わったら、出し方も変えてよい場面です。

現場で試しやすいこととして、次のようなことが挙げられます。

- 台本の高さを上げ、視線と首の角度を保つ
- 立ち位置で足を固めすぎず、体重を左右に移せる余裕を残す
- 長いシーンの前に、一度肩を下ろして息を入れ直す

姿勢の癖は自分では気づきにくいものです。可能な場面で自分の立ち姿を確認してみると、思っていた形と違うことがあります。首や肩の張り、声の出しにくさが収録のたびに続くようであれば、耳鼻咽喉科（できれば音声を専門とする医師）に相談してみることも検討してください。
