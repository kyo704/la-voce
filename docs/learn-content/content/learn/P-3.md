ライブハウスは、声にとってやさしい環境ではありません。何が起きているかを分けて見ておくと、対処の順番が決まります。

### 乾燥

空調と照明で、フロアも楽屋も乾きやすい場所です。声帯の表面は薄い粘液の層に覆われています。この層が乾くと、振動の効率が落ちると言われています。喉に張り付くような感覚。いつもより息が要る感覚。どちらも乾燥のサインとして語られます。こまめに少量ずつ水分を取る方法が、一般的には勧められています。

### 煙と粉塵

スモークマシンの煙は、使う液や機材によって性質が異なります。長時間その中にいると、喉や気道に刺激を感じる人がいるようです。古い建物では粉塵も加わります。煙の中に長く立ち続ける演出なら、リハーサルの段階で立ち位置を相談しておく手もあります。

### 音量

爆音の中では、無意識に声が大きくなりやすいと言われています。これはステージ上だけの話ではありません。フロアでの会話も、楽屋での打ち合わせも同じです。

会場の環境は選べないことが多いものです。だからこそ、変えられる部分から手をつけるのが現実的です。水分、立ち位置、返しの量、会話の量。どれも小さいですが、積み上がる側の要因です。

刺激感や声の変化が数日以上続く場合は、耳鼻咽喉科（できれば音声を専門とする医師）にご相談ください。
