声の不調は、多くの場合、数日で戻ります。だからこそ「いつまで様子を見るか」の線引きが難しくなります。

一般に、受診を検討する目安としてよく挙げられるのは次のような場合です。

- **声のかすれが2週間以上続いている**
- 痛みがある、または飲み込むときに痛む
- 声が出ない日がある
- 息が苦しい感じを伴う
- 血の混じった痰が出る
- 首やあごの下にしこりを感じる
- 同じ症状が周期的に繰り返している

このうち「2週間」は、多くの場面で目安として使われている期間です。ただし、これは絶対的な基準ではありません。声を仕事にしている人の場合、**もっと早い段階で相談したほうが良い場面が多くあります。** 仕事に直結するためです。

### 事前に決めておく

不調の最中に受診するかどうかを判断するのは難しいものです。本番が近ければ「行っている場合ではない」と考えがちで、本番が終われば「もう治った気がする」と先送りになります。

そのため、調子の良いときに自分の基準を決めておくことをおすすめします。「かすれが◯日続いたら行く」「本番が◯日以内にあるなら、迷ったら行く」。La Voce の症状カレンダーは、何日続いているかを客観的に示してくれます。

### 質問票の点数を目安にする

RSI が基準値を超えた、VFI の「休息による回復」が下がってきた。こうした変化も、受診を検討する材料になります。ただし、これらはスクリーニング目的の参考値であり、点数が診断を意味するわけではありません。

判断に迷った場合は、耳鼻咽喉科（できれば音声を専門とする医師）にご相談ください。
