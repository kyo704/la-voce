分析タブの一番上に出る「声の調子スコア」は、六つの記録を独自の重み付けで統合した100点満点の参考指標です。

内訳は、喉のコンディション・声の質・睡眠・メンタルの安定度・喉の症状の少なさ・水分摂取の六つです。それぞれが100点換算で表示されるので、総合点が下がったときに、どの要素が引っ張っているかが分かります。

### 総合点そのものを追わないでください

この点数は、医学的な評価でも、他人と比べられる数値でもありません。すべて自己申告の記録から作られています。同じ「喉3」でも、その日の基準は人によって違いますし、同じ人でも時期によって変わります。

見るべきは総合点の上下ではなく、**六つのうちどれが低いか**です。「喉のコンディションが70点で、ここが全体を約7.5点押し下げています」という表示が出るのは、そのためです。総合点が同じ75点でも、水分が低い日と睡眠が低い日では、やることが違います。

### 直近2週間で固定されています

このスコアは期間セレクタの影響を受けず、常に直近2週間で計算されます。長期の傾向ではなく「いま」を見るための指標だからです。長期の推移を見たいときは、各項目の個別のグラフをご覧ください。
