騒がしい場所にいると、人は自分の声を無意識に大きくします。これはロンバード効果と呼ばれ、相手に聞こえるようにという意識とは別に、自動的に起きるものだと言われています。

問題は、**本人がその自覚を持ちにくい**ことです。周囲がうるさいので自分の声も聞こえにくく、どれだけ張っているかが分かりません。歌った量は記録できても、この分は記録から漏れがちです。

該当する場面は多くあります。ライブ後の会場、居酒屋、移動中の車内、稽古場の休憩時間、電話。歌う仕事の日より、その前後の時間のほうが声を使っていた、ということが起こりえます。

### 減らす工夫

一般に行われている工夫としては、次のようなものがあります。

- 相手との距離を詰める（声量ではなく距離で解決する）
- 静かな場所に移動してから話す
- 大人数の会話の中心に長くいない
- 音楽のかかっている場所での長話を避ける
- 電話よりメッセージを使う

どれも当たり前に見えますが、意識していないと実行されません。

### 記録に残す

La Voce に発声セッションを記録するとき、歌った時間だけでなく、こうした「歌う以外で声を使った時間」も含めて考えてください。発声負荷バランスの精度は、この漏れの少なさで決まります。
