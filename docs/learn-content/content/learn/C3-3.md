声の高さを記録するとき、二つの約束事があります。記録画面ではなくこちらにまとめました。日々の記録のたびに読む必要はありません。

### 表記は国際式です

音名の後にオクターブ番号をつけます。ピアノの真ん中のド（ミドルC）は「**C4**」と表記します。これが国際式です。

ヤマハ式（真ん中のドを C3 とする方式）を使ってきた方は、番号が1つずれるのでご注意ください。日本の音楽教育ではヤマハ式に慣れている方が多いので、最初の数日は間違えやすいところです。

例：真ん中のドの上のソ → **G4** ／ 真ん中のドの下のラ → **A3**

### 地声で記録してください

裏声（ファルセット）ではなく、話し声と同じ地声の高さで記録してください。

理由は、**地声のほうがコンディションの変化が現れやすく、日々の比較の基準として安定している**ためです。裏声は、体調が悪い日でも比較的出てしまうことがあり、変化のサインが埋もれやすくなります。一方で地声の最高音は、むくみや疲労を素直に反映する傾向があります。

分析タブの「音域到達マップ」「ウォームアップ効率」「起き抜け・発声後の声の高さの推移」は、いずれもこの前提で作られています。裏声を混ぜて記録すると、これらの指標の意味が変わってしまいます。
