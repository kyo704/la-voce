声帯の表面は薄い粘液の層に覆われています。この層が、振動する声帯どうしの摩擦をやわらげていると考えられています。乾燥は、この層を薄くします。

乾いた声帯は、振動を始めるためにより強い息を必要とするようになると言われています。同じ音を出すのに、いつもより力がいる。高い音の立ち上がりが鈍い。長く歌うと後半で急に重くなる。乾燥した日の不調は、こうした形で現れることが多いようです。

### 乾燥には二つの経路がある

ひとつは**環境からの乾燥**です。空調、飛行機、暖房、乾いた楽屋。喉の表面から直接水分が奪われます。

もうひとつは**体内の脱水**です。水分摂取が足りない、汗をかいた、利尿作用のある飲み物が多かった。こちらは飲んですぐには戻らないと言われています。粘液が作られるまでに時間がかかるためです。

この二つは対処が違います。環境からの乾燥には加湿や吸入が、体内の脱水には継続的な水分摂取が対応します。本番前に慌てて水を飲んでも間に合わないのは、後者が時間のかかる経路だからです。

### La Voce での見方

「環境の快適帯」では、気温ではなく絶対湿度（空気中の実際の水分量）で環境を記録しています。同じ湿度◯％でも、気温が変われば実際の水分量は変わるためです。記録が溜まると、自分にとって喉が快適な範囲が見えてきます。

乾燥感が続く場合や、水分を摂っても改善しない場合は、耳鼻咽喉科にご相談ください。
