## 1. 結論

**「健康情報」を廃止し、「学ぶ」に一本化します。**

理由:

- 両者に **同じ内容の記事が重複** していた（逆流性食道炎の記事が2箇所）
- 両者を **分ける基準がユーザーから見えない**（どちらを読めばいいか判断できない）
- 「学ぶ」の7章立ては論理的で良い骨格を持っている。健康情報の記事はすべてこの章のどこかに収まる

統合後のメニュー名は **「学ぶ」** とします。

## 4. 削除・変更の判断（実装者はこの通りに実行してください）

### 4-1. 削除するもの

**① 「身長からの参考体重レンジについて」を削除**

理由: このアプリは分析タブのエネルギー可用性で「**体重や体型ではなく**、消費に対して摂取が足りているかを
見る指標です」という立場を明確に取っています。身長から体重レンジを提示する記事はこの立場と矛盾します。
声楽家・ミュージカル俳優は摂食障害のリスクが相対的に高いとされる職種でもあり、体型の基準値を示すことは
避けるべきだと判断しました。

**代替として C4-8「食べることと声 ― エネルギー可用性という見方」を新規に用意しました。**
必要な情報（活動量に見合う摂取が取れているか）は、体型に触れずに伝えられます。

**② 「学ぶ」側の「逆流性食道炎と声」を削除**

理由: 健康情報側の「逆流性食道炎・咽喉頭逆流症（LPR）と歌手への影響」と内容が重複しています。
**健康情報側の本文のほうが詳しく完成度が高い**ため、そちらを採用し、学ぶ側を削除します。
統合後のIDは C2-1。末尾に RSI 質問票への接続を1段落追記してください（本文ファイル参照）。

**③ 「── からだ（全職業共通）──」セクションを削除**

理由: このセクションと第1章の両方に「声帯という器官のこと」「逆流性食道炎と声」が表示されており、
**同一ページ内に同じ記事が2回**出ていました。共通記事を章内に配置する新構造で解消します。

**④ 空の章の「まだ記事がありません」表示を削除**

記事0件の章は章ごと非表示にしてください。

### 4-2. 改題するもの

| 現在 | 変更後 | 理由 |
|---|---|---|
| その他、歌手が注意すべき症状 | 気をつけたい症状のいろいろ | 全職業共通の章に置くため「歌手」を外す |
| 歌手に役立つ運動 — 目的別に整理 | 声を使う仕事に役立つ運動 ― 目的別に整理 | 同上 |

### 4-3. 移設するもの

**「今日の記録」タブの音名ルール長文を、C3-3 として学ぶへ移設**

現在、記録画面に以下の2つの長文が **常時展開** されています。

- 「表記のルール：音名の後にオクターブ番号をつけます…（国際式・ヤマハ式の説明）」
- 「ここでの音名は、裏声（ファルセット）ではなく、話し声と同じ地声の高さで記録してください…」

合わせて200字以上あり、**毎日開く記録画面で毎日表示されています。** 記録のテンポを最も損なっている箇所です。

対応:
1. 記録画面では「？」アイコンに畳む。初回のみ自動展開する
2. 「？」から C3-3 の記事へリンクする
3. C3-3 には既存の文言をそのまま含めた完全版を置く（本文ファイル参照）

**内容自体は削除しないでください。** これはドメイン理解の深さが出ている重要な説明です。表示場所だけを変えます。

## 7. 記事本文の扱い

同梱ファイル:

```
_執筆規定.md                     ← 今後記事を追加するときの規定。必ず踏襲すること
_統合設計書.md                   ← このファイル
共通_1章2章.md                   ← C1-1〜C2-6
共通_3章.md                       ← C3-1〜C3-9
共通_4章5章.md                   ← C4-1〜C5-4
共通_6章7章.md                   ← C6-1〜C7-1

職業別_アナウンサーナレーター.md ← A-1〜A-8
職業別_声優.md                   ← S-1〜S-8
職業別_ポップスロック.md         ← P-1〜P-8
```

各記事は以下の形式です。

```
## [記事ID] タイトル

- **章:** 所属する章
- **一覧表示用の1行:** 記事一覧に出す28字以内の説明

本文
```

「※既存記事。移動のみ」と書かれているものは、アプリ内の既存の本文をそのまま使ってください。書き直し不要です。

### 記事本文の扱いについての注意

記事は医学・生理学に関わる内容を含みます。以下を守ってください。

- **本文を勝手に要約・改変しないこと。** 断定を避ける言い回し（「〜と言われています」）は
  意図的なものです。簡潔にする目的でこれを断定形に直さないでください
- **受診を促す締めの一文を削らないこと**
- **出典や研究を追加しないこと。** 本文には具体的な論文・研究の引用を一切入れていません。
  「根拠を補強するため」であっても、確認できない出典を足さないでください
- 公開前に、**声の専門家（音声を専門とする医師、または言語聴覚士）による監修**を受けることを推奨します。
  記事は一般に知られている知見の範囲で書かれていますが、専門家の確認を経ていません
