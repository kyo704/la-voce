描き足すと、この羊にない部品が増えて、絵柄がずれます。

- 左と右を両方置けば、**2つ同時**に持てます（例：左に楽譜、右にコーヒー）
- 1つだけなら `_R` を既定に。傘・蓄音機・新聞のような大きいものは `_C` が向きます
- 3通りとも、いちばん上に来る点で **y=540**。口は y=414 なので、**顔は隠れません**
- 足は y880〜951 なので、**地面に置いたようにも見えません**
- `items-index.json` の `hands` に同じ数値が入っています

新しい持ち物を足すときは `handfix.py` の `place(img, 'L'|'C'|'R')` を通すだけで、同じ位置にそろいます。

## 2. 土台の3行（これで何着でも作れます）

```python
def jaw(x):      return max(-0.00237595*x*x + 2.49995*x - 58.78, 490)   # 頭と胴の境目
def shoulder(x): return 592 - 150*((x-511)/300)**2                       # 肩の下がり
def top_y(x):    return max(jaw(x)-14, shoulder(x))                      # 服の上端
```

- 胴のかたち：中心 (511,660)、rx=268、ry=300 の楕円
- 襟巻きの下辺：`-0.00160767x² + 1.643818x + 255.353`
- 服は最後に **元画像のアルファで切り抜く**（靴だけ例外）
- 帽子：耳は y83〜227、x345-424 と x599-678。**耳を帽子の上に焼き込む**ので別レイヤーは不要

## 5. 注意（3つ）

### ① 民族衣装は「代表」ではありません
1点でその国を代表させると、必ず「うちの地方は違う」が出ます。アプリの表示は
**「〇〇の伝統的な装いより」**のような書き方にして、「〇〇の民族衣装」と断定しないでください。
特にドイツとオーストリアは地域が重なります（どちらもアルプス圏の装いが有名）。
今回はオーストリアを**ウィーンの宮廷服**にして、意図的にずらしました。

### ② 時代ものは削ってあります
- 縄文・弥生は出土品からの**復元＝推定**。年代や名称を断定しない
- 平安の十二単は本来もっと横に広がります。羊の輪郭に収まらないので**襲の色目を裾と袖口だけ**で表現
- 主な参照：風俗博物館「日本服飾史」、文化遺産オンライン「縄文時代衣服（復元）」

### ③ 武器は作っていません
刀・弓・鉄砲は、時代ものとしては自然でも**アプリの持ち物としては入れませんでした。**
必要ならご指示ください。ただ、ストアの年齢区分に影響する可能性があります。
