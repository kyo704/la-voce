## §0 答え ── ★Confirm signup にも、必ず要ります

```
Magic Link      ★{{ .Token }} を足す   … いまお使いの方が、入るとき
Confirm signup  ★★{{ .Token }} を足す … ★はじめての方が、登録するとき
```

★**両方です。** 理由を書きます。

```
supabase.auth.signInWithOtp({ email, options: { shouldCreateUser: true } })

　　そのアドレスが★登録済み   → ★Magic Link のひな型が飛びます
　　そのアドレスが★はじめて   → ★★Confirm signup のひな型が飛びます
```

★つまり、⑪（ホーム画面までの導線）で**はじめての方が受け取るのは、
　Magic Link ではなく Confirm signup のほうです。**

```
★★ここに {{ .Token }} が無いと、
　　はじめての方は、★1人も登録できません。
　　リンクだけが届き、★押すと既定のブラウザで開きます。
　　★ホーム画面に置いていただいた意味が、そこで消えます。
```

★→ ★**Confirm signup のほうが、むしろ重要です。**

## §1 ★消さずに、足してください

```
★{{ .ConfirmationURL }} の行を、★消さないこと。
```

理由。

```
・★いま動いているものを、先に壊さない
・★パソコンから登録する方には、★リンクのほうが速い
・★数字が読み取れない方（拡大している方・スクリーンリーダーの方）の逃げ道になる
```

★2つ並べて置きます。★どちらでも入れます。

## §4 ★文言について、決めたこと

```
◯ 日本語にする              ★お客さまは日本語の方です。英語のままにしない
◯ 数字を、大きく・広く出す   ★書き写していただくものです。32px・字間 0.3em
◯ 「1時間で使えなくなります」 ★★Supabase の既定が1時間です。
                              ★変えたら、★この行も変えること
◯ 「心当たりがないときは、捨ててください」
                              ★★他人のアドレスを打ち間違えた人が必ず出ます
                              ★受け取った方を、不安にさせないための1行です

✕ 「このメールは自動送信です。返信できません」
                              ★冷たいだけで、何も助けません
✕ 「至急」「必ず」「お早めに」  ★急かさないこと（9月3日の決まり）
✕ 会社名・住所の署名          ★特商法の表示は、★サイトの側にあります
                              ★メールに毎回入れると、★数字が下に押されます
```

★件名も、Supabase の画面で変えられます。

```
Confirm signup  →  Woolsong の登録用の数字
Magic Link      →  Woolsong にログインする数字
```

★★件名に、★数字そのものを入れないこと。
　★通知の画面に出て、★肩ごしに見られます。

## §5 ★貼り替えたあと、確かめること

```
□ ★はじめてのアドレスで登録してみる（★Confirm signup が飛びます）
　　→ ★数字が本文に出ているか
□ ★すでにあるアドレスで入ってみる（★Magic Link が飛びます）
　　→ ★数字が本文に出ているか
□ ★iPhone のメールで、★数字が読める大きさか
□ ★リンクのほうも、まだ動くか（★消していないこと）
```

★★1つめが、いちばん大事です。
　★はじめての方の道が、★いま塞がっています。
