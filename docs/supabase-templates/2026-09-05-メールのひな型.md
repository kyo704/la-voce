## §1 ★消さずに、足してください


```
・★いま動いているものを、先に壊さない
```

★2つ並べて置きます。★どちらでも入れます。

## §3 Reset Password ── ★★このまま貼り替えてください（いちばん大事）

★「パスワードを忘れた」を押した方に飛びます。
★★この数字を入れて、★その場で新しいパスワードを決めていただきます。

```html

<p>下の数字を、アプリの画面に入れてください。</p>

<p style="font-size:32px;letter-spacing:0.3em;font-weight:bold;margin:24px 0;">{{ .Token }}</p>

<p>この数字は、1時間で使えなくなります。</p>

<hr>

<p style="color:#6b6257;font-size:13px;">
心当たりがないときは、そのまま捨ててください。
いまのパスワードは、そのまま使えます。
</p>
```

★★ここには、★{{ .ConfirmationURL }} を置きません。

```
★理由 ── ★押されてしまうからです。
　★押すと、★既定のブラウザが開きます。
　★★ホーム画面に置いたアプリの、外に出ます。
　★そこでパスワードを決め直しても、★アプリの側には反映されません。
　★「決め直したのに入れない」という、★いちばん困る形になります。

★「パソコンからも」の逃げ道は、★§2 の登録のほうに残してあります。
　★★再設定だけは、★数字1本にします。
```

## §4 ★文言について、決めたこと

```

                              ★変えたら、★この行も変えること
```
