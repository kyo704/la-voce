## 5. 伴奏（新設）

```
ピアノ ／ オーケストラ ／ バンド ／ 音源（カラオケ・CD） ／ アカペラ・無伴奏 ／ その他
```

**出す職業：classical / musical / pops のみ。**
**★voiceActor / narrator / announcer には出さない。**

### 5-1｜★v1 では係数を作らない

**記録するだけです。負荷の計算に一切入れないでください。**

理由：伴奏の大きさは、既存の「騒音」（屋外1.3／中継1.2／スタジオ1.0）と
「モニター環境」（なし1.25／ウェッジ1.10／インイヤー1.0）の係数と**重なります。**
**未較正の定数をもう1つ足すと、既存の分析が濁ります。**

**データが貯まってから、実測で決めます。**これは「声の型の配合を v1 では計算に使わない」
（憲章 §4-3）と同じ扱いです。

## 6. ★埋まっていない2か所

**坂本さんが埋めるまで、空欄のままにしてください。★想像で埋めないこと。**

```
① 落語（rakugo）のテッシトゥーラ相当の語
   → ★決着（2026-08-31）。高さでは持ちません。
     演目カードに5つの属性を付けます
     （地の声／男の声／低い男の声／女の声／子供の声）。
     曲と同じで、演目ごとに1度だけ選びます。毎回は聞きません。
     ★v1 は記録するだけ。負荷の係数は作りません（伴奏と同じ扱い）。
     落語の負荷は、これまでどおり活動係数（高座 1.6）で見ます。

② 声優（voiceActor）の「役の高さ」という言い方が適切か
   → ★決着（2026-08-31）。★欄そのものを作りません。
     既存の声質係数（ナレーション0.8／通常の芝居1.0／張り上げ3.5／
     叫び5.0／悲鳴6.0／ダミ声4.0）が、話し方で負荷を捉えています。
     声優の負荷は「高さ」ではなく「出し方」で決まります。
```

**★なぜ高さに変換してはいけないか（判断-落語と声優の役の属性.md §1）**

songFactor は「その人自身の、無理なく出せる音域の中心からどれだけ離れているか」で
測ります。**自分を基準にした距離**です。
「子供の声」のような**絶対的な属性を固定の高さに置き換えると、この相対性が壊れます。**
同じ「女の声」でも、演者によって自分の基準からの距離はまったく違います。

★出典 docs/lavoce-判断-落語と声優の役の属性.md

**空欄の間は、その項目を画面に出さないでください。**
「何も出さない」ほうが、当てはまらない語を出すより安全です（落語の曲目カードと同じ判断）。

## 7. 喫煙・飲酒（新設）

### 7-1｜なぜ入れるか

2020年の研究（プロの俳優65名・歌手63名）で、**喫煙は俳優50.8%・歌手17.5%**でした。
無視できる数字ではありません。

### 7-2｜記録の形

```
その日、たばこを吸った    あり ／ なし
その日、お酒を飲んだ      あり ／ なし

★本数を聞かない
★量を聞かない
★銘柄・種類を聞かない
★どちらも任意
★未成年には項目ごと出さない（年齢フラグを見る。フェイルクローズ）
```

**★本数と量を聞かない理由：**聞いた瞬間に、責められている画面になります。
「ほかの仕事」で時給や職種を聞かないのと同じです。
**そして二値で足ります。**中央値で二分する必要すらありません。

### 7-3｜★既存の食事タグと二重にしない

**飲酒は、すでに食事のタグに「遅い時間にお酒」があります。**

```
新設「その日飲んだか」   → 脱水・粘膜への影響を見る
既存「遅い時間にお酒」   → 逆流への影響を見る（食事と就寝の族）

★別々の族として扱い、二重計上しない
★既存のタグを消さない
```

### 7-4｜族

**★中核5項目に入れないでください。**憲章 §3-1「任意項目は必ず別の族」。

```
嗜好品の族（2つ）
  ① 吸った日 ／ 吸わなかった日
  ② 飲んだ日 ／ 飲まなかった日

★この2つの中だけで BH-FDR
★3ゲートを例外なく適用
```

### 7-5｜★言ってはいけないこと（憲章 §2-1 に追記）

```
✗ 「本数を減らしましょう」
✗ 「禁煙をおすすめします」
✗ 「飲酒量が多いです」
✗ 「控えたほうがよいでしょう」
✗ 「◯日連続で吸っています」
```

**「働きすぎです」「バイトを減らしましょう」と同じ線です。**
アプリが出せるのは事実だけで、判断は本人のものです。

**★この項目では特に厳しく守ってください。**
言われた瞬間に、正直に書かなくなります。
**そして書かれなくなったら、この項目を作った意味が消えます。**

### 7-6｜データモデル

```ts
// 既存の日次記録に2列を足す。新しいテーブルを作らない
smokedToday?: boolean      // 未成年は null のまま
drankToday?: boolean

// ★本数・量・銘柄のフィールドを作らない
// ★RLS は本人のみ。教師・管理者のポリシーを作らない
// ★守りのテスト3本の FORBIDDEN_KEYS に追加：
//    'smokedToday','drankToday'
```
