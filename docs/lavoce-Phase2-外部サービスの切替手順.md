## ★★★ 最重要：仕様書のURLが間違っています ★★★

| | |
|---|---|
| 仕様書 §7-1 が書いている | `https://woolsong.app/api/line/webhook` |
| **実際に存在するルート** | **`https://woolsong.app/api/line-webhook`** |

ハイフン1つで、階層がありません。
**仕様書のとおりに入れると 404 になります。**
LINE コンソールの「検証」ボタンが失敗し、
**LINEからの通知が全部届かなくなります。**

### LINE コンソールに貼り付ける値（★これをコピーしてください）

```
https://woolsong.app/api/line-webhook
```

## 7-1｜LINE（★これが Phase 4 を止めている項目です）

調べた結果、仕様書が想定しているより小さい作業です。

| 仕様書の項目 | このアプリでの状況 |
|---|---|
| Webhook URL の変更 | ★必要。上のURL |
| 「検証」で 200 を確認 | ★必要 |
| LIFF のエンドポイント | **使っていません**（該当なし） |
| LINE Login のコールバック | **使っていません**（該当なし） |
| リッチメニュー・定型文のリンク | コードには1つもありません。コンソール側をご確認ください |
| 友だち追加URL（line.me） | ★変更不要 |

★コードで使っているのは Messaging API だけです
　（`LINE_CHANNEL_SECRET` と `LINE_CHANNEL_ACCESS_TOKEN`）。

### 手順

- [ ] 1. LINE Developers コンソール → 該当チャネル → Messaging API 設定
- [ ] 2. Webhook URL を `https://woolsong.app/api/line-webhook` に変更
- [ ] 3. 「検証」を押して **200** が返ることを確認する
- [ ] 4. 実際に友だち追加して、返信が届くことを確認する
      （「Woolsongを友だち追加いただきありがとうございます。」と返ります）

**★§16-1: 転送を有効にする前に、必ずここを終わらせてください。**
**Webhook は 308 を追いません。**

### ついでにお願いしたいこと（改名の積み残し）

アプリの中に「①LINEで『La Voce』を友だち追加」という案内が
残っています。これは **LINE公式アカウントの表示名**で、
コードではなく LINE の管理画面で決まります。

- [ ] 5. 公式アカウントの表示名を「Woolsong」に変更する
- [ ] 6. 変更したら教えてください。アプリ側の文言を合わせます

★先にアプリ側だけ変えると、その名前で探しても見つかりません。

## 7-2｜Resend（★急ぎません）

調べた結果、**利用者にメールは送っていません**。

`RESEND_API_KEY` を使っているのは `app/api/feedback/route.js` の
1ファイルだけで、それは**坂本さん宛のフィードバック通知**です。
本文にリンクは入っていません。

| | |
|---|---|
| 利用者向けのメール | Resend では送っていません（認証メールは Supabase 側） |
| 本文中のリンク | ありません |
| Phase 3・4 を止めるか | ★止めません |

### 手順（やるとしても、あとで構いません）

- [ ] 1. Vercel の環境変数 `FEEDBACK_FROM_EMAIL` の現在値を確認する
      （設定されていると、コードの既定値は使われません）
- [ ] 2. `@woolsong.app` から送りたい場合、Resend でドメイン認証
      （SPF / DKIM / DMARC を Vercel の DNS に追加）
- [ ] 3. ★認証が完了してから、送信元を変える

**★§16-3: 認証が終わる前に送信元を変えると、メールが1通も届かなくなります。**

## おすすめの順番

**LINE だけ先に、単独でやってください。**
