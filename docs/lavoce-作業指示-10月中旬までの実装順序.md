## 4. ★G4の前にやること

### 4-1｜バックアップの復元を、一度通す

「優先順位つき残タスク.md A-P0-1」です。**G4は既存データの移行を伴うので、その前に必ず。**

```
□ 本番DBのダンプを取るスクリプト（1コマンド）
□ ダンプの健全性検証（テーブルごとの行数・最新レコード日時）
□ 別環境への復元手順を docs/backup-restore.md に
□ ★坂本さんが手順書を見ながら実際に復元し、
   復元先でログインして記録が読めることを確認する
```

**★これを通していない状態でG4に入らないでください。**20人に配った後の移行です。

### 4-2｜レッスンモードの解体を先に

G4のレッスン日程・振替は、解体後の構造の上に載ります。**順番を逆にすると二度書きになります。**

解体の手順は「レッスンモードの解体.md §1-3」のとおり：
**コードを消す前に、現在「レッスンモード」と呼ばれる画面・機能を1行ずつ列挙し、DB書き込みの有無（既存データ件数を含む）と他画面からの参照有無を報告し、坂本さんの承認を得てから削除する。**

★消す場合もデータは残し、画面だけ外す（`deletedAt`）。**一括削除はしない。**
