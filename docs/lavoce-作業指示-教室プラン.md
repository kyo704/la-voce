**完了の定義**：下の A-2 のテストが全部通り、

## C. 段階3｜先生の招待と担当の割り当て

### C-1 ｜ 先生を教室に招待する（2日）

**参照：仕様書 §6.1・§6.2**

```
owner / admin が招待コードを発行 → 先生本人が承認して参加
7日で失効 ・ 1回だけ有効 ・ 0/O/1/l/I を除いた文字
```

**招待コードの画面には、必ず教室名を表示すること。**
どこに参加しようとしているのか分からないまま承認させないこと。

---

### C-2 ｜ 役割の変更と、担当の割り当て（2日）

```
owner / admin が
   ・先生の役割を変える（owner / admin / teacher）
   ・生徒に担当の先生を割り当てる（1人の生徒に複数の先生を割り当てられる）
   ・担当を外す（Assignment.endedAt を入れる。行は消さない）
```

**必須の条件**

- **担当が変わったら、生徒に必ず通知する**（新しい先生に健康の面が見えるため）
- **担当の割り当てに、生徒の承認は要らない**（教室内の運営だから）
- **owner は最低1人。** 最後の owner を降格・削除できないようにする
- 担当を外した瞬間に、**過去の分も含めて見えなくなる**（A-2 の 13）

**完了の定義**：1人の生徒に3人の先生を割り当てられる。
1人を外すと、その先生からその生徒が即座に見えなくなる。

## D. 段階4｜生徒の複数教室

### D-1 ｜ つながり画面（2日）

**参照：仕様書 §4.2**

```
生徒が、所属している教室を一覧で見られる
教室ごとに、担当の先生と、共有している内容が書かれている

```

**「つながりを解除する」を、探さないと見つからない場所に置かないでください。**

---

### D-2 ｜ 教室ごとの共有設定（2日）

**参照：仕様書 §3.2・§9 の `ShareScope`**

```
共有する相手   ● 担当の先生だけ（既定）  ○ 担当の先生と、教室の管理者
共有する内容   声 / 症状 / 睡眠 / 活動 / 水分 / 食事 / 体組成 /
              心の余裕 🔒 / 稽古ノート / 学ぶのメモ
```

**必須の条件**

- **`mental` の既定は false。変更しないこと**
- **記録画面に 🔒「先生には見えません」のバッジを常時表示する**
- 変更は**即時反映**。先生側にキャッシュを残さない
- **教室ごとに別々の設定**（1つの設定を全教室で共有しない）

## E. 段階5｜レッスン日程

### E-1 ｜ Lesson を (教室 × 先生 × 生徒) で作る（2日）

**参照：仕様書 §5.1**

- 日時は必ず **UTC ＋ tz** で保持（国際展開仕様 §2.3）
- **`teacherNote` は先生専用。生徒に表示しない**
- 繰り返し（毎週◯曜◯時）に対応する

---

### E-2 ｜ 見える範囲（1日）

**参照：仕様書 §5.2**

```
生徒        … 自分のレッスン全部を、教室をまたいで1つのカレンダーに
担当の先生   … 自分が担当するレッスン
管理者      … その教室のレッスン全部
```

**生徒のカレンダーは、必ず教室を横断して1つに統合してください。**
教室ごとに別のカレンダーにすると、重なりに気づけません。

---

### E-3 ｜ ★ 重なりの検出（2日）

**参照：仕様書 §5.3**

| 検出するもの | 誰に出すか |
|---|---|
| **同じ生徒の時間が重なった** | 生徒と、両方の先生 |
| **同じ先生の時間が重なった** | その先生と、教室の管理者 |
| 1日のレッスンが4件を超えた | 生徒本人にだけ、そっと |

```
⚠ 9/3（火）15:00 が2件重なっています
    ◯◯音楽教室 ・ 山田先生
    △△養成所 ・ 鈴木先生
```

**必須の条件**

- **警告を出すだけ。自動でレッスンを動かさない**
- **予約を拒否しない**（本当に重なることがあります）
- **教室をまたいだ重なりも検出する**（生徒の側から見た重なり）

**完了の定義**：別々の教室に登録された2件が重なったとき、生徒に警告が出る。

---

### E-4 ｜ 先生の画面から生徒の状態へ（1日）

```
今日のレッスン
  15:00  田中○○   ⚠ 記録 3/7日 ・ 偏差値 41   →
```

**タップしたとき**

- **担当している生徒**  → その生徒の状態ページへ
- **担当していない生徒** → 日程の詳細だけ。状態は出さない

**ここで `canView(viewer, org, student, 'health')` を必ず通してください。**

## G. 禁止事項

- ❌ **管理者に、担当していない生徒の健康データを見せない**（仕様書 §3）
- ❌ `canView()` を通さないデータ取得を作らない
- ❌ **画面側で権限を判定しない**
- ❌ 担当を外れた先生に、**過去の分**を見せ続けない
- ❌ **アプリ内メッセージ・チャット・DM を作らない**（提案が来たら断る）
- ❌ **空き枠の公開・予約の受付・部屋の管理を作らない**
- ❌ レッスン料の決済・請求書・返金を作らない
- ❌ 重なりを検出したときに、**自動でレッスンを動かさない・予約を拒否しない**
- ❌ `ShareScope.mental` の既定を true にしない
- ❌ 共有設定を、全教室でひとつにまとめない
- ❌ 同意の記録を上書きしない
- ❌ **A-3 を飛ばして B に進まない**
- ❌ B-3 で、突き合わせをせずに旧経路を消さない
- ❌ 今回の範囲外（§13 の 7〜11）に手をつけない
