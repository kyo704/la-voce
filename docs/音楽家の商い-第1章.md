# 01　時期を外すと、何をしても届かない

## 読む前に

同じ会場、同じ料金、同じ主催で、1年目249名、2年目120名。
**何が起きたのだと思いますか。**

```
・演奏の質が落ちた
・宣伝が足りなかった
・その日、ほかの催し物と重なっていた
```

**★どれも正解になり得ます。**
この三つは同時に起こりますし、切り分けられないことのほうが多い。
ここで考えてほしいのは、**そのうち一つだけが、公演の前に調べられる**ということです。

## 本文

**お客さまの数は、こちらの努力だけでは決まりません。**
**その日、ほかへ行く理由がどれだけあったかで決まります。**

### ★見るのは「日」ではなく「時間帯」です

ここを取り違えている人がとても多い。

**「その日、地域に行事がない日」を探そうとすると、見つかりません。**
夏も秋も、どこかでは必ず何かをやっています。祭りも、市も、体育行事も。
**カレンダーの上では、空いている日などほとんど存在しません。**

**探すのは、一日のなかの空白です。**

盆明けの週末を思い浮かべてください。
たしかに祭りをやっている地区はあります。
**しかしその多くは、夕方から夜です。**
帰省の客も送り出したあと、**日中にすることが、ぽっかりと空いている。**

そこに十四時開演を置くと、**誰とも競合しません。**
夜の祭りに行く人も、昼なら来られます。

逆に、十一月の土曜日の午後はどうでしょう。
文化祭、収穫祭、地域の発表会、ホールの自主事業。
**同じ時間帯に、行き先がいくつもあります。**

**同じ公演でも、この二日では別の結果になります。**
これは運ではありません。**調べれば分かることです。**
そして多くの音楽家は、調べていません。

### 空白が生まれやすい時間帯

```
・盆明けの週末の★日中（祭りは夜に集まりやすい）
・正月明けの中旬（松が明けて、まだ何も始まっていない）
・梅雨明けの直後
・連休が明けた次の週末
・地域の行事が★午前で終わる日の、午後
```

### 埋まりやすい時間帯

```
・文化祭・学園祭の季節（九月下旬〜十一月）の★昼
・運動会・発表会の午前〜昼
・農繁期（田植え・稲刈り。★地方では朝から夕方まで人が出ません）
・大型連休の当日（★遠出の予定に負けます）
・選挙の投票日
・同じホールの自主事業と近い日
```

**同じ日でも、午前・午後・夜で、空いている場所が違います。**
「その日はやめよう」と決める前に、**時間をずらせないかを考えてください。**

### 調べ方

```
① 市・町の広報の行事欄を、前年の同じ月で確認する
② 観光協会のイベントカレンダー
③ 会場の年間予定表（★主催事業は強敵です）
④ 近隣の中学・高校の文化祭の日程
⑤ 農協や地域の回覧板
```

**★そのとき、日付だけでなく開始時刻を控えてください。**
「同じ日にある」と「同じ時間にある」は、まったく違う話です。

**★ひとつ、逆説があります。**

**ホールが空いている日は、ほかの人も避けた日かもしれません。**
「予約が取れた」を「良い日だった」と勘違いしないでください。

日程は、集客の手段のひとつではありません。**上限を決めるものです。**
どれだけ良い演奏をしても、その日に来られる人の数を超えることはできません。

## 覚えておくこと

> **見るのは日ではなく時間帯。日程は、集客の上限を決める。**

## 用語

**動員** 実際に来た人数。★売れた枚数ではありません。
340枚発行して来場249名なら、**91枚ぶんの席が空いています。**

**逆風要因** 同じ日に、客が別の場所へ行く理由。★先に数えるもの。

## 自分の場合を書く

**Q1.** 次の本番の日程を決めるとき、あなたの土地では何を調べますか。

**Q2.** あなたの地域で、一日のうち「みんなの予定が空いている」のは
何曜日の、何時ごろですか。逆に、絶対に外すべき時間帯は。

**※ 答え合わせはありません。採点もしません。**
**あなたの土地と、あなたの活動では、本文と違う答えが正しいことがあります。**
**書いたものは、あなたの記録に残ります。**

# 02　アンケートは、感想を聞く紙ではない

## 読む前に

アンケートで、いちばん価値がある欄はどれだと思いますか。

```
・感想の自由記述
・どの曲が良かったか
・住所と名前
```

★当てなくて構いません。読み終わったあとに、もう一度考えてください。

## 本文

**アンケートは顧客名簿です。感想はおまけです。**

演奏会のアンケート回収率は、ふつう二割から三割です。
熱心なお客さまが多い公演では、六割近くまで上がることもあります。

**しかし、回収率が高くても意味がありません。**
**住所や連絡先まで書いてくれた人の数が、次につながる人数だからです。**

249名が来て、連絡先まで残ったのが78名。
**次に届けられるのは、三割だけ**です。
残りの171名は、どこの誰か分かりません。

**来年また、ゼロから集めることになります。**

**これが、自主公演がいつまでも黒字にならない最大の理由です。**
毎回ゼロから集めているからです。

### 何を聞くか

**感想の欄は、いちばん最後で構いません。**
先に置くべきは、**次の公演を組み立てるための情報**です。

```
① 名前
② 住所（★次の案内を封書で送るため）
③ メールアドレス
④ 年代
⑤ どこで知ったか（★宣伝の効き目が、ここでしか分かりません）
⑥ 好きな曲・聴いてみたい曲、ふだん聴く音楽
⑦ 誰と来たか（一人・夫婦・親子・友人）
```

**④と⑤と⑥が、次の公演の設計図になります。**

年代が分かれば、**どの層が抜けているか**が見えます。
どこで知ったかが分かれば、**次にお金と手間をどこに使うか**が決まります。
何を聴きたいかが分かれば、**プログラムを勘で組まずに済みます。**

### 名簿があると、何ができるか

```
・次の公演の案内を、封書で送れる
・★年賀状を出せる
・チラシを「置く」のではなく「届ける」ことができる
・「あの方は親子で来てくださった」と、思い出せる
```

**年賀状は効きます。**百通で六千円ほど。
**一年に一度、名前を思い出してもらう費用としては安い。**
そして相手は、**すでに一度お金を払って来てくれた人**です。

「音楽家からの年賀状」は、捨てられにくいという利点もあります。

### 名簿の先に、人脈があります

**一枚のアンケートで得られるのは、一人ではありません。**

来てくださった方の後ろには、その人の家族、友人、
勤め先、通っている教室、地域の集まりがあります。
**そして人は、自分が良いと思ったものを、人に言いたい生きものです。**

だから、**すでに来てくださった方を大事にすることが、
いちばん安い新規集客**になります。

```
・案内を、いちばん早く送る
・名前を覚えて、当日に声をかける
・「二枚目はお連れさまの分に」と言える形にしておく
・年賀状や礼状を、途切れさせない
```

**★お得意様は、放っておくと消えます。**
逆に、こちらから届け続けている限り、**その人が次の客を連れてきます。**
一年に数回の手紙で、**一人が二人になり、二人が四人になる。**
広告費をかけずに客が増えるのは、この経路だけです。

### 回収率より、記入率を上げる

```
・鉛筆を席に置く（★ペンより書かれます）
・記入台を出口の手前に置く
・回収箱を「置く」のではなく、★スタッフが手で受け取る
・「演奏会のご案内をお送りします」と、住所欄の上に書く
・配るのは開演前。書いてもらうのは休憩と終演後
```

**★出口で手渡しに受け取ると、記入率が変わります。**
箱に入れる形では、書いた人しか近づきません。

### 名簿は、資産であり責任です

```
・「演奏会情報を送る」と書いたなら、その目的にしか使えない
・鍵をかけて保管する
・★団体を誰かに引き継ぐとき、名簿はそのままでは渡せません
```

## 覚えておくこと

> **公演で残るのは、売上ではなく名簿である。**

## 用語

**リスト** 次の公演を知らせられる人の名簿。**枚数ではなく人数が資産。**

**記入率** 来場者のうち、住所や名前まで書いた人の割合。★回収率とは別の数字。

## 自分の場合を書く

**Q1.** あなたの公演で、住所まで書いてくれる人を増やすには、
何を一つ変えますか。

**Q2.** いま、お客さまの名前を何人思い出せますか。
その人たちに、一年で何回、こちらから連絡していますか。

**※ 答え合わせはありません。採点もしません。**
**あなたの土地と、あなたの活動では、本文と違う答えが正しいことがあります。**
**書いたものは、あなたの記録に残ります。**

# 03　いま聴く人だけを見ていると、未来がなくなる

## 読む前に

クラシックを聴かない人を呼ぶために、いちばん確実なのは。

```
・有名な曲だけを並べる
・チケットを安くする
・子どもを呼ぶ
```

★当てなくて構いません。読み終わったあとに、もう一度考えてください。

## 本文

地方の自主公演では、来場者の八割から九割が五十代以上、
**四十代がほぼゼロ**という分布になることが珍しくありません。

高齢のお客さまは、いちばん来てくださる、ありがたい層です。
**ただしその層だけを見て活動を組み立てると、十年後に演奏する場所がなくなります。**

**私たちには、未来が要ります。**

### 三つの層を、別々に考える

```
① いま聴く層      いちばん来る。今日の売上を支える
② いま聴かない層  二十代〜六十代。★数がいちばん多い
③ 子ども          ★一枚では終わらない。親と、二十年後を連れてくる
```

**②を無視すると裾野が広がりません。③を無視すると次の世代がいなくなります。**

### ★「子どもは一枚しか買わない」は、間違いです

子ども料金を安くすることを、**損だと思わないでください。**

**子どもは、一人では来ません。**

```
子ども 500円 ＋ 保護者 3,000円 ＝ 3,500円
```

**そして親は、四十代です。**
年代の穴が、ここでしか埋まりません。
四十代を直接呼ぶ方法はほとんどありませんが、
**子どもを通してなら、来ます。**

きょうだいで来れば三枚、祖父母が付いてくれば五枚になります。
**一枚が二枚以上になるのが、この層の性質です。**

さらにその子が二十年後にお客さまになります。
**短期でも長期でも、二倍以上の見返りがある**——
子ども料金は、値引きではなく**そういう計算**です。

### 安くするだけでは、楽しめません

呼ぶところまでが半分。**楽しませるところまでが、もう半分です。**

```
・曲を短く切る（★一曲まるごとは長い）
・何を聴けばいいかを、先に言う
・立ってよい、動いてよい時間を作る
・★終演後に、楽器や譜面に触れる時間を作る
```

### ★選曲を、間違えないでください

子ども向けというと、**童謡や、子ども用の易しい曲**を並べたくなります。
**そうではありません。**

子どもは、知っている曲だから喜ぶのではありません。
**聴いた瞬間に「これは楽しい」と体で分かる曲**に反応します。
知らない曲でも、いい曲は伝わります。**子どもを、なめないでください。**

```
・★アップテンポを軸にする（速い曲は、言葉がなくても伝わります）
・拍がはっきりしている、体が動く曲
・音量と音色が大きく動く曲（★静かなだけの曲は、続けない）
・同じ国・同じ年代の曲ばかりを並べない
　→ 似た響きが続くと、大人より先に子どもが飽きます
・イタリア、ドイツ、フランス、ロシア、日本、南米。
　★時代も、色も、混ぜる
```

**並べ方は「易しい順」ではなく「飽きない順」です。**

### トークが、演奏と同じくらい効きます

```
・曲の前に、一言だけ。★長い解説は要りません
・「どこを聴くか」を一つだけ渡す（★二つ渡すと、どちらも残りません）
・専門用語を使わない
・子どもに直接、話しかける（客席全体に向けて話さない）
・★間違えても笑える空気を、最初の一曲までに作る
```

**楽しみ方を教えるところまで含めて、はじめて次につながります。**

これは慈善ではありません。**投資です。**

## 覚えておくこと

> **子どもの一枚は、親の一枚と、二十年後の一枚を連れてくる。**

## 用語

**客層** 来ている人の年代・性別・地域の分布。★アンケートで毎回とる数字。

**裾野** その音楽を聴く人の全体の広さ。★いま聴かない人を一人増やすこと。

## 自分の場合を書く

**Q1.** 子どもに聴かせるなら、あなたは何を弾きますか。
童謡以外で、三曲挙げてください。なぜその三曲ですか。

**Q2.** あなたの土地で、四十代を呼ぶ入口は何になりますか。

**※ 答え合わせはありません。採点もしません。**
**あなたの土地と、あなたの活動では、本文と違う答えが正しいことがあります。**
**書いたものは、あなたの記録に残ります。**

# 04　ブランドは、同じ曲を繰り返すことから始まる

## 読む前に

名前を覚えてもらうために、初期にいちばん効くのは。

```
・毎回ちがう曲で幅を見せる
・同じ曲を、あちこちで繰り返す
・難しい曲に挑戦する
```

★当てなくて構いません。読み終わったあとに、もう一度考えてください。

## 本文

**初期に、レパートリーの広さを見せてはいけません。**

**「あの人の、あの曲」**が一つできるまで、同じ曲を繰り返してください。
自分の技術がいちばん映える曲を、**あちこちで、何度も。**

聴衆の耳は、繰り返しで馴染みます。
そして馴染んだ曲は、次に聴いたとき**「知っている」に変わります。**

**知っている曲がある人が、また来ます。**

幅を見せるのは、名前が知られてからです。
**順番を逆にすると、何をする人か伝わらないまま終わります。**

### 舞台の上でつくるもの

```
・立ち振る舞い
・笑顔
・言葉づかい
・演奏の質
```

**この四つで、「ふつうの人とは違う」と感じてもらいます。**
**演奏だけでは足りません。**

聴衆は、音だけを聴いているのではありません。
**舞台に立っている人間を見ています。**

### ★舞台を降りてからが本番

```
・ロビーでお客さまと話すときの距離感と言葉づかい
・★会場を出るまで、私服も見られている
・常に名刺を持ち歩く
```

**次のお客さまが、どこで現れるか分かりません。**
そして名刺は、次の演奏の場所を連れてくることがあります。

**真摯であることは、演出ではありません。**
ただし、真摯さが伝わる振る舞いは、**身につけるものです。**

### やらないことを決める

**ブランドは、やることではなく、やらないことで決まります。**

```
例）「ポップスは演奏しない」
```

**これを決めた瞬間に、何をする人かが伝わります。**
断ることで、輪郭ができます。

## 覚えておくこと

> **ブランドは「あの人の、あの曲」が一つできたときに始まる。**

## 用語

**十八番** 自分の技術がいちばん映える曲。★初期は、これを繰り返すことが戦略。

**接触回数** その音楽に触れた回数。★回数が増えるほど、好意的に受け取られます。

## 自分の場合を書く

**Q1.** どこでも弾く一曲を決めるとしたら、何にしますか。理由も。

**Q2.** 人から「あの人の、あれ」と言われるとしたら、
「あれ」に何が入ってほしいですか。

**※ 答え合わせはありません。採点もしません。**
**あなたの土地と、あなたの活動では、本文と違う答えが正しいことがあります。**
**書いたものは、あなたの記録に残ります。**

# 05　いちばん強い宣伝は「たまたま聴いてしまった」

## 読む前に

クラシックを聴かない人が、初めて心を動かされる場面は。

```
・チラシを見て、興味を持って買いに来たとき
・通りかかった催しで、偶然に聴いたとき
・映像で見たとき
```

★当てなくて構いません。読み終わったあとに、もう一度考えてください。

## 本文

**聴かない人は、チケットを買いません。買う理由がないからです。**

だから最初の接点は、**買わずに聴ける場所**でなければいけません。

```
・市や県が主催する祭り、記念式典
・商店街や駅前の催し
・道の駅、観光施設のロビー
・学校公演
```

**わずかな出演料でも構いません。そこは宣伝の場です。**

### なぜ効くのか

チラシを見て来る人は、**すでに興味がある人**です。
祭りで偶然に聴いた人は、**興味がなかった人**です。

**裾野を広げるとは、後者を一人増やすことです。**

そして偶然に出会った音楽は、記憶に残ります。
**探して来た音楽より、強く残ることさえあります。**

### 気をつけること

```
・音響は期待できません。★それでも成立する曲を選ぶ
・立ち止まる人は少ない。★短く、聴き映えのする曲
・★名刺とチラシを必ず持っていく
・その場で名簿の受け皿を用意する
```

**演奏して終わりにすると、何も残りません。**

### 屋外は、当てにしない

**屋外の催しは、天候で消えます。**
台風ひとつで、宣伝の計画がまるごと飛ぶことがあります。

**★屋外の宣伝は、計画の柱にしないでください。**
当たれば得、外れても痛くない位置に置きます。

## 覚えておくこと

> **買わずに聴ける場所が、聴かない人への唯一の入口。**

## 用語

**接点** その人が、あなたの音楽に初めて触れる場面。★買う前の接点をいくつ持つか。

## 自分の場合を書く

**Q1.** あなたの町で、たまたま人が通る場所はどこですか。

**Q2.** そこで演奏するには、誰に話をつける必要がありますか。

**※ 答え合わせはありません。採点もしません。**
**あなたの土地と、あなたの活動では、本文と違う答えが正しいことがあります。**
**書いたものは、あなたの記録に残ります。**

# 06　値段は、あなたではなく土地が決める

## 読む前に

チケット代を決めるとき、最初に調べるべきものは。

```
・かかった費用
・その土地のほかの公演のチラシ
・自分の演奏の質
```

★当てなくて構いません。読み終わったあとに、もう一度考えてください。

## 本文

**どれだけ立派なチラシを作っても、その土地の相場は決まっています。**

三千円が当たり前の地域で五千円をつければ、
**演奏の質とは関係なく、売れにくくなります。**
逆に、相場が五千円の地域で三千円をつければ、
**安いのではなく「そういう水準の演奏会」だと受け取られます。**

**値段は、質を伝える情報でもあります。**

### 決め方の手順

```
① その土地のチラシを、できるだけ多く集める
   （ホールのロビー、市民会館、図書館、観光案内所）
② 会場の規模ごとに価格を並べ、平均を出す
③ 自分たちの位置を決める（平均か、上か、下か）
④ 会場の格・敷居・キャパシティで調整する
⑤ 来場見込み数と掛けて、収入を試算する
```

### アンケートが、次の値段を教えてくれます

```
「妥当」が八割を超え、「安い」が一割近く出ているなら
　→ ★上げてよい合図です
```

百二十名の公演で五百円上げれば、六万円の増収です。
**費用は一円もかかりません。**

**そして値段は、下げるより上げるほうが難しい。**
**上げられる合図が出ているのに上げないのは、機会を捨てています。**

### 会場が価格を決める

```
・格式の高いホール → 高くできる。★同時に敷居も上がる
・小さなサロン     → 高くしにくい。★満席にはしやすい
・キャパが大きい   → 単価より、埋まるかどうかが問題
```

**五百席で三千円より、八十席で五千円のほうが手元に残ることがあります。**

### ★売れ残った席の値段は、ゼロ円です

当日、空いている席には**一円の価値もありません。**
公演が終われば、その席は消えます。

**だったら、埋めてください。**

```
・売れ残った分を、招待に回す
・★まだ来たことのない人に、優先して配る
・学生・子ども・地域の福祉施設に、無料または割引で開放する
・当日券を、終演三十分前から値下げする
```

**これは値崩れではありません。広告費です。**

チラシを千枚刷るのに数万円かかります。
**空席を十枚配って、そのうち三人が名前と住所を書いてくれたら、
チラシ千枚より確実です。**

しかも、来た人は**中身を知った状態**で帰ります。
次の案内が、はじめて「知っている人からの手紙」になります。

```
★ただし、三つだけ守ってください

① 先に買ってくれた人より良い席にしない
② 「無料でも入れる公演」だと思われる配り方をしない
   （★毎回、誰にでも配ると、値段が壊れます）
③ 配った人にこそ、アンケートを必ず書いてもらう
```

**敷居が高いと思っている人ほど、お金を払っては来ません。**
その人を中に入れる手段が、**ゼロ円の席**です。

### 費用から値段を決めない

総支出を来場者数で割ると、必ず高くなりすぎます。
**その数字でチケットは売れません。**

**値段は相場が決め、費用は別に削るものです。**

## 覚えておくこと

> **値段は相場が決める。費用は、値段とは別に削る。**

## 用語

**相場** その地域で、同じ規模の公演につけられている価格帯。★チラシを集めれば分かります。

**CPA（顧客獲得単価）** 一人に来てもらうのにかかった費用。**総支出 ÷ 来場者数。**

## 自分の場合を書く

**Q1.** あなたの地域の相場は、いくらだと思いますか。根拠も一行で。

**Q2.** 前回、売れ残った席は何席でしたか。
その席を、次はどう使いますか。

**※ 答え合わせはありません。採点もしません。**
**あなたの土地と、あなたの活動では、本文と違う答えが正しいことがあります。**
**書いたものは、あなたの記録に残ります。**

# 07　プログラムは、演出の一部である

## 読む前に

プログラムの厚さを決めるものは。

```
・曲数
・予算
・その公演をどう感じてほしいか
```

★当てなくて構いません。読み終わったあとに、もう一度考えてください。

## 本文

**プログラムは、情報を載せる紙ではありません。**
**手に持った瞬間の重さと手ざわりが、その公演の格を先に伝えます。**

```
格式を感じてほしい   → 厚い紙、少ない文字、広い余白
親しみを感じてほしい → 軽い紙、写真を多く、大きな文字
学んで帰ってほしい   → 解説を厚く、ただし★易しく
```

**曲数から決めてはいけません。**
**どう感じてほしいかを決めてから、量を決めます。**

### 載せるもの

```
① 表紙
② 出演者の写真
③ 目次
④ プロフィール
⑤ 曲目
⑥ 曲の解説
⑦ 主催者からのことばと、協力者への感謝
⑧ 注意事項
```

### 解説の書き方

```
・難しくしすぎない
・想像しやすい絵や写真を置く
・★文字を詰め込まない
・学術的になりすぎない
```

**解説は、知識を見せる場所ではありません。**
**次の十分を楽しむための準備です。**

書いた本人には物足りないくらいが、ちょうどよい分量です。

### ★誤植は必ず出ます

二十数ページのプログラムを作れば、誤植は数か所出ます。
曲名、作曲家の表記、歌詞、協力者名の重複。

```
・全員で、日を分けて二回読む
・★協力者の名前は、声に出して読み合わせる
・可能なら、外部の人に一回見てもらう
```

**協力者の名前の間違いは、いちばん失礼な誤植です。**
**そして、いちばん起きやすい誤植でもあります。**

## 覚えておくこと

> **プログラムの紙の厚さは、その公演の格を先に伝える。**

## 用語

**宣材写真** 宣伝に使う撮影済みの写真。★一度撮れば数年使えます。費用は年で割って考えます。

## 自分の場合を書く

**Q1.** 次のプログラムに、あなたなら何を入れますか。
逆に、入れなくてよいものは。

**Q2.** それは、誰が読むことを想定して書きますか。

**※ 答え合わせはありません。採点もしません。**
**あなたの土地と、あなたの活動では、本文と違う答えが正しいことがあります。**
**書いたものは、あなたの記録に残ります。**

# 08　SNSは、名前のない人には効かない

## 読む前に

無名の若手にとって、SNSの集客効果は。

```
・最も強い
・中くらい
・ほとんどない
```

★当てなくて構いません。読み終わったあとに、もう一度考えてください。

## 本文

**正直に言います。ほとんど効きません。**

理由は単純です。
**SNSは、すでに知られている人を増幅する道具**であって、
**知られていない人を知らせる道具ではない**からです。

自主公演の来場者に「どこで知りましたか」と聞くと、
**半分以上が「出演者の知人・関係者」になることが珍しくありません。**
ホームページやSNSから来た人は、ごく少数です。

そして、来場者の多くがLINEを日常的に使っていたとしても、
**それはSNSから集客できることを意味しません。**

**★「利用率が高い」と「そこから集客できる」は、別のことです。**

投稿を増やしても、見ている人がいなければ届きません。
**そして無名の演奏家の投稿を、見ている人はいません。**

### では、何をするか

**★人を呼べるゲストを招くことです。**

```
自分の客 40名 ＋ ゲストの客 80名 ＝ 120名
```

**そしてその八十名を、自分のお客さまにします。**

そのために必要なのは、**ゲストより良い時間をつくること**です。

```
・構成（★どの順番で聴かせるか）
・演奏の質
・振る舞い
・言葉づかい
```

**ゲストの客の前で、ゲストを超える。**
これは失礼な話ではありません。**呼ばれた側も、それを期待しています。**
**超えられない相手を呼んでも、意味がありません。**

### それでもSNSを持つ理由

```
・すでに知っている人が、活動を確認する場所
・★名刺を渡したあとに、見に来られる場所
・記録として残る場所
```

**集客の道具ではなく、信用を確かめられる場所として置いておきます。**

## 覚えておくこと

> **SNSは知られている人を増幅する。知られていない人には、ゲストが要る。**

## 用語

**認知経路** どこで公演を知ったか。★アンケートで毎回とる一問。

**バーター** 互いの客を交換する形の共演。★呼べる人を呼び、その客を自分の客にする。

## 自分の場合を書く

**Q1.** いま呼べるゲストを、三人挙げてください。
その人に、こちらから何を返せますか。

**Q2.** あなたのSNSは、集客につながっていますか。
つながっているとしたら、どの投稿からでしたか。

**※ 答え合わせはありません。採点もしません。**
**あなたの土地と、あなたの活動では、本文と違う答えが正しいことがあります。**
**書いたものは、あなたの記録に残ります。**

# 09　請求書は、あなたの値段を宣言する紙

## 読む前に

演奏の依頼を受けたとき、請求書に書くべき項目は。

```
・演奏代だけ
・演奏代と、事務・企画費を分ける
・一式としてまとめる
```

★当てなくて構いません。読み終わったあとに、もう一度考えてください。

## 本文

**演奏だけが仕事ではありません。**

企画を立て、曲を選び、共演者を集め、日程を調整し、資料を作る。
**その時間に値段をつけていない人が、あまりにも多い。**

```
演奏代        100,000円
事務・企画費  150,000円
              ────────
合計          250,000円
```

**分けて書くだけで、相手の理解が変わります。**
「演奏に二十五万は高い」は起きますが、
**「演奏十万＋企画十五万」なら、何にお金を払っているかが見えます。**

### 請求書に書くもの

```
・宛名（★様。会社なら御中）
・自分の氏名・住所・電話
・請求日
・請求金額（税の扱いを明記）
・品目（単価 × 数量 ＝ 金額）
・振込先（銀行・支店・店番号・口座種別・番号・名義）
・備考（振込手数料の負担、支払期限）
```

**形式は、一般的なひな形をそのまま使ってください。**
独自の形にする必要はありません。

### ★ギャランティは、演出で変わります

**演奏の質だけで決まると思わないでください。**

```
・言葉づかい
・服装
・返信の速さ
・資料の丁寧さ
・当日の立ち振る舞い
```

**同じ演奏でも、これらが整っている人には高い金額が付きます。**
**そう扱われた人は、次も高く呼ばれます。**

社会的な評価が実力に追いついていなくても、
**それを演出することで、金額は上がります。**
そしてその金額が、次の実力を育てます。

**逆に、一度安く受けると、その値段が自分の相場になります。**

### 安く受けるとき

安く受けてよい場面はあります。**ただし、理由を相手に伝えてください。**

```
「今回は◯◯という趣旨なので、この金額でお受けします」
```

**理由のない値引きは、次から「その値段の人」になります。**

## 覚えておくこと

> **一度受けた金額が、自分の相場になる。**

## 用語

**ギャランティ** 出演料。★演奏の対価だけを指すとは限りません。

**事務・企画費** 演奏以外の準備にかかる労働への対価。★分けて書くことで、初めて存在が見えます。

## 自分の場合を書く

**Q1.** 前回の仕事の金額は、誰が決めましたか。
相手ですか、自分ですか。

**Q2.** 安く受けるとしたら、何を条件にしますか。

**※ 答え合わせはありません。採点もしません。**
**あなたの土地と、あなたの活動では、本文と違う答えが正しいことがあります。**
**書いたものは、あなたの記録に残ります。**
