## 1. 全体の流れ

```
Stage 0  土台            ← すべてに優先。1.5日
Stage 1  記録が続く仕組み  ← 収益に最も効く
Stage 2  観測            ← Stage 1 と並行
   ── 判断ゲート① ここで方針を見直す ──
Stage 3  声の構造変更     ← 専用セッション。他を並行させない
Stage 4  構造変更に依存するもの
Stage 5  画面の作り替え
   ── 判断ゲート② 課金に進むか ──
Stage 6  課金の土台
Stage 7  指導者プラン     ← 収益の本命
Stage 8  拡張
```

**目安：Stage 0〜7 で 4〜6か月**（個人開発＋Sonnet の想定）。

## ── 判断ゲート① ──

**Stage 3 に進む前に、必ずここで止まってください。**

Stage 2 の結果（入力率・離脱の分布・ヒアリング・マイクロ調査）を突き合わせて、
次を確認します。

1. **削った項目の判断は合っていたか**（0-3 と 1-5 の答え合わせ）
2. **何日目に離脱しているか。** 3日目なら入力コスト、14日目なら価値不足
3. **ヒアリングで、仮説が外れた箇所はどこか**
4. **7日目アンケートで、3層（朝30秒／週次の発見／本番）のどれに需要があったか**

**4 の結果によっては、Stage 4・5 の優先順位が変わります。**
「本番に合わせたい」が最多なら、ピーキング曲線を前倒しする、といった判断です。

## 時間がないときに削るもの

**削ってよい**

- Stage 1-6（単位・文字列キー化）→ 国際化を先送りするなら後回し可
- Stage 1-7（環境の自動取得）→ 手入力のままでも動く
- Stage 5-7 5-8（ノート・学ぶの再配置）
- Stage 8 のすべて

**削ってはいけない**

- **Stage 0 のすべて** — データが失われます
- **Stage 3 の Step 1（読み取り互換レイヤー）** — 安全弁です
- **Stage 6-1〜6-4** — 法的義務であり、課金の前提です
- **Stage 7-1 の公開範囲設定** — 記録の質が死にます
- **判断ゲート①②** — 止まらないと、外れた仮説の上に積み上げ続けます
