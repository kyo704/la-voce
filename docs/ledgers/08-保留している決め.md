# 08 ★保留して いる 決め

★★★ここは **決めの 台帳** です。★「まだ 作って いない もの」は 書きません。
　★★あれは 直す もの で、★画面や コードの 中に 注として 置いて あります。
　★★ここに 書くのは ── ★**決めが 要る のに、★まだ 決まって いない もの** です。

★★決まり

```
★1つにつき 5つ 書きます ──
　★何が 決まって いないか
　★いま どう なって いるか（★事実）
　★決めないと 何が 起きるか
　★★引き金 ── ★いつ もう一度 考えるか
　★どこに 注が あるか（★コードの 中）
★★引き金の 無い 保留は、★二度と 見直されません（★2026-09-16 の 覚え）。
```
