**★2日あとに書いた「3ゲート」が有効です。**設計憲章 §1-1 がこれです。


**★確度の星も、残っていたら外してください。**3ゲートは通ったか通らないかの二値で、

### 1-2｜★「30秒モード」に、いま何が入っているか

**坂本さんの指摘で気づいたことがあります。私の設計の見落としです。**

30秒モードと中核5項目を並べます。

| 30秒モード（私の記録では） | 中核5項目 |
|---|---|
| のどの調子 | 睡眠時間 |
| 声の出来 | **本番外の発話時間** |
| 昨夜の睡眠 | 絶対湿度（自動取得） |
| | 本番・レッスンの翌日か |
| | **起きたときのむくみ** |

**重なっているのは睡眠だけです。**

30秒モードが集めているのは**結果（y）**、中核5項目は**原因（x）**です。
つまり——

```
★30秒モードだけを毎日続けても、x は睡眠しか埋まりません。
　絶対湿度は自動なので埋まる。
　しかし「本番外の発話時間」「起きたときのむくみ」が抜け、
　活動の記録がないと「本番の翌日か」も判定できません。

★3ゲートは、x と y の両方が揃った日しか数えません。
```

**きちんと毎日30秒モードを続けている人でも、3ゲートに必要な日数が貯まらない**——
という状態になっている可能性があります。

**確認してほしいこと**

```
□ 30秒（かんたん）モードに、いま何の項目が入っているか。一覧で
□ 「起きたときのむくみ」は入っているか
□ 「本番外の発話時間」の入力形式は何か（数字入力か、選択か）
□ ★項目ごとの記録率を出せるか（どの中核項目が埋まっていないか）
```

**★私の記録が古い可能性があります。**すでにむくみが入っていれば、§2 は半分不要です。

## 2. 中核5項目が埋まる構造に変える

**★§1-2 の確認が終わってから着手してください。**

### 2-1｜★強制しない。配置で解く

```
✗ 中核5項目を必須にする
✗ 埋まっていないことを警告する
✗ 「あと2項目です」と催促する
```

**理由：**催促は憲章 §8-1 の禁止事項です。そして催促は**調子が悪い日の記録率を下げます。**
それは製品の中身を壊します。継続率が上がっても、やりません。

### 2-2｜やること（4つ）

```
① 記録画面の★最上部に、中核5項目を固めて置く。それ以外はその下
   → 上にあるから自然に埋まる。全部★任意のまま

② 30秒（かんたん）モードに「起きたときのむくみ」を足す
   → 3択・1タップ。増えるのは5秒
   → ★「3つだけでいい」という説明は変えない。4つになっても「これだけでいい」

③ ★「本番外の発話時間」を、数字入力から選択に変える
       15分 ／ 30分 ／ 1時間 ／ 2時間以上   の4択
   → 中央値で二分するだけなら、これで足ります
   → ★数字を入れたい人のために、詳細モードには数字入力を残す
   → 既存の数値データは★変換しない。選択肢は代表値（15/30/60/120分）で保存

④ 項目ごとの記録率を測り、★埋まっていない中核項目だけを
   「今日の1つ」の枠に出す
   → ★新機能ではありません。既存の枠の使い道を変えるだけ
   → 文面は事実だけ：「むくみは、まだ3日ぶんです」
   → ★「記録しましょう」「あと◯日です」と書かない
```

**③がいちばん効くと思います。**「本番外で何分話しましたか」に毎日数字で答えるのは、
重すぎます。**中央値で二分するだけなら、4択で十分です。**

### 2-3｜★変えないもの

```
★「とばす」があること
```

## 4. 用語の整理（参考・実装なし）

坂本さんから「この2つは何が違うのか」と聞かれました。**同じデータを違う軸で切っています。**

| | 声の時差マップ | 効いた習慣ランキング |
|---|---|---|
| 問い | **いつ**効くか | **どれが**効くか |
| 軸 | **時間**（何日後） | **項目**（順位） |
| 変数 | 連続量 | 二値（あった／なかった） |
| 手法 | スピアマン順位相関 ρ | Hedges' g ＋ 信頼区間 |
| ラグ | **0〜3日をすべて見る** | **前日→翌日に固定** |
| 図 | ヒートマップ | ドット＆ウィスカー |
| 例 | 「睡眠不足の**2日後**に落ちます」 | 「白米を食べた**翌日**は…」 |

**時差マップ＝時間軸、習慣ランキング＝項目軸。**

★画面の説明文でこの区別が付いていない場合は、§1-3 の一覧に含めてください。
