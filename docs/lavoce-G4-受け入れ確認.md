## ① lessons ── 他人のレッスンが見えないこと

**満たすこと**：+s1 から見えるレッスンのうち、自分のものでない行が **0**。

**確かめ方**（+s1 のセッション）
```sql
select count(*) as "見える行数",
       count(*) filter (
         where not exists (
           select 1 from public.teacher_student_links l
            where l.id = lessons.link_id and l.student_id = auth.uid())
         and (student_id is null or student_id <> auth.uid())
       ) as "★自分のものでない行"
  from public.lessons;
```

**失敗の見え方**：「自分のものでない行」が 1 以上。
直す前は 1 でした（`(org_id IS NULL) OR …` が素通りさせていた）。

## ⑮ オーナーが抜けて、教室は続く ── 契約者の知らせが出ること

**満たすこと**：オーナーが退会しようとしたとき、その教室に★ほかの運営者
（責任者）が残っているなら、**止めずに**次の1行と連絡先が出る。

```
あなたが退会すると、この教室の契約者がいなくなります。
運営を続けるには、運営者にご連絡ください。
   [運営者に連絡する]（mailto・件名に教室ID）
   [了解しました。退会を続けます]
```

**確かめ方**
1. +g4t2 の教室に、+g4t3 が責任者として居ることを確かめる
2. +g4t2 で もっと → アカウントの削除 → 削除する を押す
3. ★止まらず、上の知らせが出ること
4. ★「了解しました」を押すと、もう一度押せば進める状態になること
   （★ここで実際に消さないでください。教室が必要です）

**失敗の見え方**
- 二択（教室を閉じる／教室を残す）が出る → ★止めすぎです。
  責任者が残っているので、教室は続きます。
- 何も出ずに消える → 契約者が黙って居なくなります。
- ★責任者（+g4t3）が抜けるときにも出る → 出しすぎです。
  責任者は契約者ではありません。
- ★生徒（+g4s1）が抜けるときに出る → 出しすぎです。

★「教室を動かせるか」と「誰が払うか」は、別の問いです。
　止めるのは前者が0になるときだけ。後者は知らせるだけです。

　憲章：「★画面ごと権限で囲まないこと。説明・案内・戻る道のどれかを必ず出す。」

### B｜禁じた言い回しが出ていないこと

- 「まだ」（★全面禁止）
- 「確認してください」（急かす言葉）
- 「もう一度お試しください」（★通らない経路に出していないこと）
- 「あなたの出席登録は取り消されました」（主語が人）
- 断定的な相関文（「◯◯が原因です」）
- 他の利用者との比較・平均・順位（★恒久的に作らない）

### C｜戻る道があること

行き止まりが無いこと。権限で止まる画面には、**必ず押せる選択肢**を置きます。
★ボタン1つ＋文章での案内、という形にしないこと（案内も押せるようにする）。

### D｜実機で歩く

iPhone の実機で、A と同じ道を歩きます。
- 入力欄に触れて、画面が拡大しないこと（16px 以上）
- 下端が安全領域に隠れないこと
- 機内モードにして、**白い画面にならない**こと
