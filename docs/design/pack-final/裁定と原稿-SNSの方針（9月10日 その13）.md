# §7 ★note ── 長い版（★柱C・1本目）

## 題

```
　なぜ、点数を出さないのか
```

## 本文（★案・約1,800字）

```
声楽家です。オペラを歌いながら、自分の声のための記録のアプリを作っています。

このアプリは、点数を出しません。「今日のコンディション 74点」も、「声の調子 A評価」も、
赤・黄・青の信号も、ひとつも出しません。

作りはじめた頃は、出すつもりでした。記録したものを合成して、ひとつの数字にする。
そのほうが分かりやすいし、たいていのアプリはそうしています。実際に一度、作りました。
そして、消しました。

---

**消した理由**

体調を記録するアプリを使っていた人が、こう書いていました。

「アプリに、体調を否定された」

その日、本人は調子が良いと感じていた。けれどアプリは低い点数を出した。
それを見た瞬間に、良かったはずの一日が、悪い一日になった。

点数は、判定です。判定には基準が要ります。
では、声の調子に、全員に当てはまる基準はあるでしょうか。

ありません。

睡眠が7時間あれば声が出る人もいれば、6時間のほうが良い人もいます。
乾いた部屋で歌える人もいれば、湿度がないと声帯が動かない人もいます。
本番の3日前に追い込む人と、3日前に完全に休む人と、どちらも一流です。

基準がないところに点数をつけると、それはただの、根拠のない断定になります。
そして断定は、当たっているときより、外れているときのほうが、記憶に残ります。

---

**もうひとつの理由**

こちらは、あとから知りました。

心理学に、自己決定理論という考え方があります。
Deci と Ryan という研究者が長く積み上げてきたもので、128の実験をまとめた分析があります。

そこで分かっているのは、こういうことです。
**自分の内側から出てきた動機は、外から報酬や評価を与えると、かえって弱くなることがある。**

声を使う人が記録をつける動機は、たいてい、とても強い内側の動機です。
「自分の声を守りたい」。それ以上の理由は要りません。

そこに「今日は74点」を足すと、何が起きるか。
守りたいから記録するのではなく、点数を上げるために記録するようになる。
そして点数が下がった日に、記録をやめる。

つまり、点数を出さないのは、やさしさの話ではありません。
**効果の話です。** 点数を出したほうが、続かなくなる。

---

**では、何を出すのか**

並べるだけです。

声の調子と、昨夜の眠りと、歌った時間と、むくみを、同じ日付の線の上に、上下に並べます。
本番のあった日には、縦の帯が入ります。

そこに、文章は添えません。「よく眠れていますね」も書きません。
矢印も、目標線も、良い悪いの色分けも、置きません。

見て、何かに気づくかもしれないし、気づかないかもしれない。
気づかない日のほうが、たぶん多い。それでいいと思っています。

ひとつだけ、条件が揃ったときに、短い文がひとつ出ます。
「よく眠れた日に、◎が多く出ています」というような、一行です。

出すには、三つの門を通る必要があります。
同じ条件の日がそれぞれ10日以上あること。差が、偶然では説明しにくい大きさであること。
たくさん調べたぶんの補正をかけること。

通らないあいだは、こう出します。

「まだ、はっきりした差は見えていません」

声と暮らしのアプリを34本調べました。
「見つかりませんでした」と言うアプリは、1本もありませんでした。

当たっているように見せるのは、簡単です。
当たっていないと言うほうが、難しい。

---

**声を使う人には、これが要ると思っています**

本番の前に、私たちは自分の体を疑います。
喉が変だ、と思った瞬間に、それが本当に変なのか、緊張なのかが、分からなくなる。

そのときに必要なのは、判定ではありません。
「先週の火曜日も、同じことを書いていた。そしてその日は歌えた」
という、事実です。

判定は、こちらから出しません。
出すのは、あなたが書いたものだけです。
```
