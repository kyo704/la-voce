# §1 ★並べる ── 「1本」ではなく「上下に 並べる」

## 1-1 何が 間違っていたか

```
　★前　「何を」から 1つ 選ぶ → その 1本だけ 線を 引く
　★→ ★これは「ならべる」では なく、ただの グラフです。
```

★**この製品の いちばんの 売りは、営業資料の 1ページ目に こう 書いてあります。**

> 声の調子と、眠りと、夕食の時刻と、湿度を、**同じ日付の軸に上下に並べます。**
> だから「声が出なかった日は、前の晩の夕食が遅かった」という並びが、**自分の目で見えます。**

★**その 売りを、★画面が していませんでした。**

## 1-2 直したこと

```
　◯ ★選んだものを ぜんぶ、★1つの 日付の 軸の 上に、★上下に 並べます
　◯ ★レーンは 5本まで（声の出来／のどの調子／むくみ／声を使った時間／昨夜の睡眠）
　◯ ★本番・レッスンの 日は、★縦の 帯が ★全部の レーンを 貫きます
　　　→ ★「本番の 前後で、上下が どう 動いたか」が 1目で 見えます
　◯ ★押して 出し入れできます。★1つは 残します
　◯ ★下の表は「いちばん多い日／いちばん少ない日／まんなか」
　　　✕ ★平均を 出しません（★合成した 数だからです）
```

## 1-3 ★色を そろえました（★tokens 違反を 直しました）

```
　★前　5系列に 5色（#840C24 / #8C6115 / #447862 / #6D5D50 / #B23A48）
　　　　★→ ★tokens.md「✕ 系列ごとに 別の色相」に 触れていました
　　　　★→ ★とくに #B23A48 は ★信号色に 見えます

　★いま　★2系統だけ
　　　　　◎○△ の もの　→ --enji の 濃淡（.95 / .66 / .42）
　　　　　量の もの　　　→ --midori の 濃淡（.95 / .60）
```

★**そして 絵の 中の 色を、★CSS 変数で 書き直しました。**
★→ ★暗い画面に 切り替えると、★線も 文字も 目もりも いっしょに 変わります。

# §2 ★くらべる ── 「比べられていない」は、そのとおりでした

## 2-1 何が 間違っていたか

```
　★前　「本番のあった日」と「そうでない日」の
　　　　★平均を 2行 並べただけ

　★→ ★分けかたが 違います（★本番の有無では ありません）
　★→ ★日数（n）を 出していません
　★→ ★3つの 門が、★どこにも ありません
　★→ ★★だから「比べた」ことに なっていません
```

★**営業資料の 2ページ目に、こう 書いてあります。**

> 1 同じ条件の日が、それぞれ **10日以上**あること
> 2 差が、**偶然では説明しにくい大きさ**であること
> 3 **たくさん調べたぶんの補正**をかけること
> 通らないあいだは「まだ、はっきりした差は見えていません」

★**これが 画面に 1つも ありませんでした。**★売っているものと、見本が 別でした。

## 2-2 直したこと

```
　★分けかた（★変えられません）
　　　声が 出た日（◎）　と　出づらかった日（△）
　　　★「ふつう（○）」の 日は どちらにも 入れません。★その日数も 出します

　★くらべるもの（★選びます）
　　　昨夜の 睡眠／声を 使った 時間／のどの 調子／むくみ／食べ終えてから 寝るまで
　　　★無料は 1つ。★「しらべる」で 5つまで（★画面で 切り替えて 見せます）

　★出しかた（★丸の 帯）
　　　★丸 1つ＝1日。★重なると 濃くなります（★濃淡だけ。色を 分けません）
　　　★縦の 線＝まんなかの 値。★右端に 日数
　　　★→ ★2本の 帯が ずれているか どうかが、★目で 見えます

　★3つの 門（★画面に 出します）
　　　① それぞれ 10日以上　　　→ ★いま 何日 たまったかを 出します
　　　② 散らばりに くらべた ひらき ≧ 0.50
　　　③ ★選んだ 数だけ 厳しくします（0.50 ＋ 0.12 ×（選んだ数−1））

　★通ったときだけ 1文。★通らないあいだは
　　　「まだ、はっきりした 差は 見えていません」
```

## 2-3 ★見本で 3つの 状態が ぜんぶ 見えます

| どのくらい | 何が 起きるか |
|---|---|
| **14日** | 門① で 止まります（◎3日／△7日）★「日数が 足りない」姿 |
| **4週** | ★3つとも 通ります → ★1文が 出ます |
| **3か月** | 門② で 止まります（ひらき 0.32）★「日数は 足りたが 差が 小さい」姿 |

★**期間を 押し替えるだけで、★3つの 状態が 順に 出ます。**
★★**これが「当たっていないと言うほうが 難しい」の 実物です。**

## 2-4 ★書き方の 決まり（★守っています）

```
　✕「効いた」「原因」「〜のせいで」
　◯「一緒に 出ています」
　✕ ％・確率・p 値の 数字
　◯「偶然では 説明しにくい 大きさ」という 言い方と、その 数だけ
　✕ 門①を「あと○日」と 書く
　◯「10日の うち　◎7日　△4日 たまりました」（★進んだ側から 書く）
```
