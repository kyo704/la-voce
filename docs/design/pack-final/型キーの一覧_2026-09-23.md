## 紙の形（`portfolios.paper_type`）★見本は6型

| 鍵 | 名前 | 向く先 | 注 |
|---|---|---|---|
| T5 | クラシック | 日本の音大・コンクール | 最も安全。機械が読める |
| T1 | ミニマル | 欧州の音楽院・格を示す | 3件しか書かない |
| T3 | スプリット | 声優・俳優 | 左に条件を固定 |
| T4 | タイムライン | 経歴で語る・留学した方 | 縦の線で歩みを |
| T2 | グリッド | 写真がある方 | 写真が4点要る |
| T6 | 和・縦書き | 邦楽・和物 | 洋楽には使わない |

★**食い違い（坂本さんに1問）**：裁定146 は「紙の形（12型）」と書いていますが、見本と裁定127 は**6型**です。
見本が正なら、裁定146 の「12型」は誤り。直す前に確かめたいところです。実装は当面 **6型（T1〜T6）** で進めてください。

## 実装での使い方

```yaml
portfolios.web_type   : t01〜t15 のどれか1つ
portfolios.paper_type : T1〜T6 のどれか1つ（いつでも無料で変えられる）
page_types_owned      : Web の形だけを持つ（紙は持ち物にしない）
Woolsong に含まれる1型: 最初に選んだ形が source='included'（または 'trial'）
480円で買う形         : source='bought'
分野を変えたときの1つ : source='field_free'（分野ごとに1回）
★大文字小文字を区別する（t01 と T01 は別）。実装で小文字に直さない
```
