## 2. 各列の埋め方（Code）

```yaml
何を入れたか: 移行の SQL を読み、専門の言葉を使わずに1行で
どの表に・何行: 移行の SQL から表の名前と、本番に今も残っている行数（select count で）
本物のデータとつながっているか:
  - 試しの学校・試しの人だけにつながる → 「つながっていない」
  - 本物の学校の中にある・本物の人に付いている → ★「本物の ○○ の中にある」と名前（学校名）で。人の名前は書かない
消すと何が起きるか:
  - 連鎖して消える表（ON DELETE CASCADE の先）を必ず書く
  - 画面で何が変わるか（見える区分・名簿・出欠が減る など）
  - ★記録（体調・声・書いたもの）が消えるかどうか。消えるものが1つでもあれば、その行に★
判断の欄: 空で出す（坂本さんが書く）
```

- 消す移行は apply_migration で（直接 SQL にしない）。消したあとに行数を数え直して、表の「いまも残っているか」を「消えた」に
