## 1. Woolsong とは

声を使う人（声楽家・声優・俳優など）の体調記録アプリ。坂本 響さん（オペラ歌手・イタリアの音楽院在籍・日本に住民登録）が一人で開発。

- **個人向け**：記録・ふりかえる・ノート・ひつじ（育成）・しらべる（声の分析）・マッチング（伴奏者探し）・ポートフォリオ・ホームページ
- **学校向け**：名簿・日程・連絡・行事・出欠・採点・レッスン割
- **公演の運営**：香盤表・稽古・出欠（2027年7月〜）
- 38人が使用中。販売は **個人 2027年1〜3月／学校 2027年4月**。10月19日は欧州へ出発（販売はしない）

## 3. 変えない原則（CLAUDE.md 33行の要点）

- 点数・順位・平均との差・偏差値・信号色を出さない。催促しない
- 先生は生徒の健康の記録を見られない（そのための列を持たない）。健康と学務は別の層
- 取り上げない。消すときは消す（隠して済ませない）。記録・ノート・ひつじは消えない
- 本番にテストデータを入れない（test が既定）
- `select('*')` を書かない。RLS は USING と WITH CHECK の両方。`*_log` に update/delete を作らない
- `NOT_YET` には外す条件を添える
- 進め方：共通の土台は一括、個別の画面は機能まで1枚ずつ

**決まりの例外は3件だけ**（増やさない）：①マッチング成立前は定型文のみ ②通報は坂本さんが見る ③ホームページのお問い合わせ転送

## 8. 繰り返さないこと（このチャットで私がした失敗）

1. **構文の検査だけで「動く」と言った**。別のファイルにある仕組み（`SH`・`openSheet`）を運営の見本で使い、白い画面にした。辞書を使う場所が辞書より前にあり、iPhone 版が2日間画面を移れなかった。
   → **見本を直したら、必ずブラウザで開いて全画面を押す**（下の §9 の道具）
2. **道具を較正せずに信じた**。エスケープの数え方を誤り、あるものを「無い」と3回報告した。
   → 既知の1件で道具が当たるか先に確かめる
3. **裁定を会話だけで終えた**（その131・紙とページの分離）。坂本さんに指摘された。
   → 裁定を出したら、その場でファイルにする
4. **見た目を自分で作って2度「雑」と言われた**（t11〜t15）。
   → 見た目は Fable に回す
5. **見本の「全部自動で振り分ける」が、あとの裁定と矛盾したまま残っていた**。
   → 裁定を出したら、見本に矛盾が残っていないか探す
6. **学部を消すと中の学科も消える、を見本に入れた**。Code が実害を指摘して止めた。
   → 「黙って消える」を作らない

---

7. **本番でのなりすまし（BEGIN／set role／ROLLBACK）を指示した**（2026-09-21・裁定159 S1 の証明）。2026-09-15 に ROLLBACK が効かず権限の昇格が坂本さんのアカウントに残った事故があり、tools/ask_ledger.py の決まり3で禁止されている。Code が断って、実在の試しの利用者で証明した
   → 台帳の試験は「実在の試しの利用者」で。なりすましを書かない。指示を書く前に Code の決まり（ask_ledger.py）を確かめる

8. **関数の露出を anon の実行権だけで判断した**（2026-09-21・裁定162）。authenticated にも実行権が無く、サーバの service_role だけが呼ぶ設計（No.024）だったのに「誰でも呼べる」と書き、サーバからの呼び出しを壊す修正案まで出した。Code の検証で分かった
   → 関数の露出は anon・authenticated・呼び出し元の3つで見る。修正案を出す前に、呼び出し元を Code に確かめる
