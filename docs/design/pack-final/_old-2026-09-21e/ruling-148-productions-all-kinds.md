```yaml
ruling: 148

```

---

## 1. DECISION

```yaml
表は1つ: 「何をやるか（行）× 誰が出るか（列）」
種類ごとに変えるもの: ことば と 少しの違い だけ（ことばの出し分けと同じ考え）
仕組みを種類ごとに分けない: 分けると「同じ決めが2か所」になる
```

## 2. MODEL（★ここが 今回の 中心）

```yaml
行: 名前 ／ まとまり（幕・部。無くてよい）／ 分 ／ メモ ／ 順（ガラでは出番の順）
列 = 枠:
  1人の枠:    役・奏者・ソリスト
  交代の枠:   ダブルキャスト（A・B）。オペラ・演劇・ミュージカルだけ
  何人かの枠: パート・声部・団体（合唱団・バンド・四重奏）
マス:
  1人・交代の枠: ●
  何人かの枠:    ● または 人数（オーケストラ・合唱）
呼ぶ人 = 選んだ行で マスがある枠の人。同じ人を2度数えない

ごちゃ混ぜ: 団体を1つの枠にする。呼ぶと中の全員に届く
  reason: 種類を混ぜる仕組みを別に作らない。ガラ1つで足りる
```

## 3. KINDS

| 種類 | 表の名前 | 行 × 列 | その種類だけのもの | 出す時期 |
|---|---|---|---|---|
| オペラ・ミュージカル・演劇 | 香盤表 | 場面 × 役 | ダブルキャスト・カバー | 2027-07 |
| オーケストラ・吹奏楽 | 乗り番表 | 曲 × パート | 人数・降り番・トラ・持ち替えはメモ | 2027-07 |
| 合唱 | 出番表 | 曲 × 声部 | 人数・パート練習 | 2027-07 |
| ガラ・発表会・フェス | 出番表 | 演目 × 出演者・団体 | 出番の順・入り・転換 | 2027-07 |
| 室内楽・リサイタル | 曲目と奏者 | 曲 × 奏者 | 合わせの予定が中心 | 2027-10 |
| バンド・ライブ | セットリスト | 曲 × メンバー | サポート・曲のメモ（キー・テンポ） | 2027-10 |
| ダンス | 香盤表 | ナンバー × ダンサー | 振り入れ・場当たり | 2027-10 |
| そのほか | 表 | 自分で名付ける | — | 2027-10 |

```yaml
最初の1問: 公演を作るとき「どんな公演ですか」だけ聞く
あとから変えられる: 変わるのはことばと見出しだけ。書いたものは消えない
  人数を●の種類へ変えても、人数は持ったまま（●で見せるだけ）
第2群（2027-10）: ことばを足すだけで出せる。仕組みは第1群と同じ
  reason: 何でもできる道具は何にも強くない。まず音楽大学と市民団体でそのまま使えるもの
```

## 4. 降り番（オーケストラ・合唱）

```yaml
人数 < 枠の人数 のとき: 降り番を決める（運営が名前を選ぶ）
決まるまで: 枠の全員を呼ぶ
  reason: 呼び漏れより呼びすぎに倒す。来なくてよい人が来るほうが、要る人が来ないより軽い
本人に見えるもの: 自分の列にだけ「乗り」「降り番」の言葉。ほかの列は人数
作らない: 席の順（プルト・首席の並び）
  reason: 並びは順位に読める。紙と口頭で足りる
分奏・パート練習: 稽古を組むとき「列をしぼる」。しぼらなければ選んだ行に出る全員
```

## 5. 人の種類

```yaml
出演者 ／ トラ（エキストラ）／ サポート ／ スタッフ
料金: 全員を数える（トラも子どもも1人。裁定その143・147）
トラ: 枠の中で印をつける。人数に入る
スタッフ: 照明・音響・舞台・衣裳・メイク・楽器運搬・受付 など。香盤表の列ではなく「当日の進行」で呼ぶ
フリーの舞台スタッフ・トラ奏者:
  いくつもの公演に呼ばれても、本人の日程に全部並ぶ（source='org'。裁定その141）
  reason: 現場ごとにアプリが違う、を1つにできる。ここが個人に効く
```

## 6. 当日の進行（★P2 から P1 へ前倒し）

```yaml
区切り: 仕込み・入り・リハ（場当たり・ゲネプロ・サウンドチェック）・開場・開演・終演・バラシ
ガラ・発表会: 出番の順が中心
  行の順 = 出番の順。入れ替えると、あとの時刻を全部計算し直す
  転換の分を行ごとに持つ（前の出番との間）
  入りの時刻を行ごとに持つ（1組ずつ）
ほかの種類: 行の分の合計＋休憩 で終演を出す
見える範囲:
  出演者: 自分の入りと自分の出番だけ
  スタッフ: 自分が呼ばれた区切りだけ
  ほかの人の時刻: 出さない（サーバが返さない）
静かにしない: 本番の3日前〜も、この画面は出す（体調の分析とは別。裁定その141）
進行表の PDF・出演料の台帳: P2（2027-10）のまま
```

## 7. PRICE

```yaml
tiers:
  15人まで: 0円     # バンド・室内楽はほぼここ
  40人まで: 20,000円
  120人まで: 50,000円
  300人まで: 100,000円
  600人まで: 150,000円   # ★足した。市民の第九・フェス
600人を超える: 扱わない。「ご相談」も置かない（窓口を設けない。裁定その141 C3）
ほかは裁定その143・144のまま（作るのは無料・16人目で初めて払う・差額・期限は払った時に固定）
```

## 8. KEEP（どの種類でも変えない）

```yaml
- 出演者の体調は、制作・舞台監督・指揮者・バンドリーダーの誰にも見えない
- DM を作らない。連絡は LINE のまま
- 既読を数えない（配った日だけ）
- 楽譜を配らない（セットリストの曲名・キー・テンポのメモはよい）
- チケット・座席・予約を作らない
- 休んだことは運営の記録。本人の画面に「無断欠席」と出さない
- 子どもが出る公演は裁定その147（保護者のアカウント）
```

## 9. ANSWERS

```yaml
ポップス・ロック: 対応する（第2群）。ことばを足すだけ
  勝負するところ: 体調は誰にも見えない／連絡の窓を作らない／日本語／現場が増えても日程が1つ
子どもの出演: 裁定その147で決定済み（15歳未満は保護者のアカウント）。見本はまだ（次の作業）
ホームページの型: 裁定その146で決定済み（14日は選び直し、以降1型480円の買い切り）
```

## 10. MOCK（2026-09-21・design-v11）

```yaml
PC・iPad（運営）:
  公演を作る: 最初に「どんな公演ですか」（8種類）→ 選ぶと ことばと例が変わる
  行事の一覧: 公演3つ（オペラ／オーケストラ／ガラ）。押すとその公演へ
  乗り番表: 数字のマス。つけるときマスを押すと 人数（−・＋）と 降り番。未決は ＊

  出演者とスタッフ: 出演者・トラ・サポート・スタッフに分けて出す
```

## 11. VERIFY

```yaml
Q1: 種類を変えても、行・列・マス・出欠が1件も消えない
Q2: 降り番が決まるまで、枠の全員が呼ばれる
Q3: 降り番の人に、その曲だけの稽古の呼び出しが届かない
Q4: 同じ人が2つの枠にいても、呼ぶ人に1回しか出ない
Q5: 出演者の画面に、ほかの人の入り・集合・出番の時刻が1件も出ない（サーバが返さない）
Q6: スタッフには、自分が呼ばれた区切りしか出ない
Q7: 席の順（プルト）を持つ列が、どの表にも無い
Q8: 601人目を招こうとすると、段が無いことだけが出る（「ご相談」が出ない）
Q9: 出番を入れ替えると、あとの時刻と終演がすべて変わる
```
