## ★パソコンだから できること（★3つだけ）

**★見た目を 変えただけでは ありません。★スマホでは できないことが 3つ あります。**

### 1　日程 ── 先生を 横に ならべる

```
　　　　　斎藤　渡辺　高橋　大川　森　外部
　9:00　声楽A  声楽B  ★重なり  …
　10:30 …
```

★**全部の 枠を 一度に 見ます。**★スマホは 1人ずつ しか 見られません。
★時間の 列は 左に 止まります。★横に ずらしても 消えません。

### 2　日程を 組む ── 表と 名簿を 同時に

```
　左　曜日 × コマ（★数＝その時間に 来られる人数）
　右　★選んだ枠に 来られる方　＋　門下の 名簿（学年の 順・置いた場所つき）
```

★**スマホでは 上下に 分かれていたものが、★横に 並びます。**
★「まだ」を 押すと、その方が <b>入れられる 枠の 一覧</b>へ。
★「ぜんぶ 自動」は 下書き。★あとで いくらでも 直せます。

### 3　役職 × できること ── 1枚の 表

```
　　　　　 ご請求 名簿 日程 行事 おしらせ 門下 かたち 役職 │ 自分の日程 門下に書く 出欠 時間
　学長　　　●　　●　　●　　●　　●　　●　　●　　● │
　事務長　　○　　●　　●　　●　　●　　●　　●　　● │
　教授　　　○　　○　　○　　○　　○　　○　　○　　○ │　●　　●　　●　　●
```

★**丸を 押すと、その場で 変わります。**
★灰色の 列は、あなたが 持っていない ものです（★渡せません）。
★スマホでは 1つずつ しか 見られませんでした。
