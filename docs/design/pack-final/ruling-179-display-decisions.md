# RULING 179 — 裁定で決めた表示は、裁定の更新とセットでしか消せない

```yaml
ruling: 179
date: 2026-09-23
version: design-v26
from: Code の報告（2026-09-23）── 比較グラフ画面から、裁定で決めた表示が 説明なく消えていた
  コミット c3c53fe7（2026-09-13・AI との共同作業）で
    本番・レッスンの日の帯／レーンの構造／2系統の色／◎○△の凡例 が 消えていた
  ★坂本さんに記憶がなく、裁定は生きたまま、lib/lineUp.js にコメントだけ残っていた
  ★2週間、誰も気づかなかった
```

## 1. 決定（今回の件）

```yaml
方針: ★㋑（復元）。消えた経緯に 判断の記録が無い＝★決定ではなく事故
  決定なら 裁定を直すのが順番。裁定が生きたまま コードだけ消えているなら ★裁定が正
復元するもの: 本番・レッスンの日の帯／レーンの構造／◎○△の凡例と帯の説明
★復元の前に確かめるもの（1件だけ）: 2系統の色（えんじ・みどり）が 何を表していたか
  指標の系統（体調／活動 など）を分けるもの → 復元してよい
  ★良い・悪い を表していた → 復元しない。「信号色を使わない」に触れる
    その場合は ★裁定の側を その部分だけ直す（＝下の決まりのとおり、裁定を更新する）
復元のあと: ★見本と突き合わせる（段3a の A・225画面に この画面は入っている）
```

## 2. 恒久の決まり

```yaml
★裁定で「画面に出す」と決めたものを消す変更は、★裁定の更新とセットでないと入れない
  裁定を直さずに消えていたら、それは ★事故として扱い、復元する
  AI との共同作業でも同じ（むしろ そこで起きやすい）
記録: 表示を変える判断は、裁定か「意図したもの」の記録（tools/promises/accepted.md）に残す
```

## 3. 検査の仕様（tools/display_guard.py・新しく作る）

```yaml
なぜ既存の道具で足りないか:
  promise_diff: ★注記の「文」を見る。図・帯・凡例・色の系統は文ではないので 拾えない
  ruling_mock_check: ★見本に入っているかを見る。★実装から消えたことは見ない
  perm-matrix: 権限の出し分けだけ
  → ★「裁定で決めた表示が 実装にあるか」を見る道具が無い

台帳（tools/display_registry.json）:
  1件 = {裁定番号, 画面, 何を出すか, 実装での印（import・関数名・CSSクラス・文字列）, 追加日}
  例:
    {"ruling":"111","screen":"くらべる","shows":"本番・レッスンの日の帯",
     "markers":["hadPerformanceOrLesson","LANES"],"file_hint":"lib/lineUp.js","added":"2026-09-13"}
やること:
  ① 台帳の各行について、markers が ★実装のどこかに現れるかを見る（grep）
  ② 1つでも消えていたら ★止める（RESULT: NG）。裁定番号と画面名を出す
  ③ 「意図して消した」ときは、★裁定を直し、台帳の行も直す（消すだけは許さない）
走らせるところ:
  release_check の中（配る前）／毎日の見張り
★この道具は 実装（リポジトリ）を読む。Opus は実装を見られないので、
  ★台帳の markers は Code が埋める。Opus は「何を出すと決めたか」を書く

最初に入れる行（Opus が分かるぶん）:
  裁定111 くらべる: 本番・レッスンの日の帯／レーンの構造／◎○△の凡例
  裁定119 全画面: 点数・順位・信号色を出さない（★逆に「出てはいけない」の行。mobile_parity と重ねる）
  裁定176 もっと: 切ってある機能の一覧（運営だけ）
  裁定165 採点: 順位を返さない
  裁定147 公演: 子どもの緊急の連絡先は 運営だけ
  裁定178 公演: 書き出しに 体調の列を作らない
```

## 4. VERIFY

```yaml
- 台帳に載せた印を 実装から1つ消す → ★display_guard が止める（裁定番号と画面名が出る）
- 裁定と台帳を同時に直して消す → 通る
- 台帳に無い表示を消しても 止まらない（★だから 台帳を育てることが仕事）
```

## 5. 正直に言っておくこと

```yaml
★この道具があっても、台帳に載せていない表示は守れない
  今回の帯も、台帳があっても「載せていなければ」素通りした
  → ★裁定を書くときに、同時に台帳へ1行足す。それを Opus の手順に入れる
★2週間気づかなかったのは、道具が無かったからではなく「見ていなかった」から
  段3a（見本と実装の突き合わせ）を 定期的に回すことが、いちばん確かな網
```
