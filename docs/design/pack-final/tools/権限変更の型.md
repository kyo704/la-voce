# 権限変更の型（RLS・ポリシー・RPC の権限を変えるとき）

2026-09-21 ／ Opus ／ 裁定159（S1・S2）で固まった手順。★本番の権限を変えるときは、必ずこの型で出す
道具: `python3 tools/decision_needed_check.py <報告ファイル>` が PASS になってから、坂本さんに出す

## 手順

1. **test で作る**（本番に試しのデータを入れない。CLAUDE.md）
2. **実在の試しの利用者で証明する**（★なりすまし＝BEGIN／set role／set_config／ROLLBACK は使わない。ask_ledger.py 決まり3。2026-09-15 の事故）
3. **較正を入れる**: 「読めるはずの人が読める（1行以上）」と「読めないはずの人が読めない（0行）」の両方。どちらか片方だけでは証明にならない
4. **記録が要る処理は fail closed**: 記録を書いてから中身を返す。書けなければ返さない
5. **本番の影響人数を数える**（その権限を持つ人・その表の行数）。`policy_diff.py` で前後の差分・減る役職・増える役職・画面を出し、減る／増える役職ごとに試験を1つずつ
5b. **記録を書く関数なら** `fail_closed_lint.py` を通す
6. **DECISION_NEEDED を書く**（下の見出しを全部）→ 道具で確かめる → 坂本さんの承認 → 本番に当てる
7. **当てたその日に**: リポジトリへ写す／適用後の pg_policies を読み直して出す／修正の記録に1行

## DECISION_NEEDED の見出し（★全部要る。無い見出しは「該当なし」と理由を書く）

```
## DECISION_NEEDED
## 何を変えるか            （1〜3行。裁定番号）
## SQL全文                  （```sql …``` そのまま。ファイル名だけにしない）
## 戻すSQL                  （```sql …```。当てたあと戻す手順）
## 変える前のポリシー        （pg_policies の qual と with_check をそのまま）
## 変えた後のポリシー        （test で当てた後の pg_policies）
## USINGとWITH CHECK        （両方あること。USING(true) が無いこと）
## 試験                     （試しの利用者ごとに：誰・何をした・期待・結果の行数。較正の1件を含む）
## なりすまし               （「使っていない」と書く）
## fail closed              （記録が要る処理なら、書けないと返さないことの試験。要らないなら理由）
## 本番の影響               （その権限を持つ人の数・表の行数・いま読めている人が読めなくなるか）
## 承認                     （坂本さんの承認の欄。空のまま出す）
```
