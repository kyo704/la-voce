# §2 ★★では、どう 落とし込むか（★裁定）

## 2-1 ★★項目を 増やしません

★**★いちばん 大事なところから 書きます。**

```
　★「職業ごとに 記録の 項目を 足す」── ★★これを しません。
```

★**理由が 2つ。★2つ目が 効きます。**

```
　★① ★記録は「★2タップで 完成・1回30秒」が 売りです。
　　　 ★中核5つ ＋ 任意4つ に 絞り込みました。★足すと この線が 崩れます。

　★② ★★★項目を 増やすと、★言えることが 減ります。

　　　★門③（★たくさん 調べたぶんの 補正）が あります。
　　　★★調べる 数が 増えるほど、★門は 厳しくなります。
　　　★→ ★職業別に 5項目 足すと、★★1文が 出にくくなります。

　　　★★「専門的にした つもりが、★何も 言えなくなる」
　　　★★これが、★この製品で いちばん 起きやすい 事故です。
```

## 2-2 ★★職業が 決めるのは「★言葉」と「★順番」です

```
　★★何を 集めるかは ── ★全職業 同じ。★変えません。
　★★職業が 決めるのは ── ★★何と 呼ぶか。★何を 先に 出すか。
```

★**4つ だけです。**

| 職業が 決めるもの | 中身 |
|---|---|
| ★**① 言葉** | ★画面の 語を 差し替える |
| ★**② 並び** | ★「くらべるもの」の 初期の 候補 |
| ★**③ とだなに 並ぶもの** | ★歌ってきた曲／演じた役／担当した番組 |
| ★**④ 学ぶの 中身** | ★7章立ての 例と 文を 差し替える |

## 2-3 ★①言葉 ── ★具体的に

| いまの語 | 声楽・ミュージカル | 声優・ナレーター | アナウンサー | 教える・話す仕事 |
|---|---|---|---|---|
| 本番 | ★本番／公演 | ★収録／アフレコ | ★放送／生放送 | ★授業／講演 |
| 稽古 | ★稽古／レッスン | ★練習／ボイトレ | ★練習 | ★準備 |
| 声を 使った 時間 | ★歌った 時間 | ★声を 出した 時間 | ★話した 時間 | ★話した 時間 |
| 門下 | ★門下 | ★★（★使わない） | ★（使わない） | ★（使わない） |
| とだな | ★歌ってきた もの | ★演じた 役 | ★担当した 番組 | ★（使わない） |

★**★★「使わない」が あることが 大事です。**
★★**職業ごとに 足すのでは なく、★★引きます。**

## 2-4 ★②並び ── ★「くらべるもの」の 初期候補

```
　★★候補の 一覧は ★全職業 同じです（★項目を 足さないので）。
　★★変わるのは ★どれが 上に 出るか だけ。

　★→ ★★こちらから 決めつけません。★順番を 変えるだけです。
```

## 2-5 ★★禁じること（★★これを 落とさないでください）
