## §1 段と式

```
無料　　先生1人＋生徒5人まで　　0円
教室　　先生2人・生徒30人まで　月2,980円／年29,800円（14日 ためせる・カード不要）
　　　　教室ページ・40人までの公演を含む
学校　　それより多い（先生3人以上、または生徒31人以上）
　　　　月額 ＝ max( 12,800 , min( n×400 , max(n,100)×350 , max(n,300)×250 ) )
　　　　n ＝ 名簿の人数（在籍している学生）
　　　　2つ以上の計算が当たるときは、安いほうを当社が当てる
```

自動では上げない。上限を超える方を招こうとしたときに1度たずねる。断れば招かない（裁定155 C3）。
下げることはしない。期限まで使って次を選ぶ。

## §3 数え方（第1版のまま）

```
数える　その学科・コースに在籍している学生
数えない　休会中／招待して返事待ち／先生・事務（何人いても）
いつ数える　毎月1日
月の途中で増えた　日割りにしない。増えた月から1か月ぶん
月の途中で減った　返金しない。次のご請求から反映
年の一括前払い　月額の2か月ぶんを引く（＝10か月ぶん）
年の途中で増えた　増えたぶんだけ毎月ご請求
年の途中で減った　返金しない。次の1年ぶんから引く（繰り越し）
自動更新　しない（年払い）
```

## §4 導入支援

100,000円。**名簿100人以上のときだけ**（第1版の「50人以上」を改める。裁定155 Q4）。1回だけ（初年度）。
中身：説明会・研修・初期設定・学生向けの配布物。訪問の約束はしない。

## §6 0円の導入期間（裁定156）

| | 0円 | ご請求の始まり |
|---|---|---|
| 最初の1学科 | 2027年9月30日まで（2027年2月までに年間契約） | 2027年10月1日 |
| 2校目から | 契約日から最大3か月（次の4月1日を超えない） | 導入期間の翌月1日か4月1日の早いほう |
| 教室 | なし（14日の体験だけ） | — |

値引きはしない。0円期間の延長はしない（1校目の1回を除く）。止めても請求なし。学生の記録は残る。
最初の1学科へのお願い（事例掲載・聞き取り・時間の計測）は、**契約書とは別の1枚**。無くても契約は成立する。

## §9 変えるとき

値段を変えるときは、本書を書き換えて版を上げる。そして**同じ日に次の4つを直す**。

- ☐ 本書
- ☐ 営業資料（料金のページ）・特商法ページ・契約書の別表
- ☐ 実装（lib/orgRoster.js）
- ☐ 見本3本（全画面・iPhone・運営の billYen）

1つでも残ると、また気づけなくなる。★Sonnet は、値段に触れる依頼を受けたら、この4つの突き合わせを1行で報告する。
