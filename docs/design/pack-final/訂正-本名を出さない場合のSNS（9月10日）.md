# §0 ★★先に ── ★避けられないことが 1つ あります

★**★SNS の 前に、★これを 決めておかないと あとで 困ります。**

```

　★★★氏名は 代えられません。
```

★**だから、★★正確には こうです。**

```
　✕ 「本名を 出さない」
　◎ ★★「SNS で 名乗らない」

　★→ ★★10月19日に 販売を 始めた 時点で、

```

```
　★→ ★★あとで「隠していた」と 言われない ために、★この違いを 押さえてください
```
