# §9 ★抽出の 形

## 9-1 ★1つの 文字列に、★文脈を 付けてください

```json
{
  "id": "furi.kura.gate1.title",
  "ja": "それぞれ 10日以上 あること",
  "where": "ふりかえる → くらべる → 3つの門",
  "who": "生徒・声のプロ 本人",
  "why": "統計の 門の1つ目。日数が 足りているかを 言う",
  "max": 26,
  "keep": ["10日"]
}
```

★**この5つが 無いと、精度が 落ちます。**

| 欄 | なぜ 要るか |
|---|---|
| `where` | ★同じ「出す」が、★esporre／mostrare／emettere に 分かれます |
| `who` | ★生徒に 言うのか、事務に 言うのか で 敬語の 高さが 変わります |
| `why` | ★★いちばん 効きます。★「約束」なのか「説明」なのかが 分かります |
| `max` | ★イタリア語は 日本語より **30〜40% 長く**なります（§12） |
| `keep` | ★訳しては いけない 語（数・記号・固有名） |

## 9-2 ★抽出しては いけないもの

```
　✕ 曲名・作曲家名　　　★記録の データです。アプリの 文字では ありません
　✕ 学部・学科・役職名　★★学校が 入れます（★第1部）。★訳しません
　✕ 人の 名前
　✕ 通貨の 記号・数字そのもの
```
