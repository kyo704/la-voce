# §0 読み方

```
　目的　　その画面が 何のためにあるか（★1行）
　読む　　画面に 出すために 要るデータ
　書く　　その画面から 変わるデータ
　押す　　押せるもの → ★何が起きるか／どこへ行くか
　出さない ★その画面で 出してはいけないもの
```

★**§1（共通）は 全画面に かかります。★画面ごとに 繰り返しません。**

# §1 共通のふるまい（★52画面 すべて）

## 1-1 下のタブ

```
　個人　★きょう／記録／ふりかえる／ノート／ひつじ（★5つ・固定）
　運営　★ホーム／日程／名簿／行事／連絡／設定（★owner）
　　　　★ホーム／日程／名簿／行事／連絡（★admin）
　　　　★★日程 だけ（★staff）

　★タブを 押すと、その群の いちばん上の画面へ（★中の状態は 覚えない）
　★★同じタブを もう一度 押しても 何も 起きない（★先頭へ戻らない）
```

## 1-2 上のバー

```
　個人　★歯車（⚙）→ もっと（A10）
　運営　★「‹ もどる」→ 個人アプリの「きょう」へ
　　　　★役割の札（owner/admin/staff）★押せません。表示だけ
　★運営の上から2番目に、★いつも この帯：
　　　「この画面から、生徒の健康の記録には たどりつけません」
　　　★★消さない・畳まない・スクロールで 隠さない
```

## 1-3 4つの状態（★どの画面にも 要ります）

| 状態 | どうするか |
|---|---|
| **空** | ★白紙にしない。★何をすると 埋まるかを 1行。★「まだありません」だけで 終わらない |
| **読み込み中** | ★灰色の 形を 置く（★ぐるぐるを 使わない）。★0.3秒 未満なら 何も 出さない |
| **失敗** | ★「いま つながりません。書いたものは 端末に 残っています」＋「もう一度」 |
| **オフライン** | ★上に 細い帯 1本。★★書けます。★あとで 送ります |

★**書いたものを、失敗で 消さないでください。**★これは いちばん重い決まりです。

## 1-4 無料と 有料の 出し分け

```
　★有料のものは ★隠しません。★見せて、押せなくします。
　★押したら「しらべる」の 案内へ（★1画面）。★戻ると 元の場所
　★札は「しらべる」の1語だけ。★「PRO」「プレミアム」と 書かない
　★★催促しない。★案内は 押したときだけ
```

## 1-5 ★静かにする期間（★本番の3日前 〜 翌々日）

```
　★出す　　★ならべる（14日・4週・3か月）／さかのぼる／記録／ノート／ひつじ
　★★出さない　★くらべる／かぞえる／★本番でそろえる
　★見せ方　★切替を うすくし、押すと 1行だけ
　　　　　　「いまは お休みです。本番の翌々日から、また 出ます」
　★★入口は 閉じない。★記録は いつもどおり 書ける
```

## 1-6 保存

```
　★「保存」ボタンを 作らない。★選んだ瞬間に 保存
　★例外　★記録（A03）と 連絡（D02/D05）は「出す」を 押したとき
　★取り消し　★消したものは「もとにもどす」で 1回だけ 戻せる（★5秒）
```

## 1-7 数の 出し方

```
　✕ ％・達成率・進捗バー・連続日数・「あと◯日」「あと◯点」
　◯ 実数（★38日／2.1回／3時間51分）
　★5人未満の かたまりは 数を 出さない（★「5人未満」とだけ）
```

## 1-8 押せる大きさ

```
　★44px 以上。★文字を 大きくしても 44px を 下回らない
```
