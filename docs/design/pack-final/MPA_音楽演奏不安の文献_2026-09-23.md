# 音楽演奏不安（MPA）の文献 ── Woolsong の設計の根拠

2026-09-23 ／ Opus。査読（9/7）§5・総合評価（9/10）§6-10 で「唯一うちにしかない根拠になる」とされていた空白を埋めるもの
★用途：説明サイト／大学への営業／規約・ポリシーの「なぜ点数を出さないか」

## 1. どれくらいの人が抱えているか

```yaml
professionals:
  値: 16.5%〜60%（系統的レビュー・Fernholz ほか 2019）
  重いもの: 「深刻な問題」に絞ると おおよそ 3人に1人
students:
  値: 21%〜50%。10代の演奏者では 33%
choral_singers:
  値: 地域の合唱の歌い手の調査で 95% が何らかの症状（過呼吸・こわばり・口の渇き）
注意: 定義・尺度・集め方が研究ごとに違い、直接は比べられない（同レビュー）
出典:
  - Fernholz et al. (2019) Performance anxiety in professional musicians: a systematic review（有病率 16.5〜60%）
  - Factors associated with MPA in adolescents: a systematic review（2024）── 学生21〜50%・10代33%
  - Group ACT intervention for MPA in student vocalists（合唱の歌い手 95%・声の仕事に固有の困難）
```

## 2. 声の仕事に固有の理由（★Woolsong の利用者そのもの）

```yaml
- 歌い手の楽器は 呼吸と発声そのもの。不安になると その両方が乱れる
  → 息の支えが落ちる・声の響きが変わる・立ちくらみ（過呼吸）
  → 器楽の人より「不安 → 声が変わる → さらに不安」の輪が短い
- それでも、声の仕事の人は MPA の研究の中で 人数が少なく、扱われてこなかった（同論文）
出典: Examining a Group ACT Intervention for MPA in Student Vocalists（PMC7272702）
```

## 3. ★「点数を出さない」「順位を出さない」の根拠

```yaml
反芻（はんすう・rumination）:
  - 本番の前の反芻は、注意の資源を食い、否定的な自己評価を強め、MPA を悪化させる
  - 本番の後の反芻は、次の本番の不安を育てる（社会不安の維持の輪と同じ形）
自分に向く注意（self-focused attention）:
  - 自分に注意が向くほど演奏は落ちる。注意が外（課題）に向くほうがよい
  - 高い圧力の場面では、自己意識の高い人ほど演奏が落ちる
評価の圧：
  - 外から課された完璧さ（socially prescribed perfectionism）は、反芻を通して MPA を高める
  - 結果ではなく「努力・過程・伸び」をほめる関わりのほうが、不安を下げる
→ Woolsong の設計との対応:
  ★点数・順位・信号色を出さない       … 「自分の出来を測る数字」を毎日見せることは、反芻と自己注視を増やす側の働きをする
  ★本番の前日・当日は何も言わない     … 本番前の反芻を増やさない
  ★「良い／悪い」の判定をしない       … 否定的な自己評価の材料を渡さない
  ★記録は 事実と 並びだけ            … 注意を「自分の出来」ではなく「事実」に向ける
出典:
  - Cognitive and attentional processes associated with performance anxiety in community musicians（2026）── 反芻・否定的な自己注視・出来の評価が、演奏不安を説明
  - Self-consciousness and trait anxiety influence music performance in high-pressure situations（2024）── 圧力下では自己意識が演奏を下げる
  - The cognitive engine of evaluative threat: socially prescribed perfectionism and MPA（2026）── 外から課された完璧さ → 反芻 → MPA
  - Psychological predictors of MPA among vocal students（2025）── 結果より努力・過程をほめる関わり
  - Psychological resilience and MPA in choir members（2026）── 本番前の反芻が MPA を強める
```

## 4. 測り方（大学に話すとき）

```yaml
K-MPAI（Kenny Music Performance Anxiety Inventory）:
  - MPA の標準的な尺度。40項目・6つの側面（早期の関係・心理的な脆さ・身体の不安・抑うつ／絶望・本番の場面の不安・心配／反芻）
  - 22の言語に訳され、400を超える研究で使われている
  - ★日本語版（K-MPAI-R）が検証されている（400人・プロ200／アマ200・歌い手91人。α=0.93）
  → 大学に「Woolsong はこの尺度を使いますか」と聞かれたときの答え:
     ★使いません（うちは点数を出さない）。ただし、この尺度が何を測るものかは理解したうえで、設計を決めている
出典:
  - Kenny (2023) The K-MPAI: scale construction, cross-cultural validation…（Frontiers in Psychology）
  - Validation of the Japanese version of the K-MPAI-R（PMC12213870）
```

## 5. どこに書くか

```yaml
説明サイト:「なぜ 点数を 出さないのか」の節に、3 の対応をそのまま（数字は 3人に1人・声の仕事の輪の短さ）
大学への営業資料: 1ページ目の「なぜ この形か」に、有病率と「評価の圧が反芻を通して不安を高める」
規約・ポリシー: 医療ではない旨のとなりに「点数・順位を出さない理由」を1文
★禁じ手（書かない）:
  - 「Woolsong を使うと不安が下がる」──★言えない（効果を確かめた研究はない）
  - 有病率を「うちの利用者の○%が」と言い換えない（別の集団の数字）
  - 病名・診断に近い言い方（薬機法・裁定157 T5）
```
