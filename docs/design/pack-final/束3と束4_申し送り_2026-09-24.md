# 束3（記事3枚）・束4（ノート3枚）── ★作る前に

2026-09-24 ／ Opus ／ ★本物で 確かめました

## 1. ★束3 は「同じ型を 3回」では ありません

```yaml
★3枚は ★別の 型です（★私が 前に「同じ型」と 書いたのは 誤りでした）
  記事      ★1本の 記事の 本文（★冒頭3行で 結論・本文 800〜1,500字）
  もっと深く  ★一覧（技術・からだ・ことば … 章立て）
  深い記事    ★1本の 深い記事の 本文（★更新日・読むのに 約9分）
★つまり:「一覧 → 本文」が ★2組 あります（★学ぶ→記事／もっと深く→深い記事）
★作る順: ★「もっと深く」（一覧）→「深い記事」（本文）→「記事」
  ★一覧を 先に 作ると、★本文の 入口が できます
```

## 2. ★台帳（★両束とも 揃っています）

```yaml
束3 article_notes（★書き込み）／article_progress（★復習の箱）
  ★守り: どちらも ★本人だけ（auth.uid() = user_id）
  ★★read の 表は ありません ── ★これは 決めごとです（★読んだ本数を 数えない・裁定119）

  ★守り: ★4本（select・insert・update・delete）すべて 本人だけ
  ★列: kind・body・lesson_on・teacher_label・repertoire_name・said_text・next_action・gained_text
    ★「次に 自分が 言うこと」（next_action）が 列に あります ── ★見本の ことばと 一致
```

## 3. ★1つだけ 判断が 要ります（★Code へ）

```yaml
★article_notes に ★shared_with_teacher（先生と 共有するか）の 列が あります
★ところが:
  ★見本の どこにも「★先生と 共有」は 出てきません
  ★裁定にも ありません（★探しました）
  ★本番の 中身は ★0行（★誰も 使っていません）
  ★そして ★守りは 本人だけ ── ★true に しても ★先生は 読めません
★私の 見立て: ★昔の 名残です。★使うなら「先生は 記録を 見られない」に 触れます
★私の 勧め: ★そのまま 触らない（★0行・★守りで 閉じている）
  ★列を 消すのは ★出発の あとで よい（★消すのは いつでも できます）
★★ただし ★実装で この列を ★使わないでください（★true に しない）
```
