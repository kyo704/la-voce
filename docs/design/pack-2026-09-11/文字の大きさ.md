---

# §0 なぜ 要るか

```
　★運営モードを 使うのは、★学校の 事務の方です。
　★★年齢の幅が、★学生より ずっと 広いです。
　★そして 見るのは ★名簿・日程・帯 ── ★小さい字が いちばん 多い画面です。
```

★**そして 調べたところ、★文字の大きさ以前に ★色の問題が ありました（§5）。**
★**そちらのほうが 急ぎます。**

# §1 ★大きな決まり ── ★設定は 1か所だけ

```
　★★運営モード専用の 設定を 作らないでください。
　★1つの設定が、★個人アプリと 運営モードの 両方に 効きます。
```

★理由：**同じ人が、同じ端末で、両方を 行き来します。**
★片方だけ 大きいのは、**壊れて見えます。**

## 1-1 ★置き場所

```
　★個人アプリ　★歯車 →「もっと」→「文字の 大きさ」
　★★運営モード　★上のバーの 右に ★同じ歯車を 置き、★同じシートを 開く
```

★**★下タブの「設定」に 入れないでください。**
★理由：**staff は 下タブが「日程」1つだけ**で、設定に 入れません。
★**staff こそ、字が 小さくて 困る人です。**

## 1-2 保存

```
　★端末ごとに 保存（localStorage）。★サーバーに 送りません
　★★読めなかったときは「ふつう」で 立ち上げる（★try/catch）
　★★アカウントに 紐づけない（★別の端末では 別の設定でよい）
```

# §2 何を 変えるか ── ★4段

| 段 | 名前 | 倍率 | 本文の大きさ |
|---|---|---|---|
| 1 | ふつう | 1.00 | 13.5px |
| 2 | 大きめ | 1.15 | 15.5px |
| 3 | もっと 大きい | 1.30 | 17.5px |
| 4 | いちばん 大きい | 1.50 | 20px |

```
　★「小さい」は 作りません。★小さくして 得をする人が いません
　★％を 出しません。★「ふつう／大きめ／もっと大きい／いちばん大きい」だけ
```

## 2-1 ★一緒に 大きくするもの

```
　◯ 文字
　◯ 行の 高さ
　◯ 文字まわりの 余白（★上下の padding）
　◯ ボタン・押せるところの 高さ
　◯ 一覧の 1行の 高さ
　◯ 日程の 1時間の 高さ（★⑧⑩ の 42px / 19px）
```

## 2-2 ★大きくしないもの

```
　✕ 枠線の 太さ
　✕ 角の 丸み
　✕ 影
　✕ アイコンの 中の 線
　✕ ★羊の絵・装いの絵（★別の話です）
```

---

# §3 ★作り方 ── rem に 直します

```css
　html { font-size: calc(16px * var(--scale)); }   /* --scale = 1 / 1.15 / 1.3 / 1.5 */
```

```
　★文字と、文字に付く 余白・高さ　→ ★rem
　★枠線・角丸・影・絵の大きさ　　 → ★px のまま
```

★**全部を rem に する必要は ありません。★上の分け方だけ 守ってください。**

## 3-1 ★下限を 持たせるもの（★縮まない・小さくならない）

```
　★入力欄の下の 1行（★連絡の「門下の全員と先生が読みます」）
　　　　→ ★★11px を 下回らない。★段1でも 11px。★段が上がれば 一緒に 大きく

　★健康の線（「この画面から 生徒の健康の記録には たどりつけません」）
　　　　→ ★★同じ。★どの段でも 消えない・折り返してよい

　★押せるところ　→ ★★どの段でも 44px 以上
```

# §4 ★大きくすると 壊れるところ（★4つ・先に 決めます）

## 4-1 ★運営モードの 下タブ（6つ）

```
　ホーム／日程／名簿／行事／連絡／設定　★6つ × 360px ＝ 1つ 60px
　★段4（1.5倍）では 入りません。
```

```
　★決め　★★下タブの 文字だけ、★上限を 1.2倍に する
　　　　　★★2行に 折り返さない
　　　　　★アイコンは いま 使っていないので、そのまま
```

## 4-2 ★帯（出欠の表）と、名簿の 表（PC）

```
　★決め　★横に ずらせるように する（★名前の列は 止めたまま）
　　　　　★★これは「本文は 横スクロールしない」の 例外です
　　　　　★★表だけ。★流れ（連絡・ノート）は 例外に しません
```

## 4-3 ★⑨ 1週間の 濃さの地図（7日 × 6人）

```
　★段1・2　★7日ぶん そのまま
　★★段3・4　★★4日ずつに 分ける（★‹ › で 送る）
```

★**横スクロールに しないでください。**地図は「ひと目で 見る」ためのものです。
★**4日でも ひと目で 見えます。★7日を 横に 流すと、意味が なくなります。**

## 4-4 ★日程の よこ持ち（⑩）

```
　★段3・4では、★6人 ぜんぶは 入りません。
　★決め　★★横に ずらせるようにする（★時間の列は 止めたまま）
　　　　　★「先生をえらぶ」で 3人に 絞れるようにする
```

# §5 ★★先に これを 直してください ── 色が 薄すぎます

★**文字を 大きくしても、★色が 薄いままなら 読めません。**
★**計算したところ、★2つの色が 基準を 満たしていません。**

| 色 | いまの値 | 紙の背景との 比 | 判定 |
|---|---|---|---|
| `--ink` #261913 | | 15.82 | ◯ |
| `--ink2` #6D5D50 | | 5.84 | ◯ |
| **`--ink3` #A79684** | | **2.65** | **★不可**（4.5未満） |
| `--enji` #840C24 | | 9.46 | ◯ |
| **`--yama` #BF8722** | | **2.90** | **★不可** |
| `--midori` #447862 | | 4.74 | ◯ |

★基準は WCAG AA の 4.5：1（本文）です。

## 5-1 ★直し（★2行だけ）

```css
　--ink3: #7C6C5E;   /* 2.65 → ★4.68 */
　--yama: #8C6115;   /* 2.90 → ★5.08 */
```

★**色みは ほとんど 変わりません。★濃くなるだけです。**

## 5-2 ★そして 使い方の 決まり

```
　★--ink3 は、★これから 罫線・アイコン・区切りにだけ 使ってください
　★★注記（.note）の 文字は、★--ink2 に します
　★→ ★「小さい字を 薄い色で 書く」を やめます
```

★**うちは 注記が 多い製品です**（★「これは並びです」「原因は分かりません」）。
★**その注記が いちばん 読みにくい、という状態でした。**

# §7 ★やらないこと

```
　✕ 端末（OS）の 文字サイズに 自動で 合わせる
　　　→ ★PWA では 当てになりません。★アプリの中で 決めます
　✕ 文字を 太くする 設定
　　　→ ★いまは 作りません。★大きさで 足りるか 見てから
　✕ 「読みやすさモード」のような まとめた名前
　　　→ ★何が 変わるか 分かりません
　✕ 印刷に 効かせる
　　　→ ★印刷は いつも 同じ大きさ
　✕ 学校が 生徒の 文字の大きさを 決める
　　　→ ★端末ごと・本人のものです
```
