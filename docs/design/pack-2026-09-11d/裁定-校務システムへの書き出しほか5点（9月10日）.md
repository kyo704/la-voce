# 裁定 ── 校務システムへの 書き出し ほか 5点

---

# 1　★校務システムへ 書き出せますか　── ★できます。ただし 形が 大事です

## 1-1　結論

```
　★★つなぐ 口（API）で つなぐのは、★いまは やりません。
　★★「取り込める 形の ファイルを 出す」── これが いちばん 確実です。
```

**理由は 3つです。**

```
　★1　★校務支援システムに、外から つなぐ 口が ほとんど ありません
　　　　BLEND／賢者クラウド／EDUCOM／システムディ ── どれも 公開の API が ありません
　　　　（★1社ずつ 交渉して 個別に つなぐと、★1校ごとに 作り直しに なります）
　★2　★どの システムも「CSV の 取り込み」は 必ず 持っています
　　　　★出席簿・名簿・時間割は、いまも 表計算で やりとりされています
　★3　★ファイルなら、学校の 側が <b>中身を 見てから</b> 入れられます
　　　　★自動で つながっていると、間違いが そのまま 流れます
```

## 1-2　何を 出せるか（★設定 →「書き出す（校務システムへ）」）

```
　名簿　　　　　　学籍番号／氏名／カナ／学部／学科／学年／担当の先生／状態／入学年月
　レッスンの 日程　日付／曜日／開始／終了／先生／学籍番号／氏名／場所／種別
　レッスンの 出席　日付／学籍番号／氏名／先生／出欠／つけた人／つけた時刻
　行事　　　　　　日付／行事名／開始／終了／場所／対象 学年／対象 学科
　役職と 所属　　 氏名／役職／学部／学科／事務の 分野
```

## 1-3　★形（ここが いちばん 手間の かかるところ）

```
　形　　　　CSV ／ Excel（.xlsx）／ ★iCalendar（.ics・日程だけ）
　文字コード ★Shift_JIS ／ UTF-8 ／ UTF-8（BOMつき）
　　　　　　★古い 校務システムは Shift_JIS が 多いです
　改行　　　CRLF ／ LF
　日付　　　2026/09/14 ／ 2026-09-14 ／ 20260914 ／ ★令和8年9月14日
```

★**★見出しの 対応表（いちばん 効きます）**

```
　うちの 見出し　　→　学校の 様式の 見出し
　　学籍番号　　　→　生徒コード（BLEND）／生徒ID（賢者）／児童生徒番号（EDUCOM）／学籍№（システムディ）
　　氏名　　　　　→　生徒氏名／氏名／学生氏名
　　出欠　　　　　→　出欠区分／出欠

　★4社の ひな型を 入れてあります。★1つ 押すだけで 列名が 変わります
　★手で 打ち直せます。★保存できます（★毎回 直しません）
　★出る ファイルの はじめの 2行を、その場で 見せます
```

## 1-4　★出さないもの（★選択肢に ありません）

```
　✕ 生徒の 声の記録　　✕ からだの記録　　✕ ノート・レパートリー
　✕ 時間割の 中身　　　✕ 受診用の 1枚　　✕ 連絡の 本文
　✕ くらべる・かぞえるの 結果

　★★「切り忘れ」が 起きないように、★はじめから 選べなくして あります。
```

## 1-5　★守ること

```
　★★誰が・いつ・何を 書き出したかが 残ります（★個人情報を 外へ 出す 行為だからです）
　★iCalendar は 1件ずつ 変わらない 番号（UID）を つけます（★二重に 入りません）
　★★取り込み（校務システム → うち）は、★まだ 作りません
　　　★1校目が 決まって、その学校の 様式を 見てから 作ります
　　　★推し量って 作ると、★作り直しに なります
```

# 2　★重なりの「このままで よい」を 取り消せます

**★ご指摘のとおりです。★片づけたら 二度と 戻せない のは、危ないです。**

```
　「このままで よい」を 押すと
　　★片づいた 印に なります
　　★★<b>誰が・いつ 片づけたか</b>が 下に 出ます
　　★そこに「★やっぱり 直す（取り消す）」が 出ます
　　★押すと、★知らせた 状態に 戻ります（★まだ 知らせていなければ「まだ」へ）

　★先生の 側も 同じです
　　「動かせません」などの 答えにも「★答えを 取り消す」を 置きました
```

# 4　★門下の 連絡は、ふだん 運営から 見えません（★変更）

**★坂本さんの ご判断です。★私の 前の 裁定を 変えます。**

```
　いままで　★事務・責任者は 門下の 連絡を いつでも 読める
　これから　★★ふだんは 見えません。★門下の 一覧そのものが 出ません
```

★**そのとおりだと 思います。**
　★事務が 日頃 門下の 中身を 確かめる 用事は、★ありません。
　★見られる状態を 置いておくこと 自体が、★事故の 種です。

## 4-1　では、事故・苦情の ときは

```
　★役職の「できること」に、こう 置きました
　　　★事故のときに 門下を 読む（★ふだんは 切ってあります）

　★★はじめは、どの 役職にも 入っていません（★10役職 ぜんぶ ✕）
　★いちばん上の 役職（学長）が、必要なときに 入れます
　★入れている 間は、連絡の 画面に ★帯が 出ます
　　　「いま、門下を 読める 状態に なっています。★調べが 終わったら 切ってください」
　　　★その場で 切れます
　★開いた記録は 残ります（★運営の 中だけ・求められたら お見せします）
```

★**これで、「ふだんは 見えない」と「事故のときは 調べられる」が 両立します。**

# 5　★「未送信 2件」が 開けなかった

**★私の 作り忘れです。★画面を 作りました。**

```
　★上のバーの 黄色い 札を 押す　→　未送信の 画面
　★連絡の 画面の 帯からも 行けます

　2つに 分けて 出します
　　★下書き（★書きかけ・宛先や 本文が 途中）
　　★送れませんでした（★つながらなかった）

　できること
　　★つづきを 書く　→ その 中身の まま「おしらせを 書く」へ
　　★もう一度 出す（★送れなかったもの）
　　★消す（★5秒だけ もどせます）
```

★**書きかけは 消えません。**★途中で 閉じても、ここに 残ります。
★**送れなかったものを、こちらで 勝手に 出しません。**★つながっても 自動で 送りません。
★★**予約投稿は 作りません。**★「◯日に 出す」を 作ると、★間違いに 気づけません。

# 6　★出席を、一度に つけられるように しました（★追加）

```
　★「ぜんぶ 出席」「ぜんぶ 休み」「ぜんぶ 休講」「ぜんぶ 消す」
　　→ ★そのあと、ちがう方だけ 押して 直します

　★ふだんは ほとんどが 出席です。★1人ずつ 押すのは 時間の むだです。
　★まだ つけていない方は、★うすい 帯と「まだ」の 札で 出します
　★上に「出席 4　休み 1　休講 0　★まだ 1」
```

★**「中止」を「休講」に 変えました。**

```
　★休講 ＝ ★その回を <b>しなかった</b>とき（★先生の 都合・行事・台風など）
　★★休講は 生徒の 欠席に なりません。★数にも 入りません。
```
