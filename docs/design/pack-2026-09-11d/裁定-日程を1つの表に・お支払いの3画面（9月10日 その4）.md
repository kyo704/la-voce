# §1 ★1つの 表に しました

## 1-1 ★なぜ 分けていたのが よくないか

```
　★日程を 組む とき、先生は <b>行ったり 来たり</b> します。
　　「火曜の 3限は 会議だ」→ 予定の 画面へ → 入れる → 組む 画面へ 戻る → …

　★★<b>切り替えるたび、頭の 中の 週が 1回 消えます。</b>
　★同じ 週を 見ているのに、画面が 2つ ある のが 間違いでした。
```

## 1-2 ★どう なったか

```
　★<b>表は 1つ</b>。マスの 中身は 3つの どれか。
　　　数字（来られる人数）　／　緑（置いた レッスン）　／　灰（自分の 予定）

　★<b>マスを 押す</b>　→ 右（スマホは 下）に、その マスの ことが 出ます
　　　・空き　→ ★来られる方の 一覧（置く）　＋　★「レッスン いがいの 予定に する」
　　　・レッスン　→ 長さ・場所・くり返し・外す
　　　・予定　→ 学校／じぶんの 切り替え・名前・外す

　★★<b>マスの すみの「＋予定」</b>　→ ★1回 押すだけで 予定に なります
　　　（★どんな 名前で 入るかは、表の 下の チップで 決めます。★既定は「予定」）

　★<b>曜日の 見出し ⇣ ／ コマの 見出し ⇢</b>　→ その列・その行を まとめて
　　　★★<b>レッスンの 上には かぶせません</b>（★置いた ものは 守ります）
```

## 1-3 ★変えていないこと

```
　★★予定の マスには レッスンが 入りません（手でも 自動でも）
　★★予定の 中身が 見えるのは <b>本人だけ</b>。事務には「予定あり」だけ
　★★じぶんの 予定には、事務から「動かしてください」と 言えません
　★設定 →「自分の 予定」も <b>そのまま 残します</b>（★同じ 部品 `mineEdit()`）
　　（★学期の 頭に まとめて 埋める ときは、こちらの 方が 速いからです）
```

# §2 ★お支払い ── 3つの 画面

## 2-1 ★支払い方法を 変える（★`bill_pay` だけ）

| 選べるもの | ★決まり |
|---|---|
| クレジットカード | 毎月 引き落とし |
| 口座振替 | ★手続きに 1〜2か月 かかる、と 先に 書きます |
| 銀行振込（請求書） | ★**年払いのみ**。★毎月の 振込は 双方の 手間が 大きすぎます |

```
　★★★<b>カード番号は Woolsong に 入りません。</b>
　★★★<b>口座番号も Woolsong に 入りません。</b>

　★入れる 欄を <b>作りません</b>。★カード会社・金融機関の 画面へ 送ります。
　★うちに 残るのは <b>下4けたと 有効期限だけ</b>。
　★→ ★これは 便利さの 話では なく、★<b>持たない</b>という 決めごとです。
　★→ ★持たなければ、漏れません。★健康の 記録と 同じ 考えです。

　★引き落としの 日　25日／27日／月末 から
　★★<b>変えても、いまの 月の ご請求は 変わりません。</b>★次の ご請求から。
　★★<b>解約は この画面に ありません。</b>★お問い合わせから 承ります
　　（★誤って 押せる ところに 置きません）
```

## 2-2 ★あて先（名義）を 変える（★`bill_pay` だけ・★両方の 承諾）

```
　★あて先＝<b>お金の 責任を 持つ 1人</b>。★見る・払うは 何人でも。

　★流れ　★申し出る → ★相手が 承諾する → ★変わる
　★★<b>押しただけでは 変わりません。</b>
　★★<b>承諾されるまで、いまの あて先の ままです</b>（★止まりません）。
　★申し出は <b>1回だけ</b> 届きます。★催促しません。★取り消せます。
　★候補に 出るのは <b>ご請求を 見られる 方だけ</b>
　　（★見えない 人に 責任を 持たせません）

　★★<b>あて先の 方が 学校を 離れる ときは、先に 引き継いでください。</b>
　★　引き継がずに 役職を 外すと、★<b>誰も 払えなく なります</b>。
　★　→ ★この 一文を 画面に 出しました。★事故が 起きてからでは 遅いです。
```

## 2-3 ★領収書を 出す（★`bill` でも 出せます）

```
　★月ごと ／ 年度で まとめて（1枚＋明細）
　★宛名（★既定は 学校名。★「上様」に しません ── 経理で 通らないことが あります）
　★但し書き　★形（PDF ／ PDF＋明細CSV）
　★右に <b>出る 紙の 見た目</b>を そのまま 出します（★出す前に 確かめられます）
　★インボイス登録番号（★Woolsong の 番号）を 印字します

　★★<b>領収書は 消せません。</b>★出したことが 記録に 残ります。
　★★<b>2回目からは「再発行」と 印字します。</b>★同じ紙が 2枚 出回らないように。
　★★<b>宛名を 直しても、すでに 出した ものは 変わりません。</b>

　★★<b>払える人だけに 絞りません。</b>
　★　理由 ── ★経理の 方が 出せないと、★毎回 学長に 頼むことに なります。
　★　→ ★<b>見られる方 みんなが 出せます</b>。

　★★領収書の どこにも、<b>生徒の 名前も 健康の 記録も 出ません</b>。
　★　★人数と 金額だけです。
```

## 2-4 ★記録（★3画面 共通）

```
　★誰が・いつ・何を したかを 1行 残します。
　　（支払い方法を 変えた／あて先の 申し出／承諾／領収書を 出した／宛名を 直した）
　★★<b>消せません。</b>
　★3つの 画面 ぜんぶの 下に、同じ 記録を 出します。
```
