# 裁定 ── いくつもの 教室に 通う 生徒

**★ご指摘のとおりです。★これは「あると 良い」ではなく、★無いと 売れない ものでした。**

```
　音大の 学生は、たいてい 学外の 先生にも ついています。
　養成所の 生徒は、ボイトレにも 通います。
　★★そして 大学は、その ことを 知らない ほうが よいのです。
```

---

# §0 決めたこと（★1行ずつ）

```
　★1　生徒は いくつでも 教室に 入れます。★予定は 1つの 表に まとまります
　★2　★まとめて 見られるのは、★ご本人だけ です
　★3　教室に 見えるのは、★その教室の ぶんだけ
　★4　★★「よそにも 通っている」こと そのものを、教室に 知らせません
　★5　入り方は 2つだけ ── ★招かれる ／ ★合言葉。★こちらから 探せません
　★6　同意は ★教室ごと。★いつでも 外せます。★外しても 記録は 消えません
```

---

# §1 何が 誰のものか（★これが 全部の 土台です）

```
★★生徒 個人のもの（★教室に 属しません。★1つだけ）
　　記録（声・からだ）／ノート／レパートリー／受診用の 1枚
　　ひつじ・おうち・持ちもの
　　★★時間割（★1枚だけ）

★教室ごとのもの（★教室の 数だけ あります）
　　名簿の 在籍／その教室の レッスン／その教室の 行事と 出欠
　　その教室の 門下の 連絡／その教室の 同意
```

★**時間割が「生徒 個人のもの」であることが、この設計の 要です。**
★**教室ごとに 時間割を 分けると、★「よそのぶん」という 箱が できてしまいます。**

# §2 生徒の 画面

## 2-1　きょう ── 1つの 予定表

```
　きょうの よてい　　［ぜんぶ］［○○音楽大学］［△△声楽教室］
　　16:00　声楽A　斎藤先生　　　○○音楽大学　　第1教室
　　18:00　レッスン　鈴木先生　　△△声楽教室　　△△ 第2スタジオ
　　19:00　自主練　　　　　　　（印なし＝あなただけの 予定）

　★通っている ところが ぜんぶ、1つの 予定表に 出ます
　★★教室どうしは、おたがいの 予定が 見えません
```

## 2-2　時間割 ── よその レッスンは 自動で ふさがる

```
　あき　　　　　　　★先生に「あき」と 届く
　来られない　　　　★先生に「あきでない」と 届く（★理由は 届かない）
　授業　　　　　　　★先生に「あきでない」と 届く（★名前は 届かない）
　★ほかの 教室　　★先生に「あきでない」と 届く
　　　　　　　　　　★★どこの 教室かも、名前も 届かない

　★色を 分けて、生徒には どれが 何か 分かるように します
　★よその 教室の コマは、★その教室で 決まったものなので ここでは 直せません
```

★**先生の 画面には「あき／あきでない」の 2値しか 行きません。**
★**だから、よそに 通っていることが 自動的に 伏せられます。**

## 2-3　連絡 ── 教室ごとに 分かれます

```
　［○○音楽大学］［△△声楽教室］
　　その教室の おしらせ ＋ その教室の 門下 だけ
　★「休むことを 伝える」も、その教室の 先生に だけ
```

## 2-4　★重なり ── ご本人にだけ

```
　きょうの 画面に 1行
　　「予定が 1件 重なっています　9月12日（金）14:40 ／ 2つの 教室」

　押すと
　　① ○○音楽大学　斎藤 めぐみ 先生　第1教室
　　② △△声楽教室　鈴木 かおる 先生　△△ 第2スタジオ
　　［斎藤先生に 伝える］［鈴木先生に 伝える］［時間割を 直す］

　★★どちらを 動かすかは、ご本人が 決めます
```

# §3 ★運営（教室）の 画面 ── 変えたこと

## 3-1　★「同じ 生徒の 重なり」を、運営から 外しました

**★これは 私の 設計の 誤りでした。**

```
　いままで　同じ 生徒の 重なりを ★両方の 先生に 出す
　　　　　　→ ★★「よそに 通っている」ことが、そこで 漏れます
　　　　　　→ ★しかも 相手の 教室名まで 見えていました

　これから　★運営の「重なり」に 出すのは
　　　　　　　★同じ 場所（部屋）　★同じ 先生　── この2つだけ
　　　　　　★同じ 生徒の 重なりは ★ご本人の 画面にだけ
```

★**運営の 画面には、その旨を 灰色の 行として 書いてあります**（★隠しません）。

## 3-2　教室に 見えるもの／見えないもの（★生徒に そのまま 見せます）

```
★見えます
　　お名前 ／ 学年・コース（その教室のもの）
　　その教室の レッスンの 出欠
　　その教室の 門下の 連絡に 書いたこと
　　その教室の 行事の 出欠
　　★あなたが「あき」と 入れた 時間（★あきか どうかだけ）

★見えません
　　声と からだの 記録
　　ノート・レパートリー・受診用の 1枚
　　ひつじ・おうち
　　時間割の 中身（授業の 名前・教室・備考）
　　★ほかの 教室の こと
　　★★ほかの 教室に 通っていること そのもの
　　来られない 理由
```

# §4 ★どうやって 増やすか

## 4-1　入り方は 2つだけ

```
　★① 招かれる（★ふつうは これ）
　　　教室が メールで 招く → 生徒の「招かれている ところ」に 出る
　　　→ ★見えるもの／見えないものを 見てから、★承知して 入る

　★② 合言葉で 入る
　　　教室が 出す 6文字を 打つ → 教室の 名前が 出る
　　　→ ★見えるものを 確かめる → ★承知して 入る
　　　★小さい 教室・体験レッスン向け
　　　★合言葉は 教室が いつでも 作り直せます（★出回ったときの ため）
```

## 4-2　★★「教室を 探す」を 作りません

```
　✕ 教室の 一覧・検索・地図
　★理由　★さがせると、★誰が どこに 通っているかが 分かってしまいます
　　　　　★「◇◇教室に 高木 みなみ さんが いる」が 見えたら、それだけで 事故です
```

## 4-3　承知（同意）は ★教室ごと

```
　★1つの 教室に 入る＝★その教室ぶんの 同意 1つ
　★ほかの 教室には かかりません
　★契約では 代えられません。★ご本人から いただきます
　★18歳未満の方は、保護者の 承知も
```

## 4-4　やめるとき

```
　★いつでも 外せます
　・その教室の 名簿から 外れます
　・その教室の 予定・行事・連絡が、生徒の 画面から 消えます
　・その教室から、その生徒が 見えなくなります

　★★記録・ノート・レパートリー・ひつじは 1つも 消えません
　★これまでの 出欠と 連絡は、教室の 記録として 残ります（★運営の 義務）
　★しらべるが その教室の 束で ついていた場合は 止まります（★記録は 消えません）
```

# §5 お金の こと

```
　★数える 人数は ★教室ごと です。
　　2つの 教室に 入っている生徒は、両方が 1人ずつ 数えます。
　　★これは 二重取りでは ありません。★別々の 学校が、別々に 払っています。

　★★「しらべる」（生徒 個人の 有料機能）は 二重取りしません。
　　どちらかの 束が 効いていれば、それで 有効です。
　　（★9月10日「D束」の 二重取り防止の 決まりが、そのまま 使えます）
```

# §6 ★Code への 仕様

```
★1　Enrollment(orgId, studentId, status) を ★複数 持てるようにする
★2　生徒の 予定の 問い合わせ　orgId IN (自分の 所属ぜんぶ)
　　 教室の 問い合わせ　　　　orgId = その教室 に ★固定（★RLS で）
★3　★★時間割は orgId を 持たない（★生徒 個人の 1枚）
　　 教室に 返すのは ★free / busy の 真偽値だけ
　　 ★busy の 理由（授業名・よその教室・来られない）を ★1バイトも 返さない
★4　★★教室側の API に「その生徒が ほかに 所属しているか」を 返す口を 作らない
　　 ★件数も 返さない（★0か 1以上かも 漏れます）
★5　重なり検出
　　 場所・先生　→ 教室の 運営へ
　　 ★生徒　　　→ ★★生徒本人へ だけ。★先生・運営には 出さない
★6　同意（Consent）は (orgId, studentId) の 組で 1件ずつ
★7　合言葉（join code）は org ごと。★再発行できる。★失効させられる
★8　★教室の 検索・一覧の API を 作らない
★9　退会：Enrollment を 終了。★記録（生徒個人）に 触らない。
　　 ★出欠・連絡は 教室側に 残す（★保存期間は 教室の 規程に 従う）
```

　★大学に　「学外の 先生に ついている 学生のことは、
　　　　　　　★大学からは 見えません。★見えないほうが 安全です」

★**「見えない」ことが、そのまま 売りに なる 数少ない 機能です。**

# §8 ★確かめました ── よその 教室の コマは、大学から「あき」に 見えません

**★見本の 中で、実際に 数えて 確かめました（2026年9月10日）。**

## 8-1　生徒の 側

```
　1週間の コマ　　　　　　　　　　　36
　授業も 印も 入っていない コマ　　  18
　★そのうち、よその 教室の レッスン   2
　────────────────────────
　★★先生に「あき」と 届く コマ　　　16
```

★**よその 教室の 2コマは、あきの 数から 引かれています。**
★**画面にも「先生に 見える あき　16コマ」と 出します**（★18では ありません）。

## 8-2　先生（大学）の 側

```
　★門下 8人 × 36コマ を 総当たりで 確かめました

　　よその 教室の レッスンが ある コマで
　　「あき」と 判定されたもの　　　　★0件

　　「この時間に 来られる方」の 一覧に
　　よその 教室の 人が 混ざったもの　★0件

　　「置ける枠を 見る」に
　　よその 教室の コマが 出たもの　　★0件
```

## 8-3　しくみ（★1行）

```
　あき ＝ 「授業が 無い」かつ「来られない印が 無い」かつ「よその 教室の レッスンが 無い」

　★この3つを ★端末の中で 1つの 真偽値に して から 送ります。
　★★どれが 理由で ふさがっているかは、★送りません。
```

★**だから 先生の 画面では、**
　★「授業で 埋まっている」も
　★「バイトで 来られない」も
　★「よその 教室の レッスン」も
　★**まったく 同じ「あきでない」に 見えます。**

★**どこの 教室かも、名前も、理由も、件数も、1バイトも 出ません。**
