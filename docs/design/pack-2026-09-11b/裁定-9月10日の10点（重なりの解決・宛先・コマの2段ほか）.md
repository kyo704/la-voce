# 裁定 ── 10点（重なりの解決・宛先・コマの 2段 ほか）

**★スマホ版・PC版の 両方に 入れました。**

---

## 1　★重なりを、事務が 知らせ、先生が 直す

**★これまでは「印を つけるだけ」で 止まっていました。★先に 進めます。**

```
【事務】重なりの カード
　　「担当の 先生に 知らせる」　→ ★両方の 先生に 1回だけ
　　「まだの ぶんを ぜんぶ 知らせる」
　　「このままで よい」　→ その1件だけ 片づく
　　★状態が 出ます ── まだ／知らせた／片づいた
　　★先生の 答えが、この画面に そのまま 出ます

【先生】ホームに「あなたの 重なり ◯件」
　　★3つから 選びます
　　　① わたしが 動かします → ★空いている 枠の 一覧／★部屋を 変えるだけ
　　　② 動かせません　　　 → もう一方の 先生と 事務に そのまま 伝わる
　　　③ 事務に お願いする
　　★★両方が「動かせません」なら、事務が 引き取ります（★止まったままに しません）
```

★**事務は 動かしません。**動かすのは 先生です（★教える 中身に つながるからです）。
★**先生どうしの 自由な やりとりは 作りません。**★決まった 3つの 答えだけです
（★アプリ内メッセージ・教師どうしの DM は 恒久的に 作らない、の 決まりを 守ります）。
★**理由は 聞きません。★体調は どこにも 出てきません。**
★時間を 動かしても、部屋を 変えても、★生徒には **1回だけ** 知らせが 行きます。

## 4　★行事の 出欠は 集めません（★レッスンの 出席は 残します）

```
　✕ 行事の 出欠を 生徒に 提出させる
　✕ 行事の 出欠の 一覧を 運営が 見る
　✕ 行事の「出ます ◯人」

　◯ 行事は ★日・時間・場所・対象を 知らせるだけ
　◯ 一覧には「★◯人に 届きます」だけ

　★★レッスンの 出席は 残します（★先生が その場で つけます）
　　　出席／休み／中止　★押した その場で 変わります
```

★**理由：**行事の 出欠は、レッスンの 出席と <b>二重</b>に なります。
★そして 集めた瞬間、★「出なかった人」の 一覧が できます。★それは 作りません。

## 8　★開いた記録を、生徒・先生に 出さないことに しました（★変更）

**★9月10日の 私の 裁定を 変えます。★坂本さんの ご判断です。**

```
　いままで　★開いた記録を 生徒・先生の 画面からも 見せる
　これから　★★運営の 中だけで 見ます
```

★**理由（坂本さんの 判断を、私の ことばで 補います）：**
　★生徒の 画面に 常に 出すと、**見られている**という 気持ちを 毎日 与えます。
　★それは **記録の 正直さを 下げます**。★書かなくなる ほうが、はるかに 損です。

★**かわりに、この 3つで 約束を 守ります。**

```
　★1　利用規約と 学校向けの 1枚に、はっきり 書く
　　　「運営は、門下の 連絡を 読むことが できます。読んだ 記録が 残ります」
　★2　求められたら お見せする（★個人情報の 開示請求。★30日以内）
　★3　★記録は 消せない。★消した記録も 残る
```

★**生徒の 記録（声・からだ）は、そもそも 画面が ありません。**★ここは 連絡だけの 話です。

## 10　★時間の わり方を 2段に（学校の 基本 ＋ 先生の 個人）

```
　★学校の 基本　　学長・事務長・課長・職員 など が 決めます
　　　　　　　　　1限 9:00〜10:30 …　★全員の もとに なります

　★先生の 個人　　★先生が その 中で 決めます
　　　　　　　　　★はじめは 学校の 基本を 写します
　　　　　　　　　★90分を 45分 × 2 に 割る／10分 ずらす／昼を 長くする
　　　　　　　　　★「学校の 基本に もどす」も あります

　★★事務は、先生の コマを ★見るだけ。★直せません
　　　（★レッスンの 長さは 先生の 仕事です。
　　　　★事務が 動かすと、教える 中身に 手を 入れることに なります）

　★学校の 基本を 変えると、★自分で 決めていない 先生には すぐ 反映
　★自分で 決めている 先生には 反映しない（★1回だけ 知らせる）
　★★「日程を 組む」の 表は、その先生の コマで 出ます
```

★**できることも 2つに 分けました。**
```
　koma　　　学校の 時間の わり方・場所を 直す　（★学校ぜんぶに かかる）
　koma_mine 自分の コマを 決める　　　　　　　（★その方 自身にだけ）
　★教授・准教授・講師は koma_mine だけ。★学校の コマは 直せません
```

## 11　★自動で 振り分ける ときの 条件

**★「ぜんぶ 自動」に、先生が 条件を 付けられるように しました。**

```
　あけておきたい 曜日　　★研究日・非常勤の 日
　あけておきたい 時間　　★昼休み・朝いちばん・最終コマ
　1日に 入れる 上限　　　（既定 4）
　★続けて 入れる 上限　　（既定 3）
　★続けたあと あける コマ数（既定 1）
　　　★★声を 使う 仕事です。★先生の のども 守ります
　自分の 授業・会議を よける（既定 入）
　埋め方　　早い順（朝から）／遅い順（夕方から）
　　　　　　まとめる（同じ日に 固める）／散らす（曜日を ばらす）
　置く 順番　空きが 少ない方から／上級生から／下級生から
```

★**「空きが 少ない方から」が いちばん 置けます**（★置けない方を 作らないため）。
★**条件を 守れない方は、置かずに 残します**（★無理に 押し込みません）。
★★**生徒の 都合（空きコマ）は、条件より 優先です。**★来られない 時間に 置くことは ありません。
★**自動は 下書きです。**押したあと、いくらでも 直せます。
★条件は 覚えておきます。★次に 組むときも 同じ条件から 始まります。
