# §3 ★★文字を 大きく（★老眼対策）

## 3-1 ★考え方

```
　★★<b>画面の 外わくは 変えません。</b>
　★★<b>中の 字と ボタンを 大きく</b>し、その ぶん 1画面に 入る 量を 減らします。

　★これは、字だけ 大きくするのとは 違います。
　★★<b>押せる ところも 一緒に 大きく</b>なります。
　★（★字だけ 大きくすると、★押しにくさは そのまま 残ります）
```

## 3-2 ★4段

```
　★ふつう　／　大きめ（1.2倍）　／　もっと（1.45倍）　／　いちばん（1.75倍）
```

## 3-3 ★どこから 変えるか

```
　★PC・iPad　★上のバーの <b>「あ」</b>（★押すたび 次へ）　＋　設定 →「見やすさ」
　★iPhone・スマホ　★右上の <b>「あ」</b>　＋　設定 →「見やすさ」
```

## 3-4 ★★大きくすると レイアウトが 変わります

```
　★★<b>1.45倍からは、横ならびを やめて 上下に します。</b>
　　　（表 ＋ 右の パネル）→（表　その下に パネル）
　★→ ★表が <b>画面いっぱい</b>に 使えるので、月〜土が ぜんぶ 見えます。
　★→ ★ここを やらないと、★大きくするほど 表が せまくなり、★かえって 見えません。

　★★<b>出るものは 1つも 減りません。</b>★隠しません。★たたみません。
```

## 3-5 ★Code への 申し送り

```
　☐ ★見本では CSS の <b>zoom</b> と、<b>幅を その ぶん 割る</b> やり方に しました。
　　 ★（zoom:1.45／width:calc(1400px / 1.45)）→ ★見える 大きさは そのまま。
　☐ ★本番（React）では、<b>rem を 基準に</b> して、
　　 ★ルートの font-size を 変えるのが きれいです。

　☐ ★★端末の 設定（iOS の 文字サイズ・Android のフォントサイズ）にも <b>従ってください</b>。

```
