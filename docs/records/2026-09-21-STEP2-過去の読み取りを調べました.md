## 門下が読まれた跡はあるか

**ありません。** 理由は2つです。

1. `monka_read` を持つ方が **0人** です（本番で数えました）。
   決まりの枝は「`monka_read` を持つこと」を求めていました。
   持つ人がいなければ、その枝は1度も通りません。
2. `teacher_id=in.(99b695d8…)` の6件は、その先生ご本人か
   その門下の学生からのものです。その先生には門下が2人います。
   ご本人と門下の学生が読むのは、もともと正しいことです（裁定76）。

★ただし、**「1日ぶんで見たかぎり」です。** 残りの10日は記録が
ありません。そこで何があったかは、誰にも分かりません。

## 分かったことと、分からないこと

| | |
|---|---|
| 分かったこと | `monka_read` を持つ方は本番に0人。だから決まりの枝は通りようがなかった |
| 分かったこと | 残っている1日ぶんに、他人の門下を読んだ跡はない |
| ★分からないこと | 2026-09-10 から 09-20 までの10日ぶん。記録が残っていない |

★「読まれていない」とは書きません。「読まれた跡は見つからなかった」です。
0人という数のほうが、記録より強い根拠です。
