## 四 ── 「引数を無くして `auth.uid()` を使う」は、いまの呼び手を壊します

呼び手は2つ。どちらも **管理の客（service_role）** で、サーバが持っている
利用者の id を渡しています。

```
app/admin/page.js:167              admin.rpc("admin_entry_stats", { p_user_id: user.id })
app/api/character/unlock/route.js:87  admin.rpc("character_unlock_summary", { p_user_id: user.id })
```

★`service_role` の下では `auth.uid()` は **null** です。
引数を無くして `auth.uid()` を使う形にすると、**両方とも動かなくなります**。

この品の設計は「サーバが確かめて、サーバが呼ぶ」です。
関数は呼び手が誰かを知りません。知らないことは、源の註にも書いてあります。
