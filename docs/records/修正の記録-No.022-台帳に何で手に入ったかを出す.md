## 2. ㋐ ── 台帳の行に、理由の1行

見本 `SC['台帳']` の1行は、名前の下に理由が小さく入ります。
入口の札も「台帳（**いつ・何で** 手に入ったか）」と書いています。

`lib/itemLedger.js` に `acquisitionReason(row, t)` を足しました。

- `shop` … 「買いました」（条件がないので、道の名前をそのまま）
- `gift` … 「贈りもの」（同上）
- `unlock` … どの条件で開いたか

### unlock の逆引き

`item_acquisitions` が持つのは `shop／gift／unlock` の3つだけで、
**どの条件で開いたかは残っていません**。

`lib/sheepWardrobe.js` の `UNLOCKS` は「条件 → 品」の向きなので、
品の鍵から逆に引きます。逆引きは1度だけ作ります。行ごとに作りません。

```
propBouquet   → firstPerformance    花束
tailcoat      → performances10      燕尾服
propBaton     → firstPianissimo     指揮棒
propMetronome → tenFieldKinds       メトロノーム
hatCamellia   → practiceGoalDone    椿の髪かざり
```

### 引けないときは、何も出しません

- 条件のない品を `unlock` で渡されたとき
- 言葉が見つからないとき（鍵の文字を画面に出しません）
- 行がないとき／知らない道のとき

すべて空文字を返し、その行は描きません。作り話をしません。

### 言葉は itemLedger.js に書き写していません

9言語を持つのは `lib/translations.js` です。
`itemLedger.js` が決めるのは「どの鍵を使うか」だけです。
`t()` は呼ぶ側（`VocalTracker.jsx`）から渡します。
渡されなければ、理由の行を出しません。
