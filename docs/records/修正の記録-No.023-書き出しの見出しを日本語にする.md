## 1. ㋒ ── CSV の見出しを日本語に

いままで、CSV の見出しはデータベースの列名がそのまま出ていました。

```
date,throat_condition,voice_quality,resonance_score,sleep_hours,…（66列）
```

いまは、こうです。

```
日づけ,からだの 感じ,声の 出来（5段階),声の 出来（0〜10),眠った 時間,…
```

`lib/exportData.js` に `ENTRY_COLUMN_LABELS`（73件）と `headingOf()` を置きました。
`entriesToCsv()` は見出しの行だけを通します。**中身は1つも変えていません。**

### ★列名を、そのまま日本語にしていません

裁定の条件 ──
「見出しは『列名の意味』ではなく『実際に格納されている中身』を表すこと」。

| 列 | 実際の中身 | 見出し |
|---|---|---|
| `throat_condition` | **bodyFeel** | からだの 感じ |
| `voice_quality` | 5段階 | 声の 出来（5段階） |
| `resonance_score` | 0〜10 | 声の 出来（0〜10） |

`throat_condition` を「のどの調子」と訳すと、嘘を印刷します。
`rowToEntry` は `bodyFeel: row.throat_condition` と書いています。
見張りが、この前提そのものも毎回確かめます。

列の改名は別途あとです。それまで見出しだけを正しくします。

### ★逆に、正しく名づけられているもの

`wake_note` ／ `routine_note` ／ `pianissimo_high_note` の `note` は
**音名**です。「メモ」ではありません（`labelWakeNote` =「起き抜けの地声の音名」）。

- 起き抜けの 地声の 音名
- ルーティーン後の 地声の 音名
- ピアニッシモで 出せた 高い 音名

### ★名前の無い列は、列名のまま

空にしません。空にすると、どの列か分からなくなります。
列は今後も増えます。見張りが「名前の無い列」として数えます。

### ★止めている測り

`cpps_value` は `lib/pausedFeatures.js` の `measure.cpps` で止めています
（値が実際より低く出る。数字が信用できない）。
列も値も消していません。見出しは
「録音から 出した 数（2026年9月1日に 止めました）」としました。
尺度の名前を出していません。

## 3. ㋓ ── 約束

★見張りが緑になってから出しました（裁定の順序）。
守れていない約束を先に書かないためです。

```
書き出しは いつでも 無料です。退会された あとも、お手元の ファイルは あなたの ものです。
```

根拠 … GDPR 20条（持ち運べる形で受け取る権利）＋ 12条5項（そのために料金を取らない）。

★文言だけでなく、実際の義務として扱います。2つの縛りです。

1. 「いつでも無料」… `REQUIRE_SUBSCRIPTION` が true になっても、
   書き出しの道に門を置かない。
2. 「退会されたあとも」… 手元のファイルに期限を付けず、遠隔で消さない。

見張り⑦が、`startExport()` に支払いの門が無いことを毎回確かめます
（見るのは `reauthStillValid` ── 本人確認だけ）。
