## 1. 方向性には賛成します

坂本さんの指摘が正しいです。

> 落語家によく出てくる声の高さという概念自体がないと思われます。

**「テッシトゥーラ」は、歌のための枠組みです。**
曲には決まった音域があり、その中心が快適音域からどれだけ離れているかで負荷が決まる。
**噺には、それがありません。**

**私が §2 で「役の高さ」「地の高さ」と書いたのは、歌の枠組みを、
歌でない仕事に当てはめたものでした。**当てはまっていませんでした。

---

## 2. ★ただし、属性を「高さ」に変換しないでください

**あなたの §3（属性ごとに代表的な高さの目安を裏側で割り当てる）は、
計算式を変えずに済むという点で、うまい案です。★しかし採りません。**

### 2-1｜理由：songFactor は「本人比」の仕組みです

```
center = (低い方 + 高い方) / 2        ★本人の快適音域の中心
d      = (テッシトゥーラ − center) / half
```

**分母も分子も、その人自身の音域で決まっています。**

そこに「子供の声 → 高め」という**絶対的な属性**を入れると、**意味が壊れます。**

```
落語家Aが「女の声」を出すとき  → 常用域から3半音上げるだけ
落語家Bが「女の声」を出すとき  → 裏声に近いところまで上げる

★同じ「女の声」でも、本人比の距離が全然違います。
```

声優も同じです。**少年役を地声でやる人と、かなり上げる人がいます。**

### 2-2｜理由：★未較正の定数を、実データゼロで足すことになります

憲章 §1-5 の係数はすべて仮置きですが、**それらは既に実データを集め始めています。**
属性→高さの変換表は、**落語家も声優もテスターにいない状態で作る新しい仮置き**です。

**声の型の配合を「v1では計算に使わない」と決めたのと、同じ規律です。**

---

## 3. ★声優には、既に答えがあります

**声質係数が、まさに「役の属性 → 負荷」の変換表です。**

```
声質  ナレーション 0.8 ／ 通常の芝居 1.0 ／ ★張り上げ 3.5
      ★叫び 5.0 ／ ★悲鳴 6.0 ／ ★ダミ声 4.0
```

**声優の負荷は、高さではなく「出し方」で決まります。そしてそれは既に拾っています。**

```
★声優には、テッシトゥーラ相当の項目を作らないでください。
　「役の高さ」も「役の属性」も、新しくは作りません。
　既にある声質係数で足ります。
```

**§2 の「声優：役の高さ」という行は、削除してください。**

## 4. 落語 ── 演目に紐づけます

### 4-1｜対応関係

```
声楽     曲     → 曲にはテッシトゥーラがある
落語     演目   → ★演目には登場人物がいる
```

**噺には決まった登場人物がいます。**「時そば」なら男が二人とそば屋。
**演目ごとに固定できるので、毎回選ばせる必要がありません。**

**曲目カードで曲の最高音を一度登録するのと、同じ形になります。**

### 4-2｜選択肢（★坂本さんの言葉をそのまま使います）

```
□ 地の声（噺家自身）
□ 男の声
□ 低い男の声
□ 女の声
□ 子供の声
```

**★これは坂本さんが挙げたものです。落語家に確認するまで、増やさないでください。**

### 4-3｜★v1 では、計算に使いません

```
□ 演目に、登場人物の属性を複数選択で持たせる
□ ★記録するだけ。負荷の計算に入れない
□ ★係数を作らない
```

**伴奏（ピアノ／オーケストラ／バンド／音源）と同じ扱いです。**

**落語家のデータが集まってから、実測で係数を決めます。**
それまでは、**演目の時間 × 活動係数 1.6（高座）**で足ります。

### 5-2｜私の見立て

**「地声寄り／高め／低め／特殊」と「子供／女/男/低い男/地の声」は、
性質が違うように見えます。**

```
前者   ★本人比（自分の地声からどうか）
後者   ★キャラクターの属性（絶対的な種別）
```

**もしそうなら、案A（そのまま流用）は成り立ちません。**
選択肢が違うものを指しています。

```
案A そのまま流用       → ★おそらく無理。意味が違う
案B 新しい列を作る     → データが入っていて、他から読まれているなら、これ
案C voice_type を拡張  → 中身が同じ方向を向いていて、他から読まれていないなら、これ
```

**★数えた結果を報告してください。そのうえで決めます。**

### 5-3｜「足すなら外せるものを1つ探す」との関係

**兼用を避ける原則（年齢の件）と、矛盾しません。**

```
兼用を避けるのは、★間違えたときの害の大きさが違うとき
（安全ゲート vs 栄養計算）

今回は両方とも「演じる対象の記録」で、害の非対称性がありません。
→ ★中身が同じ方向を向いているなら、流用してよい
```
