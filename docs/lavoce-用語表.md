## 1. 声の調子（voice condition）

### 決めた語

| 言語 | 語 |
|---|---|
| ja | **声の調子** |
| en | **Voice condition** |
| zh | **嗓音状态** |
| it | **Condizione della voce** |
| de | Stimmzustand |
| fr | État de la voix |
| es | Estado de la voz |
| ko | 목소리 상태 |
| ru | Состояние голоса |

### この語が使われる2か所

| | 画面 | 見え方 | 翻訳キー |
|---|---|---|---|
| ① | 今日の記録 → 声・喉カード | 入力欄（1〜5、pp↔ff） | `labelVoiceQuality` |
| ② | 分析 → 折れ線グラフ | 線のラベル（Y軸 0〜10） | `labelResonanceScore` |

★目盛りは違いますが、**元は同じ1つの数字**です。
　`voice_quality` は `resonance_score` から導出されます
　（`VocalTracker.jsx:1660`、`quality10ToFiveScale(q) = 1 + (q/10)*4`）。

★**目盛りの表記（0〜10）をラベルに付けないこと。**
　片方にだけ付くと、また別の名前に見えます。
　グラフのY軸が0〜10であることは、軸そのものが示します。

### 経緯（★同じ不具合を繰り返さないために）

2026-08-28 まで、①は「声の調子」、②は「声の出来」でした。

- 中国語では**両方とも「嗓音状态」**で、別々の2項目が同じ名前でした
- イタリア語は `Qualità della voce` と `Resa della voce` で、意味がずれていました
- 英語は `Voice quality` と `Voice condition` でした
- ★de/fr/es/ru は、もともと②が「状態（condition）」の語で**正しく**、
  ①だけが「品質（quality）」になっていました

原因は、**列名 `resonance_score` を残したまま止まった改名**です。
コードにも痕跡があります（`VocalTracker.jsx:1513`
「声の出来（0-10。列名は resonance_score のまま）」）。

`docs/lavoce-99-作業中の状態.md` が「声の出来と響きスコア（同じ数字が
2つの名前）」として既知の不具合に挙げていたものです。
★2026-08-29、坂本さんの判断で「声の調子」に統一し、**この項目は閉じました。**

### ★触っていないもの

- 列名 `resonance_score`（そのまま）
- `quality10ToFiveScale` の式（そのまま）
- 0〜10 の入力と 1〜5 の合成スコア（そのまま）
- **`role_master.voice_quality`**（★まったくの別物）
  役の声質のチップ（地声寄り／高め／低め／特殊）。同じ識別子ですが、
  日々の記録とは無関係です。**触らないこと。**

### 見張り

`components/tests/terminology.test.js`（31件）が、
2か所のラベルが9言語すべてで一致していること、
古い語が残っていないこと、計算と列名が変わっていないこと、
役の声質に触れていないことを検査します。

## 2. 保存される日本語（★訳さない語）

`lib/storedValues.js` が正です。19語。

| 種類 | 語 | 保存先 |
|---|---|---|
| 活動の種類 | 休養／自主練習／レッスン／リハーサル／本番 | `entries.activity_type`・`activities[].kind`。★発声負荷の重みの鍵でもある |
| 声種 | ソプラノ／メゾソプラノ／アルト／カウンターテナー／テノール／バリトン／バス／その他 | `profiles.voice_type` |
| 栄養のフェーズ | 維持／増量／減量 | `profiles.nutrition_phase` |
| 記録の場面 | 朝／昼／晩 | `entries.voice_checkins` の鍵 |

★これらを翻訳キーに置き換えると、過去の記録が引けなくなり、
　発声負荷の計算が壊れます。表示は `labelKey` を経由してください。

見張り: `components/tests/stored-values.test.js`（28件）
