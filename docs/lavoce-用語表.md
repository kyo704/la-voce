## 1. 声の調子（voice condition）

### 決めた語

| 言語 | 語 |
|---|---|
| ja | **声の調子** |
| en | **Voice condition** |
| zh | **嗓音状态** |
| it | **Condizione della voce** |
| de | Stimmzustand |
| fr | État de la voix |
| es | Estado de la voz |
| ko | 목소리 상태 |
| ru | Состояние голоса |

### この語が使われる2か所

| | 画面 | 見え方 | 翻訳キー |
|---|---|---|---|
| ① | 今日の記録 → 声・喉カード | 入力欄（1〜5、pp↔ff） | `labelVoiceQuality` |
| ② | 分析 → 折れ線グラフ | 線のラベル（Y軸 0〜10） | `labelResonanceScore` |

★目盛りは違いますが、**元は同じ1つの数字**です。
　`voice_quality` は `resonance_score` から導出されます
　（`VocalTracker.jsx:1660`、`quality10ToFiveScale(q) = 1 + (q/10)*4`）。

### ★2026-08-30 改訂：目盛りを、**両方の**ラベルに付けます

もとは、こう書いていました。

> ★**目盛りの表記（0〜10）をラベルに付けないこと。**
> 　片方にだけ付くと、また別の名前に見えます。
> 　グラフのY軸が0〜10であることは、軸そのものが示します。

**この規則は、2つが同じ図に並ばない前提で書かれていました。並びました。**

分析タブの「相関の強さ」は、`FACTORS` の全項目を棒グラフに並べます。
そこには `voiceQuality` と `resonanceScore` が**両方**入ります
（どちらも中核5項目ではないので、探索族として図にだけ出ます）。
2026-08-29 に語を統一した結果、**「声の調子」という棒が2本**並びました。

値も近くなります。同じ `rep.quality` から作られており、片方は5段階に
丸めただけだからです（実際に 0.67 と 0.72 という2本が観測されました）。
利用者からは、★「声の調子が自分自身と相関している」ように見えます。

```
決めた語（2026-08-30・坂本さんの判断）
  labelVoiceQuality   … 声の調子（5段階）    Voice condition (5-point)
  labelResonanceScore … 声の調子（0〜10）    Voice condition (0–10)
```

★**これは統一の巻き戻しではありません。** 概念の名前は「声の調子」のままです。
　「声の出来」は復活させません。付けたのは**目盛りだけ**です。

★もとの規則が心配していた「片方にだけ付く」も避けています。
　**両方に付けました。** 片方だけに付けないでください。

★`components/tests/factor-labels.test.js` が、9言語すべてで
　「同じ名前の要因が2つ以上ない」ことを見ています。
　この試験は、a94dbbf（統一のコミット）の翻訳表で実際に落ちることを
　確かめてあります。次に同じことをすれば、その場で気づけます。

### 経緯（★同じ不具合を繰り返さないために）

2026-08-28 まで、①は「声の調子」、②は「声の出来」でした。

- 中国語では**両方とも「嗓音状态」**で、別々の2項目が同じ名前でした
- イタリア語は `Qualità della voce` と `Resa della voce` で、意味がずれていました
- 英語は `Voice quality` と `Voice condition` でした
- ★de/fr/es/ru は、もともと②が「状態（condition）」の語で**正しく**、
  ①だけが「品質（quality）」になっていました

原因は、**列名 `resonance_score` を残したまま止まった改名**です。
コードにも痕跡があります（`VocalTracker.jsx:1513`
「声の出来（0-10。列名は resonance_score のまま）」）。

`docs/lavoce-99-作業中の状態.md` が「声の出来と響きスコア（同じ数字が
2つの名前）」として既知の不具合に挙げていたものです。
★2026-08-29、坂本さんの判断で「声の調子」に統一し、この項目は閉じました。
★2026-08-30、統一の副作用（図の上で同じ名前の棒が2本）が見つかり、
　目盛りだけを両方に付け足しました（上の改訂を参照）。

### ★触っていないもの

- 列名 `resonance_score`（そのまま）
- `quality10ToFiveScale` の式（そのまま）
- 0〜10 の入力と 1〜5 の合成スコア（そのまま）
- **`role_master.voice_quality`**（★まったくの別物）
  役の声質のチップ（地声寄り／高め／低め／特殊）。同じ識別子ですが、
  日々の記録とは無関係です。**触らないこと。**

### 見張り

`components/tests/terminology.test.js`（31件）が、
2か所のラベルが9言語すべてで一致していること、
古い語が残っていないこと、計算と列名が変わっていないこと、
役の声質に触れていないことを検査します。

## 2. 保存される日本語（★訳さない語）
