# La Voce ／ 収集データの拡張案

歌手・声のプロ向け体調管理アプリ「La Voce」に、**追加で記録したほうがよいデータ**の提案。
既存の記録項目（喉の状態・声の調子・音名・響きスコア・症状8種・睡眠・水分・食事PFC・
気温湿度・滞在地・活動種別と時間・運動・心の余裕）を前提としています。

## 大前提：入力を増やさない

このアプリはすでに入力項目が多く、追加はそのまま継続率のリスクになります。
新しい項目は次のどれかに限るべきです。

- **1タップで済む**（3択、トグル、数値1つ）
- **既存の入力欄に1行足すだけ**（音名欄、症状チェック欄など）
- **自動で取れる**（位置情報、気象API、ウェアラブル連携）
- **週1・月1でよい**（標準化された質問票）

以下はすべてこの条件を満たすものだけを挙げています。

## A. 最優先の3つ

### A-1. 弱声の最高音（スウェリングチェック）

**いちばん推奨。** 既存の「起き抜けの音名」欄に1行足すだけで実装できます。

声帯のむくみは、大きな声より先に **「高い音の、ごく弱い声」に最初に出ます**。
喉の臨床では *swelling check* と呼ばれる手法で、次の2つの課題を
**極端に小さな音量**（"boy soprano pianissimo"、女性なら C5–C6 = 約523–1046Hz）で歌わせ、
むくみの兆候を見ます。

- 「ハッピーバースデー」の出だし
- 5音下降のスタッカート

大きな声で歌うと問題が隠れてしまうのがポイントです。陽性の徴候は
**発声の立ち上がりの遅れ／上行するほど息漏れが増える／出るはずの上限が出ない**。

| 項目 | 内容 |
|---|---|
| 入力UI | 既存の音名ピッカーをもう1つ（「pp で出せた最高音」） |
| 保存する値 | 音名（MIDI番号に変換）、任意で「立ち上がりの遅れ あり/なし」 |
| 既存分析への接続 | 「起き抜け・ルーティン後の音名推移」に3本目の線として追加。この線が下がり始めた日は、本人の自覚より早くむくみが出ている |
| 頻度 | 毎朝（ルーティンの一部として） |

出典: [Swelling Checks — Laryngopedia](https://laryngopedia.com/swelling-checks/)

### A-2. 話し声の使用量（non-singing voice use）

歌手の疲労の多くは、歌っていない時間の声から来ます。レッスンで生徒に喋る、
騒がしい店での会話（周囲がうるさいと無意識に声量が上がる＝ロンバード効果）、
電話、移動中の会話。

現状の発声負荷は「活動時間 × 活動種別」だけなので、**ここが抜けたままだと負荷を過小評価します**。

| 項目 | 内容 |
|---|---|
| 入力UI | 3択（よく喋った／ふつう／ほとんど喋っていない）＋任意で「騒がしい場所にいた」トグル |
| 保存する値 | 0 / 1 / 2 の整数、騒音環境フラグ |
| 既存分析への接続 | 発声負荷 ACWR の計算式に加算項として組み込む（例: 話し声2 = +45分相当、騒がしい場所なら ×1.3） |
| 頻度 | 毎日 |

出典: [Objective Measurement of Vocal Fatigue in Classically Trained Singers: A Pilot Study of Vocal Dosimetry Data — PMC](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC4782153/)

### A-3. 毎朝5秒の /a/ 録音 → CPPS

現状のデータはすべて自己申告です。ここに **機械が出す1本の客観的な線** が入ると、
アプリの説得力が根本的に変わります。

**CPPS（Smoothed Cepstral Peak Prominence／平滑化ケプストラムピーク突出度）** は、
声のスペクトルにおける倍音構造が雑音からどれだけ明瞭に立ち上がっているかを測る指標です。

ジッター・シマーより優れている理由:

1. **ピッチ追跡が不要** — 強い嗄声でも計算が破綻しない（ジッター・シマーは最も必要な場面で使えなくなる）
2. **連続発話でも有効** — ジッター・シマーは持続母音限定
3. **知覚との相関が強い** — 聴いて感じる嗄れの程度と r = 0.60〜0.85
4. **録音環境に頑健**

目安値（Praat 基準の CPPS）: **持続母音で 14.45 dB 未満／連続発話で 9.33 dB 未満**が嗄声を疑うライン。
スマートフォン録音は研究用機材と遜色ない、という比較研究もあります。

| 項目 | 内容 |
|---|---|
| 入力UI | 「ボタンを押して『あー』を5秒」。Web Audio API で録音 |
| 実装 | ブラウザ内でケプストラム計算（録音データ自体は端末内で完結させる設計が望ましい） |
| 保存する値 | CPPS (dB)、録音長、サンプリングレート |
| 既存分析への接続 | 「響きスコア（自己申告0〜10）」の隣に客観値として並べる。両者のズレ自体が「自己認識と実態の乖離」という新しい指標になる |
| 頻度 | 毎朝 |

**あわせて: 最長発声時間（MPT）と s/z 比**
「あー」を最長何秒、「スー」を最長何秒。タイマーだけで取れます。
**s/z 比が 1.4 を超える**と声帯の器質的な問題を疑う、という古典的スクリーニングです。
MPT 単体は呼吸支持の指標にもなります。

出典:
[Cepstral Peak Prominence (CPP) in Voice Analysis — PhonaLab](https://www.phonalab.com/en/guides/posts/understanding-cpp) ／
[Smartphone Recordings are Comparable to "Gold Standard" Recordings — Journal of Voice](https://www.sciencedirect.com/science/article/abs/pii/S0892199723000310) ／
[The S/Z Ratio as an Indicator of Laryngeal Pathology — JSHD](https://pubs.asha.org/doi/10.1044/jshd.4602.147)

## B. 週1・月1でよい、標準化された質問票

自作の5段階評価と違い、**論文の値と比較できる**のが利点です。
「あなたのVFIは同年代の演奏家の平均より低い」といった提示ができます。

| 尺度 | 正式名称 | 測るもの | 推奨頻度 |
|---|---|---|---|
| **EASE** | Evaluation of the Ability to Sing Easily | 「いま歌いやすいか」。**歌手専用に開発された尺度** | 本番・リハ直後 |
| **VFI** | Vocal Fatigue Index | 声の疲労を3因子で（疲労による発声回避／発声に伴う身体的不快感／休息による回復） | 週1 |
| **SVHI-10** | Singing Voice Handicap Index (10項目短縮版) | 歌声の支障度。長期トレンド用 | 月1 |
| **RSI** | Reflux Symptom Index | 逆流症状（9項目、**13点超で疑い**）。声のプロに多い | 月1 |

**とくに EASE を本番直後に取ることを推奨。**
すでに設計済みの「本番ピーキング曲線」の目的変数が、自己申告の5段階から
**歌手向けに検証済みの標準尺度**に変わります。

**RSI は既存項目と直結します。** すでに「夕食から就寝までの時間」「夕食の傾向
（揚げ物・炭酸・カフェイン・アルコール・トマト系）」を取っているので、
RSI スコアを目的変数にすれば、そのまま逆流と食習慣の個人分析になります。

出典:
[EASE の開発と予備的検証 — PubMed](https://pubmed.ncbi.nlm.nih.gov/23583205/) ／
[Vocal Fatigue Index (VFI): Development and Validation — Journal of Voice](https://www.sciencedirect.com/science/article/abs/pii/S0892199714001982) ／
[RSI と SVHI in Singing Students — PubMed](https://pubmed.ncbi.nlm.nih.gov/32553500/)

## C. 該当する人だけ、1タップで

### C-1. 月経周期の日数

月経前に声帯がむくむ現象（premenstrual vocal syndrome）には系統的レビューがあり、
歴史的にヨーロッパの歌劇場には *grace days*（免除日）が存在したほどです。

**周期の何日目かを入れるだけ**で、すでに設計済みの「ラグ相関マップ」が
そのまま使えます。入力コストがほぼゼロなのに、女性歌手には効き目が非常に大きい。

| 項目 | 内容 |
|---|---|
| 入力UI | 月経開始日を1タップ。以後は自動で「周期◯日目」を計算 |
| 保存する値 | 周期開始日、当日の周期日数 |
| 既存分析への接続 | 周期日を巡回変数として扱う（sin/cos 変換）か、単純に「周期の4分割」でグループ比較 |
| 表示の配慮 | 声種・性別の設定から自動で出し分け。オプトイン方式にする |

出典: [The Effect of Menstrual Cycle on Singing Voice: A Systematic Review — Journal of Voice](https://www.jvoice.org/article/S0892-1997(16)30098-4/pdf)

### C-2. 服薬

抗ヒスタミン薬（粘膜の乾燥）、吸入ステロイド（カンジダ・嗄声）、
経口避妊薬、NSAIDs、利尿作用のあるもの。既存の「夕食の傾向」と同じ
複数選択タグの形式でそのまま実装できます。

## D. 自動で取れるもの（入力を増やさない）

| データ | 取得方法 | なぜ効くか |
|---|---|---|
| 花粉・PM2.5 | 滞在地から API | 既存の気温・湿度と同じ扱い。鼻づまり・咳の症状と直結 |
| 気圧 | 気象 API | 気圧変化と体調の関係を訴える人は多い |
| フライト時間・時差 | カレンダー連携／手入力1回 | 機内の極度の乾燥と時差ぼけが二重で効く。遠征の多い層に刺さる |
| HRV・安静時心拍・睡眠ステージ | ウェアラブル連携 | 現状の「睡眠の質（主観5段階）」を客観化できる |
| 環境騒音 dB | スマホのマイク | 騒がしい環境ほど無意識に声量が上がる。A-2 の自動版 |

## E. 入力ゼロで深くできるもの

### 曲目ごとの負荷（テッシトゥーラ × 時間）

**すでに「曲目・演目」を記録しているので、新しい入力は不要です。**

曲・役に「平均音高（テッシトゥーラ）」と「演奏時間」のマスタデータを紐づければ、
**「あなたにとって重い役ランキング」**が自動で出ます。

```
役の負荷 = 演奏時間(分) × 声種の快適音域からの逸脱度

逸脱度 = |役の平均音高 − 本人の快適音域の中心| / 本人の音域幅
     ※ 本人の音域は既存の「音域（最低音）／（最高音）」設定から取得
```

蓄積すると「この役の翌日は必ず落ちる」「この役は2日空ければ大丈夫」という
**レパートリー単位の意思決定**ができるようになります。ここまでやっているアプリは
見当たらないので、差別化の要になり得ます。

---

## まとめ：3つに絞るなら

1. **弱声の最高音（スウェリングチェック）** — 既存UIに1行、今日から実装可能。むくみを自覚より早く捉える
2. **話し声の使用量** — 3択1つ。発声負荷の過小評価を解消する
3. **毎朝5秒の録音 → CPPS** — 「主観だけのアプリ」から抜け出す1手

## 注意書き

いずれの指標も自己申告および簡易計測に基づく参考値であり、医学的な診断ではありません。
質問票（EASE / VFI / SVHI / RSI）はスクリーニング目的の道具であり、
カットオフ値を超えた場合は受診の目安として提示するに留め、診断名を表示しないでください。
録音データを扱う場合は、端末内処理を基本とし、サーバに送る場合は明示的な同意を取ってください。
