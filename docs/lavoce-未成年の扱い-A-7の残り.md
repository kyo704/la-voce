## 2. A-7 の中身と、今回やったこと

A-7 の本文は6行です。

```
・生年月日、または「18歳未満か」を登録時に聞く          → ★今回やった
・18歳未満の場合
    - 保護者のメールアドレスを登録                      → ★見送り（§3）
    - 先生・教室への共有の同意に、保護者の確認メールを必須にする  → ★見送り（§3）
    - 共有できる既定の範囲をさらに狭くする（睡眠を既定から外す）  → ★見送り（§3）
    - 心の余裕・稽古ノート・学ぶのメモは、共有の選択肢に出さない  → ★見送り（§3）
    - カレンダー連携を表示しない                        → ★見送り（§3）
```

あわせて、研究利用の同意 §1-④「★未成年には出さない」に対応しました。

### 2-1｜今回やったこと

```
① 「18歳未満ですか？」を はい／いいえ で聞く
   ・登録画面（新しく入られる方）
   ・アプリの中に一度だけ出る1枚（すでに登録済みの方）
   ★生年月日ではありません。必要なのは「18歳未満か」だけで、
     生年月日はそれ以上を集めてしまいます（坂本さんの判断）。

② ★答えなくてよい
   ・登録画面では必須にしていません（研究利用の同意 §4-4）
   ・アプリの中の1枚にも「答えない」があります
   ・画面をふさぐ形（モーダル）にしていません
   ・一度出したら、飛ばされていても二度と出しません（催促にしない）

③ ★答えていない人は、未成年として扱います（フェイルクローズ）
   ・null と true は、どちらも未成年です
   ・既定値を入れていません。既定で false を入れると
     「成人だと答えた」と区別がつかなくなります

④ ★任意の同意（匿名化した統計としての利用）を、未成年に出さない
   ・ただし、すでに同意している方からは欄を取り上げません。
     欄ごと消すと、撤回する手段まで消えます（GDPR 第7条3項）。
     その場合、外すことだけができます。
```

判断の正は `lib/ageGate.js` です。**呼ぶ側で `profile.is_under_18` を
直に見ないでください。** 答えていない人が成人側へ倒れます。
`components/tests/age-gate.test.js` が、これを固定しています。

### 2-2｜`profiles.age` とは別物です

`profiles.age` は体組成（除脂肪体重・栄養の目安）の推定に使う任意の数値で、
目的が違います。**年齢の確認には使いません。**
`age` が 40 でも、この質問に答えていなければ未成年として扱われます。

## 3. ★見送ったもの（保護者同意の一式）

**保護者同意の仕組みは、まだ作っていません。**
仕様（A-7・教室プラン §7・指導者プラン §11）には書かれていますが、
今回の配布では作りません。理由は、守る対象に**まだ手が届かないため**です。

| A-7 が守るもの | いまテスターから届くか | 根拠 |
|---|---|---|
| 先生・教室への共有 | **届かない** | `canSeeTeacherFeatures()` が `is_admin` ／ `teacher_beta_access` ／ 既存のつながり を要求（`lib/featureFlags.js`） |
| カレンダー連携（ICS・Google） | **届かない** | `AddToCalendarButtons` はレッスンの札の中だけ。レッスンは上と同じ関門の内側 |
| 共有の既定範囲（睡眠を外す） | **届かない** | 共有そのものが届かないため |
| 心の余裕・稽古ノート・学ぶのメモ | **届かない** | 同上 |

つまり、いま未成年のテスターが触れるのは
**自分の記録と、自分だけの分析**です。
周期記録（§9）と 食事・就寝（§13-2）は、仕様が明示的に
「未成年でも使える（記録すること自体は制限しない）」と書いています。

### ★この見送りが終わる条件

```
教師・教室・レッスン・カレンダー連携のいずれかを、
テスターに開くとき（teacher_beta_access を配る／リンクを作れるようにする）。

そのとき、配布の前に A-7 の残り5行と 教室プラン §7 が必要になります。
★「機能を開ける」と「保護者同意を作る」は、同じ回で行ってください。
  先に開けると、大人と未成年が1対1でつながる場が、
  保護者の確認なしにできあがります（指導者プラン §11）。
```
