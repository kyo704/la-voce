## 5. G2 の 8：いま隠す機能

**10人に配るとき、次を機能フラグでオフにしてください。**

```
・先生とつながる／招待コード
・生徒一覧／生徒個別ページ
・レッスン日程
・教室に関するすべて
```

**理由**：G1 で権限を直しても、**教室まわりは G4 まで未完成**です。
壊れた機能があること以上に、**健康データの権限が保証されていない機能を人に触らせること**が問題です。

**職業の切り替えについて**

**4職種を並べたまま出さないでください。** いまの項目では、
アナウンサーは「原稿の種類がない」ことに、声優は「叫びしか見ていない」ことに気づきます。

```
選択肢1（推奨） 声楽家・ミュージカルだけで出し、他は「準備中」と表示する
選択肢2          4つ出すなら、職業別項目の再設計を G2 に前倒しする
```

**中途半端に4つ並べるより、1つで出したほうが評価は高くなります。**

## 11. いちばん大事なこと

**このアプリの成否を決める数字は1つです。**

> **調子が悪い日に、ユーザーが記録したかどうか。**

調子の良い日に記録が続くのは当たり前です。
**悪い日のデータこそ、このアプリが最も必要としているもの**であり、
**悪い日に開いてもらえるかどうかが、成立するかどうかそのもの**です。

G2 の作業（羊・保存直後の演出・即時フィードバック）は、すべてここに効きます。
**この数字が下がる変更は、他の数字が全部良くても失敗です。**
