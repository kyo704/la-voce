# 作業指示｜ブランド名の改名 La Voce → Woolsong（v2）

**Claude Sonnet 5 へ。v1（194行）を、これで置き換えます。**

**★G2（15〜20人への配布）を通過済みです。**
すでに他人の手元にあるアプリの名前を変えます。段階を分けてください。

関連：作業指示-ドメイン切替（woolsong.app）.md（★同時に進める箇所があります）

---

## 0. 決まっている事実

```
新しい名前   Woolsong
読み         ウールソング
由来         wool（羊毛）＋ song（歌）
ドメイン     woolsong.app
事業者       ★変わりません（個人事業主・同一人物）
```

**理由：La Voce はイタリア語で「その声」という一般名詞のため、
EUと米国では商標として登録できない見込みです。**

---

## 1. 原則

```
① ★変えるのは「見えるところ」だけ。配管は触らない。
② ★ブランド名を1か所の定数にする。次の改名を1行で終わらせるため。
③ ★訳さない。9言語すべてで Woolsong のまま。
④ ★事業者の同一性は変わらない → 同意の再取得はしない（§7で詳述）。
⑤ ★法務文書と同意画面は、名称とURLを1回でまとめて直す。
⑥ ★表記ゆれを作らない。Woolsong の1形だけ。
```

### ⑤が重要な理由

**同意画面の本文が変われば、textHash が変わり、版が増えます。**
名称の変更で1回、URLの変更でもう1回——**版を2回作らないでください。**

```
★順番   ドメイン切替 Phase 0（getBaseUrl 導入）を先に終わらせる
        → そのあと、本書 Phase 2 で名称とURLを同時に直す
```

### 4-2｜★洗い出しの方針（9言語）

## 8. Phase 2｜法務文書と同意画面（★名称とURLを同時に）

### 8-1｜対象

```
□ 利用規約
□ プライバシーポリシー
□ 特定商取引法に基づく表記
□ 同意画面の本文
□ 研究利用の同意の本文
```

```
サービス名   La Voce → Woolsong
事業者名     ★変更なし（坂本 響）
連絡先       ★メールアドレスを @woolsong.app にするなら、ここも
             （Resend のドメイン認証が終わってから）
URL          ★ドメイン切替の側と1回でまとめて
```

### 8-2｜★同意の再取得は「不要」です

**判断の根拠を書き残します。**

```
再取得が必要になるのは
  ・利用目的が変わったとき
  ・提供先・第三者提供の範囲が変わったとき
  ・取得する情報の種類が変わったとき

今回は
  ・事業者が★同一（同じ個人）
  ・目的が★不変
  ・取得する情報が★不変
  ・変わったのは★サービスの呼び名と、その所在地（URL）だけ
```

**したがって「表記の変更」であり、同意の再取得は求めません。**

### 8-3｜それでもやること

```
□ 新しい本文で★新しい版を作り、新しい textHash を保存する
□ ★旧版の本文と textHash を、消さずに保存し続ける（監査のため）
□ 変更履歴に1行残す
     「2026年◯月◯日 サービス名称の変更に伴う表記の変更（内容の変更なし）」
□ ★次に同意を取る人からは、新版を使う
□ 既存ユーザーには★お知らせを1回出す
     ・ボタンは「わかりました」だけ。★「同意する」にしない
     ・押さなくても機能を止めない
```

**「同意する」ボタンを出すと、同意を取り直したことになります。**
**内容が変わっていないのに取り直すと、記録の意味が濁ります。**

### 8-4｜守りのテストに追加

```
□ 名称変更のマイグレーション後、★既存の同意記録が1行も変わっていない
□ 旧版の textHash が引けること
□ 撤回済みの記録が、撤回済みのまま残っていること
```
