# 公演の種類を広げる ── 演劇を入れる／そのほかの案

2026-09-23 ／ Opus。坂本さんの提案（演劇と古典の雛形）を受けて

## 1. 演劇（★入れた）

```yaml
台帳: koen.kind に 'drama' は 最初からある（裁定148）。★足りなかったのは 作品のデータ
入れた7作: ハムレット／ロミオとジュリエット（戯曲）／夏の夜の夢／マクベス／桜の園／かもめ／人形の家
形の違い（音楽の作品と比べて）:
  場面 ＝ ★幕・場（第3幕 第1場）。番号ではない
  役   ＝ 登場人物。まとまり（職人たち・妖精たち・その他）は「何人かの枠」
  編成 ＝ ★伴奏が無いことがある → 検査をゆるめた（演劇・舞踊は編成が無くてよい）
        効果音・音楽は 省ける枠として持つ（夏の夜の夢＝メンデルスゾーン、人形の家＝タランテラ など）
★著作権に触れないもの: 台詞・戯曲の本文・翻訳は入れない。★幕と場の並びと 登場人物だけ（事実）
★翻訳の版で 幕・場の切り方が違うことがある → 上演する版で確かめる
```

## 3. そのほかの案（公演の形として足せるもの）

```yaml
★A 発表会・試演会（recital）:
  音大・教室でいちばん数が多い。★曲目を並べるだけ。役は「出演者」1つ
  香盤表 ＝ 出演順・曲目・伴奏者。★伴奏者の呼び出しが要る（いまの作りで足りる）
  → 種類に 'recital' を足す価値がある（いまは 'gala' で代用できる）
★B コンクール・オーディション:
  審査員・順番・持ち時間。★採点（裁定165）とつながる
  ★注意: 点と順位は うちの決まりで扱いが違う（採点の札と審査員の表の中だけ）
★C 収録（声優・ナレーション・レコーディング）:
  ★香盤表の形が近い: 「巻（シーン）× 役」。分刻みの呼び出し
  声優の養成所に効く（隣接市場のいちばん近いところ）
  → 種類に 'recording' を足す案
★D バレエ・舞踊（dance）:
  台帳にはある。作品データが無い（くるみ割り人形・白鳥の湖・ジゼル）
  ★音楽とセットなので、いまの作りで書ける
★E ミュージカル:
  ★ほとんどが著作権の生きている作品。上演許可が要る → 雛形は 公有のものだけ（オペレッタで代える）
★F 学校行事（卒業式・入学式・定期演奏会の式次第）:
  ★香盤表より「進行表」。当日の進行（sql/18）がそのまま使える
```

## 4. 勧める順番

```yaml
1 演劇を足した（済）→ ★声優・俳優の養成所に見せられる材料ができた
2 発表会（recital）── ★数がいちばん多い。曲目と伴奏者だけで成り立つ
3 収録（recording）── 声優の養成所。巻×役の形
4 バレエ ── 音楽の作品として書ける
5 ギリシャ悲劇 ── 合唱隊があるので「何人かの枠」の見本になる
★ミュージカルと現代劇は、上演許可の話が別なので 後回し
```
