## §3 なぜ「過去を見ること」なのか

### ① 倫理的に、いちばんきれいです

```
データは本人のもの   ★書き出しは無料・全期間。人質にしていません
売っているのは       ★「見る道具」
```

★記録そのものを制限すると、**その人の記録を人質に取る**ことになります。
　★それはしません。**見方だけを売ります。**

### ② ★続けた人ほど、払いたくなります

```
30日目より、★90日目のほうが、過去を見たくなります。
　→ ★時間が経つほど、有料の価値が上がります
```

★これは「数か月使わないと価値が出ない」問題の**逆**です。
　★続けた人が、勝手に払いたくなる形です。

### ③ ★壁が来るのが、8日目です

```
（旧）発見が出るまで数か月     ★遠すぎる
（新）本番があるとき           ★本番が無い人には来ない
★（今回）★8日目               ★全員に、早く来る
```

★そして**8日続けた人は、もう定着し始めています。** 払う確率がいちばん高いところです。

## §4 ★ただし、営業のために30日は開けてください

坂本さんは**対面で配ります。**「無料でどうぞ」と渡すのに、
★8日で壁が来ると、渡しにくくなります。

```
★最初の30日は、全部見える。
　31日目から、直近7日だけが無料になる。
```

★カードは取りません。**勝手に課金されない体験期間**です。
　（9月3日に消した `trial_period_days` とは別のものです。あれはStripeの自動課金でした。）

★30日は、**記録が習慣になる日数**としても妥当です。
　そして30日目には、その人は**自分の過去を見たくなっています。**

★文言。

```
　　　これまでの30日は、全部ご覧いただけました。

　　　あしたからは、直近7日ぶんが表示されます。
　　　それより前をご覧になるには、月580円です。

　　　★記録は、これまでどおり残ります。
　　　★書き出しは、いつでも無料です。
```

★最後の2行を必ず書いてください。**取り上げていないことを、その場で言います。**

## §5 ★触ってはいけないもの

```
✕ 記録できる項目数を減らす
✕ 記録できる日数に上限を作る
✕ ★症状ゲートを有料にする（9月4日の裁定。安全に寄る側に金を取らない）
✕ ★受診の導線を有料にする
✕ ★書き出しを制限する（法定。全期間・全項目）
✕ ★記念のもの（歌った証）を有料にする
✕ 羊を出さない／おうちを閉じる
```

★とくに3つめです。**「金を払わない人には黙っている」形を、絶対に作らないでください。**

## §6 ★もっと大事なこと（正直に）

線を直しても、**これだけでは足りません。**

```
100人が使って、★4人に1人が払う   → 月 ¥14,500
100人が使って、★20人に1人が払う  → 月 ¥2,900
```

★**線より、人数のほうが効きます。**

★坂本さんは対面で、声の仕事の人だけに配ります。
　冷たい客ではないので、**払う割合は高く出るはずです**（一般のアプリは1〜5%です）。
　★それでも、100人では足りません。

```
月10万円   ★170人（4人に1人が払う場合）
月30万円   ★520人
```

★**線を直すのは今日できます。人数は、9か月かかります。**
　★両方やってください。★でも、順番は人数が先です。

## §7 いつ変えるか

```
★いま変えてください。★まだ1件も売っていません。
```

★価格と同じです。**最初の1人が払うまでが、決める窓**です。
　あとから無料の範囲を狭めると、**すでに使っている人から取り上げる**ことになります。
　★それは、この製品がずっと避けてきた形です。
