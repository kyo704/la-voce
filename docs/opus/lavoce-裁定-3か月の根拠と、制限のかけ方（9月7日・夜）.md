# 裁定：「直近3か月」は体験期間ではありません ／ その数字の根拠
宛先 運営者・実装（Claude Code）／ 差出 Opus ／ 2026年9月7日 夜

---

# 1. まず、言葉を分けます（★私の書き方が悪かったです）

```
無料体験（トライアル）
　　★期間限定で、全部つかえる。★終わったら、使えなくなる。
　　　14日、7日など。

深さの制限（ルックバック）
　　★★ずっと無料。★終わりません。
　　★ただし、振り返れるのが「直近3か月ぶん」だけ。
```

**まったく別のものです。**

```
1年目も、5年目も、★無料のまま使えます。
毎日書けます。羊も、おうちも、レパートリーも、ぜんぶ無料です。

　★4か月目に起きるのは、これだけ：
　　「4か月前より前の傾向は、いまは見られません」
```

★**「3か月ぶんタダであげます」ではありません。**
　★**「ずっとタダ。ただし、見えるのは手前の3か月ぶん」**です。

★体験期間を作らないという9月6日の決定とも、**ぶつかりません。**別の話だからです。

# 2. ★ご質問「3か月の根拠は？」── 痛いところを突かれました

## 2-1 ★正直に申し上げます

```
昨日の時点で、私が持っていた根拠は ★これだけでした。

　　「Hevy が3か月だから」

★★これは、根拠ではありません。★借り物です。
　★しかも、そのあと調べたら「期間で切るのは業界の標準ではない」（17本中3〜4本）
　　と分かりました。★借りた先すら、多数派ではありませんでした。
```

★**ご指摘のとおりです。数字を、うちの事情から出し直します。**

## 2-2 ★うちの事情から、下限と上限を出す

### 下限 ── ★これより短いと、無料版が壊れます

```
① すでに決めてある解禁の日数（分析画面の表示規約・付録）
　　Lv2 = 3日 ／ Lv3 = 7日 ／ Lv4 = 14日 ／ ★Lv5 = 28日
　→ ★無料の窓が1か月だと、★Lv5 が開いた翌日に見えなくなります。
　　 ★「開いた瞬間に閉じる」画面になります。

② 文章を出してよい条件（各群 n ≥ 10）
　　ある項目が2日に1度書かれるとして、★両群10ずつで ★40日前後。
　　実際には ★60日ほどかかります。
　→ ★★2か月では、★通ったものが1つも見られないまま消えます。

　　→ ★下限は「2か月」。★それ以下は、無料版が意味を持ちません。
```

### 上限 ── ★これより長いと、有料の中身がなくなります

```
③ 週の集計（「多かった週7回のうち3回」）
　　両群それぞれ10週 → ★22週 ＝ 約5.5か月

　→ ★無料の窓が6か月だと、★これが無料側に入ってしまいます。
　　 ★有料に残るものが、ほとんどなくなります。

　　→ ★上限は「5か月」。
```

### ★真ん中の1点を決める

```
④ 課金の瞬間を、いつ置くか
　　健康・フィットネスの月額は、★初月で43%が落ちます（RevenueCat 2026）。
　→ ★壁は、初月の崖を越えたあとに置くべきです。
　→ ★3か月なら、★壁は4か月目。★崖の3か月あと。

⑤ ★声の仕事は、季節で回ります　←★これがうち固有の理由です
　　定期演奏会、コンクール、年末、卒業試験、オーディションの時期。
　→ ★この人たちが本当に比べたい相手は「★去年の同じ時期」です。
　→ ★3か月では、★絶対に見えません。★これが有料の中身になります。
```

## 2-3 ★結論 ── 3か月は、5つの条件を全部満たす最小の窓です

```
2か月　✕ 通ったものが見られない（②）
3か月　◎ 全部満たす
4か月　◯ 満たすが、有料の中身がやや薄くなる
5か月　△ 週の集計が無料に入りかける（③）
6か月　✕ 有料に残るものがなくなる（③）
```

★**「Hevy が3か月だから」ではなく、★「2か月では壊れ、6か月では売れないから」です。**

# 3. ★もっと大事な直し ── 制限を「どこ」にかけるか

★数字より、**こちらのほうが効きます。**

```
Hevy　　　 ★履歴の閲覧 ★全般 に3か月
　　　　　 → ★過去の記録そのものが見えません
　　　　　 → ★「自分のデータなのに」と言われます

Bearable　★カレンダーとタイムラインは ★無制限
　　　　　 ★傾向レポートと比較グラフ ★だけ 30日
　　　　　 → ★★記録は全部見える。★分析だけが浅い
```

★**Bearable の型を採ってください。**

## ★決め（これで作ってください）

```
◯ ★いつでも無料で見られるもの（★期間の制限を一切かけない）
　　自分が書いた記録そのもの
　　カレンダー
　　ノート
　　レパートリー（曲の一覧）
　　羊・おうち・持ちもの
　　全データの書き出し　★法律上、ここは動かせません（GDPR 12条5項）
　　受診用サマリー

◯ ★直近3か月ぶんだけ（無料）／★全期間（有料）
　　分析画面の傾向とグラフ
　　1週間のまとめ
　　「前も、こうでした」
　　週の集計
```

★これで、**「記録を取り上げない」という決まりに、1つも触れません。**
　★MyFitnessPal が潰された理由（自分のデータが見られない）も、避けられます。

# 4. ★有料の名前を、期間で呼ばないでください

```
✕ 「全期間の閲覧」　　　→ ★何が嬉しいのか分かりません
✕ 「3か月以上前を見る」→ ★取り上げているように読めます

◯ ★「去年の今ごろ」
```

```
11月に開くと、羊が言う：

　「去年の11月、あなたはどうしていたでしょう。」
　　［去年の今ごろを見る］
```

★**壁を、その人の記憶に立ててください。**「3か月」という数字には、誰も払いません。
　★「去年の11月」には、払う人がいます。
