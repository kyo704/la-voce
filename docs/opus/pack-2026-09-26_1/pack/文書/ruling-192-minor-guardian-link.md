# RULING 192 — 15〜17歳が 保護者の同意で つながれるようにする（★緊急）

## 0. 何が起きていたか

```yaml
★裁定107:「15〜17歳は 保護者の同意で 入れる」── 仕組みは ★すべて できていました
  guardian_consents の表・has_guardian_consent・同意を求める／受ける／取り消す 関数
★ところが 本番に ★古い引き金が 2本 残っていました
  trg_block_minor_teacher_link（teacher_student_links）
  trg_block_minor_assignment（assignments）
  どちらも assert_student_is_adult ＝ ★is_under_18 が false でなければ 止める
→ ★同意を もらっても、その先で 止まる。★裁定107 は 働いていませんでした
★Code の判断は 正しい:「★台帳を 直す前に 規約を 変えると、
  ★規約が 嘘になる 期間が できる」── ★順番は 台帳が先 です
```

## 1. 決定 ── 引き金を「同意も 見る」形に 直す

```yaml
★通すのは 次の どちらか:
  ㋐ ★18歳以上（is_under_18 = false）── いままでどおり
  ㋑ ★15〜17歳 かつ ★その学校で 保護者の 同意が 生きている
★通さないもの（★変えません）:
  ✕ ★年齢が 未回答（is_under_18 が null）── ★16人います。★答えるまで つながれません
  ✕ ★15歳未満 ── ★そもそも 登録できません（裁定191）
  ✕ ★同意が 取り消された人（withdrawn_at が 入っている）
```

## 2. ★表ごとに 分けます（★ここが 大事）

```yaml
★assignments（門下）── ★org_id が あります
  → ★その学校の 同意を 見る: has_guardian_consent(student_id, org_id)
★teacher_student_links（先生と生徒の つながり）── ★org_id が ありません
  → ★どの学校の 同意かを 決められません
  ★決定: ★どこか1つの学校で 同意が 生きていれば 通す
    理由: この つながりは ★学校に ぶら下がらない 個人どうしの 関係です
      （個人の先生・よその学校の 先生）
    ★保護者は「この子が 先生と つながること」に 同意しています。
      ★学校ごとに 取り直させるのは、★保護者に 何度も 同じことを 聞くことになります
  ★ただし ★同意が 1つも 無ければ 通しません
```

## 3. ★同意が 取り消されたら

```yaml
★すでに できている つながりは ★自動で 切りません
  理由: ★途中で 切ると、レッスンの 予定が 崩れます（★学生が いちばん困る）
★代わりに:
  ★新しく つながることは できなくなる（引き金が 止める）
  ★運営が「同意の 切れた人」の 一覧を 見られる（★下の関数）
  ★人が 見て、先生と 相談して 決める
★これは「取り上げない」の 原則どおりです（★自動で 奪わない）
```
