## §1 ★¥580 より良い理由

私は ¥580 を勧めましたが、**運営者の ¥500 のほうが良いです。**

私がいちばん強く主張したのは、これでした。

```
✕ ¥980   ★飾りが道具より高い。値段が「こちらのほうが価値がある」と言ってしまう
```

```
¥980   飾り ＞ 道具   ★逆
¥580   飾り ＝ 道具   同じ
★¥500  ★飾り ＜ 道具   ★正しい
```

★**¥500 のほうが、私の理由をよりよく満たしています。**
　私が言いたかったのは「同じにする」ことではなく、**順序を間違えない**ことでした。

そして「ワンコイン」は、**「ひと月ぶんと同じ」より強い**言い方です。
　★私の「数字を1つに」は、3つの理由のうちいちばん弱いものでした。取り下げます。

## §3 ★1つだけ、言っておきます

```
「内容も特段いいものでもないしね」
```

★**値段の理由に、これを入れないでください。**

```
◯ ワンコインだから              ★買う人の話
◯ 道具より安いから              ★買う人の話
◯ 迷わせないから                ★買う人の話
✕ 自分の作ったものが良くないから ★★売る人の話
```

★最後のひとつだけ、**性質が違います。**
　そして、これを理由にすると、**売るときに自分で勧められなくなります。**

★中身は、悪くありません。

```
1セット5点のうち、★窓の外の景色が1点入ります。

　景色を変えると、★部屋が別の場所になります。

壁と床も、面で変わります。★服より効きます。
```

★「5点の小物」ではありません。**「部屋が変わる」です。**
　売るときは、そう言ってください。
