# ② 声の予報について

## 2-0 先に、ひとつだけ

「あったほうが面白い」──これは、正しい理由です。
続けてもらえないアプリは、どんなに正確でも意味がありません。
**面白さを削る方向の助言は、しません。**

ただ、**いまの形のままでは残せません。**理由を1つだけ書きます。

```
9月6日に、本番モードの根拠を洗い直しました。
そこで確かめられたのは、たったひとつです。

　★記録すること自体に効果がある（d=0.40、95%CI 0.32–0.48、k=138、N=19,951）
　　ただしそれは「書いたものが、本人に返ってくる」形のときだけです。

　★逆に、はっきり効果が確かめられなかったもの／害が出たもの
　　・比を作って見せること（ACWR。Impellizzeri 2021 で撤回済み）
　　・「先週より悪い」形式の返し（Kluger&DeNisi：効果の38%超が負の方向）
```

**「明日の喉スコアは◯点」は、この2つ目にあたります。**
数字を出して、それが低かった日、人はその数字のとおりの声を出します。
Visible（筋痛性脳脊髄炎のアプリ）で、スコアが本人の感覚と食い違ったとき
「ガスライティングされた気がした」という報告が実際に出ています。

★いちばん怖いのは、**本番の前夜に「明日は悪い」と出ること**です。
　それだけで声が出なくなります。そして、そのとき予報は「当たった」ことになります。

だから消してくれ、という話ではありません。
**面白さを残したまま、この問題だけを外す形があります。**それが 2-2 の案です。

## 2-1 Q1「本番モードの説明としてだけ使い、声の予報は対象外とする」── ★これはできません

```
「このアプリは、明日の声を予測しません」
```

これは**アプリについての文**であって、画面についての文ではありません。
1つの画面が予測していれば、この文は嘘になります。
見出しの下に置いても、範囲は狭まりません。

**逃げ道は「言い方を変える」ことではなく、「出すものを変える」ことです。**

---

## 2-2 三つの案

### 案A ── そのまま残し、注意書きを添える

```
できること   いまの計算式をほぼそのまま使える
できないこと 「予測しません」を全ての文書から撤回する
　　　　　　 サイト・規約・説明・SNS・大学向け資料、全部です
残る危険     ・本番前夜に外れたとき、実害が出る
　　　　　　 ・精度を一度も測っていないのに「予報」と名乗る
　　　　　　 ・注意書きは効きません（2-3 で説明します）
```

### 案B ── 計算はそのまま、**返し方だけ変える** ★私の推しです

```
✕ 明日の喉の調子　72点　　　　　←　明日についての断定
◯ 昨日と似た夜のあとの朝が、これまでに6日ありました　←　過去の数え上げ
```

**中で回っている計算は、1行も変えなくて構いません。**
いまの式が出す値を「点」として見せる代わりに、
**その値が近かった過去の日を数えて、件数だけ返します。**

```
羊：「きのうと似た夜は、これまでに6日ありました。」
　　（タップすると、その6日が並ぶ。それだけ。良い・悪いは言わない）
```

これで何が起きるか：

```
・予測していない　　　→「予測しません」がアプリ全体で真のままになる
・面白さは残る　　　　→ 自分の過去が返ってくるのは、点数より面白い
・精度を守らなくていい→ 数えているだけなので、外れようがない
・★根拠のある形になる→「書いたものが本人に返る」＝ d=0.40 の形そのもの
・0件のときが弱点　　→ ★「まだ似た夜がありません」と正直に出す
　　　　　　　　　　　　（0件は「無い」ではありません・9月2日 の決まりどおり）
```

★案Bなら、注意書きは1行で済みます。
　★案Aなら、注意書きを何行足しても足りません。

### 案C ── 消す

面白さが減るので、私は推しません。**案Bで面白さは残せます。**

## 2-3 Q2「どんな注意書きを添えるべきか」

### まず、いただいた例は使えません

```
✕ 「参考程度の目安です。医学的な根拠に基づく予測ではありません」
```

理由は2つあります。

**(1) 自分で自分を否定しています。**
「予報」と名乗ったうえで「予測ではありません」と書くのは、矛盾です。
消費者庁の「打消し表示に関する実態調査報告書」（2017–2018）が
はっきり書いているのは、**強調表示と矛盾する打消し表示は効かない**ということです。
小さく書いても、下に書いても、別ページに置いても、同じです。

**(2)「医学的」という語を使うと、医学の話をしていることになります。**
「医学的な根拠はない」と書くことで、読み手は
「医学の領域の話をしているが、根拠が弱いのだな」と受け取ります。
**そもそも医学の話ではない、という立ち位置が崩れます。**

### 使える形（案Bを採るとき ── 1行）

```
これは、あなたが書いたことを数えたものです。声は測っていません。
```

### 使える形（案Aを残すとき ── ★本文と同じ大きさで、同じ画面に）

```
これは、あなたが書いたことだけから作っています。
声そのものは測っていません。
当たらない日のほうが多いつもりで、見てください。
体の具合は、これでは分かりません。
```

★これは「注意書き」ではなく**本文の一部**として置いてください。
　薄い色・小さい字・折りたたみ、すべて不可です。
　畳んだ瞬間に、打消し表示になり、効かなくなります。

### ★使ってはいけない語（画面・説明・SNS すべて）

```
予測　予報※　スコア　点　リスク　悪化　危険　注意　警告
医学　診断　症状　改善　効果　おすすめ　したほうがいい
```

※「予報」は、案Bを採るなら**使えます**。
　ただし条件があります → 2-4

## 2-4 「声の予報」という名前を残す道

天気予報は、外れることが世の中に許されている、めずらしい言葉です。
そして、誰も天気予報を医学だとは思いません。
**この言葉のもつ「外れてもいい」という了解だけを、借りることができます。**

借りるなら、見た目まで借りてください。

```
◯ 羊が空を見ている絵　／　傘・晴れ・くもり のような絵
◯ 「羊の予報」と、羊が言っていることにする
✕ ★％を出す　　　（降水確率は当たるように直され続けています。うちは違います）
✕ ★点を出す
✕ ★「悪い」と言う（「くもり」までにする。「雨」も作らない）
```

★絵にすると、数字より弱く伝わります。それが狙いです。

## 2-5 ★出してはいけない場所（これだけは、案A・案Bどちらでも）

```
D-1（本番の前日）　★出さない
D-0（本番の当日）　★出さない
```

理由：**外れたときに実害が出るのは、この2日だけです。**
そして、この2日は、いま作ろうとしている本番モードの中心です。
ここで予報が「くもり」と出れば、本番モードが本人の足を引っぱります。

★D-1・D-0 は、予報の代わりに、いま決めてある羊のことばを出してください。

## 2-6 Q3「ACWR を消すと、声の予報の式は変えずに済むか」── ★済みません

### 事実

```
prevAcwr は「比」です。比を消したら、その変数はなくなります。
式は必ず変わります。
```

### 置き換え（★これだけ直せば動きます）

```js
// ✕ prevAcwr（直近7日の負荷 ÷ 直近28日の平均）
// ◯ load7（直近7日の負荷の合計。生の値）
//    0–1 に正規化し直す。係数は据え置きで構いません。
```

**「比」が撤回されたのであって、「日ごとの量」は撤回されていません。**
Impellizzeri 2021 が示したのは、分母をランダムな値に差し替えても
オッズ比がほとんど変わらない（2.45→1.89、c統計量0.574）ということでした。
**壊れているのは分母のほうです。** 量そのものは残せます。

### ★ただし、ひとつ申し上げます

「式を変えなければ、精度が保てる」という前提は、**成り立ちません。**
この式は、**実際の転帰に対して一度も検証されていません。**
変えても変えなくても、精度は「分からない」のままです。

だから、この置き換えは精度の話ではありません。
**撤回した指標を、使い続けないための処置です。**
（撤回した指標を内部で回し続けているのが後から見つかると、そこがいちばん痛いです）

### ★もうひとつ

**本番モードの画面には、負荷の合計も比も出しません。**（判断済み・並べるだけ）
声の予報の**内部で**量を使うのは構いません。
ただし、外に「合計」「比」「◯倍」を一切見せないでください。

## 2-7 Q4「今日やるといいこと」── ★中身は消し、枠は残してください

### 消す理由（3つ）

**(1) 中身の根拠が、9月6日に全部落ちました。**

```
落ちたもの　水分の助言／加湿の助言／カフェインの助言
　　　　　　ウォームアップの助言／休養日数の助言／気圧
```

根拠が落ちたのに「今日やるといいこと」という**断定形**で出し続けるのは、
法律より前に、中身として持ちません。

**(2) 法律。★わざわざ危ないほうに寄る必要がありません。**

厚労省の「プログラムの医療機器該当性に関するガイドライン」は、
2つの軸で判断します。**①治療・診断への寄与の程度／②リスクの程度**。
「こうすると喉がよくなります」という助言は、**①を上げる方向**に働きます。
いまは非該当で通っているので、上げにいく理由がありません。

**(3) 決まりと衝突します。**
「急かさない／評価しない／催促しない」。
「今日やるといいこと」は、**やらなかった日に負債を作ります。**

### 置き換え（★同じ枠・同じ場所・同じ大きさ）

```
✕ 今日やるといいこと
◯ このごろ、よく書いていること

　直近14日で、いちばん多く選ばれた項目を2つ、並べるだけ。
　「だから、こうしましょう」は付けない。
```

★これも、案Bと同じ形です。**本人が書いたものを、本人に返しているだけ。**
　根拠のある唯一の形です。

### もし助言を残すなら（★条件）

```
◯ 残せるもの　「先月、よく眠れたと書いた日は、前の晩に◯◯と書いていました」
　　　　　　　＝★本人が過去に自分で書いたことの再提示だけ
◯ 例外        受診の導線（★これだけは残す。転帰を改善する形が確かめられている唯一のもの）
✕ 一般論の健康助言は、ひとつも出さない
✕ 「〜という人がいます」も不可（伝聞でも助言です）
```

# ★私からの一件（別件・弁護士確認事項④について）

④の既往症に**「逆流性食道炎」**が選択肢として入っています。
法律の話とは別に、**中身として外すべき**だと考えます。

```
米国 AAO-HNSF の臨床診療ガイドライン（2018、嗄声）と
欧州の合意文書（2024）が、どちらも明示的に否定しているのは、

　★喉頭を見ずに、症状だけから「逆流のせいだ」と結びつけること

です。声の不調を逆流に帰属させる推論は、
専門家がいちばん止めようとしている推論です。
```

選択肢に置くと、**アプリがその推論を後押しすることになります。**
「逆流性食道炎と書いた日は、声の調子が悪い」という並びが出た瞬間、
本人はそう結びつけます。そして、その結びつけ自体が、否定されているものです。

★弁護士の先生の論点（要配慮個人情報に病名が当たるか）とは、**別の理由**です。
　法律で残せるとしても、私は外すことをおすすめします。
