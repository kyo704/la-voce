# 第1部　219点を、どう分けるか

## §1 ★結論：量で絞るのではなく、箱を分けます

**「無料で交換できるのは219点のうち何点か」という問いの立て方だと、必ず失敗します。**
同じ品が「無料でも取れるし、お金でも取れる」形になり、**お金は「早く取る」ためのものになる**からです。

★これは9月7日朝に決めた禁止事項に正面から触れます。

> ✕ ★お金で早く進める（アイテムを買って30日を飛ばす）
>   → ★装いは別に売ります。★記録から生まれる物は、売りません
> （`lavoce-判断-記録と分析を、楽しいものにする §7`）

**だから、箱を3つに分けて、重ねません。**

```
箱1 記念　　　条件を満たした人だけ。★買えない。交換もできない
箱2 記録　　　記録で貯めて交換する。★お金では絶対に買えない
箱3 よそおい　お金で得る。★記録では絶対に手に入らない
```

★★**箱3は記録では手に入らないので、¥580・¥980の価値は薄まりません。**
　「219点のうち何点まで無料か」ではなく、**「どの品が箱3にしかないか」**で守ります。

# 第2部　追加38項目は、削除の基準に触れないか

## §7 ★ご懸念は正当です。1項目、私の案に誤りがありました

削除17点の基準は、次の7つでした。**弁護士書面の照会事項7（医療機器該当性）の非該当の論拠でもあります。**

```
① 点数を出さない（スコア化しない）
② 文献値・基準値を個人の記録に紐づけない
③ 判定しない（「不足」「快適帯から外れています」）
④ 信号色を使わない
⑤ ランキングを出さない
⑥ 医学的助言をしない
⑦ n<10 で確率を出さない
```

38項目を、この7つに照らしました。**36項目は通ります。2項目は直します。**

## §8 ★直すもの（2項目）

### 8-1｜A8「RSIの9項目の推移」── ★私の案が危なかった

今日の仕様 §3-5 で、私はこう書きました。

> Reflux Symptom Index は、…の9項目を、各0〜5で聞くものです

★**0〜5で聞いて推移をグラフにすると、それは「点数を出す」ことです。**
合計点を出さなくても、**9本の0〜5の線が並べば、実質的にRSIを運用しています。**
そしてRSIは**診断の補助に使われる尺度**です。照会事項7の論拠（点数を出さない・基準値を出さない）を、自分で崩しています。

```
★修正
　✕ 9項目を各0〜5で記録し、推移の線を出す
　○ 9項目を「気になることがあれば」の★選択肢の言葉として借りるだけ
　　　→ ★段階をつけない。あった／なかった、だけ
　　　→ ★「RSI」という名前を画面に出さない
　　　→ ★合計も、13点という区切りも、どこにも出さない
　　→ 表示は ★症状カレンダー（一色の格子）と同じ形。既に本番にあり、削除対象外です
```

★これで「記録」に留まり、「尺度の運用」になりません。

### 8-2｜E4「症状を目的にして比べる」── 条件をつけます

朝の咳払いや胸やけを「結果」の側に置く案です。動機4には必要ですが、**Ferrari & Russell 2010（症状を毎日記録すると想起頻度1.3→2.6日、強度3.1→5.1、対照群は変化なし）**に触れます。

```
★条件
　・症状を目的にできるのは、★本人が「気になること」を既に自分で開いて記録している場合だけ
　・★そのために新しく毎日たずねない
　・★既定は「声の調子」。症状に切り替えるのは本人の操作
```
