## §1 器と中身

```
★器（買える）      おうち ／ 壁 ／ 床 ／ 家具 ／ 窓の外の景色 ／ 庭 ／ 服

★中身（買えない）  友達 ／ 記念のもの ／ 畑の実り
　　　　　　　　　  ★すべて、記録から来ます
```

この分け方には、**気持ちのいい結果があります。**

```
★買った庭に、記録から来た友達が住む。
```

庭を買うと、**友達の居場所が増えます。**
友達を買ったのではありません。**来る場所を増やしただけです。**

★だから、買っても世界が壊れません。むしろ広がります。
　そして「たくさん記録した人ほど、たくさんの友達が来る」は、そのまま残ります。

## §2 ★友達は売りません

「友達も変えたら」── ここだけ、お断りします。理由を書きます。

畑と友達の設計（9月4日）で、こう決めました。

```
友達が来る   ← ★絶対湿度・季節・活動・記録の累計から
```

```
　「今日は乾いています」と言うかわりに、★画面が乾いて見えます。
```

★**友達は、体調の数字が姿になったものです。**
買えるようにすると、**この文が成り立たなくなります。**

```
✕ 友達を買う                    ★世界の住人が、記録の結果でなくなります
◯ ★友達が来る場所を買う         庭・窓辺・水辺・ストーブのそば
◯ ★友達の小物を買う             首の赤いリボン、麦わら帽子
```

★**居場所と小物は売ってよいです。** その子が来るかどうかだけ、記録に残します。

★そして、この線引きは服とまったく同じです。

```
記念のもの（歌った証）    ★買えない
おしゃれ（何も証明しない） ★買える
友達（体調の姿）          ★買えない
居場所・小物              ★買える
```

★**証明するものと、生きているものは、売らない。** これで統一されます。

## §5 ★¥580 → ¥880（税込）／年 ¥8,800

### いま上げるべき理由

```
★まだ1件も売っていません。
　だから、いま上げるのは★ただです。
```

グランドファザリング（契約時の価格を固定）を採っています。
**1件でも売ったら、その人は永久にその値段です。**
★値段を決める窓は、**最初の1件を売るまで**しかありません。それが今日です。

### ¥880 の中身

```
本番からの逆算（有料の中核）
今日の目安
★毎月のよそおい ── 服・壁・床・家具・景色から★3点
```

★**毎月3点が、初日から毎月届きます。**
　本番モードは「本番がある人」にしか効きません。
　★よそおいは、全員に、毎月効きます。

### なぜ ¥1,000 を超えないか

```
9月4日の決まり：★未成年に売るなら月額1,000円未満
　　（民法5条3項・小遣いの範囲に収まる余地）
```

★¥880 なら、15〜17歳にそのまま売れます。
　★¥1,280 にすると、保護者の同意（実物）の仕組みが要ります。

★そして ¥980 の余地を、次の値上げのために残します。

### 年額

```
¥8,800／年（月額10か月分）★9月中に開ける（9月4日の訂正のまま）
```

### 国際価格との関係

```
国際 Tier 1  $4.99 ≒ ¥794（2026年8月のレート）
日本         ★¥880 → ★国際より高くなります
```

★価格設計仕様の「日本は国際より27%安い」は、**崩れます。**
　ただし**国際価格は出しません**（9月4日）。
　★帰国後、国際を開けるときに、まとめて見直してください。この判断書を根拠に。
