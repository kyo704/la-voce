## §1 Q3 ── 資金決済法はかかりません。ただし条件が1つ

前払式支払手段の3要件のうち、**価値保存性が欠けます。**

```
価値保存性   ★残高が記録されること   → 単発購入には残高がありません
権利行使性   その残高で買えること
対価性       お金を払って手に入れること
```

★¥980 を払って、**その場で装いを受け取る**なら、それは物の購入です。
未使用残高が存在しないので、**届出も供託も情報提供義務8項目も、来ません。**

### ★ただし、1つだけ条件があります

```
✕ 「¥980 で、好きな装いを5点。★あとで選べます」
　　→ ★これは残高です。前払式支払手段になりえます

◯ 「¥980 で、★秋のよそおい（5点）」
　　→ 買う前に中身が決まっている。★その場で全部付与される
```

★**選ぶのは購入の前。買ったら、その瞬間に全部渡す。**
　「あとで選ぶ」を1つでも残すと、そこが残高になります。

★これは実装の話ではなく、**法律の分かれ目**です。落とさないでください。

## §2 Q1 ── ★単発のほうが、素直に乗ります

直感と逆かもしれませんが、ここは大事です。

```
民法5条3項
　法定代理人が★目的を定めて処分を許した財産は、
　その目的の範囲内において、未成年者が自由に処分することができる
```

これは「**小遣いで買い物をした**」ことを守る条文です。

```
一回きりの ¥980   ★小遣いで買い物をした。★5条3項の典型そのものです
毎月 ¥580        ★将来の小遣いまで先に拘束します。
                  ★「継続契約性」という、5条3項には無い論点が乗ります
```

★**法律の上では、¥980 の単発のほうが、¥580 の月額より安全です。**

金額が大きいほうが危ない、という直感は自然ですが、
5条3項が見ているのは**金額の大小ではなく、「小遣いの範囲か」**です。

```
中学生の小遣い   おおむね 月2,000〜3,000円
高校生の小遣い   おおむね 月5,000円前後
```

★¥980 の単発は、この範囲に素直に入ります。

### ★ただし、同じ月の合計を見てください

```
¥580（月額）＋ ¥980（装い）＝ ★¥1,560 ／ その月
```

★9月4日に引いた「月額1,000円未満」の線は、**月額の継続分**についてのものでした。
　単発を足すと、その月の合計は超えます。

だから、**回数に上限を置きます。**

```
★未成年（15〜17歳）は、装いの購入を★季節ごとに1回まで（年4回）
```

```
年間の合計   ¥580 × 12 ＋ ¥980 × 4 ＝ ★¥10,880／年
　　　　　　  高校生の年間の小遣い（およそ¥60,000）の★18%
```

★これなら「小遣いの範囲」から出ません。
　そして**季節ごと**という区切りは、製品の形（季節のセット）と同じです。
　**制限に見えません。** これが大事です。

## §3 Q2 ── ★二段の同意を作らないでください

ここが、今回いちばん重要な回答です。

### 二段にすると、何が起きるか

```
¥580   申告で足りる
¥980   ★もっと確実な同意が要る
```

★これを自分で作ると、**こう読めます。**

```
　「この事業者は、★申告では足りないと知っていた。
　　それなのに ¥580 のほうは申告で通していた。」
```

★**自分で作った二段が、下の段の弱さの証拠になります。**

消費生活センターや弁護士は、まさにここを見ます。
「なぜ片方だけ厳しくしたのですか」と聞かれて、
**「そちらは弱いと思ったからです」以外の答えがありません。**

### では、どうするか ── ★1本の「枠」にまとめます

すでに 9月4日に、同意の文をこう決めました。

```
★「毎月◯◯円まで、このアプリで使ってよいと認めます」
　（「契約に同意します」ではありません。★5条3項の許可の形です）
```

**この枠を広げるだけです。**

```
　［　］ このアプリで、次のことをしてよいと認めます。

　　　　・毎月 580円の、記録の機能
　　　　・★季節ごとに1回まで、980円までの装い

　　　　（1年で、いちばん多くて 10,880円になります）
```

★**同意は1回。画面は1つ。段はありません。**

そして、これは二段より**強い**です。理由：

```
① ★保護者が承認するのは「使ってよい枠」です。
　　5条3項の「目的を定めて処分を許した財産」★そのものです
② ★上限の合計額が、その場に書いてあります
　　保護者が何を許したのかが、金額で確定します
③ ★実装が1本で済みます
④ ★「なぜ片方だけ厳しいのか」という問いが、そもそも生まれません
```

★**二段は法的にも実務的にも成り立ちますが、この製品では作るべきではありません。**
　理由は、二段そのものが悪いからではなく、
　★**下の段を自分で否定してしまうから**です。

## §4 ★「確実な同意」── 3Dセキュアが答えです

ご質問の核心です。「メールの往復より強くて、簡単なものはあるか」。

**あります。しかも、もう半分入っているはずです。**

### EMV 3-Dセキュア

```
日本では、2025年3月末までに★全EC加盟店で原則導入とされました
（経済産業省 クレジットカード・セキュリティガイドライン）

やること   ★ワンタイムパスワード等で、
           ★「取引が、カードの正当な名義人によって行われている」ことを検証する
```

### なぜこれが効くのか

```
未成年が★保護者のカードを無断で使った場合
　　→ ワンタイムパスワードは★保護者の端末に届きます
　　→ ★認証が通りません

保護者が★承知の上でカードを渡している場合
　　→ ★認証が通ります
　　→ ★それは「処分を許した」ことの、かなり強い証拠です
```

★**申告は「言っただけ」ですが、3DSは「カードの持ち主が実際に承認した」です。**

### 実装

```
Stripe   payment_method_options[card][request_three_d_secure] = 'any'
         （必ず画面を出したいときは 'challenge'）
         ★Checkout Session にも同じパラメータが渡せます
```

★**1つのパラメータです。**

```
新しい個人データ   ★増えません（保護者のメールも電話も持ちません）
新しい外に出る経路 ★増えません（台帳05に足すものがありません）
新しい業者         ★ありません
```

★メールの往復を却下した理由（個人データが増える・経路が増える・証明力は上がらない）が、
　**3DSには1つも当てはまりません。**

### ★もう1つの利点 ── ライアビリティシフト

```
3DS認証が成功した支払いは、不正利用のチャージバックの責任が
★カード会社側に移ります（ライアビリティシフト）
```

★保護者が「子が勝手に使った」としてチャージバックした場合でも、
　3DSを通っていれば、こちらが守られやすくなります。

★**これは9か月イタリアにいるあいだ、特に効きます。**
　争いに対応する人が国内にいないからです。

### ★正直に書いておくこと

```
3DSが証明するのは
　◯ ★カードの名義人が、この支払いを承認したこと
　✕ 保護者が★契約に同意したこと
　　（これは別のことです）
```

★そして、確実ではありません。

```
・'challenge' を指定しても、★最終的な流れはカード会社が決めます
・カードが3DS非対応なら、★認証なしで通ります
・家族カードなど、未成年名義のカードもあります
```

★だから、**3DSは「確実な同意」ではありません。**
　★**いま手に入るもののなかで、いちばん強くて、いちばん軽いもの**です。
　そして、それで足ります。理由は §5 です。

### ★どちらにも掛けてください

```
¥980 の装い   3DS を要求する
¥580 の月額   ★こちらも要求する（初回の登録時）
```

★片方だけにすると、また二段になります。**両方に掛けてください。**
　そして両方に掛けるなら、それは「厳しさの段差」ではなく、**この店の標準**になります。

## §6 ★取り消されたとき、装いはどうなるか

これは相談に無かった論点です。**決めておいてください。**

```
問い   返金したら、渡した装いは取り上げるのか
```

★9月4日に「一度あげたものを取り上げない」と決めました。矛盾するように見えます。
　**しません。線を引き直します。**

```
★記録で得たもの（記念のもの・unlock）   ★絶対に取り上げない
★取り消された取引で渡したもの           ★戻す
```

★後者は「取り上げる」のではありません。**取引が無かったことになる**のです。
　民法121条の2の原状回復そのものです。

規約に1行。

```
　お取消しにより返金した場合、そのお買い物でお渡しした装いは、
　お手元から戻ります。記録によって手に入れたものは、そのまま残ります。
```

★**2文目を必ず書いてください。** これが無いと、返金を求めることが怖くなります。
