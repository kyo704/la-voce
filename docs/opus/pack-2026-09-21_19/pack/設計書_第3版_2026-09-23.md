## 0. この製品は何か

```yaml
一文: 声を使う人が、自分の体調と本番を、自分だけの手元に記録して見返す道具
利用者: 声楽家・声優・ナレーター・教員・学生（18歳以上）。★日本在住の方に限る
売る先: ①個人（月額・年払い）②学校（音大・養成所。運営の道具として）
作る人: 坂本 響（1名）。実装は Claude Code、設計は Opus、文書は Sonnet
```

### 曲げないもの（8項目）

```yaml
1 ★先生・学校・運営は、体調の記録に届かない（画面ではなく台帳の層で遮断する）
2 ★点数・順位・信号色を出さない（自己決定理論。点にすると動機を弱める）
3 ★因果を主張しない。「一緒に出ています」の1文だけ（n≥10・効果量・多重比較補正を満たすときのみ）
4 ★催促しない。通知は例外3件のみ
5 ★取り上げない。解約しても 手元の品は残る
6 ★書き出しは無料（GDPR20条・12条5項）
7 ★判断を取り上げない（おとりを置かない・偽の緊急性を作らない）
8 ★18歳未満は利用者にしない（保護者のアカウントの下でのみ）
```

## 1. 全体の形

```yaml
画面: Next.js（Vercel）／スマホ・PC・iPad
台帳: PostgreSQL（Supabase・東京）。★104表すべてで 行単位のアクセス制御（RLS）
認証: メールとパスワード（Supabase Auth）
決済: Stripe（1回払いと月額）
配信: Vercel ／ メール送信は外部の事業者
★守りの考え方: 画面の出し分けではなく、★台帳の層で遮断する。画面は「見せない」だけ、台帳は「渡さない」
```

### 3つの層

```yaml
個人の層: 体調の記録・ノート・本番・羊・ポートフォリオ  → ★本人だけ
学校の層: 名簿・役職・レッスン・行事・請求・レッスン割  → ★札（できこと）で制御
公演の層: 香盤表・稽古・出欠・呼び出し・当日の進行      → ★その公演にいる人だけ
★層をまたぐ結合の禁止（裁定その55・57）: entries との結合は禁止。委託データ同士の結合は可
```

## 2. 機能（2026-09-23 現在）

### 個人（販売開始で出すもの）

```yaml
きょう: 30秒の記録（★点数を出さない）／毎日 聞いてほしいこと（最大5つ・★いつ書くかを自分で決める）
ふりかえる: 通算の記録日数（★連続ではない）／羊の成長
しらべる: 統計的な関連の提示（★n≥10・効果量・多重比較補正。満たさなければ何も出さない）
受診用のまとめ: ★1回の記録でも 医師に見せられる形が出る（初日から価値が出る唯一の道）
本番: 予定・当日の記録・ふりかえり
書き出し: CSV・JSON（★無料）
退会: アプリ内で完結（★人を介さない）
```

### 学校（2027年4月から本格）

### 公演（隠してある。実装はこれから）

```yaml

出欠・呼び出し（分刻み）・楽屋・当日の進行・出演料・参加費
代役（アンダースタディ）／子どもの出演（保護者の下）／緊急の連絡先
期限: ★お支払いのときの「本番の最後の日＋30日」。延期は1回・90日まで
★前の公演から 枠だけ写せる（人・稽古・出欠・期限は写さない）
```
