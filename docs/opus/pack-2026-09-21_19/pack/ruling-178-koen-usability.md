## 1. 決めたこと

```yaml
① 出演者から見た「自分の予定」:
   自分がいつ呼ばれるかだけを返す。★他の出演者の予定・名前・体調は返さない
   → いまの香盤表は運営の道具。出演者に要るのは「自分の呼び出し」だけ
② 代役（アンダースタディ）:
   本役が休んだ稽古で、その枠を継ぐ代役を ★一覧に出す
   ★自動では呼ばない。運営が押したときだけ 呼び出しに入る
   理由: 誰を立てるかは その日の判断（声の調子・演出の意向）。台帳が決めてよいことではない
③ 香盤表の書き出し:
   行×列×人の形で返す（PDF・紙のもと）。★体調・記録の列を1つも作らない
   理由: 紙で配る団体が多い。出せないと Excel に打ち直される
④ 前の公演から ★枠だけ写す:
   写すもの: 場面・枠（役の並び）・時刻の目安
   ★写さないもの: 人・配役・稽古・出欠・呼び出し・期限・お支払い
```

## 2. 裁定144（公演の使い回しの禁止）との両立

```yaml
裁定144 が禁じたこと: ★同じ公演の題名と日付を書き換えて、期限の先へ使い回すこと
④ が すること: ★新しい公演を作り、そこへ 枠の形だけ写す
ちがい:
  - 写し先は新しい行 → ★期限は新しく数える（お支払いも新しく要る）
  - 人・配役・稽古・出欠は写らない → ★前の公演の記録が新しい公演に混ざらない
  - 元の公演はそのまま残る（消えない・延びない）
結論: ★矛盾しない。毎年同じ演目を出す学校・市民オペラのための道であって、期限を延ばす道ではない
★守り: 写し先に既に場面があれば止まる（TARGET_HAS_ROWS）。同じ公演を指しても止まる
```

## 3. VERIFY

```yaml
- 出演者が「自分の予定」を見る → 自分の呼び出しだけ。★他人の名前も体調も出ない
- 本役を「休み」にする → 代役の一覧に出る。★呼び出しは増えない（運営が押すまで）
- 代役でない人を立てようとする → NOT_AN_UNDERSTUDY
- 書き出し → 行×列の形。★体調・記録の列が無い
- 枠を写す → 場面と枠だけ入る。人・稽古・出欠・期限は写らない
- 写し先に場面がある → TARGET_HAS_ROWS
```
