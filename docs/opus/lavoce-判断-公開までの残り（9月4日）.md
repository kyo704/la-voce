## §2 裁定 ── 管轄の裁判所は、★書かないでください

```
（採用）「本規約は、日本法に準拠します。」──★これだけ書く
（書かない）「◯◯地方裁判所を専属的合意管轄裁判所とします」
```

★理由

```
1  ★書かなければ、民事訴訟法の原則で決まります
　　　→ 消費者にとって、不利になりません

2  専属的な管轄の合意は、★消費者相手だと争われます
　　　→ 弁護士確認前に、争いの種を書き込む必要はありません

3  ★坂本さんの所在地が、これから変わります
　　　→ 「当方の所在地」と書くと、9か月のあいだ意味が動きます
```

★弁護士確認のあと、必要と言われたら足せば済みます。
　**足すのは簡単で、消すのは難しいです。**
