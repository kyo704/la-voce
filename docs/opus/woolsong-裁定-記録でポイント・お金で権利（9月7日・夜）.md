# 裁定：記録でポイント、お金で「権利」

2026年9月7日 ／ Opus
坂本さんの案「ポイントは記録だけ。お金で得るのはアイテムを複数買う権利」への回答

---

## §0 結論

**案は通ります。ただし一点だけ、設計を間違えると法律が1本乗ります。**

```
★分かれ目は、たった一つ。

　　数を売る  →  危ない（「3着ぶんの権利」）
　　期間を売る →  安全（「その月のあいだ、いくつでも」）
```

理由を、実際の行政処分の事例から書きます。

---

## §1 なぜ「数」が危ないのか ── LINEの宝箱の鍵

2016年、**関東財務局が、LINEのゲーム内アイテム「宝箱の鍵」を、前払式支払手段と認定**しました（LINE POP）。

```
宝箱の鍵の設計
　・宝箱を開ける鍵。開けるとゲーム内通貨やアイテムが出る
　・★現金では買えない。ゲーム内通貨「ルビー」を介してのみ買える
　・★プレイを通じて、無償でも手に入る
```

LINE側は「これは通貨ではない。特定の用途にしか使えない」と主張しました。**却下されました。**

判断の理由（牛島総合法律事務所の解説より）：

> 資金決済法の「対価」は「必ずしも現金に限られず、**財産的価値があるものはすべて含まれる**」
> ルビーを介してしか手に入れられないものであったとしても**「対価」性は認められる**

そして解説はこう結んでいます。

> その判断は**極めて難しい曖昧なもの**となる。ゲーム内通貨のみならず、**ゲーム内通貨で取得できるアイテムについても**、前払式支払手段に該当しないかを慎重に検討する必要がある

★**無償でも手に入るのに、該当と判断されました。** 「無償の経路がある」ことは、免罪符になりません。

## §2 坂本さんの案を、3要件に当ててみます

前払式支払手段の3要件（日本資金決済業協会）：

| 要件 | 中身 |
|---|---|
| ① 価値保存性 | **金額または物品・役務の数量が、記載・記録されている** |
| ② 対価性 | 対価を得て発行される |
| ③ 権利行使性 | 代価の弁済に使用できる |

### 記録で貯まるポイント（現金では買えない）

| 要件 | 判定 |
|---|---|
| ① 価値保存性 | ○（137ポイント、という数が記録される） |
| ② 対価性 | **✕ 対価を払っていない** |
| ③ 権利行使性 | ○ |

→ **② が欠けるので、該当しません。** ★9月4日の私の判断のとおりです。この部分は安全です。

### 「3着ぶんの権利」を980円で買う場合

| 要件 | 判定 |
|---|---|
| ① 価値保存性 | **○ 「あと3着」という数量が記録される** |
| ② 対価性 | **○ 980円払った** |
| ③ 権利行使性 | **○ 服と引き換えられる** |

→ **3つ揃います。該当する可能性が高い。** 名前が「ポイント」でなくても関係ありません。LINEの鍵も「ポイント」ではありませんでした。

### 「その月のあいだ、いくつでも選べる」を980円で買う場合

| 要件 | 判定 |
|---|---|
| ① 価値保存性 | **✕ 数量が記録されていない** |
| ② 対価性 | ○ |
| ③ 権利行使性 | △（サービスの提供そのもの） |

→ **① が欠けます。該当しない側です。**

★ただし正直に書きます。**私は弁護士ではありません。** そしてLINE事案の解説自身が「判断は極めて難しい曖昧なもの」と書いています。**微妙な設計に近づかないこと**が、いちばん確かな守りです。

## §3 だから、こう作ってください

```
無料
　記録した日数でポイントが貯まる（★項目の数ではなく、日数）
　貯まったポイントで、よそおいを1点ずつ交換できる
　★ポイントは現金では買えない。この経路を作らない

有料 ¥980/月
　その月のあいだ、★ポイントを使わずに、よそおいを自由に選べる
　★数を決めない。「3点まで」も「5点まで」も書かない
　解約しても、それまでに着せたものは残る（取り上げない）
　★選ばなかった月のぶんは、翌月に繰り越さない
```

### ★絶対にやってはいけない4つ

```
✕ 「あと3着選べます」と数を表示する          → ①が立つ
✕ 「今月選ばなかった2着は来月に繰り越し」     → 残高そのもの
✕ 「有料の人はポイントが2倍たまる」           → お金でポイントを買っている（②が立つ）
✕ 「ポイントを追加購入」                      → ②が立つ。いちばん明白
```

### 数を絞りたい場合の、安全な方法

もし「1か月で217点すべて取られると困る」なら、**数ではなく時間で絞ってください。**

```
✕ 「月に10点まで」          数が記録される。繰り越しの疑いも生む
○ 「1日に1点ずつ選べる」    ★その日に選ばなければ消える。貯まらない＝残高でない
```

★「貯まらない」ことが、すべてです。

## §4 併せて直すもの

### ① 特商法のページ（★売っている名前と一致させる）

いま「よそおい **月1点**」と書いてあります。この案では月1点ではなくなります。

```
現在：よそおい 月1点
案　：その月のあいだ、よそおいを自由に選べます（1日に1点ずつ）
```

★「売っている名前と、特商法のページの名前を一致させる」は、この製品で既に決めた規則です。

### ② ポイント数を、常時表示しない

法律とは別の話です。Deci ほか 1999 のメタ分析（128研究）では：

```
予期される有形報酬・従事に随伴（「あと13ポイント」）  d = −0.40
★予期しない有形報酬（ある日ふと届く）                d = +0.01（影響なし）
```

坂本さんがポイント制を残すと決められたことに、私は異論を出しません。**根拠は出しましたし、決めるのは坂本さんです。**
そのうえで、**数だけを見せない**という中間の形を提案します。

```
✕ 「137ポイント／あと13ポイントで新しい服」
○ ホームで羊が服屋の前にいる。入れる日は、入れる。入れない日は、入れない
　 → 数を数えずに、同じことができます。しかも法律側でも「数の表示」から遠ざかる
```

★ここは坂本さんの好みが優先です。数を見せたいなら見せてください。

### ③ 未成年（★これは確認が要ります）

主要な利用者は音楽学生で、未成年が含まれます。**「服が欲しくて課金する」構造は、機能を買う構造より、未成年に対して強く働きます。**

```
確認すること
　・案Cへの転換で、未成年の課金に何を入れたか（私は中身を知りません）
　・¥980（よそおい放題）に、未成年への追加の配慮が要るか
　・★「¥580（機能のみ）」を未成年の既定にする、という選び方もありえます
```

## §5 この案の、良いところ（法律の外の話）

★はっきり良くなる点が3つあります。

```
① イタリア滞在中の基準日集計（3/31・9/30）が、要らなくなる
　 → 9月4日の私の心配「残高を集計する人が国内にいない」が、丸ごと消えます

② 記録が、お金で飛び越せない
　 → 「お金を払えば記録しなくても服が手に入る」形にならない。
　　 健康の道具として、この一線は守られています

③ 有料の二本立てが、きれいに分かれる
　 ¥580 / ¥4,800  ── 原因を見つけるための機能
　 ¥980           ── ＋よそおい
　 → 服が欲しい人と、原因を知りたい人が、別々に払える
```
