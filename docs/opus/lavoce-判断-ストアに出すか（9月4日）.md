# 判断 ── App Store と Google Play に出すか

全 226 行 / 末尾は「ストアは、客を連れてきません。棚に置くだけです。」

作成 2026年9月4日 ／ 「簡単か、手数料はいくらか」への回答

---

## §0 結論

```
簡単か      Android ★比較的かんたん（数日）
            iOS     ★かんたんではありません（★PWAはそのままでは通りません）

手数料      ★15〜30%。Stripe 直販の★4〜8倍です

いま出すか  ★出さないでください。理由は§4
いつ出すか  ★帰国後（2027年7月〜）
```

---

## §1 かんたんかどうか ── ★iOS と Android で、まったく違います

Woolsong は PWA です。ここが効きます。

### Google Play ── 出せます

```
方法      TWA（Trusted Web Activity）で包む
条件      Lighthouse のスコア 80 以上
          Digital Asset Links で所有を証明
          Service Worker が動いていること
登録料    $25（★一度きり）
道具      Bubblewrap / PWABuilder
手間      ★数日
```

### App Store ── ★そのままでは通りません

```
ガイドライン 4.2（Minimum Functionality）
　「ウェブサイトを包み直しただけのものを超える
　　機能・内容・UI を含んでいること」
```

**PWA をネイティブの殻で包んだだけのものは、リジェクトされます。**
通すには、ネイティブの通知・ディープリンク・ネイティブの画面遷移などを足す必要があります。

★それは「包む作業」ではなく、**作る作業**です。

```
登録料    $99（★毎年）
手間      ★数日では終わりません
```

そして、**健康を扱うアプリには追加の審査があります。**
9月4日に医師法の線を引きましたが、**Apple の審査でもう一度、同じことを問われます。**
（Apple のガイドラインには、健康・医療に関する項目が別にあります。）

★不在中にリジェクトが来たら、直せません。

---

## §2 手数料 ── 日本は、2025年12月に変わりました

「スマホソフトウェア競争促進法（スマホ新法）」が **2025年12月18日に全面施行**されました。
これで日本の手数料は、他国と違う形になっています。

報道でまとめられている率です（★出すときに、必ず自分で確認してください）。

```
Apple（日本）
　ストア内の購入            26%
　外部の決済を使う          21%
　外部へ誘導する            15%
　Small Business Program    10〜15%

Google（日本）
　ストア内の購入            30%
　第三者の決済を使う        26%
　外部へ誘導する            20%
　★年商100万ドル未満なら    10%（外部誘導のとき）
```

サブスクリプションについては、世界的には
**Google が初日から15%、Apple は Small Business Program で15%**（未加入なら1年目30%・2年目以降15%）
という形が続いています。★日本の新しい数字とどう重なるかは、**出すときに確認してください。**

## §3 ¥580 で計算します

```
Stripe で直接売る    手数料は★3%台
                     ¥580 → 手取り ★¥560前後

ストア経由 15%       ¥580 → 手取り ★¥493
ストア経由 26%       ¥580 → 手取り ★¥429
ストア経由 30%       ¥580 → 手取り ★¥406
```

**1人あたり、月に ¥67〜¥154 が消えます。**
100人なら、月 ¥6,700〜¥15,400。年 ¥8万〜¥18万です。

★そして Apple には、売れても売れなくても **$99/年**がかかります。

## §4 ★いま出さないでください ── 5つ

```
① ★45日しかありません
   iOS は「包む」では済みません。作る作業です

② ★PWA のまま、もう売れます
   Stripe の準備はできています。ストアは、売るために要りません

③ ★ストアは、客を連れてきません
   ここがいちばん大きな誤解です（§5）

④ ★規約が2つ増えます
   Apple と Google のガイドラインに従う義務が生まれます。
   健康を扱うので、審査は軽くありません

⑤ ★不在中にリジェクトが来たら、直せません
   アプリが消えるわけではありませんが、更新が止まります
```

---

## §5 ★「ストアに置けば見つけてもらえる」は、幻想です

```
App Store には、200万を超えるアプリがあります。
「声楽」「発声」で検索する人が、日本に月に何人いますか。
```

**声のプロ向けの道具は、検索されません。**
知っている人が、名前で探すだけです。名前で探すなら、**ウェブで足ります。**

そして坂本さんは、**営業ツールを作っています。**
客は営業で連れてくる、と既に決めているはずです。

```
★ストアは、客を連れてくる場所ではありません。
　すでに来た客に、置き場所を1つ増やすだけです。
```

置き場所を増やすために、売上の15〜30%と、45日のうち何日かを使うのは、
**いまの順番ではありません。**

---

## §6 ★それでもストアが要る理由が、1つだけあります

**支払い手段です。**

```
15〜17歳に売る、と決めました（9月4日）。
★その年齢の人は、クレジットカードを持っていないことがあります。
```

App Store 経由なら、キャリア決済や、コンビニで買えるギフトカードで払えます。
**カードがなくても買えます。** これは本物の利点です。

★ただし、**もっと安く同じことができます。**

```
Stripe は日本で、★コンビニ決済や PayPay などに対応しています。
　→ ストアに 15〜30% 払わずに、カードのない人に売れます
```

**先に、こちらを調べてください。** ストアはそのあとです。

## §7 いつ出すか

```
2026年9月〜10月   ★出さない
2026年10月〜2027年6月（不在）  ★出さない
2027年7月〜（帰国後）
  　まず Android（TWA・$25・数日）
  　iOS は、ネイティブの機能を足すと決めてから
```

★Android だけ先に出す、というのは筋が通ります。安く、速く、リスクが小さい。
**ただし急ぎません。** 帰国後で十分です。

## §8 いま調べておくとよいこと（10分）

```
□ Stripe で、★コンビニ決済／PayPay が使えるか、条件と手数料
　 → §6。★これは今すぐ効きます
```

これだけです。**ストアの登録も、審査の準備も、いまはしないでください。**

## §9 確かめたこと／確かめていないこと

```
確かめました
  ・スマホ新法の全面施行日（2025年12月18日）
  ・App Store ガイドライン 4.2 で PWA ラッパーが通らないこと
  ・Google Play の TWA の条件（Lighthouse 80以上・$25 ほか）
  ・Apple の Small Business Program（前年売上100万ドル以下・15%）
  ・Google Play の 100万ドルまで15%

★確かめていません
  ・日本の新しい手数料率の★正確な現在値
    （報道のまとめによるもので、★1次資料は見ていません）
  ・Stripe のコンビニ決済／PayPay の可否と手数料
  ・¥580 に対する Stripe の正確な手数料
```

★手数料の数字は、**出すと決めた日に、Apple と Google の1次資料で確認してください。**
この分野は、いま1年で変わります。
