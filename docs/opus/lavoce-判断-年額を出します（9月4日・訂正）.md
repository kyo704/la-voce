## §1 私の理由のどこが間違っていたか

### ①「12か月の提供義務を、9か月不在で負う」── ★過大でした

**不在は、停止ではありません。**

```
Supabase も Vercel も、坂本さんがいなくても動きます。
止まるのは「★新しく作ること」であって、「動いていること」ではありません。
```

そして12か月の義務は、年額に固有ではありません。
月額でも「今月分」の義務はあります。長さが違うだけです。

### ②「返金が10倍」── ★過大でした

10倍ですが、**元が ¥580 です。** 10人が返金を求めても ¥58,000 です。
そして**未成年には年額を出しません**（既決）ので、取消権の重い部分は当たりません。

### ③「分岐が1つ消える」── ★これだけは本当です

ただし、Stripe の price を1つ足すだけです。
**私はこれを、実装の重さとして数えすぎました。**

```
「2ヶ月も無料でアプリを続けられる人は少ない」

      ★不在のあいだに、静かに解約されます

年額  ★9か月分が、先に確保されます
      そして「もう払った」ことが、続ける理由になります
```

★**9か月放置しても離れない客を作る道具を、
　9か月放置する人が使わないのは、おかしいです。**

**不在期間こそ、年額がいちばん効く状況でした。**

## §3 出す形 ── 4つの条件

```
価格    ¥5,800／年（税込）★月額10か月分。変えません
対象    ★18歳以上のみ（未成年には出しません）
返金    ★未使用期間の日割り
時期    ★9月中に開ける。10月中旬に開けない
```

### 未成年に出さない

9月4日の決定のままです。年額は民法5条3項（小遣いの範囲）に乗りません。
一度に ¥5,800 が動きます。

★見張りに1つ足してください。

```
□ 15〜17歳と答えたアカウントに、★年額の選択肢が出ないこと
```

### 返金は、日割り

未成年の場合は**全額**でした（民法121条の2第3項）。
成人の年額は違います。**未使用の月数分を返します。**

```
規約と価格ページに、先に書いてください。

　途中でおやめになる場合は、お申し出があれば、
　残りの月数分を返金します。
```

★これが不在中の防御です。「返してもらえない」と思われるのが、いちばん揉めます。

### 時期 ── ★9月中

```
✕ 10月10日に開ける  → 買った9日後に、作った人が国外へ
◯ 9月中に開ける      → 何かあっても、国内にいるあいだに直せます
```

**遅く開けるくらいなら、帰国後まで待つほうがましです。**
9月中に開けられないなら、そのときは見送ってください。

## §4 ★年額を売るなら、1行足してください

これが今回いちばん大事な追加です。

年額は「これから12か月分」を先に受け取ります。
**その12か月に何が起きるかを、買う前に書いてください。**

```
　2026年10月から2027年6月まで、作者が国外にいるため、
　新しい機能はほとんど増えません。
　いまある機能を、そのままお使いいただく形になります。
```

★不利なことを、自分から書きます。3つ効きます。

```
① あとで「聞いていない」が起きません
② ★それでも買う人は、★いまある機能が本当に要る人です
   ★良い客が残ります
③ 返金の申し出が減ります
```

**約束を書いたら、それを守っている仕組みを隣に書く**（9月4日の決まり）。
ここでは、書くのは約束ではなく**限界**ですが、同じことです。
先に書けば、あとで説明しなくて済みます。
