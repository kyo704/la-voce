2026年9月10日 ／ Opus
問い：「先生を よこに ならべる 日程は、パソコン限定のままで よいか」

---

# §0 答え ── ★いいえ。撤回します

```
　★§4-7 の「管理者の一覧は パソコンだけ」を、★撤回します。
　★★日程も、iPhone で 出します。
```

**理由は 2つです。**

```
　★1  事務の方が いちばん 見たいのは、★出先と 授業の あいだです。
　　　★そこで パソコンは 開きません。

　★2  「パソコンだけ」は、★1つ 認めると 増えます。
　　　次は 名簿、次は 行事。★最後に「iPhoneでは 何もできない」に なります。
```

★**そして、作れます。**予定管理のアプリが、もう 解いている問題でした。

# §1 ★「先生を よこに ならべる」を、3段で 出します

| | 何を | どう見えるか |
|---|---|---|
| ⑧ | **1日 × 先生よこ** | 時間が たて、先生が よこ。★時間の列は 止める。★横に ずらす |
| ⑨ | **1週間 × 濃さの地図** | 7日 × 6人が ★1画面に 入る。中身は 出さず、★コマ数だけ |
| ⑩ | **よこ持ち** | 812×375。★6人 ぜんぶ 入る。★ほぼ パソコンと 同じ |

★**⑧は、美容室・診療所の 予約台帳が 使っている形です。**
★縦が時間、横が担当者。**iPhone の幅に 3人 入り、指で ずらすと 残りが 出ます。**
★**時間の列を 止める**のが 肝です。ずらしても、何時か 分からなくなりません。

★**⑨が、この提案の 中心です。**
★1週間ぶんの 中身を iPhone に 入れるのは、無理です。**入れません。**
★**代わりに「形」だけ 入れます。**どこが 混んでいて、どこが 空いているか。
★数字と 濃さだけなら、**7日 × 6人 = 42 マスが 1画面に 収まります。**
★押すと ⑧が 開いて、そこで 中身を 見ます。

```
　★パソコン　★中身を、広い画面で いちどに 見る
　★iPhone　 ★形を 見て、必要なところを 押して 中に 入る

　★★同じ 仕事が できれば よく、★同じ画面である 必要は ありません。
```

★**⑩は、いちばん 単純な答えです。★横に 持てば 入ります。**
★812×375 に、6人 × 10時〜19時 が 収まりました。**縮めていません。**
★（★上のバーと 下のタブを 少し 薄くしています。それだけです）

　★6  ★ボタンは 44pt（③の 出た／休み／—）
```

```
