# 裁定：「もっと」の歯車を、どこに置くか

2026年9月7日・夜 ／ Opus
坂本さんの「おうちの画面（羊の右上）に置きましたが、本当にここであってるの？」への回答

---

# §0 結論

```
★おうちの右上では、ありません。★ホームの右上です。

　ただし ★「おうちの右上にも置く」のは、正しいです。
　★中身を分けてください。
```

| 置く場所 | 中身 |
|---|---|
| **ホームの右上** | 設定／アカウント／**書き出し**／**同意の撤回**／プラン／学ぶ |
| **おうちの右上** | ★おうちのことだけ（着せかえ・置きかた・よそおいのお店） |

---

# §1 ★なぜ、おうちの右上では足りないのか（4つ）

## 1-1｜★「もっと」の中に、法律の導線が入っています

`画面レイアウト仕様` §1.1 に、こうあります。

```
| もっと | ★設定・★書き出し・学ぶ | 月1回 |
```

そして 9月2日の裁定に、こうあります。

```
「同意は、いつでも ★『もっと ＞ 設定』から撤回できます。」
　★これは、いま本番にあります（9月2日・作業指示-決めることとやること §94）
```

★つまり「もっと」の中には、次の3つが入っています。

```
① ★同意の撤回　　個人情報保護法／GDPR 第7条3項（撤回は、与えるのと同じくらい容易であること）
② ★書き出し　　　GDPR 第20条（データポータビリティ）
③ ★退会・アカウント
```

★**GDPR 第12条1項は、これらを「容易にアクセスできる形式で」提供することを求めています。**
　★おうちタブを開いて、そこから歯車を押して、さらに設定を開く ── これは**3階層**です。

## 1-2｜★規約に書いてある道と、実際の道が食い違います

```
規約・同意の文　「もっと ＞ 設定 から撤回できます」
おうちの右上　　「おうち ＞ 歯車 ＞ 設定」

　→ ★文と実物が違います。★どちらかを直さないといけません。
　→ ★規約を直すより、★場所を戻すほうが速くて安全です
```

★**Codeへ：規約・プライバシーポリシー・同意画面に「もっと」という語が何か所あるか、数えてください。**

## 1-3｜★羊に興味がない人が、たどり着けません

```
利用者のなかには、★羊もおうちも一度も開かない人がいます。
　→ その人が、★同意を撤回できません。★書き出しもできません。★退会もできません。
　→ ★「羊の部屋を見ないと、同意を取り消せない」は、成り立ちません。
```

## 1-4｜★「おうちの右上の歯車」は、「部屋の設定」に読めます

```
おうちの画面で右上に歯車があると、★模様替えや置きかたの設定に見えます。
　→ 設定を探している人は、★そこを押しません。
```

★9月2日に決めた「**画面の外にある機能は、無い機能です**」に、近づきます。

# §2 ★では、なぜ「両方に置く」のがよいのか

坂本さんが おうちの右上に置かれたのは、**間違いではないと思います。**
おうちの画面には、**おうち専用の設定が要る**からです。

```
おうちの右上　★着せかえ／置きかた／よそおいのお店／記念のものの棚
　　　　　　　→ ★この画面の中のことだけ。★歯車ではなく「⋯」か「よそおい」の字がよい

ホームの右上　★設定／アカウント／書き出し／同意の撤回／プラン／学ぶ
　　　　　　　→ ★アプリ全体のこと。★これが「もっと」
```

★**同じ歯車を2か所に置くと、押した人が「同じものが出る」と思って混乱します。**
　★形か、字を変えてください。

---

# §3 ★ホームの「下のほう」ではなく「右上」にする理由

Codeの実測では、いま**ホームの下のほう**にあります（`VocalTracker.jsx:11825-11836`）。

```
下のほう　　★スクロールしないと見えません。★はじめて開いた人は気づきません
右上　　　　★開いた瞬間に見えます。★慣習と一致します（右上＝設定）
```

★羊の絵が主役なので、**歯車は小さく、控えめに**してください。
　ただし**押せる大きさは 44×44px 以上**（画面レイアウト仕様 §1.2）。

```
　┌────────────────────────┐
　│                          ⚙ もっと │  ← ★ここ
　│                                   │
　│            （羊）                 │
```

★いまの実装は「歯車＋『もっと』の字」だそうです。**その形のままで正しいです。**
　（Codeの注釈どおり、歯車だけだと何が開くか分かりません）

# §4 ★Codeへ

```

　　→ 場所を変えるなら、★全部を直さないと、文と実物が食い違います

② 「もっと」の中に、いま何が入っているか（一覧）
　　★特に「同意の撤回」「書き出し」「退会」がどこにあるか

③ ★コードの注釈「おうちの右上の歯車から」を、実際の置き場所に合わせて直す
　　（Codeが「注釈のほうが古い」と報告した件）
```
