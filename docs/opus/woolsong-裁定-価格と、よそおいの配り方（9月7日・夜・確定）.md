## §2 法律の確認 ──「月1点」は、数量になるか

前払式支払手段の3要件のうち、①は「金額または**物品・役務の数量**が記載・記録されていること」です。
「月1点」は数量に見えます。そこで、あてはめます。

### 該当しないと考える理由

```
① 月額料金は「分析の機能を含むサービス全体」の対価であって、
　 ★よそおい1点に値段が付いていない
　 （「980円で3着」は3着に980円が付く。ここが決定的に違う）

② ★繰り越さない。今月の1点は今月で終わる。残高が発生しない

③ 会員の月会費に毎月の特典が付く形は、ごく一般的な会員サービスの構造であり、
　 これを前払式支払手段とした例を、私は知りません
```

> ★**ただし、私は弁護士ではありません。** そしてLINEの宝箱の鍵の事案を解説した弁護士事務所は「その判断は極めて難しい曖昧なものとなる」と書いています。
> だから、**そもそも数を数えない作りにしてください。** それが§3です。

## §3 実装の決まり（★この5つを守れば、境界に近づきません）

```
① ★繰り越さない
　 選ばなかった月のぶんは、消える。翌月に足さない

② ★「あと1点」「残り○点」を、どこにも表示しない
　 数を数えなければ、数量の記録は発生しません

③ ★選ばせるより、届ける（いちばん安全で、いちばん良い形）
　 月のはじめに、3点を並べて「今月のよそおい」として見せる
　 そこから1つ選ぶ。★月末までに選ばなければ、こちらが1点届ける
　 → 必ず消費される＝残高が生まれない

④ ★¥980 は「1日に1点ずつ」
　 その日に選ばなければ、消える。貯まらない
　 「月30点まで」とは書かない（★それは数量です）

⑤ ★取り上げない
　 解約しても、それまでに着せたものは残る
　 （既に決めた原則。ここで崩さない）
```

★③は、法律の側だけでなく、Deci ほか 1999 のメタ分析とも一致します。
**予期しない有形報酬 d = +0.01（内発的動機に影響しない）／予期される・従事に随伴 d = −0.40。**
「今月のよそおいが届いた」は、前者に近い形です。

## §4 残る穴と、私の判断

★正直に書きます。**¥980 には、経済的な穴があります。**

```
1か月だけ ¥980 を払う → 1日1点で最大30点 → 解約 → 服は残る
　　　　　　　　　　　　　　　　　　　　　　　　（取り上げない原則のため）

同じ30点を ¥580 の「月1点」で集めると、30か月・¥17,400
```

**それでも、このままでよいと考えます。** 理由は3つ。

```
① 30点は、217点のうちの14%。残り86%のために、また払う理由が残る
② その人は ¥980 を払っている。無料で持っていかれるわけではない
③ 穴を塞ぐ仕掛け（着られる期間の制限、返却、段階的な解放）は、
　 どれも「取り上げる」に近づきます。★この製品はそれを避けてきました
```

★もし塞ぎたくなったら、**制限を厳しくするのではなく、¥980 を年額だけにする**のがいちばん静かです（1か月だけの利用ができなくなる）。ただし買いにくくもなります。

## §5 ★確認しないと決められないこと（Codeへ）

```
① 記録でポイントは、1か月にどれだけ貯まるか
　 → ★これが分からないと ¥580 の「月1点」に意味があるか判断できません
　 　 無料で月に2〜3点交換できるなら、「月1点」は値打ちになりません

② ポイントは、いま現金で買えるか

③ いまの「よそおい放題」は、数で作られているか、期間で作られているか

④ 217点のうち、いま無料で交換できるのは何点か
```

★①の答え次第で、¥580 のよそおいを「月1点」から「月2点」に変えるか、
あるいは**よそおいを付けない**（¥580 は分析だけ、という潔い形）かが変わります。
