## ★市民オペラの稽古の形（台帳の作りに直結・CITTADINO の実例から）

```yaml
稽古: 全30回程度。前半 週1回（夜18:30〜21:00）→ 12月から 週2回（平日夜＋土日の昼と夜）
進み方: 顔合せ → 音楽稽古 → 合唱との合同稽古 → 粗通し → 通し → オケ合わせ → ゲネプロ → 本番
→ Woolsong の公演の機能に当てはめると:
  ・koen_sessions の kind に ★'orchestra'（オケ合わせ）・'dress'（ゲネプロ）を足すと、そのまま使える
  ・稽古が半年〜1年続くので、★出欠（koen_attendance）が本当に要る（誰が何回来たか）
  ・アンダースタディ（代役）の枠が要る → koen_slots の 'alt'（交代の枠）がそのまま使える
  ・参加費のある団体がある（キャスト免除・アンダースタディ45,000円）→ ★出演料（koen_fees）の逆（徴収）も要る
```
