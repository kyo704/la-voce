# 判断 ── 価格の確定

全 294 行 / 末尾は「売らないものの価格を決めないこと。決めた瞬間に、売る約束になります。」

作成 2026年9月4日 ／ 出発（10月19日）までに売るもの

---

## §0 結論

```
売る       個人プラン  ★月額 ¥580（税込）  ★これだけ

売らない   個人プラン 年額          ★帰国後（2027年7月〜）
           指導者プラン ¥3,980/¥9,800 ★価格は据え置いて凍結
           教室プラン ¥12,800         ★価格を決めません
           国際価格（T1/T2/T3）       ★Stripe に作りません
```

★「完全に決める」というご指示に、半分だけ従います。
**売るものの価格は完全に決めます。売らないものの価格は、決めません。**

理由は §1 です。

---

## §1 全部決めようとすると、決められません

いま価格が決まっていないものが1つあります。**教室プラン ¥12,800 です。**

```
・中身が薄い（★振替と日程の組み立てが無い）
・席数が2つの資料で食い違っている（20席一律 ／ 先生5＋生徒60）
・そして★教室は1つも実在しません（9月3日確定）
```

**これを決めようとすると、価格ではなく製品の話になります。** そして止まります。

★売らないものの価格を決めないでください。
決めた瞬間に、それは「その値段で売る」という約束になります。
中身が薄いまま値段だけ確定させるのが、いちばん危ない形です。

---

## §2 個人プラン ── ★月額 ¥580（税込）で確定

既存の価格設計仕様のままです。**変えません。** 理由は4つ。

```
① ★未成年に売れる価格です
   9月4日に「月額1,000円未満に保つ」と決めました。
   民法5条3項（小遣いの範囲）の中に収まります

② ★すでに仕様にあります
   決め直す作業が発生しません。45日しかありません

③ ★安いほうが、いま正しい
   実績がなく、作った人が9か月不在になり、
   「発見」が出るのは数か月先です。
   ★期待を低く保つほうが、返金も問い合わせも少なく済みます

④ ★1つしか作らなくてよい
   Stripe に価格オブジェクトを1つだけ作ります（§6）
```

### ★ただし「初期価格」と呼んでください

既存の原則に、こうあります。

```
契約時の価格を固定する（グランドファザリング）。
既存契約者を値上げしない。
```

これは良い原則ですが、**副作用があります。**

```
★¥580 で始めると、最初の利用者は★永久に ¥580 です。
```

だから、**最初からそう名づけてください。**

```
　　　¥580 ／ 月（税込）
　　　★はじめてくださった方の価格です。この価格は変わりません。
```

実装は要りません。**文言だけです。** そして3つ効きます。

```
・あとで値上げしても、角が立ちません
・早い人が得をする理由が、その場に書いてあります
・★¥580 が「安物」ではなく「初期の特典」に見えます
```

## §3 ★年額は、出発前に売りません

これが今回の新しい判断です。

```
年額 ¥5,800 は、価格として正しいです（月額10か月分）。
★ただし、10月19日の前には開けません。
```

### 理由

```
① ★12か月の提供義務を負います
   その9か月間、この製品は「作らない状態」に入ります。
   障害が起きたとき、直せる人がイタリアにいます

② ★返金の重さが10倍になります
   月額なら、返すのは最大 ¥580 です。
   年額なら ¥5,800 です。未成年からの申し出なら、なおさら

③ ★未成年には年額を出さないと決めました
   全員に月額だけを出せば、★分岐が1つ消えます。
   実装が軽くなります。45日には、これが効きます
```

★帰国後（2027年7月〜）に開けてください。そのとき改めて判断します。

## §4 指導者プラン・教室プラン ── 凍結

```
指導者 〜15人   ¥3,980/月   ★価格は据え置く。売らない
指導者 〜50人   ¥9,800/月   ★同じ
教室            未定         ★決めない
```

### なぜ指導者プランも売らないのか

G5 が降格したからです（作業指示・9月4日）。

```
G5 ＝ 教室の中で働けるようにするもの
そして★教室は0件です
```

**客がいない機能に、価格をつけて並べないでください。**
並べると「あるように見えて、無い」状態になります。9月3日に何度も見た形です。

★価格表そのものに載せないでください。**「準備中」とも書かないでください。**
書けば、それは予告になります。

### 席数の食い違いについて

```
20席一律 ／ 先生5＋生徒60
```

★これは、いま解かなくてよいです。**売らないものの中身だからです。**
帰国後、教室プランを売ると決めたときに、そこで決めます。

## §5 国際価格 ── Stripe に作りません

T1/T2/T3 の設計は良いものです。**捨てません。仕様として残します。**
ただし、**Stripe に価格オブジェクトを作らないでください。**

```
作れば、★経路が増えます
作れば、★台帳に載ります
作れば、★誰かが間違って使います
```

出発前に売るのは日本だけです。**日本円の1本だけを作ります。**

★イタリアにいる9か月のあいだも、増やさないでください。
「向こうで売れそうだから」と現地で開けると、
税・特商法・言語の3つが同時に来ます。

---

## §6 ★Stripe に作るものは、1つだけ

```
Product   Woolsong 個人プラン
Price     JPY 580 / month / recurring
          ★これ1つ
```

年額なし。ティアなし。試用期間なし（`trial_period_days` は9月3日に削除済み）。

**1つなら、間違えようがありません。**
9月3日に見つかった不具合の多くは「2つあること」から来ていました。

---

## §7 税込表示

```
★表示は「¥580（税込）」にしてください。
```

「¥580＋税」「¥580（税抜）」と書かないでください。

### 理由（正直に書きます）

```
総額表示義務（消費税法63条）は、
「事業者が消費者に対してあらかじめ価格を表示する場合」が対象です。

★免税事業者がこの義務の対象かどうかは、
　私が確かめた資料（国税庁・財務省）では★明確になりませんでした。
```

**どちらであっても、税込で書けば問題は起きません。**
逆に「＋税」と書くと、免税事業者が消費税を請求している形に見えます。
**片方だけ起きるなら、無害なほうが起きるように並べる**（9月3日の決まり）。

★消費税の課税/免税の判定そのものは、税理士に聞いてください。私は税の専門ではありません。

---

## §8 値上げの階段（★法律で区切られています）

将来の値上げは、自由ではありません。**未成年に売る限り、線があります。**

```
〜¥999      ★未成年に売れる（民法5条3項・小遣いの範囲に収まる余地）
¥1,000〜    ★保護者の同意（実物）の仕組みが要ります
```

つまり、

```
¥580 → ¥680 → ¥880 → ¥980   ★仕組みを変えずに上げられます
¥980 → ¥1,280                 ★ここで、作るものが増えます
```

★¥1,000 を超えるときは、価格の判断ではありません。**設計の判断です。**
このとき、9月4日の2本（「未成年に売ること」「同意を前に出すこと」）に戻ってください。

そして、値上げしても**既存契約者は上げません**（グランドファザリング）。
だから §2 の「はじめてくださった方の価格です」が効きます。

---

## §9 記録すること

未成年の記録（9月4日）と同じです。**全員について残してください。**

```
・契約したときの★表示していた価格
・契約したときの通貨
・価格の版（price_version など）
```

★「表示していた価格」を落とさないでください。
値上げのあと「私は¥580のはずだ」と言われたとき、これしか答えがありません。

---

## §10 決めなかったこと（一覧）

「完全に決めた」と言えないものを、隠さず並べます。

```
□ 教室プランの価格と席数     ★売らないので決めない
□ 個人プランの年額の開始時期  ★帰国後に判断
□ 国際価格の開始時期          ★帰国後に判断
□ 指導者プランの開始時期      ★教室が実在してから
□ Stripe Managed Payments     ★採るなら +3.5%。急ぎではない（9月4日）
□ 消費税の課税/免税の判定     ★税理士へ
```

★この6つを、いま決めないことが判断です。
**決めていないことを、決めたことにしないでください。**
