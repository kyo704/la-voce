2026年9月23日 ／ Opus ／ ★Sonnet・Code が 先に振り分けるための表

```yaml
使い方:

  ★決まらないものだけ Opus に回す（下の §6）
★この表で決めたときは、★「物差しの何番で決めた」と1行 残してください
```

## 1. ★守り（引き金・ポリシー）の判断

```yaml

  ★確かめる5つ: ①退会 ②親を消す ③連鎖の SET NULL ④保存期間の掃除 ⑤身元の固定×SET NULL
  ★例外なし: 退会・学校を閉じる・保存期間の掃除は ★必ず通す（規約と公表した約束のため）

  → ★掛け持ちの人で 決まらないので 直す。★呼ぶ側に渡させる
```

## 6b. ★この表の育て方（2026-09-23 追記・Sonnet の依頼）

```yaml
★新しい型の問題が出て、Opus が裁定を下したら、そのたびに
  「★これは 物差しに足す型か」を 判断します
足す条件（★3つとも 当てはまるときだけ）:
  ① ★中身を見なくても 同じ答えになる（個別の事情に よらない）
  ② ★2回以上 起きそう（1度きりの事故は 足さない）
  ③ ★答えが「やる／やらない」で書ける（「場合による」は 足さない）
足さないもの:
  ★1度きりの事故／★坂本さんが決めること／★調べないと決まらないもの
足したときに すること:
  ★番号を付けて（M28・M29…）／★きっかけになった裁定の番号を 添える
  → ★物差しが なぜそうなったかを 後から たどれるように
★物差しが増えすぎたら（M40 を超えたら）、★使われていない項目を 外します
  （増やすだけだと、★読まれなくなります）
```
