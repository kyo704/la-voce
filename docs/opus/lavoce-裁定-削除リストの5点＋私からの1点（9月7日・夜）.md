# 2. ★症状の連鎖の確率「14%」── ★★消します。★n≥10 でも消します

## 2-1 裁定

```
✕ ★★消してください。★★n が10を超えても、★出さないでください。
```

## 2-2 ★理由（★4つ）

```
① ★★これは ★将来についての主張です
　　「★翌日に張り感が出る ★確率は14%」
　　→ ★★予測です。★★予報を消したのに、★これを残すのは ★矛盾します。

② ★★3ゲートは、★これのために作られたものではありません
　　★3ゲートは「群間比較（Hedges' g）」と「相関（ρ）」の条件です。
　　★★条件付き確率は、★どちらでもありません。★通す条件が ★存在しません。

③ ★★14% だけでは、★意味がありません
　　★全体で何%なのか（★ベースレート）が無いと、★14%は高いのか低いのか分かりません。
　　→ ★★意味のない数字を、★意味があるように見せています。

④ ★★「7件中」を、★自分で書いています
　　→ ★条件を通っていないことを、★自分で表示しながら、★確率を出しています。
```

## 2-3 ★★軸を変えれば、★残せます

```
✕ 「違和感の翌日に、張り感が出る ★確率は14%（7件中）」

◯ ★「違和感を書いた日の翌日に、★張り感を書いた日　　3日
　　　違和感を書かなかった日の翌日に、張り感を書いた日　2日」

　★★両方の件数を、★必ず並べる（★片方だけだと、★主張になります）
　★★各群 10日 以上たまってから出す
　★★確率にしない。★割らない。★★件数のまま
```

★**これは ★③（過去の集計）の形です。★9月7日に決めた形と、同じです。**
