★私は、削除を ★いま はじめて知りました。★以下は、その前提で組み直したものです。

# 1. ★軽くなったもの（★利得。★これは大きいです）

## 1-1 弁護士への照会が、★1件まるごと消えます

```
照会事項7（★私が「最も重要」と書いたもの）
　・薬機法　プログラムの医療機器に該当するか
　・景表法　検証していない推定を出すことは優良誤認か
　・問い5　説明の書き分けは許されるか
　・別紙8　推定機能の説明文（案）

　★★機能が無いなら、★この照会は成り立ちません。★全部下ろせます。
```

★**照会事項が11件から10件に減り、★いちばん重いものが消えます。**
　★弁護士の費用も、回答までの日数も、**確実に減ります。**

★★**PDFを出し直します。**★照会事項7と別紙8を削除し、番号を振り直します。
　★**まだ弁護士に渡していないなら、★渡す前に差し替えてください。**

## 1-2 説明が、★1行で済むようになります

```
✕ これまで　アプリ全体では予報すると名乗り、機能ごとに予測しないと説明する
◯ これから　★「このアプリは、明日の声を予測しません」★これだけ
```

★**9月6日に私が「撤回してください」と言った一文が、★戻ってきました。**
　★そして、**こちらのほうが、はるかに説明が楽です。**

## 1-3 撤回した指標を、★内部で回さずに済みます

```
prevAcwr（急性慢性作業量比）は、9月6日に撤回しました。
　★予報の入力変数として、★内部では生きていました。

　→ ★機能ごと消えたなら、★式ごと消えます。
　→ ★★「撤回した指標が、内部で動いている」という状態が、なくなります。
```

★**これは、★あとから見つかると、いちばん痛い種類のものでした。**

# 3. ★穴の埋め方 ── ★予測なしで、同じ輪を作れます

★**「明日また開く理由」は、★予測でなくても作れます。**

## 3-1 ★過去の再訪（★9月7日の「楽しいものにする」§4 で書いたもの）

```
　「1年前の 今日、あなたは 本番でした。」
　「4月12日、あなたは『今日は出た』と 書いていました。」
　「去年の いま頃、いちばん よく歌っていたのは Caro mio ben でした。」
```

```
★これは ★予測ではありません。★数えているだけです。
★条件も要りません。★体について何も主張していません。
★★そして「毎日ちがう」「今日しか出ない」という点で、★予報と同じ働きをします。
```

★**予報より優れている点が、1つあります。**

```
予報　　　　★外れます。★外れると、信用が減ります。
過去の再訪　★★外れません。★本人が書いたことだからです。
```

## 3-2 ★羊の今日（★台詞集 §4-A）

```
「きょうは、まどの ところに ずっといました。」
　★毎日ちがう。★157本ある。★着せ替え・季節・部屋で掛け算になる。
```

★**台詞の供給源としては、★予報より、こちらのほうが大きいです。**
　★予報は5段階でしたが、★羊の今日は**内装120点 × 装い166点**で掛かります。

## 3-3 ★結論

```
★予報が消えても、★輪は作れます。
★★むしろ、★外れない輪になります。

　→ ★「楽しいものにする（9月7日）」の §9 の順番を、
　　 ★1つ繰り上げてください。
　　 　1 レパートリー
　　 　2 ★見つけたこと（過去の再訪）　←★ここが、予報の代わりになります
```
