# 第1部　③を有料にするか

## Q1｜これまでの原則と、具体的にどう矛盾するか

### ★結論：矛盾しません。私の前回の推し（無料）は、根拠が間違っていました

私は「確かめていないものを対価にしない」を理由に、無料を推しました。
**この理由は、③には当てはまりません。**

```
「確かめていないものを対価にしない」
　　→ ★これは 声の予報 のために作った決まりです。
　　　 予報は、当たるかどうか分からないものを売る話でした。

　　→ ③は ★数えているだけです。
　　　 「7回のうち3回」は、★確かめていないものではありません。★事実です。
```

```
「体についての主張でないものに条件をつけない」
　　→ ★これは「文章を出してよい条件」の話です。
　　　 ★お金の線とは、別の話でした。
　　　 ★私が2つを混ぜていました。
```

★**したがって、③を有料にしても、決まりは1つも破りません。**
　★前回の私の推しは、**根拠が弱いものでした。訂正します。**

### ★ただし、決まりではないところで、1つ問題があります

```
★★③は、しばしば「関係ありませんでした」を返す機能です。

　　「多かった週 7回 → 3回」
　　「ふだんの週 12回 → 4回」
　　→ ★ほとんど変わりません。★これがふつうの結果です。

　　★お金を取ったうえで「関係ありませんでした」と返すと、
　　　★「何に払ったのか」という話になります。
　　★無料なら「そうなんだ」で終わります。
```

★これは決まりの矛盾ではなく、**返金と評判の問題**です。

## Q2｜「無料版は物足りず、有料版で初めて面白くなる」になり得るか

### ★なりません。理由は1つだけで、決定的です

```
★★③は、出せるようになるまで ★5〜6か月かかります。
　　（両群それぞれ10週ぶん。★22週以上）
```

```
新しく登録した人が ¥580 を払う
　　→ ③を開く
　　→ 「あと 18週 ぶんたまると、出せるようになります」
```

★**買った当日に、何も出ません。**

そして9月6日に決めたことと、正面から衝突します。

```
決めたこと　★課金は、新規登録後の最初に開いたタイミングで勧める
　　　　　　（9月6日・課金の心理を論文から）

　→ ★その瞬間、③は空です。
　　 ★空のものを、いちばん高く見せる位置に置くことになります。
```

### ★そして、もっと大事なこと

```
★「物足りない無料版」は、有料版を売りません。
★「物足りない無料版」は、★アプリを消させます。
```

★無料版の仕事は「価値の**予告**」ではありません。**「価値の証明」**です。
　★証明されていないものに、人は払いません。

★①②だけの無料版は、**数字が並んでいるだけで意味がない画面**です。
　★それを見た人は、有料版を買わずに、消します。

## Q3｜③を無料にして得られる、収益以外の利点

```

　　③は「6か月つづける理由」です。

2  ★口コミ

5  ★大学・教室への営業（★9月15日）
```

## Q4｜★私の推し ── どちらでもなく、線の引き方を変えてください

### いまの案の、共通の弱点

```
案あ　③を無料　→ ★収益の決め手がない（運営者のご懸念のとおりです）
案い　③を有料　→ ★買った日に空。★売れない
```

★**「どの機能か」で線を引くから、こうなります。**

### ★案う｜「深さ」で線を引く

```
無料　★機能の種類は、ぜんぶ。★ただし、見えるのは 直近3か月ぶん
有料　★全期間　＋　書き出し
```

★これで、何が起きるか。

```
1日目　　★何も隠れていません。★全部さわれます。★価値が証明されます
3か月目　★まだ全部見えます
4か月目　★★「4か月前より前が、見えません」に、★自分のデータで ぶつかります
　　　　 → ★★これが、いちばん強い課金の瞬間です
　　　　 → ★他人のデータではなく、★自分が4か月書いたものだからです
6か月目　★③は、自然に有料側に入ります（★3か月では出せないため）
　　　　 → ★「③は有料です」と ★言わずに済みます
```

★**これは、業界の標準です。**

```
Hevy（App Store 4.9／91,000件）
　★無料版は、進捗グラフが ★直近3か月まで
　　→ ★種類を削らず、★深さだけを削っています
```

★**「取り上げない」にも触れません。**

```
★記録そのものは、消えません
★★全データの書き出しは、★無料のまま（★受診用サマリーも無料のまま）
　　→ ★見えないのは「画面での振り返り」だけです
```

### ★そして、本当に売るべきものは、これです

```
★★レパートリーの書き出し（9月7日・§3）
　　オーディション用のレパートリー表を、PDFで出す。

　　★1日目から動きます（★過去の曲を後から入れられます）
　　★声のプロが、★実際に手で作っているものです
　　★他のどのアプリにもありません
　　★科学の話が1つも要りません。★ただの一覧です
　　★★人は「入れるもの」ではなく「出てくるもの」に払います
```

### ★まとめ

```
無料　ぜんぶの機能／直近3か月／全データの書き出し／受診用サマリー
有料　★全期間　＋　レパートリーの書き出し　＋「前も、こうでした」
　　　（③は、深さの結果として ★自然に有料側に入ります）
```

★**¥580 が安く感じるのは、「機能が1つ増える」ときではありません。**
　★**「自分の全部が返ってくる」ときです。**

# 第2部　「このアプリは、明日の声を予測しません」

## ★整理は「対象外にする」ではありません。「主語を変える」です

### なぜ対象外にできないか（★もう一度だけ）

```
✕ 「★このアプリは、明日の声を予測しません」
　　　主語＝アプリ
　　　→ ★1つの画面が予報していれば、★この文は偽です
　　　→ ★見出しの下に置いても、★範囲は狭まりません
```

★これは、**予報の作りが良くなっても変わりません。**
　★的中率を出そうと、絵にしようと、**アプリは予報しています。**

### ★ですが、ご希望は叶います。主語を変えるだけです

```
◯ 「★本番モードは、明日の声を予測しません。
　　 書いたことを、本番の日を軸に、並べ直すだけです。」
```

```
　主語＝★機能
　→ ★これは真です。★本番モードは、実際に予測しません
　→ ★予報が別にあっても、★この文は偽になりません
　→ ★★つまり、ご希望どおり「本番モードの説明」として使えます
```

★**「アプリは〜しません」を「この機能は〜しません」に書き換えるだけです。**

## ★アプリ全体としては、こう名乗ってください

```
✕ このアプリは、明日の声を予測しません
◯ ★このアプリは、明日の声を予報します。
　　★そして、何回はずしたかを、隠さずに出します。
```

★**こちらのほうが、強い言葉です。そして、こちらは本当です。**

## ★書き換えの一覧（★全部直してください）

| 場所 | ✕ いまの文 | ◯ 直した文 |
|---|---|---|
| 説明サイト | このアプリは、明日の声を予測しません | このアプリは、明日の声を予報します。そして、何回はずしたかを、隠さずに出します |
| 本番モードの説明 | （同上） | 本番モードは、明日の声を予測しません。書いたことを、本番の日を軸に並べ直すだけです |
| 分析画面の上 | （同上） | ここに出るのは、あなたが書いたことの並びです。原因かどうかは分かりません |
| 規約・特商法 | （同上） | 本サービスは、医療行為、診断、治療または医学的助言を行うものではありません（★第7条4項のまま。★変えない） |

★**規約の第7条4項は、変えないでください。**
　★あれは「医療行為ではない」であって、「予測しない」ではありません。
　★予報を出しても、★あの条文は真のままです。

```
「アプリ全体としては予報すると名乗り、
　個別の機能については『この機能は予測しません』と説明する」

　★★私は、これを判断できません。
```
