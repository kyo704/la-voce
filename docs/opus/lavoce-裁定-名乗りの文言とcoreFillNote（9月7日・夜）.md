# 第1部　アプリの名乗り

## 1-1 まず、前提が変わったことを確認します

```
的中率を出さない　　→ ★私が「予報を残してよい」と言った根拠が、消えました。
　　　　　　　　　　　★的中率が、唯一の誠実さの装置でした。
```

★これは反対ではありません。**決定は決定として受け取ります。**
　ただ、**代わりの装置が要る**ということを、先に申し上げます。

★**残っている装置は、1つだけです。**

```
★「当たるかどうかを、確かめていない」と ★書くこと。

　　これは ★ぼかしではありません。★事実です。
　　★数字の代わりに、★検証していないという事実を置きます。
```

## 1-2 Code の案を、1文ずつ見ます

> このアプリは、声の良し悪しを判定しません。過去にご自身が書いたことを
> もとに、目安をお出しするだけです。当たらないこともあります。判断は
> ご自身でなさってください。

| 文 | 判定 |
|---|---|
| 「声の良し悪しを判定しません」 | **△ 危ない** |
| 「過去にご自身が書いたことをもとに」 | **◎ いちばん良い部分** |
| 「目安をお出しするだけです」 | ◯ 「目安」は良い語です |
| 「当たらないこともあります」 | **✕ ここが弱点** |
| 「判断はご自身でなさってください」 | ◯ ただし固い |

### ★「良し悪しを判定しません」が危ない理由

```
予報は「晴れ／くもり」を出します。
　★くもり は、★ほとんどの人が「悪い」と読みます。
　→ ★明日の声の良し悪しを、事実上 判定しています。

　→ ★この一文は、★嘘になりかねません。
　→ ★打消し表示が本体と矛盾している、という指摘を受ける形です。
```

★**言えるのは「今日の記録に点をつけない」までです。**明日については言えません。

### ★「当たらないこともあります」が弱点である理由

```
1　★「こともあります」は「ふだんは当たる」と読めます。
　　★私たちは、当たる割合を ★知りません。★半分以下かもしれません。
　　→ ★支えられない含みがあります。

2　★これは、まさに「打消し表示」です。
　　消費者庁の実態調査（2017〜2018）が効果を否定している型です。
　　★ぼかした否定は、効きません。
```

★**ぼかすほど弱くなります。★言い切ると強くなります。**

## 1-3 ★私の案（★これを推します）

```
このアプリは、声を測りません。
あなたが書いたことだけをもとに、明日の目安をお出しします。
当たるかどうかは、まだ確かめていません。これから確かめていきます。
決めるのは、あなたです。
```

### 1文ずつの根拠

```
「声を測りません」
　★事実です。★そして ★競合との差そのものです。
　　（Voish も Vocal Pitch Monitor も、★声を測ります。うちは測りません）
　★「測っていないのに分かるわけがない」を、★こちらから先に言っています。

「あなたが書いたことだけをもとに」
　★Code の案の、いちばん良いところ。★そのまま使います。
　★「だけ」が効いています。★医学も、測定も、他人のデータも入っていない、と言えています。

「当たるかどうかは、まだ確かめていません。これから確かめていきます。」
　★★これが、的中率の代わりです。
　★ぼかしではなく、★確かめられる事実です。
　★「まだ」「これから」が、★弱点を約束に変えています。
　★★これを書けるアプリは、★調べた34本に1本もありません。

「決めるのは、あなたです。」
　★「判断はご自身でなさってください」より短く、強い。
　★うちの決まり（判断を取り上げない）そのものです。
```

### ★短い版（帯・カード・SNS用）

```
声は測りません。あなたが書いたことだけから、明日の目安を出します。
```

### ★もっと短い版（1行）

```
測らないアプリです。
```

# 第2部　coreFillNote

## 2-1 ★私は、元の文言を見ていません。判断できません

★**元の文字列と、出る条件を、そのまま貼ってください。**
　★私が想像で書き起こすと、★また同じ間違い（本番モードのとき）をします。

★ただし、**判断の基準は、いま出せます。**下の2つで、ご自身で判定できます。

## 2-2 ★判定の基準

```
① 追いかけているか
　　◯ 開いた人にだけ、その場で見せる　　　→ ★表示です。残してよい
　　✕ 通知で送る／バッジを付ける　　　　　→ ★催促です。消してください

② 遅れている、という含みがあるか
　　✕ 「まだ」　　　　→ 遅れている含み
　　✕ 「3項目が未記入です」→ ★数を出すと、達成率になります
　　✕ 「あと少しで完成です」→ ★完成という概念を作らない
　　◯ ★項目が畳まれて並んでいるだけ　　　→ ★これが、いちばん良い形です
```

## 2-3 ★私の裁定 ── ★おそらく、復活させなくて済みます

```
9月6日の記録画面の設計（5画面のUI仕様 §4-2）が、
★すでに同じ仕事をしています。

　　＋ 声のこと　　　　選ぶ
　　＋ からだのこと　　選ぶ
　　＋ 眠り　　　　　　6時間20分
　　＋ ノート　　　　　書く

★★「＋」が付いているものが、★まだ触っていない項目です。
　★それ自体が、未記入の表示になっています。
　★別に文章を出すと、★同じことを2回言うことになります。
```

★**そして、消えた枠（ホームの目立つ位置）に戻さないでください。**

```
✕ ホームの目立つ枠　→ ★毎日「まだ書いていない」を見せることになります
◯ 記録画面の中　　　→ ★書きに来た人にだけ、その場で見えます
```

## 2-4 ★それでも要る場合

★中核5項目（朝2・夜3）という別の概念があるので、
　★coreFillNote がそれを指していたなら、話が変わります。

```
★その場合でも、置き場所は ★記録画面の中です。
★文言は「夜の項目が、まだ開いていません」ではなく、
　★ただ ★夜の項目を、畳まれた状態で ★下に並べておくだけにしてください。
```

# ★まとめ

```
1  名乗りは、1-3 の4行。★「予測しません」は全部から外す
2  「当たるかどうかは、まだ確かめていません」が ★的中率の代わり
3  coreFillNote は、★元の文字列と条件を見せてください。
　　★ただし、記録画面の「＋」で足りている可能性が高いです
4  ★ホームの目立つ枠には、★戻さないでください
```
