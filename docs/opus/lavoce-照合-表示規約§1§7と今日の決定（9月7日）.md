# 2. ★衝突2 ── 声の予報の絵に、色を付けようとしていました

```
既存 §1-4　✗ 赤・黄・緑の信号色（★色そのものが判定になる）
　　　　　　✗ 値の大小で色を変える
　　　　　　✗ 上の6色以外の色をデータに使う
既存 §7-3　赤・黄・緑の信号色を使わない
```

★**天気の絵は、判定です。** 晴れを黄色、くもりを灰色にした瞬間、
　★文章を出していなくても、**色が言っています。**（§1-4 の「3ゲートを迂回する」がこれです）

## ★裁定

```
★予報の絵は、★1色で描いてください。--ink-2（#6D5D50）。
　★晴れ・はれときどきくもり・くもり を、★形だけで区別する（§1-2 の考え方そのもの）
　★色は 1つのまま。★大きさと形で区別する

★的中率の数字も、★色を変えない。
　★30%でも赤くしない。★61%でも緑にしない。★--ink（#261913）のまま
```

★これは §1-2「色を増やさず、形で区別する」を、そのまま予報に当てただけです。

# 3. ★衝突3 ── 「自分の90日平均」の線の引き方

```

```

**抵触しません。** 90日平均は、文献値でも目標値でもなく、**その人自身の値**です。

★**ただし、引き方を間違えると「目標線」に見えます。**

## ★裁定（★これで引いてください）

```
✕ 破線　　　　★§7-6 が「目標カロリーの破線」を名指ししています。★破線は目標の合図です
✕ 点線　　　　★同じ理由で、紛らわしい
✕ 「目標」「基準」「平均以上」という語

◯ ★1px の薄い実線（--grid #E5DDC7）
◯ ★線の右端に、小さくラベル：「あなたのふだん　6時間45分」
◯ ★線の上下で、色や塗りを変えない
```
