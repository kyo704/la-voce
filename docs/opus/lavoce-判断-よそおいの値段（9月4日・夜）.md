# 判断 ── よそおいの値段

全 179 行 / 末尾は「¥580 を、この店の単位にすること。数字を1つしか覚えなくてよくなります。」

作成 2026年9月4日 夜 ／ 「一番妥当な値段は」への回答

---

## §0 結論

```
★¥580（税込）／ 1セット5点 ／ 季節ごとに1セット
```

★**月額とまったく同じ額**にしてください。

```
　　　よそおい 1セット ＝ ★ひと月ぶん
```

---

## §1 いちばん大きな理由 ── ★¥980 は、順序を逆にします

```
本番モード（プロの道具）  ★¥580 ／ 月
羊の服（飾り）            ★¥980 ／ 1回
```

★**飾りのほうが、道具より高くなります。**

この製品は「声で仕事をする人の道具」として売ると決めました。
その道具がひと月 ¥580 で、羊の服が ¥980 だと、
**値段が「こちらのほうが価値がある」と言ってしまいます。**

★値段は、いちばん短い説明文です。**言わせたくないことを、言わせないでください。**

---

## §2 二番目の理由 ── ★保護者が覚える数字が、1つで済みます

未成年の同意の文（9月4日）は、こうなります。

```
（¥980 のとき）
　・毎月 580円の、記録の機能
　・季節ごとに1回まで、980円までの装い
　　（1年で、いちばん多くて 10,880円）

（★¥580 のとき）
　・毎月 580円の、記録の機能
　・季節ごとに1回まで、★同じく580円までの装い
　　（1年で、いちばん多くて ★9,280円）
```

★**数字が1つになります。**
　保護者が確かめるのは「580円」だけ。**一度で分かります。**

★民法5条3項は「目的を定めて処分を許した財産」です。
　**目的がはっきりしているほど強い**条文です。数字が1つのほうが、はっきりします。

---

## §3 三番目の理由 ── ★迷わせない値段

```
〜¥500      ★考えずに買う
¥500〜1,000 ★少し考える
¥1,000〜    ★決めごとになる
```

★初めてお金を払う人に、**決めごとをさせないでください。**

そして、この人は**まだ何も払っていない人**です。
最初の支払いは、金額ではなく**踏み出すこと**が壁です。

★「ひと月ぶんと同じ」は、その壁をいちばん低くする言い方です。

---

## §4 ★値上げは、あとから自由にできます

ここが、月額との決定的な違いです。

```
月額 ¥580   ★グランドファザリングで、その人は永久に ¥580
　　　　　　 ★決める窓は、最初の1件を売るまで

装い ¥580   ★都度の買い物です。次から値段を変えてよい
　　　　　　 ★いつでも決め直せます
```

★**月額は取り返しがつきません。装いは取り返しがつきます。**

だから、

```
月額   ★慎重に、高めに考える（それでも ¥580 に据え置くと決めました）
装い   ★安く始めてよい。売れたら上げる
```

★安く始めることの損は、**次の季節に取り戻せます。**

## §5 いくら取り逃がすか（正直に）

```
¥980 × 年4回 ＝ ¥3,920／人・年
¥580 × 年4回 ＝ ¥2,320／人・年
　　　　　　　　　　差 ★¥1,600／人・年
```

★100人なら、年 ¥160,000 の差です。**小さくありません。**

★ただし、これは**買う人の数が同じなら**の話です。

```
¥580 で ★4人に1人が買う   → ¥580／人・年
¥980 で ★6人に1人が買う   → ¥653／人・年
```

★**この程度の差で、ひっくり返ります。**
　そして、実績のない製品の飾りに ¥980 を出す人の割合を、私は知りません。

★**分からないほうに賭けないでください。** 分かっているのは §1〜§3 です。

## §6 中身

```
1セット ＝ ★5点

　　窓の外の景色  1
　　壁            1
　　床            1
　　服            2
```

★第4便（9月4日）で、景色7・壁5・床4 を納品しました。**もう組めます。**
　足りないのは服だけです（月ごと3点×12か月＝36点は、これから描きます）。

★**選ぶのは購入の前。買ったら、その瞬間に5点すべて渡す。**
　「あとで選ぶ」を残すと、それは残高になり、資金決済法が乗ります（9月4日）。

---

## §7 やらないこと

```
✕ ★大小2種類のセット（¥480 と ¥980 など）
　　→ 選ぶことが★決めごとになります。1種類にしてください
✕ 1点ずつの単品売り（端数が出て、ポイントが欲しくなります）
✕ 期間限定・セール（★急がせない。来年また会えます）
✕ 18歳以上だけの大きいセット（★段を作らない）
```

★**1つの値段、1つのセット。** これが答えです。

## §8 まとめ

```
値段     ★¥580（税込）
中身     ★1セット5点（景色1・壁1・床1・服2）
頻度     ★季節ごとに1セット（年4回）
未成年   ★季節ごとに1回まで。3Dセキュアを掛ける
年間     ★月額 ¥6,960 ＋ 装い ¥2,320 ＝ 最大 ¥9,280
```

★もし ¥980 にすると決められるなら、それでも構いません。
　**ただし §1 だけは、目を開けて越えてください。**
　「飾りが道具より高い」ことを、承知の上で選ぶのなら、それは判断です。
