# 判断：週次のふりかえりは、売ってよいか

全 175 行 / 末尾は「売るものは変えません。**壁の置き場所を変えるだけです。**」

9月5日・夜／坂本 響
前提：`権利と課金の線引き.md`「絶対にゲートしない。例外はありません」／9月5日の裁定「8日より前を見ること（週・月・年のふりかえり）は有料」

---

## 0. 結論

**二つの規則は、ぶつかっていません。私が一つの言葉を二つの意味で使ってしまっただけです。**

- 「ふりかえりを見る」には、**まったく別の二つ**が入っています
  - ① **自分が書いたものを、もう一度見る**（9月1日の声の調子はどうだったか）
  - ② **まとめて意味を出す**（先週の平均、傾向、前の週との差、本番からの逆算）
- ①は**記録そのもの**。②は**Woolsongの仕事**

なので線はここに引きます。

> **記録そのものは、いつでも、全部、無料で見られて、持ち出せる。**
> **まとめて意味を出すことを、売る。**

9月5日の裁定は**②だけに掛かる**ものとして読み替えます。①を有料にするのは、`権利と課金の線引き.md` に正面から触れるので、しません。

---

## 1. なぜ切り分けが要るのか

「8日より前は有料」を字義どおりに実装すると、こうなります。

> 3か月記録した人が、耳鼻咽喉科で「いつから声がおかしいですか」と聞かれる。
> アプリを開く。**8月の記録が見えない。**

これは便利さの問題ではありません。**受診の役に立つはずのものが、役に立たなくなる。** 既に決めた規則「安全に関わるものは無料」に触れます。

一方で、こちらは安全とは関係ありません。

> 先月の平均が今月より0.4高い、直近3週間で下がり続けている、
> 本番の10日前としては声の使用量が多い

これは**私たちが計算して意味を付けたもの**で、記録そのものではありません。売ってよい。

## 2. 三つの案

| | 無料の範囲 | 利益 | ユーザーの気持ち | 私の見立て |
|---|---|---|---|---|
| **A**（今の裁定のまま） | 今日と直近7日だけ。8日より前は生の記録も見えない | 最大 | **最悪**。「自分の記録を人質に取られた」 | 取らない |
| **B**（推奨） | 生の記録は**全期間**（1日ずつ・書き出し）。まとめは7日まで | Aとほぼ同じ | 不満の芽が消える | **これ** |
| **C** | 週のまとめまで無料。売るのは本番モードと今日の目安だけ | 小さい | 良い | 月580円の理由が薄くなる |

### Bの利益がAとほぼ同じだと考える理由

**① 月580円を払う理由は、ふりかえりではありません。**
歌い手が金を出すのは**「本番から逆算して、今日どうするか」**です。過去の平均ではありません。ふりかえりは二番目の理由です。ここを緩めても、主な売り物は無傷です。

**② 1日ずつ辿るのは、実際にはやりません。**
3か月分を1日ずつ開いて自分で平均を出す人はいません。**壁を作らなくても、まとめが欲しい人は買います。** Bが売るのは「手間の差」であって、「意地悪な壁」ではない。これは同じ売上を、悪い感じを出さずに取る方法です。

**③ 広め方が口コミしかない以上、これは事故のもとです。**
目標は先生8人でした。**先生が1人「自分の記録が見られなくなる」と言えば、配布は止まります。** 8人しかいない経路で、この評判は致命的です。取れる売上より、失う経路の方が大きい。

## 3. Bの中身（確定案）

### 無料

| | |
|---|---|
| 今日の記録・症状ゲート・受診導線 | いつでも |
| **直近7日の数字とグラフ** | いつでも |
| **カレンダーから、過去のどの日でも開く**（1日ずつ・生の値） | **全期間** |
| **書き出し（CSV）** | **全期間・無条件** |
| 羊とおうち、装いの表示 | いつでも |

### 有料（月580円 / 年5,800円）

| | |
|---|---|
| 週・月・年の**まとめ**（平均・最大最小・前の期間との差） | |
| **傾向**（下がり続けている、など） | |
| 複数の指標を**重ねて**見る | |
| 期間どうしを**並べて比べる** | |
| 本番からの逆算・今日の目安 | |
| 本番モード | |

**判定の一行**：
> その画面が**私が計算した数**を見せているなら有料。
> **本人が書いた数**をそのまま見せているだけなら無料。

## 4. 画面と文言

### カレンダー（無料）

過去のどの月にも移動できる。日を押すと、その日の記録が出る。
**印を付けない。灰色にしない。鍵のしるしを置かない。**（既に決めた規則「「まだ」を表示しない」）

### 週のまとめ（無料の範囲＝直近7日）

```
直近7日
  声の調子  平均 3.4 ／ いちばん低い日 2（9月2日）
  睡眠     平均 6時間20分
```

### それより前の週（有料）

無料の人には、**同じ場所に**こう出します。

```
9月1日〜9月7日
  ［この週の記録を1日ずつ見る］          ← いつでも押せる

  まとめて見ると、平均や前の週との差が出せます
  ［まとめを使う］
```

- 「見られません」「有料です」「ロック」は**書かない**（禁止形の規則）
- **押せるボタンを先に置く。** 記録は必ず開ける、という事実を先に見せる
- 誘いは1行だけ。1画面に1回まで

### 書き出し

設定のいちばん見えるところに置き、**課金の状態を一切見ない。**
これが「人質にしていない」ことの、いちばん強い証拠になります。

## 5. 規則の書き換え（これで再発しません）

二つの文を、一つにまとめます。

> **記録は取り上げない。見方だけを売る。**
> **本人が書いた数をそのまま見せる画面は、期間を問わず無料。**
> **こちらが計算した数を見せる画面は、売ってよい。**

`権利と課金の線引き.md` の「絶対にゲートしない。例外はありません」は、**「本人が書いたもの」に掛かる**と注記を足してください。9月5日の裁定の「8日より前を見ること」は、**「まとめて見ること」**に書き換えます。

写した先：`権利と課金の線引き.md`／`lavoce-判断-無料の線を引き直す（9月5日）.md`／`lavoce-価格と課金の正（9月4日・確定）.md`

## 6. 見張り（Code に出す）

画面で確かめただけのものは門ではありません。**テストで留めてください。**

1. 無課金の利用者が、**1年前の日**をカレンダーから開ける
2. 無課金の利用者が、**全期間のCSV**を書き出せる
3. 無課金の利用者が、**先月のまとめ**を求めると、まとめの数は返らない（記録一覧は返る）
4. 課金が切れたあと、**過去の記録は1件も消えない／見えなくならない**
5. 3〜5の画面に、禁止形（「見られません」「できません」）が1つも出ない

4は「一度あげたものを取り上げない」の見張りです。**解約した瞬間に過去が消える**のが、この手のアプリで最も嫌われる事故なので、ここは必ず自動で見張ってください。

## 7. 決めてほしいこと（2つ）

1. **案Bでよいか。** よければ、上の規則の1文で二つの資料を書き換えます
2. **カレンダーの過去を、どこまで遡れるようにするか。** 私は**無制限**を推します。制限を付けると「何日まで」を説明する必要が生まれ、そこがまた不満の種になります。データ量は1日1行なので、10年でも3,650行です

## 8. 私の見立て

Aは、短期の売上ではBに勝ちません。**ふりかえりを見せないことで増える課金は、たぶんほとんどありません。** 増えるのは、解約と、悪い口コミです。

そして坂本さんの場合、**配布経路が先生8人しかない**。ここで「自分のデータが見られない」という話が1つ出れば、他の全部の設計が良くても止まります。

売るものは変えません。**壁の置き場所を変えるだけです。**
