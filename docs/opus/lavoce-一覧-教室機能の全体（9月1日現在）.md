# 教室機能の全体 ── 9月1日現在

作成 2026年9月1日 ／ 出典：教室プラン仕様・指導者プラン実装仕様・教室運営の範囲・教師間コミュニケーション仕様＋本日の判断

---

## 0. ★いちばん大事な変化

**今日、教室機能から「健康」が全部抜けました。**

```
これまで   先生が生徒の記録を見る。要注意の生徒が一覧に出る。記録にコメントを書く
今日から   ★先生は、生徒の記録の中身を1件も見られません
```

**残ったのは、運営です。誰がいて、いつレッスンがあって、どう連絡するか。**
**★この形のほうが、大学にも教室にも売りやすくなりました（責任を負わずに済むため）。**

---

## 1. 器 ── 誰がいるのか

```
Organization（教室・学科・養成所）
   ├── Membership   その教室の★先生や事務
   ├── Enrollment   その教室の★生徒
   └── Assignment   ★どの生徒を、どの先生が担当するか
```

**3つとも多対多です。**

```
・1人の生徒が、同じ教室の複数の先生につく（声楽＋コレペティ＋演技）
・1人の生徒が、複数の教室に所属する（音大＋個人レッスン＋養成所）
・1人の先生が、複数の教室に所属する（掛け持ちの講師）
```

### 1-1｜4つの役割

| 役割 | できること |
|---|---|
| **owner** | 契約者。お金・席の増減・教室を閉じること |
| **admin** | 管理を任された先生。お金以外は owner と同じ |
| **teacher** | 自分の担当生徒だけ。運営の面は見えない |
| **staff** | **事務。日程と出欠だけ。★健康に関するものは一切見えない** |

**★staff は必ず作ってください。** 事務の人を「先生」として登録されると、
分けたはずの権限が意味を失います。

**★個人の先生は「1人だけの教室」です。** 別の仕組みにしません。

## 2. 日程 ── レッスン

```
Lesson ＝ 教室 × 先生 × 生徒 × 時刻
　場所／オンラインか／繰り返し（毎週）／状態（予定・実施・中止・無断欠席）
　teacherNote  ★先生専用。生徒に見せない
```

### 2-1｜誰に見えるか

| 見る人 | 見える範囲 |
|---|---|
| 生徒 | **自分のレッスン全部**（教室をまたいで1つのカレンダーに） |
| 担当の先生 | 自分が担当するレッスン |
| 管理者 | その教室のレッスン全部 |
| staff | その教室のレッスン全部（★名前と時間だけ） |

### 2-2｜重なりの検出

```
同じ生徒の時間が重なった   → 生徒と、両方の先生に
同じ先生の時間が重なった   → その先生と、管理者に
1日に4件を超えた           → ★生徒本人にだけ、そっと

★教えるだけです。自動で動かしません。予約を断りません。
```

### 2-3｜管理者の週表示

先生を横に並べた表で、その日の全員の枠が見えます。重なりに印が付きます。

### 2-4｜希望申告（★まだ作っていません）

```
生徒が出す   希望回数／曜日×時間帯の ◎△×／絶対NGの日
先生が見る   重なりのヒートマップ。ドラッグで配置

★これが「年度初めの組み立て」を助ける機能です。第3優先。
```

### 2-5｜振替（★まだ作っていません）

```
教室運営の本丸とされています。★欠席の理由は聞きません。
教室ごとにルールを設定（何日前まで／月に何回まで）。
```

### 2-6｜カレンダーへの書き出し

```
A  .ics を1回ダウンロード      保険として必ず用意
B  ★ICS購読フィード（既定）    一度登録すれば自動で追随。Google認証も不要

★片方向だけです。相手のカレンダーに書き込みません。
```

## 3. 連絡

### 3-1｜門下の連絡板（8月31日に設計）

```
門下（先生と、その生徒たち）だけが読み書きできる板。
★教室の臨時の変更・緊急連絡のためのものです。

✗ 欠席の連絡を、ここに書かせない
✗ 予定（発表会の日程など）を、ここに書かせない → §4 を使う
```

### 3-2｜先生どうしの連絡（教師間コミュニケーション仕様）

```
教室プラン以上。★指導者プラン（1人）には付けません。
定型連絡とスタンプで作ります。★自由記述のチャットは作りません。
```

### 3-3｜★アプリ内メッセージ・DM は作りません

**教室になっても、大学になっても、作りません。**

## 4. 予定・行事（★今日決めたもの）

```
org_events                組織が出す予定（実技試験・発表会・合わせ・休講）
org_event_participants    ★「出ます」の印だけ。中身を持たない

　組織が1件入れる → 対象の人の予定表に出る → ★1タップで印を付ける
　当日、記録画面が活動の初期値を提案する。★確定するのは本人
　取り下げ・変更は、静かに1行。★勝手に消さない・勝手に書き換えない
```

**★複製しません。だから、ずれません。**

## 7. ★もう無いもの（今日、消えました）

```
✗ 先生が生徒の記録の中身を見る（shareScope）
　　→ 常時アクセスを外しました。★生徒がその都度、書き出して渡します

✗ 生徒一覧の「要注意」表示
　　→ 記録が見えないので、判定する材料がありません

✗ 記録へのコメント（entry_comments）
　　→ テーブルごと削除します。9月15日より前に

✗ 「先生に送る」ボタン
　　→ ★作りません。作ると常時アクセスが復活します
```

**★営業資料に「先生が生徒の状態を見られます」と書いてあったら、直してください。**
