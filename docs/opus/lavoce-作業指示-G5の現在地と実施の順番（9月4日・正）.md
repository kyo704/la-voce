## §6 持って発つもの / 置いていくもの

10月19日以降、この製品は**作らない状態**に入ります。基準はこれだけです。

```
持って発つ  ★無いと売れないもの ／ 無いと記録が壊れるもの
置いていく  ★無くても売れるもの
```

当てはめます。

```
持って発つ
  第1段 ①〜⑥        売れない
  第3段 ⑨〜⑫        売るものそのもの
  第5段 ⑯⑰          記録が壊れる／安い

置いていく（できなくてよい）
  ⑬⑭⑮              効くが、無くても売れる
  ⑱⑲⑳              ★客がまだいない
```

★⑱⑲⑳を置いていくのは、つらい判断ではありません。
**設計は済んでいます。** 判断書が3本あります。戻ってきてから、そのとおり作れば済みます。

**設計を持って発てば、実装は待てます。**

## §9 変わった決まり（G5に効くもの）

9月1日以降に増えた決まりのうち、G5 の実装中に効くものだけ。

```
・USING に auth.uid() が出てこないポリシーは、全員に開いている
・OR で繋いだとき、いちばん緩い枝が、そのポリシーの実力
・WITH CHECK では不変性を守れない（USING 側か、トリガーで）
・WITH CHECK を省くと、USING が WITH CHECK として再利用される
・本番に手で当てない。当てたら、その日のうちにリポジトリへ写す
・アプリの中だけの出来事は伝えない。外でも起きることは伝えてよい
・「まだ」を表示しない。増える方向にだけ動かす
・確かめられないことを、表示しない
・約束を書いたら、それを守っている仕組みを、その場で隣に書く
```
