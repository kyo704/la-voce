## 1 教室を 持たない人には 出さないもの

★理由：★空の 節を 出さない。★押せない 札を 出さない。

| 何 | どこ | 教室なしのとき |
|---|---|---|
| きょうの よてい | きょう | ★節ごと 出さない |
| 近い 行事 | きょう | ★節ごと 出さない |
| 先生からの 連絡 | ノート | ★★タブごと 出さない |
| 伴奏者・歌い手を さがす | ノート | ★節ごと 出さない |
| 公開範囲「同じ学校の 在籍者だけ」 | ポートフォリオ | ★選択肢ごと 出さない |

### ★残すもの ── 1つだけ

```
もっと → ★通っている ところ
```

★★全部 隠すと、★教室に 入る 道が 消えます。

★ここから「招かれている」「合言葉で 入る」へ 行けます。
★2026年10月、学生が 入る ★唯一の 道です。

★見本の 注記どおり：

```
「こちらから 教室を さがすことは できません」
「入り方は 2つだけ ── 招かれる か、合言葉」
```

## 3 ★お知らせ ── 3通り

```

　　★出欠は 集めません。知らせるだけです。

　　★読んだかどうかは、記録しません。

　　★募集に 応募する 形です。

　　★学校からは 1つも 見えません。
　　★健康の 記録は、あなたと こちらだけの ものです。


　　　　　［ 見てみる ］　　［ あとで ］
```

★★最後の 節が いちばん 大事です。
★★**学校に 何が 見えないか**を、★入った 瞬間に 伝えます。

★これは 営業資料で 大学に 約束していることと 同じ 言葉です。
★★学生 本人にも、同じ 言葉で 伝わります。

### 3-2 ★2つ目 以降の 教室に 入ったとき（★短い）

```

きょう と ノート に、△△音楽院 の 分も 出ます。

```

★★長い 説明は ★はじめての 1回だけ。★繰り返しません。

### 3-3 ★教室を やめたとき ── ★2通りに 分ける

★★どちらかは、★★残りの 教室の 数で 決まります。

**★まだ 他に 教室が ある**

```

★△△音楽院 の 予定・行事・連絡は、そのまま 出ます。

★消えるもの
　　○○音楽大学 の 予定・行事・門下の 連絡
　　この教室から、あなたが 見えなくなります

★残るもの
　　これまでの 出欠と、連絡に 書いたことは、
　　教室の 記録として 残ります（運営の 義務です）

　　　　　　　　［ わかりました ］
```

★★1行目の 直後に ★残っている 教室を 出すのが 要点です。
★★**何も 失っていない**ことが、★最初に 分かります。

**★最後の 1つを やめた**

```
○○音楽大学 を やめました。

きょう と ノート から、★教室の 節が 消えます。

★消えないもの
　　あなたの 記録・ノート・レパートリー・ひつじ
　　1つも 消えません

★また 入れます
　　招かれるか、合言葉で。
　　もっと → 通っている ところ

　　　　　　　　［ わかりました ］
```

★★「また 入れます」を 足しました。
★★節が 消えると、★戻れないように 見えます。

## 4 ★「凍結」は しません

★★坂本さんの ご提案（★やめた 学校の 機能のみ 凍結）を、★形を 変えて 採ります。

### ★理由

```
きょうの よてい  ★通っている 全教室が ★1つの 予定表に 出る
近い 行事        ★同上
先生からの 連絡  ★教室ごとに 分かれる
さがす          ★教室ごと
```

★★どれも ★複数の 教室が 混ざる 作りです。

★★節を 凍結すると、★★**残っている 教室の 予定まで 見えなくなります。**

### ★正しい 動き

| 状態 | 節 | 中身 |
|---|---|---|
| 教室 2つ → 1つ やめた | ★出たまま | ★★やめた 学校の 分だけ 消える |
| 教室 1つ → やめた | ★節ごと 消える | — |

★★「凍結」では なく ★「その 学校の 分だけ 消える」です。

## 5 ★お知らせの 決まり

```
○ ★画面の 中で 1回だけ
○ ★読み終われば 消える
○ ★二度と 出ない
✕ ★お知らせの 一覧に 残さない
✕ ★未読の 印を 付けない
```

★★理由：★★一覧に 溜めると、★次の 大事な 知らせが 弱くなります。

