## 1. 個人（販売開始で出すもの）

```yaml
記録:
  きょうの記録（30秒）── 点数を出さない・信号色を使わない
  毎日 聞いてほしいこと（最大5つ）── ★「いつ書くか」を自分で決める（実装意図・d=0.65）
  ノート（自由記述）／本番の記録／レッスンの記録
  声の記録（録音）── 本人だけ
ふりかえる:
  通算の記録日数（★連続ではない。途切れても無傷）
  月ごとのふりかえり／本番の前後の比べ
  くらべる ── 同じ日付の軸に並べる（★本番・レッスンの日の帯つき）
しらべる（有料）:
  声が出なかった日を集めて、★その前日に何が多かったかを比べられる（原因を探る手がかり）
  ★n≥10・効果量・多重比較補正を満たすときだけ出す／「〜と一緒に出ています」の1文のみ
  ★因果を主張しない（「原因はこれです」とは言わない）
  期間の切り替え（窓であって比較ではない・一度に1つ）
受診用のまとめ:
  ★1回の記録でも 医師に見せられる形が出る（初日から価値が出る）
羊（ひつじ）:
  記録すると育つ／よそおい244点＋毎月16点／★解約しても手元に残る
  留守中に小さな出来事が起きている（★放置を罰しない）
そのほか:
  お仕事を選ぶ（画面のことばが変わる：歌・声優・アナウンサー・ポップス ほか）
  書き出し（CSV・JSON）★無料／同意の取り消し／退会（★人を介さない）
  保護者の画面（18歳未満は保護者のアカウントの下でのみ）
```

## 2. 教室・学校（2027年4月から本格。いまは導入期間）

```yaml
名簿・組織:
  名簿の一括読み込み（CSV）／組織の階層（学部・学科・学年）／在籍の状態
  役職 ★10役職・できこと制（札）──「自分が持っていないことは人に渡せない」
  役職を変えた記録（★誰が変えたかが残る）
日程:
  レッスンの日程・空きコマ・重なりの検出／時間割／自分のコマ
  ★レッスン割 ── 回・希望（◎△×）・地図・配る
行事・連絡:
  行事の登録／お知らせ（★宛先を選べる）／既読の記録
請求:
  人数に応じた請求／請求書・領収書（★再発行の印字）／宛名の変更
門下:
  門下の一覧／門下に招く／★門下を開いた記録（3年保存）
採点（★切ってある）:
  評価の型・項目／点を入れる／講評（90日）／★順位を返さない
  審査員を足す／審査員相互（★締切前は不可）
★守り: 先生・学校・運営は 体調の記録に届かない（台帳の層で遮断）
```

## 3. 公演（★切ってある。台帳はできている）

```yaml
作る:
  公演を作る（★11種類：オペラ・合唱・演劇・管弦楽・吹奏楽・室内楽・ガラ・ダンス・
    ★収録・★発表会・そのほか）
  ★作品の雛形から下書き（559作品・2,995場面）── 10分で公演が立つ
  前の公演から ★枠だけ写す（人・稽古・期限は写さない）
香盤表:
  行＝場面／楽章、列＝枠、マス＝人
  枠の種類：歌手・★オーケストラ・★伴奏（コレペティ）・スタッフ
  ダブルキャスト（A・B）／何人かの枠（合唱・団体）／★代役（アンダースタディ）
  ★編成表（ピットに誰が要るか。場面ごとの例外も持つ）
稽古:
  稽古を組む（★顔合せ・音楽稽古・合唱合同・粗通し・オケ合わせ・ゲネプロ・本番）
  呼び出し（★分刻み）・解散の時刻／持ち物／場所
  出欠（★率は出さない。回数だけ）／変わったものの一覧
本番:
  当日の進行（入り・仕込み・リハ・開場・開演・終演・バラシ）
  楽屋の割り当て／控室（保護者の方も）／出演料・★参加費の徴収
  ★子どもの出演（保護者のアカウントの下・緊急の連絡先は運営だけ・20時以降の警告）
そのほか:
  ★自分の予定（出演者には自分の呼び出しだけ）
  ★香盤表の書き出し（PDF・紙。体調の列は作らない）
  カレンダーにつなぐ（1人1つの住所・★体調は1文字も入らない）
  合言葉で入る（★人数に達すると自動で閉じる）
  使える期限（★お支払いのときの「本番の最後の日＋30日」・延期は1回90日まで）
料金: ★15人まで無料。16人目から1回払い（40人2万／120人5万／300人10万／600人15万）
```

## 8. この製品が「やらないこと」

```yaml
点数・順位・信号色を出さない／連続記録で追い込まない／催促しない（通知は例外3件）

知らせを送らない（鳴るのはカレンダー）／問い合わせ窓口を人で持たない
```
