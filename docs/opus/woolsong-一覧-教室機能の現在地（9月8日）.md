# §4 ★いま決まっていること（要点だけ）

```
器　　Organization ├ Membership（先生・事務）├ Enrollment（生徒）└ Assignment（担当）
　　　★3つとも多対多。★個人の先生は「1人だけの教室」

役割　owner（契約者・お金）／admin（お金以外）／teacher（担当生徒だけ）
　　　★staff（★事務。日程と出欠だけ。健康に関するものは一切見えない）
```
