# 約束の逆引き ── 門下を開いた記録（S1・S2 の証明が、どの約束の文を覆うか）

2026-09-21 ／ Opus。★Sonnet の台帳（484件）の番号は持っていないので、**文で**書く。台帳の番号への付け替えは、文の一致で機械的にできる（Sonnet）
★「覆う」と書けるのは、その試験の出力が手元にあるものだけ。s1_prove.js・s2_prove.js の出力を見るまで「候補」とする

| 約束の文（見本 design-v21） | 守り方 | 覆う試験（候補） | 足りないもの |
|---|---|---|---|
| 開くと 開いた記録に 残ります（誰が・いつ・どの門下を・理由） | RPC が記録を書いてから返す | S2：開くと1行増える | — |
| 理由を 選ばないと 開けません | RPC が理由の無い呼び出しを止める | S2：理由が空だと開けない | 画面の試験（S3） |
| その他は 短く書く（100字まで） | DB の CHECK | S2：④で短文が空だと開けない | — |
| 開くたびに 1行 残ります | RPC が毎回 insert | ★無い見込み | 同じ人が2回開いて2行の試験 |
| 消せません | update・delete のポリシーが無い | S2：update・delete の拒否 | ★退会・学校を閉じても消えない（裁定161 FX1。いまは消える） |
| 記録は 運営の 中だけで 見ます（先生・学生の 画面には 出しません） | select のポリシー（本人＋master） | ★無い見込み | 先生・学生の試しの利用者で monka_read_log が0行 |
| 何を 読んだかは 残しません（開いたことと 理由だけ） | 表に中身の列が無い | 構造（列の一覧）で確かめられる | 列の一覧を試験に1行 |
| 門下の 連絡は、普段 運営から 見えません | org_messages の select に monka_read の枝が無い（S1） | S1：monka_read だけの人が直接 select で0行 | — |
| 書き込み欄が ありません。運営から 書けません | org_messages の insert のポリシー | ★無い見込み | monka_read だけの人の insert が拒否される試験 |
| ご本人から 求められたら、30日以内に お見せします | 運用（手順） | 試験では覆えない | 開示の手順書（誰が・どこから出すか）を台帳に。「運用で守る」と書く |

必要なもの: s1_prove.js・s2_prove.js とその出力、台帳（484件）の JSON。届いたら「候補」を「覆う」に確定させ、足りない試験のひな形を promise_coverage.py で出す
