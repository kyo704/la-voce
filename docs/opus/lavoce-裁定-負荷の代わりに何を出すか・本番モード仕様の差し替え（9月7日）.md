# 第2部　撤回した指標の席に、何を座らせるか

## 2-1 まず、何が壊れて、何が壊れていないかを正確に

### 壊れたもの

```
① 比を作ること
　　Impellizzeri et al. 2021：分母をでたらめな数字に入れ替えても、
　　判定の成績がほとんど変わらなかった（c統計量 0.574。0.5 ＝ 当てずっぽう）。
　　★つまり、比という構造が、何も足していませんでした。

　　Lolli et al. 2019：この比は、分子を分母の中にも含んでいるため、
　　★数学的に、見せかけの相関が出ます。

② 1.4 という線
　　→ ①が壊れているので、線の位置に意味がありません。
```

### 壊れていないもの

```
③ 量を測ること そのもの
　　声の量を測る枠組みは確立しています
　　（Titze・Švec & Popolo 2003：時間量・振動回数・振動距離・エネルギー）
　　★これは「測り方」の話であって、壊れていません。
```

### ★そして、はっきりさせておくこと

```
★★量に「ここを超えたら危ない」という線は、引けません。
　　騒音の被ばく量に倣った提案はありますが、
　　★合意された閾値は、存在しません。

　　→ 量は出せます。★線は引けません。
```

## 2-2 ★残っている量的な根拠は、1つだけです

```
Hunter & Titze 2009（n=72）
　声の回復　50% ＝ 4〜6時間 ／ 90% ＝ 12〜18時間 ／ ほぼ完全 ≈ 2.3日
```

★これは、9月6日の洗い直しで「**残す**」に入った、数少ないものです。

```
★★つまり ──
　　「負荷の比」には、根拠がありません。
　　★「休んだ日を数えること」には、根拠があります。

　　→ ★ACWR の席には、★「休んだ日の数」を座らせます。
```

## 2-3 ★落とし込み（3つ。この3つで、席が埋まります）

### ① 量は、2つの数でそのまま出す（比を作らない）

```
┌────────────────────────────┐
│ 今週、声を使った時間                       │
│                                            │
│   12時間30分                               │
│   あなたのふだんの週　8時間40分             │
│                                            │
│   本番　　2時間00分                        │
│   レッスン 3時間00分                       │
│   自主練　 7時間30分                       │
└────────────────────────────┘
```

```
★係数をかけない。★ただ足す。
★「多い」「少ない」「高い」と言わない。
★倍率を出さない。
★色を変えない（既存の決まり：値の大小で色を変えない）
★形は「最新値＋あなたのふだん」。★既に決めてあるものと同じです
```

### ② 休んだ日を数える　★これが、撤回した指標の代わりです

```
┌────────────────────────────┐
│ 今週、声を使わなかった日                   │
│                                            │
│   0日                                      │
│   先月の同じ時期　2日                       │
│                                            │
│   ▸ 声はどのくらいで戻るのか →              │
└────────────────────────────┘
```

```
★「休養」ではなく「声を使わなかった日」。★休めという意味を持たせない
★「0日です」で止める。★「休みましょう」と言わない
★★2.3日 という数字を、この画面に書かない
　　→ 文献の値は、記事の側に置く決まりです。★リンクだけ置く
★本番モードの中でも同じ：「今日から本番まで、記録が1件も無い日 ◯日」
```

### ③ ★その人自身の過去で、実際どうだったかを数える

**①②だけだと「だから何なんだよ」になります。**その答えがこれです。

```
┌────────────────────────────┐
│ これまでの、あなたの週                     │
│                                            │
│   ふだんより 多かった週　　7回              │
│     → 次の週に「出づらい」が増えた　3回     │
│                                            │
│   ふだんどおりの週　　　　12回              │
│     → 次の週に「出づらい」が増えた　4回     │
└────────────────────────────┘
```

```
★★これは予測ではありません。★その人自身の記録を数えただけです。
★文献も、閾値も、係数も要りません。★世界について何も主張していません。

★★必ず両方を出してください。
　　片方（多かった週だけ）を出すと、★それは主張になります。
　　両方あれば、★本人が自分で比べられます。

★7回中3回なら、★その人には効いていません。★本人がそう判断します。
★これは、声の予報で的中率を出すのと ★まったく同じ考え方です。
```

**★出してよい条件（既に決めてある条件を、そのまま使ってください）**

```
両方の群が、それぞれ10回以上たまってから出す。
　それまでは、たまった数を丸い印で見せる（既存の型のとおり）。
　文言：「◯週ぶんたまりました。あと◯週で出せます。」
```

★**②にも、同じ形が使えます。**

```
声を使わなかった日が 0日 だった週　　5回
　→ 次の週に「出づらい」が増えた　4回
声を使わなかった日が 1日以上あった週 14回
　→ 次の週に「出づらい」が増えた　3回
```

## 2-5 ★これで何が良くなるか

```
1　★嘘をつかなくて済みます
　　　量は事実。休んだ日の数も事実。過去の集計も事実。
　　　★世界について、何ひとつ主張していません。

2　★面白さが増えます
　　　「1.4倍です」より、
　　　「あなたの場合、多かった週7回のうち3回でした」のほうが、
　　　★自分の話なので、読む理由があります。

3　★自己修正します
　　　その人に効いていなければ、数字がそう言います。
　　　★アプリが押しつけません。

4　★係数を決めなくて済みます
　　　「本番は練習の1.6倍」を、誰も決められませんでした。
　　　★足すだけなら、決める必要がありません。

5　★あとで本物の根拠になります
　　　全員ぶんが貯まれば、★初めて検証ができます。
　　　★いまは、その材料を集めている段階です。
```
