## 1 合言葉に 門下を 持たせる

### 1-1 2種類

| | 誰が 作る | 入ると どうなる |
|---|---|---|
| ★学校の 合言葉 | 事務（meibo） | ★学校に 入る。★門下は 未定 |
| ★★門下の 合言葉 | ★★その門下の 先生（monka_write） | ★学校 ＋ ★その門下 |

★★★**先生が 自分で 作れる**のが 要点です。★事務を 通しません。

★顔合わせの 場で、★その場で 作って 見せられます。

### 1-2 台帳 ── ★1列 足すだけ

```sql
alter table teacher_invitations
  add column monka_id uuid references assignments_group(id);
  -- ★null なら 学校だけ
  -- ★入っていれば 門下まで
```

### 1-3 受け取る 関数

```
accept_teacher_invitation の 中で
  ★enrollments を 作る
  ★monka_id が あれば ★assignments も 作る
  ★★同じ 取引で。★片方だけ 成功する 状態を 作らない
```

## 4 ★上限 ── 裁定その77を 直します

### 4-1 衝突していた

```
裁定その77  ★1つの合言葉に ★10回で 止める・24時間
★現実       ★★門下20人が 顔合わせで 一斉に 打つ
★★→ ★11人目から 入れません
```

★あのときは ★総当たりを 防ぐ ためでした。
★★**人が 一斉に 打つ 場面を 想定していませんでした。**

### 4-2 直した 形

```
★個別の 合言葉（メール）
　★1回 使ったら 閉じる
　★10回 間違えたら 止める

★★門下の 合言葉（見せる）
　★★人数の 上限を ★先生が 決める（れい：20人）
　★★その 人数に 達したら ★自動で 閉じる
　★★期限も 決める（れい：10月31日）
```

### 4-3 ★間違いの 数え方 ── ★★IP では 数えません

```
✕ ★1つの IP から 1時間に 20回
　 ★★学校の WiFi は ★1つの IP に 見えます
　 ★★→ ★20人が 同時に 打つと 引っかかります
```

```
○ ★★ログイン済みの 人だけが 打てる
　 ★1人あたり ★10回
```

★★理由

```
★誰が 何回 打ったかが 分かります
★20人 同時でも 問題ありません
★★総当たりは ★アカウントが 要るので ★割に 合わなくなります
```

★★★裁定その77の「IPごとに 20回」は ★**取り消します。**

### 4-4 間違えた ときの 出し方（★その77のまま）

```
✕ 「その合言葉は ありません」
✕ 「期限が 切れています」
✕ 「もう 使われています」
○ ★「入れませんでした」
```

★★成功と 失敗で ★応答の 時間も 揃えること。

## 5 ★先生が 学生を 探す 仕組みは 作りません

### 5-1 理由

```
★★「こちらから 人を さがすことは できません」
```

★見本の 注記であり、★マッチングでも 通っているところでも 守ってきた 線です。

★★★**先生が 学生を 検索できると、★誰が どこに 通っているかが 分かります。**

★門下の 名簿は 見られます。★★★名簿の 外を 探せるようには しません。

### 5-2 ★同意の 問題

```
★★「先生が 入れる」と、★学生の 同意が 飛びます
```

★決まり：★「同意は ご本人から いただきます。★契約では 代えられません」

## 5-3 ★代わりに ── ★名簿から 招く

★「探す」の 代わりに、★**届く 形**を 足しました。

```
門下 → ★「＋ 門下に 招く」
　① ★合言葉を 見せる  ── 顔合わせ用
　② ★★名簿から 招く   ── ★取りこぼし用
```

### ★②の 中身

```
★学校の 名簿に いる方だけが 出ます
　中村 みな   2年 声楽   ［招く］
　高橋 かなで 2年 声楽   招待中
　小林 そら   1年 声楽   ［招く］
　伊藤 ゆい   1年 声楽   入っています
```

★★★**名簿の 外を 探すことは できません。**

★押すと、★その方の 画面に「招かれています」と 出ます。
★★入るかどうかは ★ご本人が 決めます。★こちらから 入れることは できません。

### ★なぜ これなら よいか

```
★検索  ★★一覧を 引ける → ★誰が どこに いるかが 分かる
★名簿  ★★★学校が 既に 持っている → ★新しく 分かることが ない
```

### ★これで 解ける 場面

```
★顔合わせを 休んだ
★QR が 読めなかった
★合言葉を 失くした
```
