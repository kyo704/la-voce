## §1 断りを、約束に言い換える ── 承認。ただし、約束は実装の義務になります

Fable さんの言うとおりです。

```
　✕（選別）　「答えは出しません」
　◯（安心）　「点数をつけません。急かしません。
　　　　　　　本番の前は静かにします。あなたの記録は、あなたのものです」
```

同じ中身です。前者は、読んだ人に「自分は対象外かもしれない」と思わせます。
後者は、読んだ人に「自分は守られる」と思わせます。**言い換えは、承認します。**

### ただし ── 4つ目と3つ目は、まだ実装されていません

言い換えは無料ではありません。**約束として書いた瞬間に、守る義務が生まれます。**

```
　「点数をつけません」　　　　　　→ 守れています（禁止事項に入っている）
　「急かしません」　　　　　　　　→ 守れています（催促を作っていない）
　「あなたの記録は、あなたのものです」→ 守れています（先生は中身を見られない）

　★「本番の前は静かにします」　　　→ ★まだ、そういう作りになっていません
```

いまの作りだと、**本番の朝に「羊が呼びに来る」ことがあり得ます。**
3ゲートを通った1文は、日付を見ずに出るからです。

### 裁定①（実装の指示）

```
　★静かにする期間 ── 本番の3日前 〜 本番の翌々日

　　この期間は、
　　　・羊は 呼びに来ない（1文が通っていても、期間が明けてから出す）
　　　・新しい1文を 画面の上のほうに置かない
　　　・記録は ふつうに取れる（入口は閉じない）
　　　・安全にかかわる文言（§3-2 の無料側）は ★この期間も出す
```

3日前という数字は、9月4日の裁定で採った「歌い手の慣行」の書き方に合わせています。
医学の根拠として出すのではありません。**稽古の慣行として、そう置く**だけです。

「本番」の判定は、予定表に本人が入れた本番の予定を使います。
予定が入っていなければ、この期間は発生しません。**こちらから聞きに行きません。**

## §2 4つの代わり ── 4つとも承認。3つに条件

### 2-1｜本番前の自分への言葉 ── ★承認（ここが、私の裁定が要ると言われた箇所です）

Fable さんの案：
**本番の朝に、本人が前もって書いた「本番前の自分への言葉」を1行だけ返す。**

**承認します。**理由は、これが**私たちが断ってきたものと、形が違う**からです。

```
　断ってきたもの　アプリが、記録を読んで、判断を作って、本人に渡す
　この案　　　　　本人が、前に書いた言葉を、アプリが預かって、そのまま返す
```

アプリは1文字も作りません。**私たちは、判断の主体になっていません。**
だから、3ゲートも要りません。ゲートは「私たちが何か言うとき」の装置だからです。

そして、§1で決めた「本番の前は静かにします」とも、ぶつかりません。
**静かにする、というのは「私たちが黙る」ことであって、
本人が自分に言い残した言葉まで消すことではありません。**

#### ただし、5つの条件をつけます

```
　① アプリは1文字も足さない。本人が書いた文字を、そのまま返す
　　　（要約しない・整えない・絵文字を足さない）

　② 記録の中身を、一切参照しない。条件分岐を作らない
　　　「調子がよさそうなので、この言葉を選びました」── ★これをやったら、判断です

　③ 出すのは、本番の朝に開いたとき、その場所にあるだけ。★通知しない
　　　通知した瞬間に、静かにする期間を こちらから破ることになります

　④ 何も書いていない人には、★何も出さない
　　　「まだ書いていません」と出したら、それは催促です

　⑤ 書くように誘わない。★書く場所が あるだけ
　　　「本番の前に、自分への言葉を書きませんか」── ★これは催促です
```

⑤について補足します。**書く場所は、予定表の本番の予定の中に置いてください。**
本番の予定を作った人が、その画面で見つける。それでじゅうぶんです。

#### 置き場所

```
　無料側です。金を取りません。
　　（9月4日の裁定：「静かにする方向の文言に、金を取らない」）
```

### 2-2｜学ぶ の 一般論記事 ── 承認。ただし数字を1つも書かない

すでに v4 の営業資料で「理論書としての立場」を採っています。その延長として承認します。

条件は2つです。

```
　① 9月4日の裁定に従い、★「稽古の話」として書く。「医学の一般論」として書かない
　　　✕ 「一般に、本番前は声帯の負担を減らすことが推奨されます」
　　　◯ 「本番の3日前からは、新しく積み上げるより確かめる、
　　　　　という進め方をする歌い手がいます」

　② ★文献の目安値を書かない（禁止事項）
　　　「7時間以上」「1日2リットル」── ★1つも書かない
　　　数字を書いた瞬間に、それは その人への目標になり、「あと○」に化けます
```

②は厳しく見えますが、これは間口の話でもあります。
**目安値を書くと、そこから外れている人が読むのをやめます。**

### 2-3｜レッスンに持っていく1枚 ── 承認。ただし、アプリの中に先生宛の道を作らない

禁止事項に「先生に送るボタン」「先生から生徒への『出して』ボタン」があります。
この案は、そのすぐ隣にあります。**線を、はっきり引きます。**

```
　◯ 本人が 項目を選び、自分の端末に 1枚（PDF か 画像）として書き出す
　　　　→ 印刷して持っていく。手で見せる。それは 私たちの外の話です

　✕ アプリの中から、先生の画面に 届く道
　✕ 「先生に送る」「共有」のボタン
　✕ 本人が選ばずに、全部が 自動で載る1枚
```

3つ目が大事です。**本人が選ぶ、という手間を省かないでください。**
自動で全部載る1枚は、「見せろ」と言われたときに断れなくなります。
選べるということは、**載せないと選べる**ということです。

### 2-4｜たぶんこれかも メモ ── 承認。ただし、候補を出すのはアプリではない

これが4つの中で、いちばん危ない案です。

```
　◯ 本人が「たぶんこれかも」と思ったことを、自分で書く
　✕ ★アプリが「たぶんこれかも」の候補を出す
```

後者は、**3ゲートを通っていない1文**そのものです。
n が足りない、効きが小さい、q が大きい ── だから出さないと決めたものを、
「たぶん」という言葉をつけて出すことになります。ゲートが無意味になります。

名前は「たぶんこれかも」のままでよいです。正直で、よい名前です。
**主語が本人であるかぎり、これは記録の一種です。**

### 2-5｜「断りが4つから1つに減る」について

Fable さんの数え方は、**利用者が感じる断りの数**としては正しいです。
ただし1つだけ、はっきりさせます。

```
　禁止事項の一覧は、★1行も減りません。
　減るのは「断られた」という感じであって、規則ではありません。
```

作る側は、**規則の数で数えてください。**減ったつもりになると、境目が緩みます。

## §3 入口を広げる

### 3-1｜「声のプロフェッショナル」→「声を使う人」── 承認。ただし相手で書き分ける

承認します。ランディングの言葉は広げてください。

ただし、**全部を広げるのは間違いです。**

```
　ランディング（一般向け）　　★「声を使う人のための、記録帳です」
　教育機関向けの営業資料　　　★このまま（「声を専門に学ぶ人」）
　特商法・規約　　　　　　　　★このまま（法律の文書は、広げる場所ではありません）
```

9月15日の大学営業で「声を使うすべての人に」と言うと、**弱く聞こえます。**
相手は音大です。相手にとっての専門性が、こちらの価値だからです。

**同じ製品に、2つの入口があってよい。**それは矛盾ではありません。

### 3-2｜無料を厚くする ── 承認。線を1本、引きます

「厚くする」だけだと、次に何を無料にするかで毎回もめます。線を引きます。

```
　★無料　　安全に寄るもの ／ 静かにするもの ／ 自分の記録を そのまま見るもの
　　　　　　　・記録を取る（全項目）
　　　　　　　・さかのぼる（自分の記録を、そのまま並べて見る）
　　　　　　　・初日だけで比べる（E3・9月9日に無料へ移しました）
　　　　　　　・本番前の自分への言葉（§2-1）
　　　　　　　・安全にかかわる文言（急な体重の減りなど）

　★有料　　たくさん見るもの ／ きれいに見るもの ／ 手間を省くもの
　　　　　　　・見られる期間の長さ
　　　　　　　・並べ方・重ね方の自由
　　　　　　　・書き出し
　　　　　　　・よそおい
```

この線は、覚えられます。**「黙るほうと、守るほうは、無料」**です。

### 3-3｜教室の無料枠を配布の道具に ── 不採用

**採りません。**理由は1つです。

```
　名簿1人 ¥400 という値段を、9月9日に決めたばかりです。
　無料枠を配ると、教室から見た1人あたりの値段が下がります。
　いちど下がった値段は、上げられません。
```

代わりに、こう置きます。

```
　★教室が配れるのは「無料のままで使える」という案内だけです。
　　個人の無料の帯は、もともと 誰でも 年齢に関係なく 使えます。
　　教室は、それを 生徒に 知らせればよい。枠を配る必要が ありません。

　★名簿に載っている生徒は、在籍のあいだ「しらべる」相当が使えます。
　　これは すでに ¥400 に含まれています。★別枠を 足しません。
```

つまり、**教室はすでに配布の道具です。**新しい枠を作る必要がありません。

### 3-4｜18歳未満は課金だけ制限 ── 不要です。すでに、それより広い

ここは、Fable さんの見立てに**事実の取り違え**があります。

```
　Fable さんの前提　「案C（売らない）は法的に楽だが、声優志望者を切る」
　★実際　　　　　　 案C は 採っていません。9月8日に ★案D を 承認済みです。
```

案D は、こうです。

```
　18歳未満が 買えるもの　★「しらべる」月額 ¥580 ← ★買えます
　18歳未満が 買えないもの　一括払いのもの（¥4,800 / ¥12,800）と、よそおい ¥1,280
```

Fable さんの提案（無料は年齢を問わず・課金は18歳以上）は、
**いまの案D より狭い**です。案D は、18歳未満に ¥580 を売っています。

そして、¥580 という値段は偶然ではありません。

```
　★¥999 が 線です（民法5条3項・小遣いの範囲に収まる余地）
　　¥580 は その内側。★¥1,280 は 外側。
　　一括の ¥4,800・¥12,800 は、金額でも 一括であることでも 外側。
```

**変更しません。**声優志望の15歳は、いまも ¥580 で分析機能を全部使えます。

### 3-5｜イタリアで使ってもらう ── 見せるのは承認。売るのは、いま決めません

```
　◯ 坂本さんが 現地で 自分の記録として使う
　◯ 現地の歌い手に 見せる・使ってもらう（無料の帯）
　✕ ★EU に住んでいる人に 売る ── ★いま決めません
```

売れない理由は、市場ではなく制度です。

```
　① EU消費者権利指令の 14日間の解約権が、
　　 ★「途中返金なし・買い切り」と 正面から ぶつかります。
　　 9月8日に決めたばかりの 年払いの形が、EU では そのまま使えません。

　② GDPR。声と体調は 特別カテゴリに触れます。
　　 日本の「要配慮個人情報」の同意設計を そのまま持っていけません。

　③ 特商法のページは 日本の制度の文書です。EU向けの表示が 別に要ります。

　④ 画面は 日本語だけです。
```

これは「やらない」ではなく「10月19日の売り出しには載せない」です。
現地で使ってもらって、**欲しいと言われた数を数えるところから**始めてください。
数が集まってから、制度を作る。逆にすると、費用だけが先に出ます。

## §4 届け方の順番 ── 入れ替えます

Fable さんの順番：ボイストレーナー → 音声外来・言語聴覚士 → 音大パイロット → 坂本さん自身の記録の公開 → 合唱連盟

**入れ替えます。**理由は2つ、日付と、制度です。

```
　★1　音大（9月15日）　　　　　　★動きません。もう決まっています
　★2　坂本さん自身の記録の公開　　★10月19日以降。費用0。★誰にも真似できません
　★3　ボイストレーナー
　★4　合唱連盟
　★5　音声外来・言語聴覚士　　　　★PMDA の回答が来てから
```

### なぜ2番目を上げたか

坂本さん自身が、イタリアで、自分の記録を出して歌い続ける。
**これは、他の誰にも作れない証拠です。**費用は0円で、効きは最大です。

そして、この製品が売っているのは「点数をつけないこと」です。
それを一番よく示すのは、**点数をつけずに続けている人が、実際にいること**です。

### なぜ音声外来・言語聴覚士を最後に下げたか

**ここに営業に行くと、製品が医療機器の側に寄ります。**

```
　医療者が 患者に すすめる
　　→ 医療の判断に 使われている、という外形ができます
　　→ SaMD（プログラム医療機器）の 線に 近づきます
　　→ PMDA の相談窓口への 問い合わせが ★まだ 未送信です
```

**回答が来るまで、この道は開けないでください。**
順番の問題であって、やらないという話ではありません。

## §5 やらないこと ── 承認。理由を、残します

```
　★点数・順位・毎日の判定を足して、間口を広げようとしない
```

これは、すでに禁止事項に入っています。Fable さんが足したのは**理由**です。
理由のほうを、記録として残します。

```
　それをやると、Whoop・Oura・Fitbit と 同じ土俵に立ちます。
　同じ土俵では、資本で負けます。
```

これは正しい。そして、もう1つ理由を足します。

```
　★同じ土俵に立つと、「点数に疲れた人」という お客を、自分で消します。
　　うちのお客は、他社の点数から 逃げてきた人です。
　　点数を足すことは、間口を広げる行為ではなく、★間口を閉じる行為です。
```

## §6 私からの追加 ── 間口を広げると、同じ文が医療の話に見えはじめます

ここが、この提案でいちばん見落とされやすい点です。

いまの文言は、9月4日の裁定に従って「稽古の話」として書かれています。
それが医療の話にならずに済んでいるのは、**読む人が歌い手だからです。**

対象を「声を使う人」に広げると、こういう人が入ってきます。

```
　保育士・小学校の先生・コールセンター・受付・介護職・営業職
```

この人たちにとって、声の不調は**稽古の問題ではなく、仕事の問題**です。
同じ文が、**労働環境の話・職業病の話**として読まれます。

```
　歌い手が読む　　「本番の3日前は、積み上げるより確かめる」→ 稽古の話
　保育士が読む　　同じ文 → ★「仕事のやり方を こう変えろ」に見える
```

### 裁定②

```
　★対象を広げても、文言は「稽古の話」のままにします。書き換えません。
　★仕事の場面に合わせた 言い換えを ★作りません。
　　（「授業の前は」「シフトの前は」── ★これを 作らない）

　★広げるのは 名乗りだけです。中身の書き方は 動かしません。
```

理由は、**書き分けを始めると、書き分けた先が全部、医療と労働安全の側に落ちる**からです。
「声を使う人のための記録帳です。書き方は、歌い手の稽古の言葉のままです」──
これで通ります。狭く見えることを、恐れないでください。

## §7 Fable さんの最後の1文について

> 「この製品は、健康アプリの大衆市場では勝てません。
> 　勝てるのは『声を使う人』の中で、点数と催促に疲れた人の全員です」

**同意します。**そのうえで、1つだけ足します。

「点数と催促に疲れた人」は、**まだ疲れていない人を含みません。**
いま Whoop を買ったばかりの人は、こちらに来ません。**半年後に来ます。**

だから、この製品の伸び方は、こうなります。

```
　最初は 遅い。★他社が 先に お客を 疲れさせる必要があるからです。
　そして、いちど来た人は 出ていきません。★戻る先が ないからです。
```

**10月19日に数が出なくても、設計を変えないでください。**
数が出ないのは、間口の問題ではなく、時期の問題です。

### 坂本さん
