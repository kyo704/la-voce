# RULING 185 — レッスン割「回を始める」

```yaml
ruling: 185
date: 2026-09-23
version: design-v37
from: Code の報告（★裁定139 §1 にあるのに 見本が無い。機能を開けても 0行のまま）
extends: 裁定138・139
```

## 0. なぜ要るか

```yaml
機能の切り替え（feature_flags.lesson_rounds）の配線は できている。
★けれど「回を始める」画面が無いので、開けても lesson_rounds が 0行のまま 何も出ない
→ ★入口が無い機能は、無いのと同じです
```

## 1. 誰が押せるか

```yaml
★先生本人（lesson_rounds.teacher_id ＝ 自分）
★事務（日程の札・sched_all）も 始められる。★ただし「どの先生の回か」を 必ず選ぶ
  理由: 学期の初めに 事務がまとめて始めるのが ふつう（先生に 一斉にやらせない）
  ★誰が始めたかは created_by に 残す（あとで「勝手に始まった」と言われないため）
★学生は 押せない（始まった回に 希望を出すだけ）
```

## 2. いつ押せるか

```yaml
★いつでも。時期の縛りは 置かない（学校ごとに 学期が違うため）
★ただし：同じ先生に ★開いている回（status='open'）が 2つ あってはいけない
  理由: 学生が「どちらに出せばよいか」分からなくなる
  → 2つ目を始めようとしたら ★止める（「先に 前の回を 確定してください」）
★確定した回は 何度でも 作れる（学期ごと・前期後期）
```

## 3. 始めるときに 決めること（4つだけ）

```yaml
① 名前          ★既定「2026年度 後期」のように こちらで作る（直せる）
② 期間          period_from 〜 period_to（★レッスンを置く 範囲）
③ 締切          due_on ★既定は「今日から2週間後」。★期間の始まりより前であること
④ 回数          何回ぶん 置くか（★型（lesson_presets）から 選ぶ／手で入れる）
★決めないもの:
  ★「誰に配るか」── ★その先生の門下が 自動で対象（選ばせない。門下＝台帳）
  ★時間帯の候補 ── ★先生の空きコマから 自動（裁定139）
```

## 4. ★「回を置く日」の決め（Code の問いへの答え）

```yaml
Code の仮：「回のはじめの1回だけ」で 決め打ち → ★不十分です
★正: ★置き方を 先生が選ぶ（2通り）
  ㋐ ★毎週 同じ曜日・同じ時刻（★既定）
     例: 10月6日から 毎週月曜 14:00、12回
     ★学期のレッスンは これが ほとんどです
  ㋑ ★1回ずつ 置く
     例: 不定期・隔週・本番の前だけ 詰める
★どちらでも、★実際の日付が決まるのは「確定」のとき（希望を集めたあと）。
  ★始めるときは 範囲と回数だけ。★日付を先に決めない
  理由: 学生の「出られない日」を 集める前に 日を決めたら、★集める意味がなくなります
★確定のとき:
  ㋐ → 毎週の日付を 自動で並べ、★出られない日に当たったものだけ 先生が動かす
  ㋑ → 先生が 1つずつ 置く（ヒートマップの上で）
```

## 5. 確認の画面は 要るか

```yaml
★要ります（1枚）。理由: ★学生に 希望を聞くことになるためです
  出すもの: 先生の名前・門下の人数・期間・締切・回数・置き方
  文: 「★門下の ○人に、希望を 聞きます。締切は ○月○日です。」
★「送りますか」ではなく「始めますか」。★通知は 送りません（開いたときに 見えます）
★確認は 1回だけ。★途中で やめられます（回を 消せる＝希望が 1件も無いあいだ）
  希望が 1件でも 入ったら ★消せない（★確定するか、そのまま 閉じる）
```

## 6. 始めたあと

```yaml
学生の画面に「★希望を出してください（締切 ○月○日）」が 出る（★帯の1本）
★催促は しません。出していない人が いても、★こちらからは 何も送りません
  運営は「★希望がまだの方」の一覧を 見られる（★誰に 声をかけるかは 人が決める）
締切を過ぎても ★自動で閉じません（先生が 確定するまで 開いたまま）
  理由: 締切は「目安」。★集まらないまま 閉じると 困るのは 先生です
```

## 7. VERIFY

```yaml
- 先生が始める → 通る／★事務が始める → 先生を選ぶ画面が 出る／学生 → 押せない
- 同じ先生に 開いている回が あるとき → ★止まる（「先に 確定してください」）
- 締切を 期間の始まりより 後にする → ★止まる
- 始めた直後: 学生の画面に 帯が出る／★通知は 0件
- 希望が 0件のあいだ → 回を 消せる／★1件でも 入ったら 消せない
- 置き方 ㋐ → 確定のとき 毎週の日付が 自動で並ぶ
- 置き方 ㋑ → 確定のとき 1つずつ 置く
```
