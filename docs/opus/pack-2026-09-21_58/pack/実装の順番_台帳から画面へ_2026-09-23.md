## 2. つなぐときの決まり（毎回）

```yaml
1 画面は 表を直接読まない ものがある（公開ページ・緊急の連絡先・カレンダー・学生の値段）。関数だけを呼ぶ
2 「消す」ではなく「終わりの日を入れる」: 出演者（left_at）・在籍（status）・稽古（canceled_at）・門下（ended_at）
3 記録の表（*_log・*_reads・*_changes）に 画面から insert しない
4 使えるかの判定は my_entitlements 1か所。画面ごとに判定しない
5 日付は 台帳の now() か サーバで作る（端末の時計で「きょう」を作らない）
6 列は名指しで select する（select('*') を書かない）
```

## 3. 出発までに、画面をつなぐ順（提案）

```yaml
第2週: レッスン割 → ホームページ・ポートフォリオ（公開ページまで）
第3週: 公演（作る → 香盤表 → 稽古 → 当日 → 出欠）→ 子ども（★緊急の連絡先は記録が残ることを確かめてから）
       並行: 値段（プラン・請求・学生の同意）
第4週: つながっていない画面の洗い出し（段3a の道具）→ 凍結 → 総点検
```
