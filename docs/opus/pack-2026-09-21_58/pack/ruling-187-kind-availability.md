# RULING 187 — 種類ごとの「まだ使えません」は 台帳で 縛らない

```yaml
ruling: 187
date: 2026-09-23
version: design-v43
from: Code の指摘②（2026-09-23）
  「見本は 種類ごとに『まだ使えません（2027年10月から）』の 印を持つが、
   台帳は 11種類 すべてを 受け入れる。★台帳で 強制できない制限は
   『押せるのに 約束にならない』形になるので 実装していない」
extends: 裁定148・152・176
```

## 0. ★Code の判断は 正しい

```yaml
★「台帳で 強制できない制限は 実装しない」── ★そのとおりです
  画面だけの制限は ★静かに 破れます（今日 何度も 見ました）
★実装していないのが 正しい状態です。そのまま で よい
```

## 1. 決定 ── ★台帳では 縛らない

```yaml
★koen_kind_check は 11種類 すべてを 受け入れたまま にします。★列も 足しません
理由:
  ① ★「2027年10月から」は ★私たちの 都合です。台帳の 決まりでは ありません
     （★作れない理由が 台帳に あるのではなく、★画面が まだ 無いだけ）
  ② ★期日を 台帳に書くと、★その日に 誰も 押さなくても 勝手に 開きます
     ★開けるかどうかは、★画面が できて・確かめが 済んでから 人が 決めること
  ③ ★機能の切り替え（feature_flags・裁定176）が ★すでに その役目を 持っています
     ★同じ決めが 2か所に あると、必ず ずれます（裁定148 §1 と 同じ考え）
```

## 2. では どう 出すか

```yaml
★機能の切り替えで 出し分ける（裁定176）:
  feature_flags に 種類の束を 1つずつ 持つ
    koen_kinds_group1 … オペラ・合唱・演劇（2027-07 予定）
    koen_kinds_group2 … オーケストラ・吹奏楽・ガラ・室内楽・ダンス（2027-10 予定）
    koen_kinds_rec    … 収録・発表会（時期 未定）
  ★切ってある束の 種類は「公演を作る」の一覧に ★出しません（裁定73：持っていないものを 出さない）
  ★「まだ使えません」と 並べて 見せません
    理由: ★押せない札を 見せるのは、★期待させて 断ること です
      （見本の「2027年10月から」の 印は ★私たちの 計画表です。利用者の 画面では ありません）
★見本の側:
  ★計画の印は 見本に 残します（★Code と 坂本さんが 順番を 見るため）
  ★ただし「利用者には 出さない」と 見本に 書き添えます
```

## 3. ★もし 出し分けずに 全部 開けるなら

```yaml
★それでも かまいません（台帳は 受け入れます）
  ★ただし そのときは ★見本の「まだ使えません」の 印を 消してください
  ★画面と 台帳と 見本で「使える種類」が 3通りに なるのが いちばん まずい
```

## 4. VERIFY

```yaml
- koen_kind_check は 11種類を 受け入れる（★変えない）
- 利用開始時期の 列は ★無い（★足さない）
- 切ってある束の 種類が「公演を作る」に ★出ない
- ★「まだ使えません」の札が 利用者の画面に ★出ない
- 見本には 計画の印が 残り、★「利用者には 出さない」と 書いてある
```
