## ⑫ 効いた習慣ランキング ── **確定済み（9月8日）**

出典：`woolsong-確定-削除17点の再考・これ以降動かしません（9月8日）.md` §12

```
✕ 消す　　★名前（「効いた」）と ★順位（ランキング）
◯ 残す　　★中身（2群の 件数と 点の 散らばり）
```

**消す理由は 2つ、どちらも 単独で 禁止です。**

```
　①「効いた」＝ ★因果の 主張。うちが 言えるのは「一緒に 出ています」まで
　②「ランキング」＝ ★値による 並べ替え ＋ 順位（表示規約 §7-13）
```

**★機能ごと 消すのでは ありません。**
いまの `くらべる` が、その 置き換えです。

```
　★7時間以上 眠った日の 2日後　12日
　★7時間 眠らなかった日の 2日後　 8日
　→ ★順位 1つより、両群の 件数のほうが 多くを 語ります
```

**やること**

```
□ 画面から「効いた習慣ランキング」の 名前を 消す
□ ★順位（1位・2位…）と ★並べ替えを 消す
□ ★計算そのものは 消さない。★くらべる の 材料です
□ ★元の記録（睡眠・練習時間・食事の印）は ★1件も 消さない
```
