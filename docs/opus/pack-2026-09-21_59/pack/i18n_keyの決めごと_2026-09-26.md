## 3. ★★決まり（★7つ）

```yaml
★① ★★日本語を key に しない
   ✕ t('本番')　○ t('rec.performance')
   ★理由: ★日本語を 直すたび ★key が 変わり、★訳が 全部 外れます

★② ★★文を 割らない

   ○ t('koen.callFor', {role: 役名})
   ★理由: ★★語順は 言語で 違います。★割ると 訳せません

★③ ★★同じ ことばでも ★場所が 違えば ★別の key
   ★「出す」── page.publish（公開する）／school.submit（希望を 出す）
   ★理由: ★★英語では publish と submit。★1つに すると 訳せません

★④ ★★数を 混ぜない
   ✕ t('koen.members') → 「39人」
   ○ t('koen.members', {n: 39}) → 「{n}人」／「{n} people」
   ★理由: ★★英語は 1 person／2 people

★⑤ ★★約束の 文（note.*）は ★★1文 1key
   ★理由: ★★消されたか どうかを 数えたい（★ruling_mock_check）
   ★例: note.noOtherCallTime ＝「ほかの 方の 集合時刻は 見えません」

★⑥ ★★err.* は ★台帳の 記号と ★同じ 綴り
   ★台帳: raise exception 'MINOR_TEACHER_LINK_BLOCKED'
   ★画面: t('err.MINOR_TEACHER_LINK_BLOCKED')
   ★理由: ★★突き合わせが 機械で できます

★⑦ ★★key を 消さない
   ★使わなく なっても ★消さずに 残す（★★訳が 生きています）
   ★i18n_unused.py で 数えるだけ。★半年 見てから 消す
```
