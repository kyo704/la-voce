# §1 文体（★守る線）

```
長さ　　★1〜2文。★22〜34字。★3文は作らない
語尾　　です・ます。★「〜だよ」「〜だね」は使わない（幼くなりすぎます）
表記　　ひらがな多め。★漢字は「今日・昨日・声・本番・先生」くらい
空白　　読みにくい所だけ、分かち書き（「まどの ところ」）
主語　　★型Aは「ぼく」。★型Cは「あなた」を言わない（「〜と書いていましたね」）
```

# §2 型（★5つだけ）

| 型 | 何 | 出る割合の目安 |
|---|---|---|
| **A** | 羊の今日 | ★60% |
| **B** | あいさつ（Aの前に付く。単独でも可） | 常に |
| **C** | 書いたことを返す | 20% |
| **D** | そばにいる（不調の日） | その日だけ |
| **E** | 着替えた直後 | 着替えた直後だけ |

★A が主です。**Aだけで、ずっと持ちます。**

---

# §3 選び方（★実装）

```
1  60日以内に出した台詞は、出さない（★履歴を持つ）
2  Bを引く → 30%でAを付ける → それ以外はBだけ
3  ★1日1つ。★同じ日に再訪しても、同じものを出す（★変えると読み損ねます）
4  条件付きのもの（E・D・季節・行事）は、条件が立った日だけ ★最優先
5  在庫が尽きたら、★60日の窓を30日に縮める。★同じ日に2つ出さない
```

```js
// 優先順位。上から、条件に合う最初のものを出す
E 着替えた直後 → D 不調 → 行事 → 予報が当たった → 季節 → A/B
```

# §5 データの形

```json
{ "id": "a_home_012",
  "type": "A",                     // A B C D E F G H I
  "text": "まどの さんに、ほこりが ありました。とりました。",
  "when":   { "season": null, "hour": null, "date": null },
  "needs":  { "equipped": null, "record": null },
  "weight": 1 }
```

```
★id は 変えないこと（履歴が 60日ぶん ぶら下がります）
★text を 直すときは、★新しい id を 作る（★書き換えない）
　→ ★「あの台詞、消えた」と 言われたとき、追えます
```
