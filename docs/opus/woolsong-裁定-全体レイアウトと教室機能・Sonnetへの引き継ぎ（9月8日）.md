# §7 ★★「めちゃくちゃ高性能に」── ★7つ

★教室機能で いちばん効くのは 見た目ではなく、★**通じること**です。

## 7-1 ★★電波がなくても動く（★最優先）

```
　★音大の練習室は 地下です。★教会も ホールの楽屋も 電波が入りません。
　★★「出欠を押したのに 通っていなかった」が いちばん困ります。

　□ ★当日ぶんのレッスン・行事を、★開いた時点で 端末に持っておく（IndexedDB）
　□ ★出欠のタップは ★その場で 画面に反映（★楽観的更新）
　□ ★送れなかったものは ★列に積み、★電波が戻ったら 自動で送る
　□ ★画面の右上に ★小さく「未送信 2件」。★押すと 一覧
　□ ★同じ操作を2回送っても 1回になる（★冪等キー＝lesson_id＋status＋端末時刻）
```

## 7-2 ★★1タップで終わる（★確認を出さない）

```
　□ ★［来た］［休み］［中止］は ★押した瞬間に確定。★「よろしいですか」を出さない
　□ ★取り消しは ★3秒だけ出る「もどす」で行う（★確認より速く、★間違いも直せる）
　□ ★★連続で押せる（★次の生徒に フォーカスが自動で移る）
```

## 7-3 ★★自分のカレンダーに 入る（★ICS購読）

```
　□ ★webcal:// のワンタップ購読　＋　★iPhone / Android / Google の手順を その場に
　□ ★★2本に分ける　　「自分のレッスン」　「教室の行事」
　□ ★「反映は最大24時間・こちらからは書き込めません」と 必ず書く（★Fableの指摘）
```

## 7-4 ★★通知は 3つだけ

```
　◯ 今日のレッスン・行事（★当日の朝）
　◯ 本番 3日前
　◯ 教室の行事 7日前
　✕ ★それ以外は 付けません。★健康の記録の催促は ★1つも付けません
```

## 7-5 ★★重なりは「教える」だけ。★自動で動かさない

## 7-7 ★★健康と教室を、★データの層で 分ける
