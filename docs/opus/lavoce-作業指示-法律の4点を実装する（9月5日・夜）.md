## 1. ③ 規約 第7条の差し替え（今日やる）

### 差し替える全文

```
第7条（免責）

1. 当社は、本サービスが利用者の特定の目的に適合すること、期待する
   効用を有すること、および不具合が生じないことを保証しません。

2. 当社の責めに帰すべき事由により利用者に損害が生じた場合、当社に
   故意または重大な過失があるときを除き、当社が賠償する責任は、
   当該損害が生じた時点からさかのぼって12か月間に利用者が当社に
   支払った利用料金の合計額を上限とします。

3. 前項の上限は、利用者の生命または身体に生じた損害については
   適用しません。

4. 本サービスは、医療行為、診断、治療または医学的助言を行うもの
   ではありません。体調について気になることがあるときは、
   医療機関を受診してください。

5. 当社は、利用者と第三者（指導者、所属団体その他）との間に
   生じた紛争について、責任を負いません。
```

### なぜこの形か

- **第2項の「当社に故意または重大な過失があるときを除き」が、いちばん大事です。**
  消費者契約法8条3項（令和4年改正・2023年6月1日施行）で、
  **「軽過失の場合にのみ適用されることを明らかにしていない一部免責条項は無効」**
  になりました。この一句がないと、上限そのものが無効になります
- **第3項（生命・身体は上限を適用しない）**は法律の要求ではありませんが、
  症状の見張りを持つアプリで、体のことを数千円で切る条項は
  消費者契約法10条（消費者の利益を一方的に害する条項）で無効とされる危険があります
- 上限を**12か月分**（最大6,960円）にしたのは、1か月分（580円）だと低すぎて
  10条で無効とされるおそれがあるためです

### 直したあとにすること

規約の**変更履歴**に1行足してください。

```
2026-09-05 第7条（免責）を改定。責任の上限に、故意・重過失を除く旨を明記。
           生命・身体に関する損害を上限の対象外としました。
```

**利用者に不利な変更ではないので、個別の同意は不要**と考えます（民法548条の4）。
不安なら、次のログイン時に1回だけ「規約を改定しました」を出してください。

## 2. ④ 個人情報 ── 「作らない」を決める

**要配慮個人情報を、一切持たない設計にします。**

### 作らないもの（3つ）

| | 作らない |
|---|---|
| 1 | **病名を入れる欄**。症状の選択肢に病名を混ぜない |
| 2 | **受診の結果を入れる欄**。「受診しましたか」「何と言われましたか」を聞かない |
| 3 | **自由記述欄**。サーバに送るメモを作らない |

### 症状の選択肢は、これだけ

```
のどが痛い ／ 声がかすれる ／ 咳が出る ／ 熱っぽい ／ 息が浅い ／ 鼻がつまる
```

**病名は1つも入れないでください。**（声帯結節、扁桃炎、逆流性食道炎 …）

### 根拠

個人情報保護法ガイドライン（通則編 2-3）に、こうあります。

> 身長、体重、血圧、脈拍、体温等の個人の健康に関する情報を、
> **健康診断、診療等の事業及びそれに関する業務とは関係ない方法により知り得た場合**は
> 該当しません

Woolsong は医療機関でも健診の事業者でもなく、**本人が自分で入力します。** これに当たります。
一方で「病歴」＝「病気に罹患した経歴」は要配慮なので、**病名がついた瞬間に線を越えます。**

### これで消える義務

- 取得のたびの**個別同意**（法20条2項）── 不要
- 要配慮を含む漏えいの**1件報告**（規則7条1号）── かからない

※ 不正アクセスによる漏えいのおそれは、要配慮でなくても**1件で報告義務**（規則7条3号）です。
これは消えません。

## 3. ② 未成年 ── 売ってよい。条件は3つ

### ① 保護者のメール確認

```
1. 15〜17歳が有料を選ぶ → 保護者のメールアドレスを入力する画面
2. そのアドレスに確認メールを送る
3. 保護者が確認リンクを踏むまで、課金を始めない
4. 同意した日時・メールアドレス・IP を保存する
```

同意の文面は、既に決めた1本の枠のまま。

> 毎月580円まで、このアプリで使ってよいと認めます

### ② 3Dセキュア必須（既に決定済み。必ず入れる）

カードは通常、保護者の名義です。**3DSはカード会社が名義人本人を認証します。**
「保護者のカードで、保護者が認証を通した」記録が残ることが、同意の強い裏づけになります。

`payment_method_options[card][request_three_d_secure] = 'any'`
月額・装いの**両方**に掛けてください。

### ③ 取消を言われたら、争わず全額返す

- **日割りにしない。全額。**（民法121条の2第3項は現存利益の限度ですが、争う方が高くつきます）
- 対応の担当も文面も、先に決めておく
- 1件あたり最大でも数千円です

### 変えること

**「15〜17歳は月額のみ・装いは季節ごと1回」の制限は、外してよい**です。
民法5条1項の同意を正面から取るので、5条3項（小遣い）に頼る必要がなくなりました。
単発か継続かで区別する理由が消えます。

**15歳未満を不可とするのは、そのまま**にしてください。

## 4. ① 特商法 ── 住所は出す

### 表記のひな形

```
販売業者          坂本 響
運営統括責任者     坂本 響
所在地            〒000-0000 ○○県○○市○○ 0-0-0 ○○ビル 000号
電話番号          050-0000-0000
　　　　　　　　　（受付時間：平日 10:00〜17:00／日本時間）
メールアドレス     support@（ドメイン）
販売価格          月額 580円（税込）／ 年額 5,800円（税込）
　　　　　　　　　装い 500円（税込・1回かぎり）
支払方法          クレジットカード（Stripe）
支払時期          お申し込み時、以降は毎月同日
提供時期          決済の完了後、ただちに
解約              いつでも設定画面から。次の請求日から止まります
返品・キャンセル   役務の性質上、決済後の返金は承っておりません
　　　　　　　　　（ただし当社の責めに帰すべき事由がある場合を除く）
```

- **住所はバーチャルオフィスで構いません。** 消費者庁は
  「現に活動している住所といえる限り、法の要請を満たすと考えられる」としています
- **郵便物の転送**が付いているプランを選んでください
- 電話番号は**050で構いません**

### 最終確認画面（別途・必須）

特商法12条の6。**省略できません。**

```
ご確認ください

  Woolsong 月額
  580円（税込）／ 月
  1年間お使いになると 6,960円（税込）

  お支払い     クレジットカード（毎月○日）
  ご提供       決済の完了後、ただちに
  解約         いつでも設定画面から。次の請求日から止まります

  [ 上の内容で申し込む ]
```

**「1年間で6,960円」の併記**を落とさないでください。期間の定めがない定期購入では、
消費者庁が総額の表示を求めています。ここを落とすと、**誤認による申込みの取消し**が
認められます（法15条の4）。
