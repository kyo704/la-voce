# §1 ★読み込み（校務システム → うち）

## 1-1 ★API で つなぎません。★ファイルで やります

```
　★BLEND・賢者クラウド・EDUCOM・システムディ に、
　★誰でも 使える API は ありません。
　★つないだら、学校ごとに 作り直しに なります。
　★★そして いちばん まずいのは、
　★★向こうの 間違いが、こちらへ ★そのまま 流れ込むことです。
　★→ ★人が ファイルを 入れた ときだけ 動かします。
```

## 1-2 ★5つの 段（`stImport`）

| 段 | 何を | ★決まり |
|---|---|---|
| 1 | ファイルを えらぶ | CSV（Shift_JIS／UTF-8 自動）・Excel（1枚目）・タブ区切り。★PDF は 読めません |
| 2 | 列を つなぐ | 1行目を 見出しとして 読む。★4社の ならびを 選ぶと 自動で つながる |
| 3 | 下読み | ★先頭5行だけ。★入れない 列は 取り消し線 |
| 4 | 何が 起きるか | 新しく入る／直る／変わらない／★あやしい／★ファイルに いない |
| 5 | 取り込む | ★1回だけ 取り消せる。★記録は 消せない |

## 1-3 ★★守ること（★これが 裁定の 中身です）

```
　★★① 消しません。
　　　　ファイルに 無い方を、自動で 退会に しません。
　　　　★一覧に 出すだけ。決めるのは 人です。
　　　　（★書き出した 日より あとに 入った方が、必ず ここに 出ます）

　★★② 招待を 自動で 送りません。
　　　　★メールアドレスは 既定で「入れない」に してあります。
　　　　★送るのは、名簿から 人が 押したときだけ。★1回だけ。★催促しません。

　★★③ 健康の 記録は 1つも 入りません。
　　　　★「うちの どこに 入れるか」の 一覧に、
　　　　★体調・声・睡眠の 行き先を <b>1つも 作っていません</b>。
　　　　★書き出しと 同じです（★9月10日 校務システムの 裁定 §4）。

　★★④ 担当の 先生を 変えません。★役職も 変えません。
　　　　★ファイルに 先生の 列が あっても、門下は うちで 決めます。
　　　　★役職は「役職と、できること」で 人が 決めます。

　★★⑤ 時間割は 取り込みません。
　　　　★1校目の やり方が 決まってからに します。
　　　　（★生徒の 時間割の 中身を サーバに 置かない、という 決まりに 触ります）

　★★⑥ 成績・過去の 出席も 取り込みません。
　　　　★うちで つけた ものだけを 正に します。

　★★⑦ あやしい 行は、その行だけ 入れません。★ほかは 入ります。
　　　　（学年が 学校のかたちに 無い／学籍番号が 重なっている／氏名が 空）

　★★⑧ 誰が・いつ・どの ファイルを・何行 読んだかは 消せません。
```

## 1-4 ★突き合わせの 鍵

```
　★既定　学籍番号（いちばん 確か）
　★次善　お名前 と 学年
　★★メールアドレスでは 突き合わせません（★入れていないから 使えません）
```

# §2 ★出席は「自分が 担当している レッスン」だけ

## 2-1 ★何を 変えたか

```
　★これまで　出欠つけ（レッスン名の 文字）→ 門下の 上から 5〜6人
　★これから　出欠つけ（★時間・レッスン・★担当の 先生・場所）
　　　　　　 → ★その 先生の 門下だけ
```

`push('出欠つけ',{tm,l,t,pl})`。`t` が 担当の 先生。

## 2-2 ★3つの 立場

| 誰 | ★できること |
|---|---|
| ★担当の 先生 | つけられます |
| ★ほかの 先生 | ★★<b>開いても お名前すら 出ません</b>。人数も 出しません |
| ★事務（`shukketsu` あり） | ★代わりに つけられます。★<b>事務の 名前</b>が 残ります |

```
　★★ほかの 先生に 人数も 出しません。
　★★「渡辺先生の 門下は 何人か」も、よその 情報です。
```

## 2-3 ★残したもの

```
　★ぜんぶ 出席 → ちがう方だけ 直す（★いちばん 速い）
　★休講＝その回を しなかった。★生徒の 欠席に なりません
　★まだの人は うすい 帯と「まだ」の 札
　★★体調・記録の 中身は、どの 立場でも 出ません
　★★「なぜ 休んだか」の 欄は ありません
```

# §3 ★重なりを 動かす画面を、★週の 表に

## 3-1 ★なぜ 変えるか

```
　★これまで　空いている 枠を「金曜 16:20〜17:50（5限）」と ★文字で 並べていました。
　★★これでは、いつが 空いているのか ★形で 見えません。
　★★日程を 組む画面は 週の 表なのに、直す画面だけ 文字なのは ★おかしいです。
```

## 3-2 ★どう なったか（`P_kasaFix` ／ `SC['重なりを直す']`）

```
　★行＝コマ　／　列＝曜日（★日程を 組む画面と 同じ形）

　★赤　　★いま ここ　　　重なっている ところ
　★灰　　自分の 予定　　 ★動かせません
　★緑　　ほかの レッスン ★動かせません
　★空き　★<b>その生徒が 来られて</b>、自分も 部屋も あいている
　★×　　その生徒が 来られません（押すと わけを 出します）

　★押す → 右（スマホは 下）に 出る → 場所を えらぶ → 「ここへ 動かす」
　★★押しただけでは 動きません。
　★空きが 0 のときは、その場で ★「部屋だけ 変える」へ 誘います。
```

## 3-3 ★変えていないこと

```
　★動かすのは 先生です。★事務は 知らせるところまで。
　★知らせは 1回だけ。★催促を 重ねません。
　★空いている 部屋を こちらで 探しません。★候補を 出すだけ。
　★★同じ 生徒の 重なりは、この画面に 出しません。
```

# §4 ★先生の「自分の 予定」

## 4-1 ★名前を 変えました

```
　★「自分の 授業・会議」　→　★「自分の 予定（レッスン いがい）」
　★理由　★講義でも 会議でもない ものが 入ります。
　　　　　★移動・お休み・伴奏合わせ・非常勤の 日。
```

## 4-2 ★★入れるのに 手間を かけさせません

```
　★① 上で「押したときの 名前」を 1回 えらびます（★えらばなくても よい。既定は「予定」）
　★② あとは ★マスを 押すだけ。★1タップで 入ります。
　★③ 入っているのを 押すと ★空きに もどります。
　★④ 曜日の 見出しを 押すと ★その曜日 まるごと。
　★⑤ コマの 見出しを 押すと ★その コマ まるごと（★毎週 火曜が 全部 会議、が 1タップ）。
　★⑥ 名前を 直したい ときだけ ✎（PC）／「名前を 直す」（スマホ）。

　★★名前は おまけです。★ぜんぶ「予定」で かまいません。
```

## 4-3 ★★そこに レッスンは 入りません（★ここが 裁定です）

```
　★これまで　灰色に なるだけ。★「それでも 置けますが、重なります」と 書いてありました。
　★★これは 間違いでした。
　★★自分で「ここは 空いていない」と 言った 場所に、
　★★アプリが 置けてしまうのは、★おかしいです。

　★これから
　　★placeIt が 止めます（★手で 置けません）
　　★「置ける枠」に ★出しません
　　★自動の 振り分けは ★かならず よけます（★条件では ありません。★切れません）
　　★マスを 押すと「★入れられません」と 出て、その場で ★予定を 外せます
```

## 4-4 ★見えかた

```
　★★生徒には 何も 出ません。
　★★事務には「入っているか どうか」だけ。★名前は 見えません。
　　（★「教授会」も「通院」も、事務からは 同じ「予定あり」です）
```
