## §2 ★何が起きているか（★数字で出しました）

```
羊の胴　　　中心(511,660) rx=268 ry=300　→ ★y=360〜960。★高さ600px
服の範囲　　y0 = FLAT−30 = 460 　　　　　→ 実際の上端は top_y = ★592（頭に隠れる）
　　　　　　y1 = WAIST_BOT + drop = ★814
　　　　　　　　　　　　　　　　　　　　　→ ★服の高さ 222px
```

★★**服は、胴の 37% しか覆っていません。**
　★上は頭に隠れ、★下は腰で切れて、★その下から白い胴がはみ出しています。
　→ ★これが「板を貼ったように見える」の正体でした。

## §3 ★3つの数字を変えるだけで、直ります（★試作しました）

```python

```
