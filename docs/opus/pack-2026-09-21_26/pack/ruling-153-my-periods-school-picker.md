# RULING 153 — 自分のコマの「どの学校か」を選ぶ

```yaml
ruling: 153
date: 2026-09-21
version: design-v15
from: Code「裁定151 で org_id を足したが、複数校の先生が学校を選ぶ画面が無い。3名のコマがすべて個人（null）で保存され、学校から見えない」
related: その140（複数校は学校を選ぶ・混ぜない）／その149（koma_mine を台帳に）／その151（my_periods.org_id）
priority: 低い（緊急でない）。見本だけ作る。実装は後回し
```

---

## 1. DECISION

```yaml
形: 裁定140 の「さがす」と同じ。先頭に学校の札。1校ずつ。混ぜない
0校・1校: 何も出さない（いまのまま）
  0校: org_id = null
  1校: org_id = その学校（裁定151 の移行と同じ）
2校以上:
  札: ［○○音楽大学］［△△声楽教室］［どこにも属さない］
  既定: 前回選んだ札（端末に覚える。台帳には持たない）／はじめて: 最初に入った学校
  見出し: 「○○音楽大学での コマです。ほかの学校とは混ぜません」
  学校の基本: 選んだ学校のもの
```

## 2. 札ごとの中身

```yaml
学校（koma_mine あり）: いまの「自分のコマ」と同じ。＋「どこにも属さない に戻す」
学校（koma_mine なし）: 学校の基本を読むだけ。「この学校では、自分のコマを決める役目が渡されていません」
  reason: 役目は学校ごと。ほかの学校で渡されていても、ここでは書けない（裁定151 WRITE）
どこにも属さない（null）:
  「どの学校からも見えません。あなただけのコマです」
  学校へ移す: koma_mine があり、まだ自分のコマが無い学校にだけ「移す」。たずねてから
  移せない学校には理由を1語（「もう自分のコマがあります」「この学校では決められません」）
```

## 3. 決めていないコマ（★いまの3名）

```yaml
学校の札を開いているとき、null のコマがあれば 先頭に1行:
  「学校を決めていないコマが Nつ あります（いまは どの学校からも見えません）」→ 押すと「どこにも属さない」へ
「このままでいい」: 押すとこの1行を出さない（端末に覚える）
自動で学校を決めない（裁定151 MIGRATION のまま）
知らせは送らない。この画面を開いたときだけ（催促しない）
```

## 4. SERVER（Code 向け）

```yaml
org_id の変え方: null → 学校 ／ 学校 → null だけ
  学校A → 学校B を直接は変えない。トリガで止める（OLD.org_id is not null and NEW.org_id is distinct from OLD.org_id and NEW.org_id is not null → 拒否）
  reason: 裁定151 の USING / WITH CHECK だけでは、両方の学校で koma_mine を持つ人は A→B に書き換えられる
null → 学校: WITH CHECK で has_can(学校,'koma_mine')（裁定151 のまま）
「移す」はコマの組ごと（1枚ずつではない）。1つの処理で
画面から来た org_id を信用しない。enrollments（active）を確かめる（裁定140 と同じ）
```
