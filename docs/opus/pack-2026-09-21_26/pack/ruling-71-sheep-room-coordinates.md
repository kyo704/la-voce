### ★2-2 ★本当の原因（★見立て）

### ★2-3 ★仕様

```js
/* ★カメラ ── 画面ごとに 値が違う。★関数は 同じ */
const camPlace = { k: kFit,       ox: 0,  oy: 0  };   /* ★部屋全体 */
const camView  = { k: kFit * 1.6, ox: sx, oy: sy };   /* ★羊に寄る */

/* ★kFit = Math.min(vw / ROOM.w, vh / ROOM.h)  ← ★contain */

/* ★部屋の割合 → 画面の px */
function fit(rx, ry, cam){
  return { x: (rx * ROOM.w - cam.ox) * cam.k,
           y: (ry * ROOM.h - cam.oy) * cam.k };
}

/* ★画面の px → 部屋の割合　★★fit の 逆。★同じ cam を渡す */
function unfit(px, py, cam){
  return { rx: (px / cam.k + cam.ox) / ROOM.w,
           ry: (py / cam.k + cam.oy) / ROOM.h };
}
```

★★★**`unfit` に渡す `cam` は、★そのとき描いた `cam` と ★同じもの。**

★★`camView` で描いておいて `camPlace` で逆算する、★その逆も、★★禁止です。

### ★2-4 ★確かめ方（★道具）

```js

/* ★往復して 戻るか */

  const s = fit(p.rx, p.ry, cam);
  const b = unfit(s.x, s.y, cam);
  console.assert(Math.abs(b.rx - p.rx) < 1e-9
              && Math.abs(b.ry - p.ry) < 1e-9, '★往復で ずれています');
});

/* ★★置く画面で 置いて、★見る画面で 見ても 同じ 部屋の点か */

const shown  = fit(placed.rx, placed.ry, camView);  /* ★ながめるで 描く */
/* ★★shown は 画面上 別の px。★それでよい。
   ★★部屋の点（placed）が 変わっていないことが 大事 */
```

★★★**道具を較正してください。** ★わざと `unfit` に 別の `cam` を渡し、
★★止まることを確かめてから 直しに入ること。
