# RULING 129 — ポートフォリオ／ホームページの 編集画面

```yaml
ruling: 129
date: 2026-09-21
implements: 裁定その127（型12種）／その128（ホームページ13型）
purpose: 「作るための画面」を設計する
```

---

## 1. PRINCIPLE

```yaml
★作る順序が、★そのまま 画面の 順序

  1 書く        ← ★中身が 無いと 型を 選べない
  2 選ぶ        ← ★型
  3 整える      ← ★色・書体・節の順
  4 確かめる    ← ★紙と Web を 並べて
  5 出す        ← ★公開

★do_not:
  - 型を 先に 選ばせる
    reason: ★中身が 無いと、どの型が 合うか 分からない
  - 全部 書き終えてから 見せる
    reason: ★★書きながら 見えないと、★書く気に ならない
```

## 1b. ENTRY_POINT（裁定その131）

```yaml
PROBLEM_2026_09_21:
  ★入口が3つとも マッチング経由だった
    レパートリー → ポートフォリオ → 経歴
    さがす → 経歴の帯
    応募する → ここで書く
  ★→ さがすを使わない人（声優・俳優・教える人）が辿り着けない
  ★→ そして レパートリーの奥（3階層）

★same_mistake_as: 裁定その96 §4d
  マッチングをレパートリーの奥に置いていた
  ★同じ誤りを2度した

DECISION: ★もっと の直下に置く
  もっと
  　さがす            いっしょに演奏する人
  ★あなたのページ     経歴・紙・公開
  　Woolsong          年3,600円
  　お仕事
  ★件数を出す:「13件」／公開中なら「公開中」

KEEP: ★既存の3つの入口は残す
  reason: マッチングの途中で気づいた人が、そこから書ける
  ★増やすのであって、移すのではない

VERIFY:
  ★Q1: マッチングを使わずに辿り着けること
  ★Q2: field='voice' でも辿り着けること（さがすが出ない分野）
  ★Q3: 0件のときに型を選ばせないこと
```

## 2. SCREENS

```yaml
★9画面。★既存の「経歴」を 育て、★紙とページを 分けます

P1_あなたのページ:                 # ★裁定その131。入口を新設
  where: ★もっと → あなたのページ
  ★name: 「あなたのページ」
    reason: |
      「経歴」だと書類に見える
      「ポートフォリオ」だと意味が伝わらない人がいる
      ★「あなたのページ」なら、何であるか分かる
  shows:
    - ★いまの型の小さな見本（実データ）
    - ★status:「まだ公開していません」／「公開しています」
    - 書いたものの一覧（kind ごと・件数つき）
    - ＋ 足す
    - ★出すさき: ［紙にする］［ページを作る］
  ★if_zero:
    「まだ 何も 書いていません。ひとつ 書いてみませんか。」
    ［ 書く ］
    ★型を選ばせない（§5）

P2_書く:                          # ★新規
  where: 経歴 → 足す
  ★1画面 1kind。★まとめて 書かせない
  kinds:
    education / teacher / award / performance /
    repertoire / recording / role / skill / physical /
    news / press / lesson / faq / management / link
  ★分野で 出す kind が 変わる（裁定その119）

P3a_紙の型:                       # ★12型
  shows: ★縦に 並べる
P3b_ページの型:                   # ★13型
  shows: ★縦に 並べる
  each: ★自分の 中身が 入った 小さな 見本
  ★do_not: 架空のデータで 見せる
  reason: 自分のもので 見ないと 選べない

P4_整える:                        # ★新規
  accent: 8色
  font: 明朝＋ゴシック ／ 明朝だけ ／ ゴシックだけ
  photo: 角丸 ／ 四角
  density: ふつう ／ ゆったり
  sections: 表示・非表示 ／ ↑↓ で並べ替え
  ★型をまたいで 引き継ぐ

P5a_紙をたしかめる:                # ★A4 プレビュー → PDF・印刷
P5b_ページをたしかめる:            # ★Web プレビュー → 整える・出す
  shows: ★それぞれ 単独で
  ★warn:
    - 作品が 3点未満 →「まだ 少ないかもしれません」
    - 作品が 7点超   →「6点目から 折りたたみます」
    - ★A4 が 2枚目に 溢れた →「1枚に 収まりません」
  ref: 裁定その127 §3

P6_出す:                          # ★新規
  slug: woolsong.app/@____
  ★予約語を 弾く
  scope: 自分だけ ／ 同じ学校 ／ ★誰でも
  ★既定は「自分だけ」
  noindex: ★本人が 選べる
  ★18歳未満は この画面に 入れない

P7_写真:                          # ★新規
  ★20枚まで
  ★上げるとき 1度だけ 縮小（1,200px・WebP・200KB以下）
  ★問い1つ:「この写真に、ご本人以外が 写っていませんか」
    ★答えは 記録しない。★問いを 出すだけ
  ref: 裁定その128 §7
```

## 10. VERIFY

```yaml
★Q0: もっとの直下から辿り着けること（マッチングを使わずに）
★Q0b: field='voice' でも辿り着けること
Q1: 中身が0件で型を選ばせず、書く画面へ誘導されること
```
