## 1. ★見つけた問題（sql/50 で直す）

```yaml
organizations.contract_owner_user_id → auth.users が ★NO ACTION
  → ★契約者になっている人は 退会できない（データベースが止める）
  本番: 7学校すべてに契約者が入っている ＝ ★7人がいま退会できない
  ★sql/17 で直したのは「NOT NULL × SET NULL」。これは別の型で、17では直っていない
直し（sql/50）:
  連鎖を SET NULL にする（列はもともと空を許している）
  ★契約者が外れたことを org_billing_log に残す（誰だったかは残さない）

  促していないなら、黙って「契約者なし」の学校ができる。台帳は通るが、知らせるのは画面の仕事
```

