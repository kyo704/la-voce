2026-09-21 ／ Opus ／ 方針：弁護士に頼らず、条文・官公庁の資料・判例で答えを先に出す（2026-09-14 以来）

## 0. この文書の位置づけ

```yaml
何のため: 大学の担当者が「法的に大丈夫か」を確かめるときに、先に渡す。意見書を求められる前に、問いに答えておく
書いてよいか: 自社のサービスの法的な位置づけを自社が説明するのは、自分の事務。弁護士法72条（他人の法律事件の取り扱い）に当たらない
  - 72条は「他人性」（自分の法律事件の自己の法律事務でないこと）が要件の1つ
  - この文書で報酬も受け取らない
名前: 「意見書」と呼ばない（弁護士の意見書と誤認させない。弁護士法74条の標示の禁止にも近づかない）
限り: 大学の規程が「弁護士の署名入り意見書」そのものを要求する場合は、この文書では代えられない。そのときだけ取る（台帳の引き金）
```

## 1. 大学が気にすること と 判例

### 1-1 学生の名簿を外に出すこと ── 早稲田大学名簿提出事件（最判平成15年9月12日）

```yaml
事案: 大学が講演会の参加申込者の学籍番号・氏名・住所・電話番号を、本人に無断で警察に提出した
判旨:
  - 単純な情報でも、本人が望まない相手にみだりに開示されたくないという期待は保護される。プライバシーに係る情報として法的保護の対象
  - 事前に明示して承諾を求めるのは容易だった。無断の提供は不法行為
大学にとっての意味: 名簿を外部のサービスに渡すとき、学生に知らせず・同意を取らずに進めると、この判決の型に入る
Woolsong の作り:
  - 学生は、招待を受けて本人が承知するまで学校から見えない（招待中は数えない・ご請求にも入らない）
  - 記録を書き始めるときに、同意の画面を1回出す（裁定58）。「いいえ」でも教室の機能は使える
  - 18歳未満は保護者の同意（裁定107）。15歳未満は保護者のアカウント（裁定147）
  → 「事前に明示して同意を取る」を、学生本人に対して画面で行っている
```

### 1-2 委託先から漏れたときの大学の責任 ── 宇治市住民基本台帳データ事件（大阪高判平成13年12月25日・最決平成14年7月11日で確定）

```yaml
事案: 市が乳幼児健診システムの開発を委託。再々委託先のアルバイトが住民データを複製して名簿業者に売却
判旨: 委託元の市に使用者責任。1人あたり慰謝料1万円＋弁護士費用5,000円
大学にとっての意味: 名簿を委託した先で漏れれば、大学が責任を負う。再委託先まで含めて見られる
Woolsong の作り:
  - 学校から預かるのは名簿・学務の列だけ（裁定56・57）。健康の記録は学校の委託の範囲に入らない
  - 再委託先（データの置き場・配信・決済）を契約書の別紙に全部書く（下の 3 に一覧）
  - 本番の台帳に人手でデータを持ち出す経路を作らない。書き出しは学校の役職（meibo）だけ・記録が残る
```

### 1-3 基本の情報だけでも責任 ── ベネッセ事件（最判平成29年10月23日）

```yaml
事案: 業務委託先の元社員が顧客データを持ち出し売却。子の氏名・生年月日・住所と保護者の氏名が流出
判旨: 早稲田事件を引いて、漏えい自体がプライバシーの侵害。「不快感を超える損害の立証がない」だけで棄却したのは誤り（差し戻し）
その後: 差戻審で1人1,000円。別の訴訟では、委託先の安全対策を確かめていなかった監督義務違反を認め1人3,300円
大学にとっての意味: 名簿（氏名・学籍・連絡先）だけでも、漏れれば賠償の対象。委託先の監督が問われる
Woolsong の作り: 安全管理措置の一覧（★いま38個の空欄あり。坂本さん待ち）を契約時に渡す
```

### 1-4 身体・健康に近い情報は重くなる ── TBC事件（東京高判平成19年8月28日）

```yaml
事案: エステ会社がウェブサイトの管理を委託。無料体験の申込者のスリーサイズ・関心のあるコース等が閲覧可能になり流出
判旨: 秘匿の必要性が高い情報として、1人あたり慰謝料3万円＋弁護士費用5,000円。委託先の管理責任を認めた
大学にとっての意味: 健康に関わる情報は、名簿より一段重い
Woolsong の作り（★いちばん大事な点）:
  - 学生の声・からだの記録は、学生とWoolsongの間の契約。大学は委託元にならない
  - 先生・学校の画面にその列が無い（見せない、ではなく持たない）。層をまたぐ結合をしない（裁定55・57）
  - 大学の側から健康の記録にたどりつく道が、画面にも台帳にも無い
  → 大学が「健康情報の委託元」として TBC 型の責任を負う形を、はじめから作っていない
```

## 2. 契約の性質（学校との契約）

```yaml
消費者契約法: 学校は法人なので「事業者」（2条2項）。当てはまらない
特定商取引法: 運営のために買う契約は「営業のために」に当たり、通信販売の規定は適用除外（26条1項1号。消費者庁の逐条解説：事業・職務の用に供する契約を含む）
中途解約・導入期間: 契約書の条（契約書_導入期間と途中解約の条）
事例の掲載: 別紙の同意書。学生は写さない（事例掲載の同意書）
```

- 再委託先の一覧（データの置き場／配信／決済。国・地域を書く）   ★Code・Sonnet が作る

## 4. まだ確かめていないこと（★ここを閉じれば、意見書を求められる理由がさらに減る）

```yaml
- 個人データの置き場が国外（米国など）にある場合の扱い（外国にある第三者への提供／クラウドの例外の当てはまり）。個人情報保護委員会のQ&Aでの確認
- 運営者がイタリアから作業する間の扱い（日本法の「外的環境の把握」と、EU の GDPR の拠点の考え方）
- 国立大学法人・公立大学法人が相手のとき、大学側に掛かる個人情報保護法の規律の違い
```
