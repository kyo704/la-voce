## §1 結論から

**崩れていません。今日、逆のことが起きました。**

崩れたと感じられたのは、**有料の主役を「アプリが言うこと」に置いていたから**です。
削除17点で、アプリが言えることが減った。だから商品が消えたように見えた。これは正しい観察です。

しかし今日、坂本さんが書いてくださった5行

> 声が出ない日になんで出なかったかを過去から見つけたい／出た日と悪い日の前日の生活はどう違うのか／
> 数日で4kg減って声が出なくなった／逆流性食道炎を1年間／食事をとても細かくノートに書く。それを携帯ひとつに

で、有料の主役が **「並べて見せること」** に移りました。この移動が、そのまま解決になっています。

| | 主役が「言うこと」だったとき | 主役が「見せること」になった今 |
|---|---|---|
| いつ動くか | 60日たって、条件を満たせば | **1日目から。2日ぶんでも並ぶ** |
| 何日で価値が出るか | 60日〜90日 | 14日で使える。60日で効く |
| 薬機法・景表法 | 判定に見える。危ない | 判定しない。**記録を並べているだけ** |
| 削除17点の影響 | 商品が消える | **影響しない**（消したのは全部「言うこと」の側） |
| 他のアプリとの違い | 曖昧 | **食事の細かい記録 × 声 × 時間差。存在しない** |

★念のため計算しました。3つの条件（n≥10・\|g\|≥0.4・q<0.10）で、各群10日のとき、小さめの差（d=0.4）を見つけられる確からしさは **13.5%** です。
つまり **「アプリが言う」を有料の主役に置いた設計は、そもそも成立していませんでした。** 削除のせいではありません。私の設計が最初から間違っていた。

## §2 いちばん大事な、順番の原則

> **記録できるものを先に出す。見せるものは、あとでよい。**

理由は一つだけです。**記録は、過去に遡れない。表示は、あとから足せる。**

今日「夕食を食べ終えた時刻」の欄を作れば、10月19日の出発までに **42日ぶん** が溜まります。
「くらべる」の画面を先に作って、記録欄を10月に作ったら、その42日は永久に失われます。

★これが、手順の書き換えのすべてです。

### 第5段：売る

**★ここが、いちばん大きな書き換えです。**

```
いまの計画：出発前（10月上旬〜中旬）に販売開始
提案      ：11月に延ばす
```

**延ばす理由（3つ）**

1. **物理的に間に合わない。** 特商法ページはバーチャルオフィス契約待ち、それはマイナンバー再発行（10月7日頃）待ち。
   売れるのは早くて10月8日。**出発の11日前**です。決済の不具合が出たら、飛行機の中で直すことになります。

2. **買う理由が、まだ画面にない。** 案Aの「奥」（60日の気づき）は、いまの38人にはまだ届きません。
   11月なら、9月に記録欄を出しておけば、その人たちは **60日以上の記録を持って** 有料の画面に出会えます。
   買う瞬間に価値が見えている。これが、いちばん確実な売り方です。

3. **削除がまだ終わっていない。** 売ってから消せば「取り上げ」になります。消してから売れば、ただの改良です。
   17点の削除は今週から。落ち着くのは9月下旬です。

**延ばさない場合の代案**（坂本さんが11月を待てないと判断された場合）

```
10月8日〜18日：「早くから使ってくださっている方へ」として、38人にだけ、
　　　　　　　 年額 ¥4,800 を提示する。買い切りに近い形にして、
　　　　　　　 出発後のサポート負担を最小にする。
　　　　　　　 一般公開は11月。
```

★どちらを取るかは、坂本さんの生活の見通し（イタリアでの費用）が決めることで、私が決めることではありません。

## §4 おうちのポイント制（ご質問への回答）

**代わりの制度を、私は用意していませんでした。「消せ」とだけ言いました。無責任でした。**

残してよいと思います。直したいのは1か所だけです。

| いま | 直す | なぜ |
|---|---|---|
| 記録した**項目の数**で増える | 記録した**日数**で増える。1日に何個書いても1日は1日 | 項目数だと、症状を余計に書き足す動機が生まれる（Ferrari & Russell 2010 RCT：健常者が症状を毎日記録すると、想起頻度 1.3→2.6日、強度 3.1→5.1。対照群は変化なし） |

もう一つ、加えるとよいもの：**季節でも増える**。
10月19日に発って、忙しくて2週間書けなくても、季節は進み、羊の毛は伸びている。
**書けなかった日を、取り返せない損失にしない。**

★これも私の意見です。今のままにする判断も、坂本さんが持っています。
