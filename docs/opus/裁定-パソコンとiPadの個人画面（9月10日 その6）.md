# §0 何を 決めたか

```
　★スマホの 個人画面を、そのまま 大きくしません。
　★★大きい画面には、大きい画面にしか できないことを 置きます。
```

★スマホは「**その場で 1つ 入れる**」ための 道具です。
★パソコンと iPad は「**ならべて 見くらべる**」ための 道具です。
★だから 同じ機能でも、**出す順番と 大きさを 変えます**。

# §1 5つの タブ（★スマホと 同じ並び）

| タブ | ★スマホ | ★パソコン・iPad |
|---|---|---|
| きょう | 上から 順に | ★★左右2列。左に 羊のおうち（大）、右に ことば＋記録＋よてい |
| 記録 | 1項目ずつ めくる | ★★5項目が **1画面に ぜんぶ** 出ます |
| ふりかえる | 小さい線 | ★★**90日ぶんの 大きな線（880×250）**＝ここが 本命 |
| ノート | 一覧→本文 | ★★左に 一覧、右に 本文（2つの ペイン） |
| ひつじ | おうち | ★★おうちが 大きく、置き場所が 8か所 見えます |

★**タブの 名前・数・並びを 変えないでください。**
★スマホと 同じにしておくと、持ちかえても 迷いません。

# §3 ★「ふりかえる」が パソコンの 本命

```
　★90日ぶんを 1本の 線で 出します（★880×250）
　★★本番の日には 縦の 帯を 引きます
　★→「本番の 前後で どうだったか」が、★スマホでは 見えません
```

★ここでも **点数・順位・予報は 出しません**。
★出すのは **その人が 入れた ものだけ** です。

★条件（何を・いつから）は **左の 列**に 置きます。
★線を いじる ボタンを、線の 上に 重ねないでください。

# §6 ★大きい画面での 文字の 大きさ

```
　★ふつう ／ 大きめ ／ もっと ／ いちばん　（★4段階）
　★★「いちばん」でも、★端末の 枠は 変わりません
```

★仕組み：`zoom` と `width:calc(X / var(--z))` を 組み合わせています。
★**枠の 物理サイズを 保ったまま、中身だけ 大きくなります。**

★★横に はみ出させないでください。★老眼の 方が いちばん 困ります。
