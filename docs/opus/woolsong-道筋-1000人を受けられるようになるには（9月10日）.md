# 道筋 ── 1,000人の名簿を 受けられるようになるには

2026年9月10日 ／ Opus
問い：「いまは お受けしていません」を、どうすれば 外せるか

---

# §0 答え ── 2段あります

```
　★レベル1　★書類だけ。★お金は ほとんど かかりません。★今年中に できます
　　　　　　　→ ★私立の学校の 多くは、これで 通ります

　★レベル2　★第三者の証明（Pマーク・ISMS）。★半年〜1年 ＋ お金
　　　　　　　→ ★国公立・大規模は、これが 要ります
```

★**そして いちばん大事なことを 先に 書きます。**

```
　★1,000人という線は、★本当は 人数の線では ありません。
　★★「証明を 求められるかどうか」の 線です。

　★300人の私立　　→ 聞かれないことが 多い
　★2,570人の大学　→ ★必ず セキュリティの 質問状が 来ます
```

★だから やることは「人数を 増やす準備」ではなく、**「質問状に 答えられる状態を 作ること」**です。

---

# §1 ★すでに できていることが、たくさん あります（書いていないだけ）

★質問状の 大半は、**うちが すでに やっていること**です。

```
　◯ 先生が 生徒の健康の記録を 見られない　★画面そのものが ありません
　◯ 要配慮個人情報の 専用の同意画面（consentAt が null なら 記録させない）
　◯ RLS（行ごとの アクセス制御）
　◯ 担当が 終わったら 見えなくなる（Assignment.endedAt）
　◯ 連絡は 90日で 消える
　◯ 録音を 捨てる。★動画を 持たない
　◯ 中身を こちらで 読み取って 調べない
　◯ 運営の画面から 健康の記録へ 行けない
```

★**これは、たいていの製品より 強いです。**
★**弱いのは 中身では なく、「書いた紙が ない」ことです。**

# §4 ★いま いちばん大きな 穴 3つ

## 4-1 ★閲覧のログが ありません（★今日 私が 作った穴です）

```
　★今日、★運営の方が 門下の連絡を 読める、と 決めました。
　★★誰が いつ 何を 読んだかの 記録が ありません。
```

★**「読めるが、読んだ記録が 残らない」は、いちばん 危ない形です。**
★学校の情報システム課は、**必ず ここを 突きます。**

```
　★足すもの　★運営の方が 門下の連絡を 開いたら、1行 残す
　　　　　　　★誰が・いつ・どの門下を
　★★そして、★先生と学生の画面から その記録を 見られるように します
　　　　　　　（★「読まれたかどうか」を、書いた人が 確かめられる）
```

★**これを足すと、③の画面の「読むだけです」が、★証明できる約束になります。**
★手間は **1日** です。★見本③に 入れ直します。

## 4-2 ☐ 保管の場所（国）が、確かめられていません

```
　★データベースが 日本にあるか、海外にあるか。
　★★海外なら、外国にある第三者への提供（法28条）の 話が 出ます。
　★学校は、ここを 必ず 聞きます。
```

★**Code へ：★Supabase の リージョンを 確かめて、1行 返してください。**
★（★東京なら、話が とても 楽になります）

## 4-3 復旧の 目標が ありません

```
　★止まったら、いつまでに 戻すか。★決めていません。
　★2,570人が 使う日程表は、★止まると 授業が 止まります。
```

★いまは 1人です。**「24時間以内」と 約束できません。**
★**だから レベル1 の 7 で、★正直な数字を 書きます。**
★**書いていない約束より、控えめでも 書いた約束のほうが 強いです。**


# §6 ★では、9月15日に 何と 言うか

★**「お受けしていません」を、そのまま 言わないでください。**
★9月15日に会う学校は、たぶん 1,000人を 超えません（声楽科なら 216人ほど）。

★**聞かれたときだけ、こう答えてください。**

```
　「いまは、名簿1,000人までで お受けしています。
　　★体調の記録は、法律で とくに 大切に扱うと 決められた情報です。
　　★お預かりする量が 増えるほど、体制の証明が 要ります。
　　★安全管理の一覧と、事故のときの手順は、★書面で お渡しできます。
　　★プライバシーマークは、★2027年度に 検討しています。」
```

★**「できません」ではなく「ここまでは できます、その先は こうします」です。**
★**そして 最後の2行が あるかどうかで、印象が まったく 変わります。**
★**だから §2 の 8点を、★9月15日より 前に 1つでも 作っておきたいのです。**
