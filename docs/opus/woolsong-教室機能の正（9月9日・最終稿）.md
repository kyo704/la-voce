# §1 器 ── 誰がいるのか

```
Organization（教室・学科・養成所）
   ├── Membership   その教室の ★先生や事務
   ├── Enrollment   その教室の ★生徒
   └── Assignment   ★どの生徒を、どの先生が担当するか
```

**3つとも 多対多です。**

```
・1人の生徒が、同じ教室の複数の先生につく（声楽＋コレペティ＋演技）
・1人の生徒が、複数の教室に所属する（音大＋個人レッスン＋養成所）
・1人の先生が、複数の教室に所属する（掛け持ちの講師）
```

## 1-1 役割 4つ

| 役割 | できること |
|---|---|
| **owner** | 契約者。お金・名簿の増減・教室を閉じること |
| **admin** | 管理を任された先生。お金以外は owner と同じ |
| **teacher** | 自分の担当生徒だけ。運営の面は見えない |
| **staff** | **事務。日程と出欠だけ。★健康に関するものは一切見えない** |

★**staff を必ず作ってください。** 事務の人を「先生」として登録されると、分けたはずの権限が意味を失います。
★**個人の先生は「1人だけの教室」です。** 別の仕組みにしません（`kind:'solo'`）。

## 1-2 ★担当を外れたら、過去の分も見えなくなります

```
Assignment.endedAt が入った時点で、★その先生からは 何も見えなくなります。
★「担当だった期間の分は見られる」を 作らないでください。生徒に説明できなくなります。
```

## 4-5 振替（★まだ作っていません・教室運営の本丸）

```
① 生徒が「休みます」を送る（定型連絡。★理由は聞かない）
② 振替の対象かどうかを、教室のルールで自動判定
③ 対象なら、担当教師の空きから ★候補日を3件
④ 生徒が1つ選ぶ
⑤ 教師が承認 → 確定 → レッスンが作られ、消化回数が更新される
⑥ カレンダーのフィードに反映
```

★**②〜③の自動化が 価値の中心**です。「振替の記録を残す」ことが目的ではありません。

★**欠席の理由を聞きません。**「体調不良のため」を選ばせると、健康情報を教師に渡すことになります。
　当日欠席と事前連絡の区別は、**理由ではなく 連絡した時刻**で判定できます。

```ts
interface MakeupPolicy {
  orgId: string; enabled: boolean
  deadlineHours: number      // 何時間前までの連絡なら振替可（例 24）
  validWithinDays: number    // 振替の有効期限（例 60 ／ 当月内なら31）
  maxPerTerm: number         // 期間内の振替回数の上限
  carryOver: boolean         // 未消化を翌月に繰り越すか
}
```

★**既定値は控えめに。Woolsong が「正しい振替ルール」を決めないでください。**

## 6-1 門下の連絡板

```

     ＝ ★Assignment（teacherId, studentId, endedAt）で すでに表現できている
```

| 見える人 | 見えない人 |
|---|---|

★**90日で自動的に消えます。**
★**名前は「掲示板」ではなく「連絡」です。**（伝えることがある人が使う場所）

### ★いちばん大きな危険 ── 体調が、ここから漏れます

```
学生が書く「今日は喉の調子が悪いので、レッスン休みます」
　→ 誰も約束を破っていません。学生が自分で書きました。
　→ しかし 体調のことが、先生と門下の20人に伝わりました。
　→ 次の学生は「休むときは理由を書くものだ」と学びます。
★「記録は見られない」が、機能としてではなく 習慣として、静かに嘘になります。
```

**対処（3つとも実装してください）**

```
① 投稿欄の下に、常に1行
　　★「ここに書いたことは、門下の全員と先生が読みます。
　　　　体調のことは、書かなくて構いません。」
② 欠席の連絡を、連絡板に書かせない（連絡板に「休みます」の導線を作らない）
　　★定型連絡は、先生1人にしか届きません。門下の20人には届きません
③ ★投稿の中身を、サーバーが検査しない
　　「体調の語を検出して警告する」を作らないこと。サーバーが全員の投稿を読むことになります
```

★**①の一行が、実際の守りです。** 安く、正直で、これ以上のものはありません。

## 13-1 ★「記録・分析まわり」を作らない理由

| 作らないもの | 理由 |
