# RULING 186 — 門下を 誰が決めるか（3通りから 学校が選ぶ）

```yaml
ruling: 186
date: 2026-09-23
version: design-v38
from: 坂本さんの指摘（2026-09-23）
  「学生を信じて 自分で担当の先生を選ばせてもよい。担当は あらかじめ知らされている」
  「事務が選ぶ／先生が選ぶ／生徒に選ばせる を 選べるようにした方がいい」
extends: 裁定138・139・185
```

## 0. いまの姿（本番）

```yaml
① ★事務が作る（assignments に 名簿の札で 書く）
② ★先生が招く（teacher_invitations → 学生が 受ける）
★学生が 自分で選ぶ道は ありません
★そして 裁定185 で「回を始めるのは 事務か先生」としたため、
  ★先生20人の学校では 事務が 20回 同じ画面を開くことになります（★負担）
```

## 1. 決定 ── 学校が 3つから 選ぶ

```yaml
設定（学校の形）に「門下の 決め方」を 置く。★既定は ㋑
  ㋐ ★事務が 決める      名簿から 組む。学生も先生も 触らない
  ㋑ ★先生が 招く（既定） 先生が 招き、学生が 受ける（いまと同じ）
  ㋒ ★学生が 選ぶ        学生が 一覧から 担当の先生を 選ぶ
★㋒のとき、★先生の承認が 要るかどうかを さらに選べる（★既定は 要る）
  ★承認なしにできるのは、★学校が「担当は すでに 決まっている」と 言える場合だけ
```

## 2. ★なぜ ㋒に 承認を 既定で置くか

```vaml
★門下になると、★その先生の レッスン割の 対象になります（先生の 予定が 埋まる）
→ ★先生が 知らないうちに 生徒が 増えるのは、先生の 時間を 勝手に 使うことです
★ただし 承認は「拒む」ためではなく「★気づく」ためのもの:
  ★1タップ。理由は 聞きません。★保留のままでも 学生は 困りません（希望は 出せる）
★学校が「担当は 入学時に 決まっている」と言えるなら、★承認なしにしてよい
  （音大は ほとんど これです。★だから 選べるようにします）
```

## 3. ★見えるもの・見えないもの（変えない）

```yaml
★どの決め方でも、★先生は 学生の 体調の記録を 見られません（裁定138）
★学生が 選ぶときに 見えるのは: ★先生の名前・担当している人数（★多い順では 並べない）
  ★空いている／埋まっている は 出しません（★「人気の先生」を 作らないため）
★学生が 自分で 外すことは できません（★外すのは 事務か 先生）
  理由: ★レッスンが 進んでいる途中で 外れると、先生の 予定が 崩れます
```

## 4. ★事務の負担への答え（裁定185 の直し）

```yaml
★「回を始める」で ★先生を 複数選べるようにします
  期間・締切・回数・置き方は 共通。★先生ごとに 回が 1つずつ できます
  → 20人でも ★1回の 操作で 済みます
★回数が 先生ごとに 違うとき（学部12回・院15回 など）は、
  ★始めたあと 一覧で 直せる（★始めるときには 分けない）
```

## 5. VERIFY

```yaml
- 設定に「門下の 決め方」があり、★既定は「先生が 招く」
- ㋒にする → 学生の画面に「担当の 先生を 選ぶ」が 出る
- ㋒＋承認あり → 先生に「受けますか」が 出る。★保留でも 学生は 希望を 出せる
- ㋒＋承認なし → 選んだ時点で 門下になる
- ★どの決め方でも 先生は 体調の記録を 見られない
- ★学生の画面に「空き」「人気」は 出ない
- 回を始める: ★先生を 複数選べる。★1回の操作で 人数ぶんの 回ができる
```
