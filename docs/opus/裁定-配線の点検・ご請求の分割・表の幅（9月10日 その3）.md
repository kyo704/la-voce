# §2 ★ご請求 ──「見る」と「払う」に 分けました

## 2-1 ★なぜ 分けるか

```
　★見たい人は 多いです（★予算・人数・来月の 見込み）。
　★★でも <b>払う</b>・<b>カードを 変える</b>のは、そう ではありません。
　★1つの つまみだと、「見せる」ために「払える」まで 渡すことに なります。
```

## 2-2 ★いまの 決まり（★学校が 変えられます）

| | 学長 | 副学長 | 事務長 | 学部長 | 学科長 | 課長 | 職員 | 先生 |
|---|---|---|---|---|---|---|---|---|
| ご請求を **見る** | ● | ● | ● | ● | ○ | ● | ○ | ○ |
| ご請求を **払う** | ● | ○ | ○ | ○ | ○ | ○ | ○ | ○ |

```
　★見るのは 何人でも 持てます。
　★★<b>ご請求の あて先（名義）だけが 1人</b>です。
　★　（★引き継ぎには、いまの あて先の 方の 承諾が 要ります）
　★見るだけの 方には「★あなたは 見るだけです／払えるのは 学長」と 出します。
　★★領収書は、見られる方 みんなが 出せます。
```

## 2-3 ★★これは 安全のためでも あります

```
　★★事務長に「払う」を 渡すと、★<b>事務長が 学長を 作れて</b> しまいます。
　　（★決まり ──「自分が 持っているものは、人に 渡せる」）
　★→ ★事務長は <b>見るだけ</b>に しました。
　★→ ★学校が どうしても 渡したければ、★学長が 役職の 画面で 渡せます。
```
