## 0 何が 問題だったか

```
いままでの 書き方
　400円の 根拠：「しらべる」年額 4,800円 ÷ 12
```

★★消費者契約法 9条1項1号の「平均的な損害」は、
★**その事業者に 生じる 損害**が 基準です。

★★★**他社の 価格でも、★別サービスの 価格でも ありません。**

★「しらべる」は 別の 商品です。★その 価格が、
★「一年のよそおい」の 利用権の 価値を 表す 必然性が ありません。

## 1 ★直したあとの 書き方

```
一年のよそおい　12,800円（税込）・1回払い

　★内訳
　　デジタルアイテム 244点　　　8,000円
　　1年間の 利用権　　　　　　　4,800円
　　　　　　　　　　　　合計　 12,800円

　★244点は、お支払いの 日に お渡しします。返品は できません
　★★利用権は、1か月あたり 400円（4,800円 ÷ 12）
　★途中で おやめに なる場合、★未経過の 月数 × 400円を お返しします
```

★★★**数字は 変わりません。★根拠だけが 自社の ものに なります。**

## 2 ★なぜ この 形が 通るか

```
★買い切りの 部分（244点・8,000円）
　★お渡しした 時点で 履行が 終わります
　★中途解約の 返金の 対象に なりません
　★「返品不可」を はっきり 書けば 有効です
　　（特定商取引法 15条の3 ただし書）

★★利用権の 部分（4,800円）
　★継続的な 役務の 性質が あります
　★月割で お返しします
　★★4,800円 ÷ 12 ＝ 400円。★これが「平均的な損害」の 算定です
```
