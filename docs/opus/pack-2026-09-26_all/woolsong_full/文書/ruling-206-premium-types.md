## 1. ★なぜ「出すときに」か

```yaml
★★選ぶ ときに 取ると:
  ★中身を 入れてみないと ★似合うか 分かりません
  ★★「買ってから 違った」が 起きます
★★出す ときに 取ると:
  ★★中身を 入れて、★下見で 見て、★それから 決められます
  ★★お金を 払う ときには ★もう 出来上がっています
★★ただし ★選んだ ときに ★必ず 言います（★上の ②）
  ★★言わずに 作らせてから 請求するのは ★不意打ち です
```

## 3. ★★その型だけの 飾りを 出さない

```yaml
★★坂本さんの ご指摘:
  「ホームページの カスタム機能に、★それらだけにしか 使われていない
   ★画像の 大きさや 配置方法は 出さないで」

★★そのとおりです。★理由を 書きます:
  ★★出すと ★「どの型でも できる」と 思わせます
  ★★無料の 型で 選んでも ★何も 変わりません ── ★嘘に なります
  ★★カスタムの 一覧が 長くなり、★探しにくく なります

★★決め方:
  ★★2つ以上の 型で 使う もの → ★カスタムに 出す
  ★★1つの 型でしか 使わない もの → ★出さない（★その型の 中に 埋める）
  ★例: ★Maison の「写真を 全面に 敷く」── ★Maison だけ → ★出さない
      ★「写真の 形（丸・角丸・四角）」── ★多くの 型で 使う → ★出す

★★台帳: page_template_slots に すでに ある 形（sql/87）
  ★★型ごとに「置ける もの」を 宣言します
  ★カスタムの 一覧は ★「2つ以上の 型に ある もの」だけ
```
