## §2 新しい形

```
入る            ★メールアドレス ＋ パスワード
                  ずっと使える。★変更できる。端末が覚える

パスワードを忘れた ★6桁をメールに送る → その場で新しいパスワードを決める
                  （＝ いまの「再設定」を、リンクではなく6桁にしたもの）

メールも失った    ★復旧コード（登録時に1回だけ表示・控えてもらう）

入ったあと        ★長いセッション。自分で出るまで入ったまま
                  ★書き出し・削除・メール変更・復旧コード再発行のときだけ、確かめる
```

★**入口は1つのままです。** 6桁は入口ではなく、**入口の鍵をなくしたときの道**になります。

★「1時間で切れる」も、これなら普通のことです。**再設定の道は、短命でよいのです。**

## §4 ★いちばん効くのは、ここです

パスワードを主にするなら、**端末に覚えさせないと意味がありません。**
そして、覚えさせるかどうかは、**HTMLの書き方で決まります。**

```html
<!-- ログイン -->
<form>
  <input type="email"    name="email"    autocomplete="username">
  <input type="password" name="password" autocomplete="current-password">
  <button type="submit">入る</button>
</form>

<!-- 新規登録 -->
  <input type="password" autocomplete="new-password">
```

★守ること。

```
□ ★本物の <form> にする（div にボタンを置くだけだと、保存されません）
□ ★submit のボタンにする
□ ★autocomplete を正しく書く
　　→ これを外すと、★パスワードでも自動入力されず、6桁より遅くなります
```

★**ここを外すと、この判断の意味が全部消えます。** 見張り検査に1行足してください。

```
□ 実機で、パスワードが保存され、★Face ID で入れること
```
