# 裁定 ── 役職への 一本化ほか 7点

**★いちばん大きいのは §7 です。「役割」という 考え方を なくしました。**

---

## 1　長さの ボタンを「オプション」に

```
　日程を 組む →（置いた枠を 押す）→「オプション（長さ・場所・くり返し）」

　画面の いちばん上に、いつも この2行
　　★ここから 下は オプションです。
　　　決めなくても、レッスンは 置かれています。

　見出しも すべて
　　オプション ── 長さ ／ オプション ── 場所 ／ オプション ── くり返し ／ オプション ── いつまで
```

★**置いた その瞬間に、レッスンは 成立しています。**
★**長さも 場所も、あとから いつでも 決められます。**

---

## 2　長さは スワイプ、期間は カレンダーだけ

```
★長さ　★スワイプの ホイール（時間 0〜4 ／ 分 0〜59）
　　　　★1分きざみ。上に いまの 長さが 大きく 出ます
　　　　★「30分／45分／60分」の 決め打ちボタンは やめました

★いつまで　★カレンダーだけ（★押し間違いを 防ぐため）
　　　　　　★「2027年3月31日」などの 決め打ちボタンは やめました
　　　　　　★前の月・次の月に 動けます
```

---

## 3　門下の 名簿を 学年の 順に

```
　★学年で 並べます（★並びは 設定の 学年マスタの 順）
　　佐々木 りん　声楽1年
　　山口 そら　　声楽1年
　　小林 あきら　声楽1年
　　大野 ひかる　声楽2年
　　…
　★同じ学年の 中は 五十音順
　★画面の上に「★学年の 順に 並べています」と 書きます
```

★**代表を 決める画面・時間割の 集まり・日程を 組む画面の 名簿 ── ぜんぶ 同じ 並びです。**

---

## 4　受診用の 一文を 弱めました

```
　✕ ★これが 無いと、紙の 意味が ありません。　←★強すぎました。消しました
　◯ ★この 2つだけで、1枚に できます。
　　  見出しも「かならず 入るもの」→「はじめから 入っているもの」に
```

★**「足さないと 意味が ない」と 読ませない。**
★**2項目のままでも、それで 完成です。**

---

## 5　【不具合】羊の「配置を 変える」が 押せなかった

**★私の 作りの 誤りです。**
引き出しを 開けたとき、画面ぜんぶに 透明な 覆いを かけていました。
**★覆いを 押したことになり、引き出しが 閉じて 全画面に 戻っていました。**

```
★直したこと
　★したくの ときだけ、覆いを かけません（★部屋が そのまま 押せます）
　★「配置を 変える」を 押すと ──
　　　引き出しが「おくもの」に 切り替わり、
　　　★上に 7か所の 帯（まど・かべ1・かべ2・たな・つくえ・いす・ゆか）が 出ます
　　　★場所を 選んで 品物を 押すと、その場所に 置かれます
　★閉じるのは「おわり」「これでいい」だけ（★事故で 閉じません）
```

---

## 6　学年を 足したり 消したり

```
　設定 →「学校の かたち」→ ★学年
　　1年／2年／3年／4年／修士1年／修士2年／博士1〜3年／研究生 …
　　★足す・消す。★早押しの 候補も 置きました
　　　（修士1年・修士2年・博士1年・研究生・専攻科・別科・
　　　　初等科・中等科・本科・専科）

　★行事の「対象 ── 学年」からも、その場で 足す・消すへ 行けます
　★使われている ものは 消せません
```

---

## 7　★★役職に 一本化しました（★「役割」を なくしました）

### 7-1　何を やめたか

```
　✕ 役割　　代表 ／ 教室の責任者 ／ 先生 ／ 事務　←★この 4つを 消しました
　✕ 役職　　学長 ／ 学部長 ／ 教授 ／ 事務長 …　←★ただの 呼び名でした

　◯ ★役職が そのまま「できること」です。★2つ あった ものを 1つに しました
```

★**理由：**同じ人に「役割：教室の責任者／役職：学科長」の 2つが 付いていて、
★**どちらが 効くのか、画面から 分かりませんでした。**

### 7-2　できること（12個）

```
★学校ぜんぶに かかる もの（8つ）
　　ご請求を 見る・払う
　　学校ぜんぶの 名簿を 見る・直す
　　学校ぜんぶの 日程を 見る・直す
　　行事を 出す・直す
　　学校ぜんぶへ おしらせを 出す
　　門下を 読むだけ（★開いた記録が 残ります）
　　学校の かたち（学部・学科・学年・分野）を 直す
　　ひとの 役職を 変える

★その方 自身にだけ かかる もの（4つ）
　　自分の レッスンの 日程を 組む
　　自分の 門下に 書く
　　出欠を つける
　　時間の わり方・場所を 直す
```

### 7-3　★タブは「できること」から 決まります

```
　ホーム　　名簿 or 日程 or ご請求 の どれかが ある
　日程　　　日程（ぜんぶ or 自分の）が ある
　名簿　　　学校ぜんぶの 名簿が ある
　門下　　　自分の 門下に 書ける
　行事　　　行事が ある
　連絡　　　おしらせ or 門下を 読む or 門下に 書く の どれか
　設定　　　時間 or かたち or 役職 or ご請求 の どれか
```

★**役職の 中身の 画面に「この役職で 出るタブ」を 出しています。**
★**つまみを 切ると、その場で タブが 変わります。**

### 7-4　★渡せる／渡せないの 決まりは 1つ

```
★★「学校ぜんぶに かかる ことは、自分が 持っていないと 渡せません」

　　→ 学科長は、自分に「ご請求」が 無いので、
　　　 誰にも「ご請求」を 渡せません。★権限の 持ち上げが 起きません。

★ただし「その方 自身にだけ かかる」ものは、持っていなくても 渡せます
　　→ ★学長は 教えなくても、教授に「自分の 日程を 組む」を 渡せます
```

★**画面では、渡せない つまみを 灰色に して、押すと 理由を 出します。**★隠しません。

### 7-5　いま 入れてある 役職（★はじめの ひな型）

| 役職 | できること |
|---|---|
| **学長** | ★12個 ぜんぶ（★ご請求を 持てるのは 1人だけ） |
| **副学長／事務長** | ご請求 以外 ぜんぶ |
| **学部長** | ご請求・役職 以外 |
| **学科長** | 名簿・日程ぜんぶ・行事・門下を読む・出欠・時間 |
| **教授／准教授** | 自分の 日程／自分の 門下／出欠／時間 |
| **講師** | 自分の 日程／自分の 門下／出欠 |
| **課長** | 日程ぜんぶ／出欠／時間／★ひとの 役職を 変える |
| **職員** | 日程ぜんぶ／出欠／時間 |

★**「事務の 一部にだけ 役職変更を 許す」というご要望は、これで 満たしています。**
　★**課長には 付け、職員には 付けていません。**
　★**どの 役職に 付けるかは、大学との ヒアリングで 決められます**（つまみ 1つです）。

★**先生（教授・准教授・講師）には「ひとの 役職を 変える」が ありません。**
　★設定に 役職の 一覧が **出ません**。

★**門下の 代表だけは、この仕組みの 外です。**
　★**その門下の 先生（自分の 門下に 書ける方）だけが 決めます。**
　★学長でも 事務長でも 変えられません。

### 7-6　役職を 足す・直す・消す

```
　設定 →「役職と、できること」
　　★足す　　名前を 打つ → はじめは ★できることが 1つも ない
　　★直す　　名前も、12個の つまみも
　　★消す　　★その役職の方が いる間は 消せません
　　★何人 いるかを 一覧に 出します
```

## ★Code への 注意（この回）

```
★1　★役割（owner/admin/teacher/staff）の 列を ★廃止。
　　　★役職（posts）と、その 権限（12個の 真偽値）に 一本化する
　　　★画面には 役職の 名前だけを 出す
★2　★タブ・画面の 出し分けは ★権限から 導く。★役職名で 分岐しない
★3　★★権限の 確かめは サーバでも 行う。
　　　★「学校ぜんぶに かかる もの」は、付与者が 持っていなければ 拒否する
★4　★ご請求（bill）を 持てるのは ★1人だけ。★引き継ぎは 両者の 承諾を 必要にする
★5　★門下の 代表は 役職の 仕組みの 外。★Assignment.isRepresentative のまま
★6　★レッスンの 長さは ★分の 整数で 持つ（★「45分」の 文字列に しない）
★7　★くり返しの 終了日は 必須。★日付は カレンダー入力だけを 許す
★8　★羊の したくの 覆い（オーバーレイ）を、部屋の 上に かけない
```

# ★追記（同日・さらに 2点）

## 8　【不具合・原因が 分かりました】羊の「したく」が 反応しない

**★私の 作りの 誤りです。★原因は 羊の 画面では ありませんでした。**

```
　★画面の 下に 出る「知らせの 帯」（トースト）が、
　★★消えるまでの 5秒間、その 場所の 押しごとを 受け取っていました。

　　.toast.on { pointer-events: auto }   ←★これが 原因
```

**「したく」は 帯と ちょうど 同じ 高さに あります。**
だから、**何かを 押した 直後の 5秒間だけ、したくが 効かなく なっていました。**
（★間を おいて 押すと 効くので、見つけにくい 不具合でした）

```
★直したこと
　★帯は ★どんなときも 押しごとを 受け取りません（pointer-events: none）
　★「もとにもどす」の 文字だけが 押せます
　★したくの ボタンを、帯より 上に 置きました（z-index）
```

★**Code へ：この 直しは 羊の画面だけの 話では ありません。**
★**帯と 重なる 位置に ある ボタンは、ぜんぶ 同じ 目に 遭っていました。**

---

## 9　★重なり ── 何が 重なっているのか

**★ご指摘のとおりです。「2件」とだけ 出ていて、中身が 分かりませんでした。**
**★そして「同じ 場所」を 見ていませんでした。★いちばん 起きるのに。**

### 9-1　3つに 分けて 出します

```
　★同じ 場所　　同じ 時間に、同じ 部屋を ちがう先生が 使っている
　　　　　　　　★これを いちばん 上に 出します（★いちばん 起きます）
　　　　　　　　9月9日（火）13:30〜15:00　第1教室
　　　　　　　　　① 斎藤 めぐみ　声楽A　高木 みなみ
　　　　　　　　　② 高橋 のぞみ　声楽C　田中 ゆい

　同じ 先生　　その先生が、別の 部屋に 同時に 入っている
　同じ 生徒　　★教室を またいで 見ます（よその 教室と かち合っている）
　（★1日の レッスンが 4件を 超えた ── ★その生徒 本人にだけ、そっと）
```

★**「ぜんぶ／場所／先生／生徒」で しぼれます。件数も 出ます。**
★**行事の リハーサルとの 重なりも、場所の 重なりとして 出します。**

### 9-2　★やらないこと（変えていません）

```
　✕ 自動で 動かす　　　✕ 予約を 断る　　　✕ 空き部屋を 探す
　✕ 部屋の 予約そのもの
　◯ ★印を つけて、人が 決める
　◯ 「このままで よい」で、その1件だけ 印を 消す（★記録は 残る）
```

### 9-3　誰に 出すか

```
　同じ 場所　　両方の 先生と、名簿を 見られる 役職
　同じ 先生　　その先生と、名簿を 見られる 役職
　同じ 生徒　　★生徒本人と、両方の 先生
```

★**Code へ：`場所`（room）の 重なり検出を 足してください。**
★**いまは「先生」と「生徒」しか 見ていません。**
★**部屋は マスタ（MST.place）を 鍵に、同じ 日・同じ 時間帯で ぶつけます。**
