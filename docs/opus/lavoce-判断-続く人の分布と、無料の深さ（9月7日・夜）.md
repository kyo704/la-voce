# 判断：人は何日続けるのか。無料の深さは、どこが適正か
宛先 運営者・実装（Claude Code）／ 差出 Opus ／ 2026年9月7日 夜
調べたもの：継続の実測 8本（うち n=109,914 の研究1本）／ 課金の実測 2本（115,000＋16,000アプリ）／ 習慣形成 4本

# 0. ★先に、運営者のご指摘について

> すべての有料機能を使ってから出なくても、それを楽しみにできるのであれば、
> あえて使わせる前に無料期間が終わっても問題ない

**★このご指摘は、データに支持されています。私が昨日言ったことのほうが、雑でした。**

```
RevenueCat 2026（115,000アプリ）
　体験させずに課金させる（ハードペイウォール）　→ 12か月後の課金者の残り ★27%
　体験させてから課金させる（フリーミアム）　　　→ 　　　　　　　　　　　 ★28%

　★★ほぼ同じです。
　★「体験させてから売ったほうが定着する」という通説は、★支持されていません。
```

```
Loewenstein 1987（The Economic Journal）
　同じ快い体験に、いくらまで払うか
　　いますぐ　1.00
　　3時間後　1.30
　　24時間後　1.59
　　★3日後　1.78　←★最大
　　1年後　　1.31

　★★「少し先にある」ほうが、支払意思が高くなります（savoring）。
```

```
Spotify Wrapped（Sensor Tower）
　年に一度の振り返りだけで、DAU が前日比 ★+13〜14%（2022・2023年とも）
```

★**「楽しみにできるものは、使う前でも売れる」── 正しいです。**
　★私が昨日「空のものは売れない」と言ったのは、**日付と絵のないもの**に限った話でした。

```
✕ 「あと18週たまると出せます」　→ ★日付がない。★絵がない。★ただの借用書
◯ 「去年の11月、あなたはどうしていたでしょう」
　　　→ ★★日付がある。★自分が書いたと知っている。★楽しみになる
```

# 1. ★人は何日続けるのか（実測）

## 1-1 いちばん近い研究 ── ★n = 109,914

```
Pratap et al. 2020, npj Digital Medicine
　8つのデジタル健康研究、★109,914人、約350万タスク

　★継続日数の中央値　5.5日
　★参加者の半数以上が、★最初の1週間で離脱
　★54.6% が「放棄者」群。★その使用日数の中央値は 1日

　★臨床医の紹介　44日　vs　★自分で見つけた人　4日（★11倍）
```

★**臨床医の紹介で11倍になる。これは、大学・教室ルートの価値そのものです。**

## 1-2 記録アプリ全般

```
Baumel et al. 2019, JMIR（93アプリ）　★30日後に残る人の中央値 3.3%
Business of Apps（健康・フィットネス）　★D30 3%
Adjust 2023（健康・フィットネス）　　　 D1 24%　D30 7%
Quettra（1.25億台の実測）　　　　　　  D30 9.55% → ★D90 3.97%
Helander 2014（食事の写真記録・189,770人）★1週間以上続いた人 2.58%
```

## 1-3 ★うちに当てはめた、正直な分布

```
入れた人を100とすると

　1日目　　  25人ほど
　7日目　　  12人ほど
　30日目　　  5人ほど
　90日目　　  3人ほど
　180日目　   2人ほど
　365日目　   1人ほど
```

★★**壁を3か月に置くと、★そこに到達する人は「100人中3人」です。**
　★壁を7日に置くと、★12人です。**4倍ちがいます。**

## 1-4 ★「D30以降は横ばい」は、嘘でした

★私は、そう思い込んでいました。**一次資料では確認できませんでした。**

```
Quettra の実測　D30 9.55% → D90 3.97%　★58%減っています
```

★そして、**平らに見えるときの理由が、思っていたのと逆でした。**

```
Fader & Hardie 2018（Journal of Interactive Marketing）
　★平坦化は「残った人が強くなった」からではありません。
　★「やめやすい人が先に抜けた」からです（sorting effect）。
　★個人レベルの離脱の危険は、★むしろ上がっている場合があります。
```

## 1-5 ★もう1つ、設計に効く発見

```
medRxiv 2026（214人・4か月・26,907件のチェックイン）
　★残っている人の記入率は、★17週にわたって 71〜91% で安定。★下がりません。

　★★記録アプリの敵は「だんだん雑になること」ではありません。
　　★「ある日ぱったり辞めること」です。
```

★**「続けやすくする」より「辞める日を作らない」ほうが効きます。**
　★これは、うちの決まり（急かさない・連続記録をやめる・休む日を作る）を裏づけます。

```

```

★**だから、深さは「収益のため」ではなく「まっとうさのため」に決めるべきです。**

# 4. ★7日は、短すぎます。理由は3つ

```
① ★すでに決めてある解禁日数と、噛み合っていません
　　Lv5 = 28日で開く分析があります。
　　→ ★28日目に開いた画面が、★7日ぶんしか映しません。
　　→ ★★「開いた瞬間に、ほとんど見えない」

② ★「気づき」を、無料では一度も見られません
　　文章を出してよい条件（各群10以上）は、実際に ★40〜60日かかります。
　　→ ★7日の窓では、★通ったものが表示される場所がありません。
　　→ ★★無料版が、★一度も価値を証明しません。

③ ★調べた17本の、★どれよりも短いです
　　Bearable 30日 ／ Hevy 3か月 ／ MyFitnessPal 2年
　　→ ★7日は、★業界で最も厳しい設定です。
　　→ ★MyFitnessPal（2年）ですら「自分のデータなのに」と叩かれています。
```

# 5. ★私の答え ── 60日

## 5-1 下限と上限

```
下限 ★60日　★これ以下だと、無料版が一度も「気づき」を出せません（§4-②）
上限 ★5か月　★これ以上だと、週の集計（22週）が無料に入り、有料が空になります
```

## 5-2 その間で、どこでもよい理由

```
★60日でも90日でも、★到達する人数はほとんど変わりません（3〜4人 vs 3人／100人中）。
★そして、収益の85%は ★7日以内に決まっています。

　→ ★★この幅の中では、★数字の精度に意味がありません。
　→ ★★短いほうを採ってください。★★60日です。
```

★**理由は、運営者のご懸念（3か月は長い）が、この幅の中では正しいからです。**
　★60日は、**無料版が一度だけ仕事をする最小の窓**です。

## 5-3 決め

```
◯ ★期間の制限を、一切かけないもの
　　自分が書いた記録そのもの／カレンダー／ノート／レパートリー
　　羊・おうち・持ちもの
　　★全データの書き出し（★GDPR 12条5項。動かせません）
　　★受診用サマリー

◯ ★直近60日（無料）／★全期間（有料）
　　分析画面の傾向とグラフ
　　1週間・1か月・1年のまとめ
　　「前も、こうでした」
　　週の集計
```

# 6. ★体験期間について（Code のご質問 1-a・1-b への回答）

## 6-1 ★9月4日の決まりは、撤回しなくてよいかもしれません

```
9月4日 §1-2 ／ 9月6日 §2
　「体験期間は作らない。★終わるときに、必ず何かを取り上げるから」

　★★この理由は、正しいです。★撤回すべきではありません。
```

★**そして、深さで切ると、★取り上げが起きません。**

```
入会1か月目の人は、★2か月ぶんのデータを ★持っていません。
　→ ★60日の壁は、★その人には ★存在しません。
　→ ★★まだ持っていないものは、★取り上げられません。

★★深さで切ると、★「体験期間」が自動的に生まれます。
　★しかも、★終わる日がありません。★追いつかれるだけです。
```

★**9月4日の決まりは、生きたまま使えます。書き換えは要らないかもしれません。**

## 6-2 ★それでも体験期間を作るなら ── ★目的が違います

```
★体験期間の目的は「機能を体験してもらうこと」★ではありません。
★★「Day 0 の課金画面を、成立させること」です。

　登録の途中で課金画面 ＋ ★体験期間あり　★1.35%
　登録の途中で課金画面 ＋ ★体験期間なし　★0.82%
　　（Adapty 2026・10,000本以上の実測）
```

★**これが、Code のご質問1-b への答えです。**

```
ご指摘　「前も、こうでした」は2回目の本番からしか使えない。
　　　　 本番の間隔は数週間〜数か月。
　　　　 ★どんな体験期間の長さでも、この機能の価値は体験できない。

★★そのとおりです。★そして、それで構いません。
　★体験期間は、その機能を体験させるためのものではないからです。
　★★体験期間は、★支払いのタイミングを作る道具です。

　→ ★体験期間が覆う機能を、★選ぶ必要はありません。★全部で構いません。
　→ ★14日で体験できるものは「分析の深さ」と「まとめ」です。★それで足ります。
```

## 6-3 ★日数

```
体験→課金　★17〜32日 42.5%　／　5〜9日 37.4%　／　4日以下 25.5%
ランダム化実験（n=680,588）　3日→7日で 総課金率 ★+20.9%（p<0.01）
健康・フィットネスの採用　5〜9日が ★54%（最多）
```

★**14日を推します。**★長いほうが良いという方向は、相関と実験の両方で一致しています。

## 6-4 ★書き換えが要る文書（Code のご指摘 1-a）

```
★深さだけで行く場合　　→ ★9月4日・9月6日の決まりは、★そのまま。
　　　　　　　　　　　　　★「体験期間は作らない。深さで自然に生まれる」と1行足すだけ

★体験期間も作る場合　　→ ★書き換えが要ります。★理由も書き換えてください
　　　　　　　　　　　　　旧：体験期間は、終わるときに取り上げる
　　　　　　　　　　　　　新：★体験期間は、支払いのタイミングを作る道具である。
　　　　　　　　　　　　　　　★終わっても、記録は1つも取り上げない。
　　　　　　　　　　　　　　　★見えなくなるのは、深さだけである。
```

# 7. ★「実験公開期間中につき無料」の表記（Code のご指摘 1-c）

```

　★★「期間」と書いてあります。★終わる日があるように読めます。

```

```

　　有料の機能をはじめるときは、前もってお知らせします。
　　記録と、書き出しは、そのあとも無料のままです。」
```

★**「期間」という語を使わないでください。**★終わりを予告すると、始める人が減ります。
