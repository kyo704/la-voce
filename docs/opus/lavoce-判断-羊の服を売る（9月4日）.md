## §3 服は、何を表すか

★買った服が「歌った証」に見えてはいけません。だから、

```
◯ 季節のよそおい（春の上着・浴衣・毛糸の帽子）
◯ 色ちがい・柄ちがい
◯ 小物（めがね・かばん・マフラー）
◯ 部屋のもの（クッション・カーテン・ラグ）

✕ 舞台衣装
✕ 王冠・月桂冠・トロフィーの類
✕ 特定の役を思わせるもの
```

★**舞台のものは、全部 unlock 側です。** 売りません。

## §4 ★ポイントはやめてください ── 法律が1本増えます

有償のポイントは、**資金決済法の「前払式支払手段」**にあたります。
3つの要件を全部満たすからです。

```
価値保存性   サーバに残高が記録される
権利行使性   その残高で服を買える
対価性       ★お金を払って手に入れる
```

★無償で配るポイントは該当しません（対価性がない）。**有償だけです。**

### 何が乗ってくるか

```
① ★情報提供義務（8項目）を、規約か画面に書くこと
   発行者名／利用可能金額／使用期限／苦情窓口／利用可能範囲／
   利用上の注意／★未使用残高の確認方法／約款の存在

② ★基準日（毎年3月末・9月末）の未使用残高を集計すること

③ 未使用残高が★1,000万円を超えたら、財務局へ届出
   ＋★未使用残高の2分の1以上を供託

④ 残高の管理・失効の扱い・返金の按分を、全部作ること
```

★③は当分来ません。**でも①②④は、1円目から来ます。**

### 「6か月で失効」という抜け道について

```
発行の日から★6か月内に限って使えるものは、適用除外です。
```

★使わないでください。理由は2つ。

```
① ★失効するポイントは、利用者に不利です
   この製品は「取り上げない」で通してきました。ここで崩さないこと
② ★未成年に売ります。失効する前払いを未成年に売るのは、いちばん悪い形です
```

### そして

```
★9か月イタリアにいるあいだに、基準日が★2回来ます（9/30・3/31）。
　残高を集計する人が、国内にいません。
```

★**ポイントは、いま作るものではありません。**

## §5 ★推奨A ── 月額に含める（「今月のよそおい」）

いちばん良い形だと思います。

```
　有料プランの方は、★毎月ひとそろい選べます。

　　　　　9月のよそおい
　　　［ 秋の上着 ］［ 木の実のかばん ］［ 栗色のマフラー ］
　　　　　　　　［ これにする ］
```

### なぜこれが良いか

```
① ★新しい決済経路が0本
   ポイントなし。資金決済法なし。Stripe に何も足しません

② ★¥580 の中身が増えます
   本番モードは「本番がある人」にしか効きません。
   ★服は、全員に効きます

③ ★毎月、開く理由が1つ増えます
   「続ける必然性」への、直接の答えです

④ ★解約しても、もらった服は残ります
   取り上げない（原則2）。★罰になりません
   　→ そして「先月の服はある。今月のが選べない」が、続ける理由になります

⑤ ★未成年の問題が起きません（§7）

⑥ ★値上げの理由になります
   ¥580 → ¥680 にするとき、「毎月の服」が説明になります
```

★**⑥を軽く見ないでください。** いま ¥580 で始めて、
グランドファザリングで最初の人は永久に ¥580 です（9月4日）。
値上げするには、**中身が増えた理由**が要ります。服は、その理由になります。

### 作るもの

```
□ 月ごとのセット定義（3点×12か月＝36点）★私が描けます
□ 「今月のよそおい」の画面（1画面）
□ 選んだものを character_inventory に入れる（★理由の文は付けない）
```

★**表は増えません。** 既存の持ち物に入れるだけです。

## §6 推奨B ── セットの都度売り（ポイントなし）

もっと売りたい場合。**単品売りにしないでください。**

```
✕ 「秋の上着 ¥120」
　　→ 端数が出るので★ポイントが欲しくなります
　　→ そして決済手数料が重すぎます

◯ ★「秋のよそおい 5点 ¥480」
　　→ 端数が出ません。★ポイントが要りません
```

```
実装   Stripe に one-time の price を1つ足すだけ
法律   ★資金決済法は乗ってきません（前払いではなく、物の購入だから）
```

★AとBは両立します。**月額の人は毎月1そろい、それ以外に季節のセットを売る。**

```
9月4日に決めました：★未成年に売る個人プランは月額1,000円未満に保つ
　　（民法5条3項・小遣いの範囲に収まる余地）
```

```
月額 ¥580 ＋ 服のセット ¥480 ＝ ★¥1,060
　　→ ★線を超えます
```

★だから、

```
15〜17歳   ★推奨A のみ（月額に含まれるぶんだけ）
　　　　　  ★セットの都度売りを出さない
18歳以上   A と B の両方
```

★これは推奨Aを採る、もう1つの理由です。
