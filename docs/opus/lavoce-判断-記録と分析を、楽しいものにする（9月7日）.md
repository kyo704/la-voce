# §0 私が間違えていたこと

この2日で私が出した文書を数えました。

```
「これを出すな」　　　　　9本
「これを出してよい」　　　1本（的中率）
```

**引き算しかしていませんでした。**
正確さは守れましたが、**その結果できあがったのは「よくできた計器」です。**
計器は、楽しくありません。

そして、私は1つ、大きな見落としをしていました。

```
★記録が本人に返ってくる場所を、★私は「分析画面」1つだと思っていました。
　★だから、返し方の全部に、正確さの制約がかかりました。
```

**返す場所は、2つあるべきでした。**

# §1 ★2つの水路

```
┌──────────────┬──────────────────────┐
│ 水路A　正確さ            │ 水路B　楽しさ                     │
├──────────────┼──────────────────────┤
│ 分析画面                 │ 羊・おうち・庭・持ちもの           │
│ 体についての主張をする   │ ★体について何も主張しない         │
│ → 条件を通ったときだけ   │ → ★条件が要らない                 │
│ 数字・グラフ・文献       │ 物・絵・季節・数え上げ             │
└──────────────┴──────────────────────┘
```

★★**ここが鍵です。**

```
「あなたがいちばんよく書くのは、木曜の夜です」
　　→ ★体についての主張ではありません。★行動についての事実です。
　　→ ★条件が要りません。★そして、面白い。

「よく眠れた日は、声が出やすいです」
　　→ ★体についての主張です。★条件が要ります。
```

**記録の"意味"は規制されますが、記録の"かたち"は規制されません。**
★私は、この2つを分けずに、両方に同じ制約をかけていました。

# §2 記録が、物に変わる ── ★これが本体です

## 2-1 決まりと衝突しない理由

```
連続記録　★禁止（9月1日）── 途切れると失われるから
集めること ★可　　　　　  ── ★集めたものは、減らないから
```

**同じ「たまる」でも、向きが逆です。**
連続記録は「失う恐れ」で動かします。集めることは「増える楽しみ」で動きます。

★うちの決まり（減らない数だけ出す）と、**完全に一致します。**

## 2-2 仕組み

```
記録が30日ぶんたまるごとに、★おうちに物が1つ増える。

　　羊：「30日ぶん たまりました。たなが 1つ ふえました。」
```

```
★予告してあること　　「あと6日で、なにか ふえます」と ★先に言う
　　→ ★いつ来るか分からない報酬は、★依存の作り方です。★やりません
★休んだ日も数える　　「今日は書かない」を押した日も、30日に含める
　　→ ★休むことが損にならない
★止まらない　　　　　書かない日があっても、★たまった数は減らない
```

## 2-3 ★何が増えるかは、その人の記録が決める

**ここが、いちばん効くところです。**

```
夜によく書く人　　→ ランプ／月の見える窓／小さな明かり
本番が多い人　　　→ 譜面台／花束／舞台の写真
レッスンが多い人　→ 楽譜の束／メトロノーム／黒板
眠りをよく書く人　→ ふとん／まくら／ゆたんぽ
外で歌う人　　　　→ 庭の木／ベンチ／鳥の巣箱
落語・語りの人　　→ 座布団／めくり／扇子
```

★**おうちが、その人の記録の形になります。**
　★誰の家も、同じになりません。

```
★評価ではありません。「本番が多いほうが良い」とは言っていません。
★★ただ、その人が何を書いたかが、★部屋の形になるだけです。
```

★内装は**すでに120点あります。**足りないぶんを作ればよいだけです。

# §3 レパートリー ── ★価値と楽しさが、ここだけ一致します

## 3-1 これは分析ではなく、台帳です

```
記録の「扱った曲」を、★ただ集めて並べるだけ。

┌──────────────────────────┐
│ これまでに 歌った曲　　47曲                │
│                                            │
│ Caro mio ben              12回　最後 9/4  │
│ Sebben crudele             8回　最後 8/28 │
│ Che farò senza Euridice    6回　最後 8/12 │
│ …                                          │
│                                            │
│ ［書き出す］                                │
└──────────────────────────┘
```

```
★条件が要りません。★数えているだけです。
★体について何も言っていません。
★そして、★声のプロにとって、本当に要るものです。
```

## 3-2 なぜこれが強いか

```
1  ★オーディションのレパートリー表が、勝手にできています
　　　→ ★書き出せる。★これだけで課金の理由になります

2  ★「初めて歌った日」が残ります
　　　→ 「この曲、3年前から歌っているのか」は、★誰にも作れない喜びです

3  ★他のどのアプリにもありません
　　　Voish も Vocal Pitch Monitor も、★曲名を持っていません

4  ★書くほど増える。★減らない
```

★★**これを最優先で作ってください。**
　★分析より、予報より、先です。

## 3-3 育て方

```
第1段階　曲名の一覧と回数（★これだけで成立します）
第2段階　作曲家・言語・声種でまとめる
第3段階　★「この時期によく歌っていた曲」（季節・年ごと）
第4段階　★書き出し（PDF・オーディション用の体裁）
```

# §4 見つけたこと ── ★条件の要らない発見

**体について主張しないものは、いくらでも出せます。**
★分析画面ではなく、**おうちに置いてください。**羊が言います。

```
【自分の癖】
　「あなたが いちばんよく書くのは、木曜の夜です。」
　「9月に入ってから、19日 書いています。」
　「朝に書く日と、夜に書く日が、半分ずつです。」

【数え上げ】
　「これまでに 47曲 の名前を 書いています。」
　「本番は、これまでに 12回 ありました。」
　「A先生の レッスンは、通算 38回 です。」

【過去の再訪】★これがいちばん効きます
　「4月12日、あなたは『今日は出た』と 書いていました。」
　「1年前の 今日、あなたは 本番でした。」
　「はじめて書いた日から、312日 たちました。」

【季節】
　「去年の いま頃、いちばん よく歌っていたのは Caro mio ben でした。」
```

★**「過去の再訪」は、記録アプリだけができることです。**
　★1年つづけた人にしか出せません。★1年つづける理由になります。

# §5 年の1枚・季節の1枚

```
季節が変わるとき、★その季節の1枚の絵ができる。

　・その季節の部屋にいる羊（★その人の家具・その人の服）
　・書いた日が、庭の花になっている
　・その季節にいちばん歌った曲の名前
　・本番の数
```

```
★点数を出さない。★去年と比べない。★「よく頑張りました」と言わない
★ただ、その季節が1枚になるだけ
★★保存できる。人に見せられる
　　→ ★これが、いちばん静かな広め方になります
```

★年に4回。★12月には「今年の1枚」。

# §6 記録の画面で、何を返すか

いまは、2タップ目で「保存しました」と出ます。**これは領収書です。**

```
◯ 2タップ目で返すもの
　1  羊が すこし反応する（★毎回ちがう。★1文）
　2  ★「30日まで あと6日」（★予告。★毎回同じ場所）
　3  ★到達した日は、物が届く（★ここだけ大きく喜ぶ）
```

```
★★「保存しました」を消してください。
　　★羊が反応すれば、保存されたことは伝わります。
```

---

# §7 ★やらないこと（★楽しくするための、線）

```
✕ ★いつ来るか分からない報酬（★可変比率）
　　→ ★依存の作り方そのものです。★30日ちょうど、と予告します

✕ ★失われるもの（★連続記録・期限つきアイテム・逃したら二度と手に入らないもの）
　　→ ★季節のものは、★来年また来ます

✕ ★他人と比べる（★順位・平均との比較・友だちの記録）

✕ ★通知で呼び戻す（★「あと1日で…」は催促です）
　　→ ★予告は、★開いた人にだけ見せます

✕ ★羊が待っている・寂しがる
　　→ ★羊は一生しあわせに生きています（9月6日・夜）

✕ ★お金で早く進める（★アイテムを買って30日を飛ばす）
　　→ ★装いは別に売ります。★記録から生まれる物は、★売りません
```

★**最後の1つが、いちばん大事です。**
　★記録から生まれる物を売った瞬間に、★記録の意味が消えます。

# §8 分析画面は、どうするか

★**いまのままでよいです。**

```
分析画面は「正確さ」を引き受けます。
　　条件を通ったものだけ。数字と、文献と、疑いの一文。
　　★ここを楽しくしようとしたのが、私の間違いでした。
```

★ただし、**入口を変えてください。**

```
✕ タブに「分析」があり、開くと計器がある
◯ ★おうちに、羊が「見つけたこと」を言う（§4）
　　→ ★そのうち、条件を通ったものだけに「くわしく →」が付く
　　→ ★押すと、分析画面のそのカードに飛ぶ
```

★**分析は、行く場所ではなく、★呼ばれて行く場所にしてください。**
　★これは、既に決まっている「学ぶ」の設計（発見から記事へ飛ばす）と同じ形です。

# §9 作る順番

```
1  ★レパートリー（§3 第1段階）　　★いちばん効きます。★1日でできます
2  ★見つけたこと（§4）　　　　　　★条件が要らないので、すぐ出せます
3  ★記録の画面の返し（§6）　　　　★「保存しました」を消す
4  ★30日で物が増える（§2）　　　　★内装120点が、ここで生きます
5  ★何が増えるかを記録で決める（§2-3）
6  ★季節の1枚（§5）
7  ★分析の入口を、おうちからにする（§8）
```

★1と2は、**今週できます。**そして、この2つだけで、印象が変わります。

# §10 ★1行にすると

```
★正確さは、分析画面が引き受ける。
★楽しさは、おうちが引き受ける。
★★そして、その2つをつなぐのが、
　　「書いたものが、物になる」ことです。
```
