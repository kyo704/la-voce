## §2 坂本さんの指摘は正しい。ただし理由は「機能が少ない」ではありません

**★¥580 は、「分析＝アプリが言うこと」の対価として設計された価格でした。**

```
案A（有料の中身）
　入口：複数指標を並べる／1週間のまとめ／レパートリー表／よそおい月1点
　奥　：気づき(60日)／前も、こうでした／去年の今ごろ／週の集計(22週)
```

このうち「気づき」は、3つの条件（n≥10・|g|≥0.4・q<0.10）を通ったときだけ出る1文です。
**今日計算したとおり、各群10日で小さめの差を捉える確からしさは 13.5%。ほとんど出ません。**

> **★¥580 は、出ないものに値段を付けていました。** 削除17点のせいで薄くなったのではなく、**最初から中身がなかった**のです。坂本さんが「高い」と感じるのは正確です。

## §3 計算：この規模では、価格より人数が効きます

有料に転換した人数 × 価格（月）

| | ¥380 | ¥480 | ¥580 | ¥980 |
|---|---|---|---|---|
| 38人 | 14,440 | 18,240 | **22,040** | 37,240 |
| 60人 | 22,800 | 28,800 | 34,800 | 58,800 |

| 200人 | 76,000 | 96,000 | 116,000 | 196,000 |
| 500人 | 190,000 | 240,000 | 290,000 | 490,000 |

**38人を起点に、下げる効果と増やす効果を比べます。**

```
いま　　　　　 ¥580 × 38人 = 22,040円/月
価格を下げる　 ¥380 × 38人 = 14,440円/月　　　★ −7,600円
人を増やす　　 ¥580 × 58人 = 33,640円/月　　　★ +11,600円 ← 大学1校で20人
両方やる　　　 ¥380 × 58人 = 22,040円/月　　　★ ±0円
```

> ★**¥580 を ¥380 に下げるなら、有料の人が 1.53倍（38人→58人）にならないと、いまと同じ額にすらなりません。**
>
> そして **9月15日の大学営業で20人取れれば、価格を¥200下げるより大きい。**
> 価格に悩む時間より、**8日後の営業資料の点検のほうが、金額として効きます。**

★もう一つ、下げることの非対称性。

```
下げる： いつでもできる。今日できる
上げる： ★既存の利用者に30日前告知が要り、離脱を招く。
　　　　 あすけんは値上げの理由を長文で説明しています
```

**38人しかいない今なら、下げても影響はほぼありません。だからこそ、急いで下げる理由もありません。**

### ★そのときの、無料と有料の線（引き直し）

今日「並べて見せるのは1日目から、条件なし」と決めました。それを全部無料にすると売るものが消えます。
**深さで切ります。**

```
無料　 ならべる（時系列に1本ずつ並べる）
　　　 くらべる ── ★見張り1つ、時間差は「前日」だけ
　　　 全期間の閲覧／書き出し／受診用まとめ／記録

有料　 くらべる ── 見張り5つ、時間差4種（前夜・前日・2日前・当日朝）
¥580   レパートリー表／週の集計／去年の今ごろ／前も、こうでした
　　　 よそおい 毎月1点
```

★これなら、**無料でも原点（自分の原因を見つけること）に触れられます。** そこは壁の向こうに置かない。
そして本気で探す人は、見張りを増やしたくなる。**1日目から差があり、記録が溜まるほど差が開きます。**
