## §15 いま効いている決まり

```
・USING に auth.uid() が出てこないポリシーは、全員に開いている
・OR で繋いだとき、いちばん緩い枝が、そのポリシーの実力
・WITH CHECK では不変性を守れない（USING 側か、トリガーで）
・WITH CHECK を省くと、USING が WITH CHECK として再利用される
・本番に手で当てない。当てたら、その日のうちにリポジトリへ写す
・アプリの中だけの出来事は伝えない。外でも起きることは伝えてよい
・「まだ」を表示しない。増える方向にだけ動かす
・★確かめられないことを、表示しない（★列の名前にも通す）
・約束を書いたら、それを守っている仕組みを、その場で隣に書く
・片方だけ起きるなら、無害なほうが起きるように並べる
・★売らないものの価格を決めない
・★正の側に、写した先を書いておく
```
