## §1 裁定1 ── 食い違い3点

### 1.1 まず、正をどこに置くか

```
★正は「実装」です
　　→ 文書を、実装に合わせます
　　→ ただし、実装が原則に反しているなら、実装のほうを直します
```

★今回の3点は、いずれも実装が原則に反していません
　（職業も出欠も、教室機能に必要なものです）。**文書を直します。**

### 1.2 直す方向の規則 ★新しく決めます

```
「見えるもの」は、★実装より多めに書く
「見えないもの」は、★実装より少なめに書く
```

★間違えたときに、**利用者の不利にならない方向へ倒す**ためです。

```
（危険）実装は職業も渡すのに、文書は表示名だけと書く
　　　　→ ★渡していないと言ったものを、渡しています

（安全）文書に職業も書く
　　　　→ 実際に渡らなくても、誰も損しません
```

### 1.3 (1) 職業

```
★規約 第5条に、職業を足してください
```

### 1.4 (2)「見えません」── A-2 の形に揃えます

★Code の理由づけが正しいです。

```
「見えません」          ★約束です。破れます。9/3に実際に破れました
「見る仕組みはありません」★仕組みの不在です。仕組みが無ければ、破れません
```

★同じ表現を規約に置けば、**同じ事故で規約違反になります。**

★さらに強い形を提案します。

```
（推奨）「本サービスは、指導者・運営者が利用者の体調の記録を
　　　　　参照する★機能を持ちません。」
```

★「見えない」（状態）ではなく「機能がない」（構造）と書きます。
　**A-2 と規約の両方を、この形に揃えてください。**

### 1.5 (3) 出欠 ── A-2 に足します

```
★A-2（同意画面）に、出欠を足してください
```

★理由

```
実装は出欠を先生に見せています
　　→ 規約だけに書いて、同意画面に無いのは★順序が逆です
　　→ 利用者が実際に読むのは、同意画面のほうです
```

### 1.6 ★根本の直し ── 2か所に同じことを書かない

★この食い違いが起きた原因は、**同じ内容が2か所にあること**です。

```
A-2（同意画面）    先生から何が見えるか
規約 第5条         同じこと
　　　　　　　　　 → ★片方だけ直されて、ずれました
```

★直し方

```
docs/legal/consent-scope-ja-2026-09-v1.md を作る
　　★「教室・学校で、誰に何が見えるか」を、ここに1回だけ書く

　　A-2 の画面     ★このファイルから生成する（または同じ文を機械的に貼る）
　　規約 第5条     ★同じ
```

★**7つ目の台帳（利用者に示している約束）に、この行を登録してください。**
　「約束と、それを守っている仕組みを、同じ行に並べる」── 今日決めた規則です。

## §2 裁定2 ── 断言をやめる。ただし例外が1つ

★明文化してください。**校閲の基準にします。**

```
★書かない（仕組みの状態について）
　　「絶対に」「一切」「決して」「必ず」「100%」
　　「〜されません」「〜見えません」

★書く
　　「〜する機能はありません」        ← 構造の不在
　　「現在の仕様では〜」＋版番号        ← 時点を明示
```

### ★例外 ── 自分の行為は、断言してよいです

```
仕組みの状態  ★断言しない  （守れるかどうかが、自分の手の外にあります）
自分の行為    ★断言してよい（守るかどうかが、自分で決められます）
```

```
（○）記録を売りません
（○）広告に使いません
（○）同意なく第三者に渡しません
　　　★これらは「やらないと決めたこと」です。断言できます

（×）先生には見えません
（×）外部に出ることは絶対にありません
　　　★これらは「仕組みがそうなっているはず」です。断言できません
```

★この線引きを、そのまま基準にしてください。

```
自分が「する／しない」を決められることは、断言してよい
仕組みがどうなっているかは、断言しない
```

### 公開中のポリシーの「絶対にありません」

★2026-09-v1 で穏当な形になっているなら、そのままで結構です。
　**さかのぼって直す必要はありません。**版で管理されているので、
　「いつ、どう変えたか」が残ります。

## §3 裁定3 ── 年齢の二段構え

```
15歳  登録の可否・保護者の同意
18歳  先生との連携の可否（★実装済み）
```

★二段構えの理解で正しいです。**ただし、規約に「15歳」と書かないでください。**

★理由

```
坂本さんの回答は「別途お知らせします」で維持、でした
　　→ 15歳と書くと、★決めたことになります
　　→ そして15歳未満の保護者同意の仕組みは、まだ作っていません
　　→ ★また「書いたのに、無い」を作ります
```

★規約 第2条の書き方（推奨）

```
　お子さまのご利用については、別途お知らせします。

　なお、現在の仕様では、18歳未満の方は
　指導者との連携を行うことができません。
```

★これで

```
・実装にあるもの（18歳）は、正しく書けます
・まだ決めていないもの（15歳）は、書きません
・そして★「別途お知らせします」の期限は、教室プラン販売前です
```

★**この保留は、記録に残してください。**

```
15歳未満の保護者同意の仕組みが無いことは、
★保留しているあいだ、問題として続いています
　　→ インシデントではありませんが、★既知の未対応として台帳に載せる
```
