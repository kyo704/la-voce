# 0. ★これは「かわいさ」の話ではありません。記録率の話です

記録アプリで、いちばん大きい摩擦はこれです。

```
★悪い日を、書きたくない。
　　書くと、画面が暗くなるから。
```

**羊が、何を書かれても、しあわせなままなら、書く重さが消えます。**

```
9月6日に確かめられた、唯一のもの
　★記録すること自体に効果がある（d=0.40、95%CI 0.32–0.48、k=138、N=19,951）

　→ ★効果は「書いた回数」に乗ります。
　→ ★書きやすさを上げることが、そのまま効果を上げます。
　→ ★★「羊が一生しあわせ」は、この効果を最大にするための機構です。
```

★かわいいから、そうするのではありません。**そのほうが、効くからです。**

```

✕ 落ち込む　　　しょんぼりした顔・うつむき・涙
```

# 2. しあわせ ＝ ずっとニコニコ、ではありません

```
✕ 常に上機嫌・常にハイテンション
　　→ ★不気味です。★見ているほうが疲れます

◯ ★おだやかな幸福
　　ぼーっとしている／昼寝している／窓の外を見ている
　　お茶を飲んでいる／転がっている／なんとなく庭にいる
　　→ ★これも、しあわせです
```

★**静かでいいのです。**「何もしていない」は、しあわせの一つの形です。

# 3. ★台詞の中心を、移します

```
✕ これまで　「あなたは、こうでした」　←　ユーザーの話しかしない
◯ これから　★「ぼくは、きょう、こうしていました」　←　羊の話を足す
```

**なぜこれが効くか。**

```
1  ★無限に作れます（★台詞の数で差別化する、という今日の決定に直結）
2  ★ユーザーを評価しません。羊の話なので、評価のしようがありません
3  ★開くたびに違う。★「今日は何していたかな」で戻ってきます
4  ★着せ替えと掛かります。着ているもの × 季節 × 部屋 × 天気
```

## 台詞の型（★4つ。この4つだけで組んでください）

```
型A　羊の今日　　★いちばん多く出す
　　　「きょうは、まどの ところに ずっといました。」
　　　「あたらしい ぼうしが、すこし おおきいです。」
　　　「にわの はなが、ふえていました。」

型B　あいさつ　　★短く。★間があいても、同じ言い方
　　　「おはようございます。」
　　　★「ひさしぶり」「待っていた」は使わない

型C　書いたことを返す　★事実だけ。★評価しない
　　　「きのうは、よく眠れたと書いていましたね。」
　　　★「よかったですね」「えらいです」は付けない

型D　そばにいる　★不調の日。★心配ではない
　　　「きょうは、ここにいます。」
　　　「よこに います。」
　　　★★「大丈夫ですか」とは聞かない。★聞くと、答える義務が生まれます
```

# 4. ★場面ごとの、正しい振る舞い

| 場面 | ✕ してはいけない | ◯ 正しい |
|---|---|---|
| **予報を外した日** | 「はずしました。ごめんなさい」 | ★何も言わない。ふつうの型Aを言う。（数字が数えています） |
| **予報が当たった日** | — | ★すこし喜ぶ。「あ、あたりました。」★毎回は出さない |
| **的中率が低いとき** | 「あてにしないでください」 | ★数字だけ出す。★羊は何も言わない |
| **「出づらい」と書かれた日** | 悲しい顔・「大丈夫ですか」 | ★型D。★顔は変えない |
| **10日ぶりに開いた日** | 「ひさしぶりですね」 | ★「おはようございます」＋型A。★間があいたことに触れない |
| **本番の前日（D-1）** | 予報・励まし・助言 | ★型A。★「あしたですね。」まで。★「がんばって」は言わない |
| **本番のあと** | 「どうでしたか？」 | ★D+1 の質問は画面が出す。★羊は型A |

| **記録が0件のとき** | 「はじめましょう！」 | 「はじめまして。」＋型A |
| **課金しなかった** | — | ★一度も触れない |
