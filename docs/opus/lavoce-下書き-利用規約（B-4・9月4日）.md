## §0 ★同じ嘘が、2か所にあります

```
/billing        「14日間無料、お試し後は自動的に有料移行」
利用規約 第3条  「無料お試し期間終了後、月額料金が発生する有料サービスです」
                「解約手続きが行われない限り、契約は自動的に更新されます」
利用規約 第4条  「解約時点までの利用料金は返金されません」
```

★アプリは、いま無料で動いています。**3か所とも、事実と違います。**

★これは書き間違いではありません。**構造です。**

```
有料前提のテンプレートを入れて、無料のまま公開している
　　→ 1か所直しても、他が残ります
　　→ ★料金に触れている箇所を、全部まとめて直してください
```

★重さについて

```
/billing   画面の文言
利用規約   ★契約の文書
```

★利用者は「解約しないと課金される契約」に同意しています。
　実際には課金されていないので、**お金の被害はありません。**
　しかし、**「課金されると思ってやめた人」がいた可能性は、消えません。**

★これで、B-4 の公開を急ぐ理由が1つ増えました。
　**弁護士確認を待たない判断が、さらに正しくなりました。**
