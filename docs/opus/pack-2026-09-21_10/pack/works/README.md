## ★人の目で確かめてほしいところ

```yaml
- オペラの番号の立て方（版によって省く番号がある。台帳には入れてあり、公演ごとに外す）

- 組曲は「よく演奏される版」で入れた（火の鳥1919年版・ペールギュント第1組曲 など）
```
