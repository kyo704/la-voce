
```yaml
RULE:
  お試し: 15型すべて、自分の中身で見られる（Woolsong 未加入でも見られる）
  含む: Woolsong（年3,600円）で1型
  選び直し: はじめの14日間は何度でも無料。その日に使っている形が「持っている形」になる
  追加: 14日を過ぎたら、別の形は1型 480円（税込）の買い切り
  行き来: 一度持った形は、いつでも無料で行き来できる（戻るときにまた払わない）
  無料のまま: 色・書体・写真の形・余白・節の順番（型の中の調整）
  分野を変えたとき: 新しい分野の形を1つ無料（分野ごとに1回）
  やめたとき: 買った形は残る。再開したらまた使える（取り上げない）

WHY_NOT_CHANGE_FEE:  # 坂本さん案「変えるたびに払う」から組み替えた理由
  - 最初の1回で選び間違える人が多い（公開してから気づく）
  - 前の形に戻るときにまた払う形は、損をした気持ちが強く残る
  - 主なサービス（Squarespace は無料で変更、Wix は変更不可）に変更料の例が無い
  → 「変更料」ではなく「持ち物が増える」形（よそおいと同じ考え）

PAPER: 紙の形（12型）は別。いつでも無料で変えられる（坂本さん承認）
  reason: 出す先で使い分けるのが正しい使い方（日本の音大ならクラシック、欧州ならミニマル）

LEGAL:
  特商法の表示: 1型480円・買い切り・引き渡し後の返品不可を、買う画面と料金ページに
  App Store: アプリの中で売るなら IAP（15%）。480円 → 手取り 408円

MOCK（2026-09-21）:
  あなたのページ → ページの形：持っている形／ほかの形（無料 or 480円）
  ページの形を見る：お試し（点線の枠）→ この形にする／買う（板でたずねる）
  見本だけのスイッチ：選び直し期間を過ぎたことにする
  ★ブラウザで確かめた（お試し中は無料で入れ替わる → 期間後は480円 → 買った形へ無料で戻れる
    → 分野を変えたら1つ無料・2つ目は有料 → 紙は無料と表示）

VERIFY:
  Q1: 14日以内は、何度変えても請求が無い
  Q2: 14日後、持っていない形に変える前に必ず値段が出る
  Q3: 持っている形へは、何度戻っても請求が無い
  Q4: Woolsong をやめて再開したら、買った形がそのまま使える
  Q5: 紙の形の変更で、請求が1度も出ない
```
