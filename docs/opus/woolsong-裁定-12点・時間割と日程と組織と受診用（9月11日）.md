## 11　★大人数の 振り分け ── 私の 案

**ご質問「学校が 振り分ける」か「本人が 選ぶ」か。★答えは 両方です。**

```
★★「本人が 選ぶ → 学校が 確かめる」

　① 招くとき　学校が 分かっていれば その場で 入れる（★一括でも）
　② 分からなければ 空のまま 招く
　③ ★本人が 入るとき、学部・学科・学年（事務なら 分野・役職）を 自分で 選ぶ
　④ ★本人が 選んだものには「未確認」の 札が つく
　⑤ 責任者が 一覧で「未確認だけ」を しぼって、まとめて 確かめる
```

**理由は 3つです。**

```
　★1　2,570人の 学校で、学校が 全員ぶん 入力するのは できません
　★2　しかし 本人任せだと、★ご請求の 人数と 食い違います
　★3　だから「本人が 埋める（速い）＋ 学校が 確かめる（正しい）」に 分けます
```

★**そして 一覧は、いつも しぼれます。**
```
　すべて ／ ★未確認だけ ／ 学部 ／ 学科・コース ／ 事務の 分野 ／ 役職 ／ 役割
　★全員を 出すことも できます（★大きい学校では、全員は 探せません）
```
