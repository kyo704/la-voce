# RULING 181 — 20時より後の呼び出しの警告は、運営にだけ出す

```yaml
ruling: 181
date: 2026-09-23
version: design-v27
extends: 裁定147（公演に出る子ども）
from: Opus の案を坂本さんが採った（2026-09-23）
```

## 1. 決定

```yaml
★20時より後まで子どもが呼ばれている稽古・本番では、★運営にだけ 警告を出す
  出る場所: 稽古を組む画面／当日の進行／呼ぶ方の一覧
  文: 「子どもの方が 20時より 後まで 呼ばれています」（★理由も是非も書かない）
★保護者には 出さない
```

## 2. なぜ運営だけか

```yaml
① ★決めるのは運営。時間を動かせるのは運営であって、保護者ではない
② 保護者に出すと ★断りづらくさせる
   「20時を過ぎます」と先に知らされると、断れば子どもが外されるかもしれない、と感じさせる
   ★判断を取り上げないという決まりに近いところで、圧を作らない
③ 保護者には ★事実（入りと解散の時刻）が すでに見えている
   警告は「遅い」という評価であって、事実ではない。★評価はこちらから押しつけない
```

## 3. やらないこと

```yaml
★時間を自動で動かさない／★呼び出しを自動で止めない（運営が決める）
★何時までにすべきかを こちらから決めない（地域・団体・学校の規則が違う）
★保護者に通知を送らない（催促しない・通知は例外3件のまま）
★「遅い」と記録に残さない（評価を台帳に入れない）
```

## 4. VERIFY

```yaml
- 子どもが 20:30 まで呼ばれている稽古 → ★運営の画面に警告が出る
- 同じ稽古を 保護者が見る → ★警告は出ない。入りと解散の時刻は見える
- 子どもがいない稽古 → 警告は出ない
- 20時ちょうど → 出ない（「より後」）
- ★警告は台帳に残さない（画面で出すだけ）
```
