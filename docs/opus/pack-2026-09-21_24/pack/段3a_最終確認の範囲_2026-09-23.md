## 4. 進め方（Code）

```yaml
1 毎回 route_map を先に走らせる（前提の状態がそのまま出る）
2 1画面ごとに ㋐（実装が足りない）／㋑（見本が古い）／㋒（意図的に違う）を選んで1行で報告
3 ㋑ は Opus が見本を直す。㋐ は Code が作る。㋒ は台帳に1行
4 1つの機能が終わるたびに mobile_parity と allsc を走らせる（片方だけ直った、を防ぐ）
5 最後に release_check（Opus）
```
