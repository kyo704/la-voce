# 作品のデータの型 ── これを埋めると、そのまま台帳に入ります

2026-09-23 ／ Opus ／ 裁定174・sql/27。Fable・坂本さんが埋める用

## 1. 形（1作品＝1つの JSON）

```json
{
  "title": "フィガロの結婚",
  "composer": "モーツァルト",
  "composer_sort": "Mozart, Wolfgang Amadeus",
  "kind": "opera",
  "year_written": 1786,
  "source": "hand",
  "source_id": "figaro",
  "instrumentation": ["管弦楽"],
  "roles": [
    { "label": "スザンナ" },
    { "label": "フィガロ" },
    { "label": "合唱", "is_group": true }
  ],
  "scenes": [
    { "label": "第1番 二重唱", "group_label": "第1幕", "minutes": 4, "roles": ["スザンナ", "フィガロ"] },
    { "label": "第2番 カヴァティーナ", "group_label": "第1幕", "minutes": 3, "roles": ["フィガロ"] }
  ]
}
```

## 2. 埋め方の決まり

```yaml
kind: opera／chorus／drama／orchestra／gala／chamber／band／dance／other のどれか
roles:
  - 名前は 日本語で（日本の音大で使う呼び方）。原語は要らない
  - 合唱・児童合唱・オーケストラなど「何人かのまとまり」は is_group: true
  - ★ここに書いた名前だけが scenes の roles に使える（綴りが1文字でも違うと入りません）
scenes:
  - オペラ: 番号（第1番 二重唱）。group_label に 幕
  - 交響曲・室内楽: 楽章（第1楽章 Allegro）。group_label は空でよい
  - ガラ・リサイタル: 曲名を並べるだけ（roles は空でよい）
  - minutes: 分かるときだけ。分からなければ書かない
source_id: 自分で決めた短い英字（figaro・zauberflote・mozart-requiem）。★同じ id で入れ直すと、中身が入れ替わる
書かないもの: 歌詞・対訳・あらすじ・楽譜（著作権。裁定174）
```

## 3. 入れ方（Code）

```sql
select public.upsert_work('<ここに JSON>'::jsonb);
-- 何件入ったかは、返ってきた id で確かめる
-- 揃い方（completeness）は自動で付く: 場面×役まで → full ／ 役まで → roles ／ 場面まで → movements ／ 名前だけ → title
-- ★full の作品だけが、公演の「下書きを作る」に出る
```

## 4. 埋める順番（裁定174 §3）

```yaml
1 坂本さんがこれから関わる作品
2 音大の実習でよく出るオペラ10作: フィガロ／魔笛／ドン・ジョヴァンニ／コジ・ファン・トゥッテ／カルメン／
  椿姫／ボエーム／蝶々夫人／ヘンゼルとグレーテル／こうもり
3 合唱つきの大曲5作: モーツァルト レクイエム／フォーレ レクイエム／メサイア／第九／カルミナ・ブラーナ
4 それ以降は、使った人の雛形から
★まず1作品（フィガロ）を作って、かかった時間を測る。10作の見当が付きます
```

## 5. よくある詰まり

```yaml
- 「役の一覧に無い名前」を場面に書いた → ★入りません（黙って取りこぼさず、その場で止まります）
- 役名の表記ゆれ（伯爵夫人／アルマヴィーヴァ伯爵夫人）→ どちらかに統一。roles に書いた綴りが正
- 同じ作品を2回入れた → source_id が同じなら 入れ替わるだけ（増えません）
- 交響曲に roles を書かない → それで正しい（movements 止まりになります）
```

## 外から取り込むとき（2026-09-23 追記・sql/39）

```yaml
なぜ要るか: 能の現行曲は約240、狂言も約250、歌舞伎の演目は数百。★手で書ききれない
  いま手で入れたもの: 能13・狂言9・歌舞伎26（十八番18を含む）
決まり:
  取り込みは ★サーバだけ（画面からは呼べない）
  重複よけ: 出どころ（source）＋ 向こうの id（source_id）。★本番に索引が既にある
  ★既にある作品は 中身を上書きしない（人が直した内容を消さないため。2回目は skipped）
  揃い方（completeness）: 'title'（題名だけ）→ 'movements'（場面あり）→ 'roles'（場面と役あり）→ ★'full'（人が確かめた）
  ★取り込んだ直後は is_public=false。「下書きを作る」に出ない
  運営が verify_work で確かめて はじめて 利用者に出る
出どころの候補:
  能・狂言: 公開されている曲目の一覧（流派で曲名・分類が違う点に注意）
  歌舞伎: 演目のデータベース（enmokudb.kabuki.ne.jp）
  西洋音楽: MusicBrainz・Wikidata（CC0）
★注意: 取り込みで入るのは「題名・作者・分類」まで。★場面×役は 人が作るか、確かめる必要がある
```
