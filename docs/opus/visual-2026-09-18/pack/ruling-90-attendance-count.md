## 4 ★出さないもの

```
✕ ★率（％）
✕ ★「9 / 12」の 形     ← ★★見た人が 割ります
✕ ★出席順の 並べ替え    ← ★★既定は 名前順

```

```
★「出席 9」「12回目 / 30回」── ★別々に 出す
★★「9 / 12」── ★★★画面が 割っています
```

★★見た人が 頭の中で 割るのと、★**画面が 並べて 見せる**のは 別です。

### ★★★の 印

```
★規定に 足りない 見込み
★色を 使わない。★印だけ
★責める 形に しない
```

## 5 ★授業の 型（プリセット）

### 5-1 ★なぜ 要るか

```
★音大では ★1つの 授業名に ★複数の 門下が あります
　★「声楽実技」を ★6人の 先生が 持つ
　★★年30回・週1回 は ★全部 同じ
　→ ★★1つ 作って 6つに 当てる
```

★★★無いと、★同じことを 6回 打ちます。

### 5-2 ★台帳

```sql
create table lesson_presets (
  id uuid primary key default gen_random_uuid(),
  org_id uuid not null references organizations(id),
  name text not null,           -- 「声楽実技（前期）」
  total_count int not null,     -- ★年30回
  note text,
  created_at timestamptz default now()
);

create table lesson_preset_targets (
  preset_id uuid references lesson_presets(id) on delete cascade,
  teacher_id uuid references auth.users(id),
  org_id uuid not null,
  primary key (preset_id, teacher_id)
);
```

### 5-3 ★RLS ── ★同じ紙に 書くこと

```sql
-- lesson_presets
alter table lesson_presets enable row level security;

create policy lp_select on lesson_presets
  for select to authenticated
  using (has_can(org_id,'meibo') or has_can(org_id,'monka_write'));

create policy lp_write on lesson_presets
  for all to authenticated
  using (has_can(org_id,'meibo'))
  with check (has_can(org_id,'meibo'));

-- lesson_preset_targets ── ★同じ
```

```
★roles は ★authenticated
★USING と WITH CHECK の ★両方
★USING(true) を ★書かない
★org_id を ★必ず 持つ
```

### 5-4 ★誰が 作るか

```
★作る・消す  ★事務（meibo）
★見る       ★先生（monka_write）も 見られる
```

★★年間の 回数は ★**学校が 決めるもの**です。
