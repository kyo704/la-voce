## §1 運営者の見立てには、根拠があります

「数百円・月額・すぐ解約できるものは、実際には取り消されないだろう」

これは勘ではありませんでした。**民法5条3項**にあたる可能性があります。

```
民法5条1項  未成年者の法律行為には、法定代理人の同意が必要
民法5条2項  同意のない行為は★取り消せる
民法5条3項  ★法定代理人が処分を許した財産（＝小遣い）の範囲は、取り消せない
```

日本通信販売協会（JADMA）の解説は、5条3項の例として
**「毎月数百円程度の継続購入」**を挙げています。

つまり、**価格が抗弁の一部になります。**

```
月額 数百円   ★小遣いの範囲、と言える余地があります
月額 数千円   ★言いにくくなります
年払い        ★言えません（一度に大きく動きます）
```

### ★だから、これを決まりにしてください

```
未成年に売る個人プランは、★月額1,000円未満に保つ。
これを超えるなら、★保護者の同意の仕組みを作ってから。
```

**価格の上限が、法律上の理由で決まりました。**
あとで値上げするときは、この判断書に戻ってきてください。
値上げは、値段だけの話ではなくなりました。

## §2 ★同意画面は、取消権を封じません

ここは正直に書きます。**チェックボックスは、法定代理人の同意ではありません。**

本人が「同意を得ました」と言っただけです。それは本人の申告であって、
保護者の意思表示ではありません。**取消権はそのまま残ります。**

### では、無意味か

いいえ。**3つ、実際の効き目があります。**

```
① JADMA が事業者に求めている形そのものです
   ・未成年は親権者の同意が必要と、明確に表示・警告する
   ・年齢または生年月日の申告を求める
   ・未成年なら「親権者の同意を得た旨」の申告を求める
   ★この3点を満たしていること自体が、こちらの誠実さの証拠になります

② 未成年者に、★情報が届きます
   「親に見せるべきものだ」と、その場で知ります。多くはそれで見せます

③ 争いになったとき、★何を表示していたかを示せます
```

**封じるためではなく、伝えるために置きます。** そう理解して作ってください。

---

## §3 ★生年月日は、取らないでください

生年月日を入力させ、嘘の生年月日を入れさせると、**詐術（民法21条）**が成立しやすくなる、
という実務上の議論があります。取消権を封じる方向に働きます。

**それでも、取りません。** 理由は4つ。

```
① 9月4日に「生年月日は取得しない」と決め、ポリシーに書くと決めました
② 詐術の抗弁は「★利用者が嘘をつくのを待つ」設計です。この製品の思想と合いません
③ 個人データが増えます
④ ★数百円なら、5条3項（小遣い）のほうが強い抗弁です。詐術に頼る必要がありません
```

3帯（15歳未満／15〜17歳／18歳以上）の自己申告のままで進めてください。

そして 9月4日に書いたとおり、**17歳が「18歳以上」と答えれば通ります。それは防げません。**
防げないことを前提に、§5 の返金の約束で受けます。

## §4 承認する形

運営者の提案を、そのまま承認します。1つ足します。

```
① 未成年には★個人の月額プランだけを出す        ★承認
   年払いなし／教室・団体プランなし／長期契約なし
② 決済の前に、未成年専用の同意画面を出す        ★承認
③ ★返金の約束を、先に書いておく                ★追加
```

③が、この設計でいちばん効きます。

---

## §5 ★返金の約束（最重要）

規約（B-4）と、同意画面の両方に書いてください。

```
18歳未満の方、またはその保護者の方からお申し出があった場合は、
直近のお支払いを返金し、すぐに解約します。理由は伺いません。
```

### なぜこれが効くのか

```
・取消しを主張されたとき、★争わないと先に決めておくことになります
・争うコストのほうが、数百円より高いです
・★カードは保護者名義のことが多いです。
  チャージバックにされるより、こちらから返すほうが安く済みます
・書けば契約の一部になり、こちらの義務になります。★守るつもりなので問題ありません
```

★「クーリング・オフ」とは書かないでください。
**通信販売にクーリング・オフはありません。** 無いものの名前を使うと、それ自体が誤りです。
これは**自主的な返金**です。そう書いてください。


## §7 ★「保護者の方へ」のページ

これを作ってください。安く、実際に効きます。

未成年が保護者に**見せられるもの**です。メールは送りません（経路を増やしません）。
URL を1つ置くだけです。

```
書くこと
  ・これは何のアプリか（声を使う人の、体調と負荷の記録）
  ・いくらか（毎月◯◯円）
  ・どうやめるか（画面のどこ）
  ・返金の約束（§5と同じ文）
  ・連絡先
```

★「保護者の同意フォーム」にしないでください。
それを作ると、保護者の個人データを持つことになります。**見せるだけのページです。**

## §9 更新のたびに、1行出す

未成年のあいだだけ、支払いのあとに1行。

```
昨日、今月分のお支払いがありました。やめるときは、ここから。
```

★これは催促ではありません。**起きたことの通知**です。
毎月のことなので、忘れられます。忘れたまま続くのが、いちばん揉めます。

そして、**解約の導線を隠さないでください。** 1タップで届くところに置きます。
