## §2 iOS ── ② ホーム画面に置く

★**ここでブラウザ側に登録画面を出さないでください。**

理由です。

```
iOS では、Safari とホーム画面版で★保存場所が別です。
ブラウザで登録させると、ホーム画面から開いたとき★ログアウトしています。
```

だから、**登録より先に置かせます。**

```
　　　まず、ホーム画面に置きましょう。

　　　　［ スクショ1：共有ボタンを押すところ ］
　　　　　　　　　↓
　　　　［ スクショ2：「ホーム画面に追加」を選ぶところ ］
　　　　　　　　　↓
　　　　［ スクショ3：「追加」を押すところ ］

　　　画面の下の　⬆　を押してください。

　　　　　　　　［ あとで ］
```

★守ること

```
・★実物のスクリーンショットを使う（描いた絵ではありません）
・共有ボタンは★画面の下です。矢印で指してください
・「あとで」を必ず置く。★出口のない画面を作らない
・★この画面のまま止める。自動で次に進めない
　　（追加したかどうかは、★アプリからは分かりません）
```

### 追加したあとの案内（同じ画面の下に、常に出しておく）

```
　　　追加できたら、ホーム画面に戻って
　　　　［ アプリのアイコンの絵 ］
　　　このアイコンを押してください。
```

★アイコンの絵を出してください。**探せない人がいます。**

### 「あとで」を押した人

ブラウザで登録できる道を出します。ただし、**先に伝えます。**

```
　　　このまま、ブラウザでも始められます。

　　　あとでホーム画面に置いたときに、
　　　★もう一度だけ、数字を入れていただきます。

　　　　　　［ このまま始める ］
　　　　　　［ ホーム画面に置く ］
```

★不利なことを、先に書きます。あとで驚かせません。

### Safari 以外で開かれた場合

```
　　　この画面は Safari で開いてください。
　　　　　　　［ 開き方 ］
```

★iOS 16.4 以降なら、対応しているブラウザからも追加できます。
ただし対応していないものもあるので、この1行を用意してください。

## §3 iOS ── ③ ホーム画面から開く

standalone で開かれたら、**そこが本番です。**

```js
const isStandalone =
  window.navigator.standalone === true ||
  window.matchMedia('(display-mode: standalone)').matches
```

```

　　　　　　ようこそ。

　　　　　　［ はじめる ］
　　　　　　［ すでにお使いの方 ］
```

★「追加ありがとうございます」と書かないでください。
**追加したかどうかを、アプリは知りません。** 知らないことを言わない、の規則です。

```
　　　メールアドレスを教えてください。

　　　［                    ］

　　　　　　［ 次へ ］

　　　パスワードは要りません。
```

★パスワードを作らせないでください。

```

　　　［ ＿ ＿ ＿ ＿ ＿ ＿ ］
```

せっかく置いたアプリの外に出ます。

## §5 ⑥ 職業 ── 1問だけ

```
　　　あなたに合う項目を出します。

　　　　［ 歌う人 ］
　　　　［ 教える人 ］
　　　　［ 話す仕事の人 ］
　　　　［ あとで選ぶ ］
```

★ここで3問も4問も聞かないでください。**記録の前に置く問いは、1つだけです。**
残り（声種・所属など）は、**記録を1つ入れたあと**に聞きます。

★理由：**まだ何も受け取っていない人に、質問だけが続く**のがいちばん重いです。

## §6 ⑦ 今日の記録 ── ここが山です

```
　　　今日のことを、ひとつだけ。

　　　　昨夜の睡眠　　［ ─ ● ─── ］  7時間

　　　　　　　［ 記録する ］

　　　　　　　［ あとで ］
```

★**最初は1項目だけにしてください。** 5項目を並べない。
「1つ入れたら終わった」という体験を先に渡します。

記録したあと。

```
　　　　　　［ 羊が喜ぶ ］

　　　ありがとうございます。記録がひとつ入りました。

　　　　　　［ 続けて入力する ］
　　　　　　［ 今日はここまで ］
```

★ここで初めて、羊とおうちが出ます。**ごほうびは、記録のあとです。**

## §7 Android ── ⑥ ホーム画面に置く（最後）

Android は**保存がブラウザと共有されます。** だからログインが続きます。
**順番を入れ替える必要がありません。**

記録を1つ入れたあとに、1回だけ出します。

```
　　　ホーム画面に置いておくと、すぐ開けます。

　　　　　　［ 置く ］　　［ あとで ］
```

「置く」で `beforeinstallprompt` の保留したイベントを発火させます。**1タップです。**

```js
// 形だけ示します
let deferred = null
window.addEventListener('beforeinstallprompt', e => { e.preventDefault(); deferred = e })
// 「置く」を押したとき： deferred.prompt()
```

★`beforeinstallprompt` が来ない端末もあります。そのときは**この画面を出さないでください。**
押せないボタンを見せないこと。

## §8 全画面に共通の決まり

```
・★段の数を見せる（●●●の3つ）。短いことが分かると、進みます
・★どの画面にも「戻る」がある
・★どの画面にも出口がある（「あとで」）
・催促しない。★断ったものは、二度と出さない
　　→ 代わりに、設定の中に「ホーム画面に置く方法」を常設で置く
・「インストール」と書かない。★「ホーム画面に置く」
　　→ インストールと書くと、ストアを探されます
```

★外部の解析サービスを入れないでください。自分のサーバに、日ごとの数だけ。

```
★standalone で開かれた                  回
メールアドレスを入れた                 人
6桁を入れた                            人
職業を選んだ                           人
★記録を1つ入れた                        人
```

★個人を特定しない形で。日ごとの数だけで足ります。

**いちばん大きい落ち込みが、次に直す場所です。**
私の予想では、iOS の「ホーム画面の案内を見た → standalone で開かれた」です。
