```yaml
FOUND_AND_FILLED:
  公演_運営（PC）:
    - 稽古を作れても 直す・取り消すが無かった → 稽古の一覧 ／ 稽古の中身（直す・取り消す）
      取り消し: 1度たずねる。お知らせは送らない。出欠の記録は残る
    - 出演者の一覧・外すが無かった → 出演者（外す: たずねる。本人の記録は消えない。料金の段は下がらない）
    - 配役でキャストを入れ替えられなかった → A・B を押して、招いた方から選ぶ／空ける
  公演_出演者（スマホ）:
    - 合言葉で公演に入る画面が無かった → 公演に入る（8文字。年齢・保護者の同意を通る）
    - 稽古を押しても中身が見られなかった → 稽古（自分の集合・場所・場面。自分の出る場面を太字）
      来られないときは「稽古場の LINE で」（連絡の窓は作らない）
  ポートフォリオ:
    - 「消す」が押しても動かなかった → 直す・消す（たずねる）・↑で並べ替え
    - 写真の画面が無かった → 写真（20枚まで・位置情報を消す・肖像の問い。答えは記録しない）
  ホームページ:
    - 型を15のうち8つ固定で出していた → 分野に合わせて出す（音楽9／声5／舞台4）＋「教える仕事も」で2つ
    - 公開後の設定が無かった → ページの設定（URL・QR・お問い合わせの転送・検索に出さない・下げる）
      出したら、そのまま設定の画面へ

CHECKED:
  ブラウザで1つずつ押して確かめた（直す・消す・並べ替え・写真を足す・型の数・出す→設定・
  入る→公演→稽古・稽古を直す／取り消す・出演者を外す・キャストの入れ替え）
  4本の全画面: 読込エラー0（開けないのは既存の6画面だけ）
  途中で直した: 板を閉じても画面が描き直されず、足した写真が見えなかった

STILL_NOT_BUILT:          # ★わざと後回しにしているもの
  - 公演の進行表・本番当日の画面・CSV 読込・PDF（2027-10〜 P2）
  - 過去の稽古の出欠を見る画面（きょうの分だけ）
  - 公演が終わったあとの「これまでの 出演」（出演者側）
  - 紙・PDF の書き出しは札だけ（本物の PDF は作らない）
  - ホームページを「見る人」の側の画面は、15型の見本ファイルに別にある
```
