## なぜ間違いだったか

**1　謝る羊は、可愛くありません。**
　謝罪は上下をつくります。可愛さは、対等さから来ます。
　★あつ森の住民も、Finch の鳥も、謝りません。

**2　的中率61%なら、4割の朝に「ごめんなさい」が出ます。**
　★週に3回謝るキャラクターは、すぐ嫌われます。

**3　朝いちばんの画面で、キャラクターが自分を責めています。**
　★声が出づらい人が開くアプリで、これは最悪です。

**4　「あてにしないでください」は、★助言です。**
　しかも、自分の機能についての助言。
　★数字が出ていれば、あてにするかどうかは本人が決めます。
　**「判断を取り上げない」という決まりに、私が反していました。**

**5　★私がやっていたのは、誠実さの「演出」です。**
　本当の誠実さは、的中率の数字を出した時点で、もう達成されています。
　謝罪はその上に乗せた飾りで、★実質は「誠実に見せるための演技」でした。

---

## ★決まり（これを足してください）

```
★数字が、正直を引き受ける。
★羊は、可愛さだけを引き受ける。
★1つのものに、2つの仕事をさせない。
```

## 差し替え

### 外した日

```
★何も言いません。
　その日の、ふつうのことばを言います。
　★的中率の数字は、外した回数を、すでに正しく数えています。
```

### 当たった日

```
◯ 羊が、すこし喜んでよい。★1〜2文。★毎回は出さない
　　「きょうは、よく出ましたね。」
　　「あ、当たりました。」
★★当たったときだけ言う。★外したときは黙る。
　　→ ★これで、羊は「はしゃぐ子」になります。「反省する子」ではなく
```

### 的中率が低いとき

```
✕ 羊が「あてにしないでください」と言う
◯ ★数字だけを出す。「23回中 7回（30%）」
　　★丸めない。★良く見せない。★言い訳もしない。★それで足ります
```

### 「そんなことない」を押されたとき（★§4-3 は、このまま）

```
「そうですか。おぼえておきます。」
　★これは謝罪ではありません。★受け取っただけです。★このまま残します
```
