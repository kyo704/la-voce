# RULING 156 — 学校の導入期間（0円）

```yaml
ruling: 156
date: 2026-09-21
version: design-v18
from: Fable「SCHOOL_FREE_PERIOD」（design-v13 の範囲。2026-09-21）
closes: 裁定155 C4（導入期間は未決）
premise:
  - 学校の販売開始は 2027年4月
  - パイロット1校は 2027年2月にレッスン割を使う
  - 契約は「0円の導入期間つき年間契約」。無償パイロットではない（錨を0円にしない）
```

```yaml
DECISION: Fable 案を採る。1点だけ足す

最初の1学科（パイロット）:
  契約: 2027年2月までに年間契約（公表価格で）。開始日を契約書に書く
  0円: 2027年9月30日まで
  請求: 2027年10月1日から（公表価格）
  かわりに: 事例の掲載／パイロット報告書への協力（先生2人・事務1人の聞き取り）／事務と先生の時間の前後の計測（契約時に基準値を記録）
  reason: 時間で引く。値段は引かない。2校目に「1校目は公表価格で契約している」と言える
2校目から:
  0円: 契約日から最大3か月。ただし次の4月1日を超えない
  請求: 導入期間の翌月1日か 4月1日の早いほう
  例: 11月に契約 → 11〜1月 0円、2月から請求。4月に稟議が要る学校は、契約を4月始まりにする
教室: 14日の体験（カードなし）だけ。学校の導入期間は使わない
0円のあいだ:
  - 名簿の人数を毎月1日に数え、請求が始まる額を「半年の使われ方」1枚（裁定138 R4）に載せて1月に見せる
  - 止めても請求なし。学生の記録は残る（取り上げない）
  - 学生価格は初日から本人が買える（学校は関与しない。裁定138）
しない:
  - 0円期間の延長（1校目の1回を除く）
  - 値引き。変えるのは名簿の範囲（学年・コース）だけ

★足す（事例の掲載）:
  - 学校名・写真の掲載は、学校の書面の同意を取ってから
  - 写真に学生を写さない（建物・先生〈本人の同意〉まで）。子どもは裁定147 のとおり写さない
  reason: 学生は掲載に同意する立場にない（契約の当事者でない）。事例のために学生の顔を出さない

注記: 学校（学校法人）は事業者なので、消費者契約法の B案（裁定110・155 C1）は当てはまらない。年間契約の途中解約は契約書で定める（B案と同じ考え＝未経過月を返す、を推奨）

VERIFY:
  Q1: 契約書に開始日・0円の終わりの日・公表価格が書いてある
  Q2: 0円期間の終わりの1か月前に、日付で1回だけお知らせが出る
  Q3: 0円期間中に止めた学科で、請求と学生の記録の消失が0件
  Q4: 事例の写真に学生が1人も写っていない

MOCK（design-v18）:
  運営のプラン（スマホ・PC）に「学校の導入期間（0円）」の3行（最初の1学科／2校目から／教室）
  見本の切替「導入期間中」: 今月 0円、「2027年9月30日まで 0円。そのあと 月○円」
```
