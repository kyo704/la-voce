## 0 なぜ書き直すのか（1分で）

いまの営業資料3ページ目は、こう言い切っています。

> 学科・コースが、健康情報を預からない設計です。……個人情報保護法上の
> 「取扱いの委託」に当たりません。学科側に監督義務や安全管理措置の書面が
> 発生しないことを、契約書に明記しています。

採点を預かると、★**学務データについては委託が発生します**。

- 成績は学生の個人情報。学校が当社に預ける形になる
- 学科側に監督義務と安全管理措置の書面が生じる
- ★「発生しません」と書いた直後に、別の経路で発生させることになる

だから、**隠さず二層として正しく書きます。**

```
健康の層   預からない。誰も見られない。契約で禁じる    ← 変えない
学務の層   ★預かる。委託として、正しく書く            ← 足す
```

★これは弱くなる話ではありません。「健康だけは絶対に預からない」が、
かえってはっきりします。

## 1 営業資料 3ページ目

### 1-1 いまの構成と、どこを直すか

```
いま
  見出し「学科・コースが、健康情報を預からない設計です」
  ① 学生の体調を、学科が預かると、こうなります
  ② この形なら、責任が発生しません        ← ★ここを二層に
  ③ いま、できること／これから作ること
  ④ やらないと決めていること              ← ★1行足す
```

### 1-2 見出しの案

```
学科・コースが、健康情報を預からない設計です
　　↓
★健康の記録は、学科が預かりません。学務のデータは、正しくお預かりします
```

★短くするなら「預かるもの、預からないもの」。

### 1-3 ②を、この表に差し替える

```
　　　　　　　　　　預かる人　　　学科の責任　　　先生が見られるか

健康の記録　　　　　当社のみ　　　★なし　　　　　★見られない
（声・体・眠り）　　（学生と直接）

学務のデータ　　　　当社が　　　　★あり　　　　　役職による
（名簿・出欠・　　　学校に代わって（委託として）
　日程・成績）　　　お預かり
```

### 1-4 本文（案）

```
■ 健康の記録は、学科が預かりません

　学生はご自分で登録し、当社と直接の関係に立ちます。
　学科・大学から当社へ、学生の健康の記録をお渡しいただく必要がありません。
　講師・教員は、学生の健康の記録を1件も見られません。

　「見せない設定にしてある」のではありません。そういう画面が、
　はじめから存在しません。設定の変更でも、管理者の権限でも、
　開くことはできません。

　この形により、健康の記録については、個人情報保護法上の
　「取扱いの委託」に当たりません。学科側に監督義務や安全管理措置の
　書面が発生しないことを、契約書に明記しています。

■ 学務のデータは、正しくお預かりします

　名簿・出欠・日程・実技試験の成績は、学校の業務そのものです。
　これらは、学校に代わって当社がお預かりします。
　★これは個人情報保護法上の「取扱いの委託」にあたります。

　委託である以上、次のことを契約書に書きます。
　　・当社が何のためにお預かりするか（目的の限定）
　　・どこに置き、誰が触れるか
　　・いつ消すか（★実技試験の成績は、書き出しから90日で自動的に消えます）
　　・漏えいしたときに、何時間以内にご連絡するか
　　・ご解約のときに、どうお返しし、どう消すか

　学校の正本は、貴学の校務システムです。当社は一時的な通り道です。
```

### 1-5 ④に足す1行

```
・実技試験の順位は、アプリの中で付けません。点数の一覧は書き出せますので、
　順位が必要な場合は、貴学の仕組みでお付けください
```

★これは弱みではなく、2ページ目（他人と比べない）との一貫性の証明です。

### 1-6 ★書き換えの注意

- ★「委託に当たりません」の1文を、**健康の記録に限定**してください。
  いまは全体にかかる書き方です。ここを直さないと、渡した書類と実物が違います

## 2 契約書に足す条項

### 2-1 いまの形

第7条などで「健康情報は委託ではない」と書いてあるはずです。
★そこは残します。**別条として、学務データの条項を足します。**

### 2-2 条文（案）

```
第○条（学務データの取扱いの委託）

1　本条において「学務データ」とは、甲（学校）が乙（当社）に対し、
　　本サービスを通じて取り扱わせる次の情報をいう。
　　　① 学生の氏名、学年・コースその他の在籍に関する情報
　　　② レッスン・授業の日程および出欠に関する情報
　　　③ 実技試験その他の評価に関する情報（点数および講評を含む）

2　甲は、学務データの取扱いを乙に委託する。乙は、本契約の目的の
　　範囲内でのみ、これを取り扱う。

3　乙は、学務データについて、個人情報の保護に関する法律第23条に
　　定める安全管理措置を講じる。その内容は別紙のとおりとする。

4　乙は、学務データを第三者に再委託する場合、あらかじめ甲に
　　書面で通知する。再委託先の一覧は別紙のとおりとする。

5　乙は、学務データの漏えい、滅失または毀損を知ったときは、
　　★これを知った時から24時間以内に甲へ通知し、その後速やかに
　　事実関係および再発防止策を書面で報告する。

6　実技試験の評価に関する情報は、甲が書き出しを行った日から
　　★90日を経過した時点で、乙のシステムから自動的に削除される。
　　甲は、当該情報の正本を自らの校務システムにおいて保管するものとする。

7　本契約が終了したときは、乙は、甲の指示に従い、学務データを
　　返還または削除し、その完了を書面で報告する。

第○条（学生の健康に関する記録）

1　学生の声および身体に関する記録（以下「健康記録」という。）は、
　　乙と学生との間の個別の契約に基づき、乙が学生本人から直接
　　取得するものであり、★甲から乙への委託には該当しない。

2　甲の役員および従業員（教員・講師を含む。）は、健康記録を
　　閲覧することができない。乙は、現時点において、そのための機能を
　　設けていない。乙は、本契約の期間中、健康記録を甲に開示しない。

3　甲は、健康記録の内容を、成績の評定その他の学生の評価に
　　用いてはならない。

4　甲は、学生に対し、健康記録の作成を義務づけてはならない。
```

★第2項は、設定ではなく設計の話だと示すための一文です。
うちのいちばん強い主張なので、条文に残します。

★★2026-09-20 訂正：「機能が存在しない」→「現時点において設けていない」
　★理由：断定すると、将来 機能を足したとき ★契約違反に なります
　★あわせて「開示しない」を ★継続の 義務として 足しました
　★★主張の 強さは 変わりません

### 2-3 ★どちらの条を先に置くか

★健康の条を**先**に置いてください。

- 読む人（学長・事務局長）が最初に気にするのは健康です
- 「預からない」を先に読ませ、そのあとで「学務は預かる」を読ませる

## 3 安全管理措置の一覧（学務データぶんを追加）

個人情報保護法の4分類に沿って、★学務データの行を足します。

### 3-1 組織的安全管理措置

```
・学務データを取り扱う者を、代表者1名に限定する
・取扱いの記録（いつ、誰が、何に触れたか）を残す
・★漏えい時の連絡経路を定める（学校の担当者へ24時間以内）
・年1回、取扱いの状況を点検する
```

★「代表者1名」と正直に書いてください。ひとりで作っていることは弱みではなく、
触れる人が少ないという強みです。

### 3-2 人的安全管理措置

```
・従業者は現在1名（代表者）である
・委託先（別紙）との間で、秘密保持を含む契約を締結している
・★新たに従業者を置く場合、あらかじめ学校に通知する
```

### 3-3 物理的安全管理措置

```
・学務データは、クラウド事業者のデータセンター（所在地：別紙）に保管する
・紙媒体での出力・保管は行わない
・★代表者の端末に学務データを保存しない（画面表示のみ）
```

### 3-4 技術的安全管理措置

```
・通信はすべて暗号化（TLS）
・保管時も暗号化
・★役職ごとに触れる範囲を制限し、機械で総当たりして確かめている
　（10役職 × 主要12画面）
・健康の記録については、★学校側の権限からアクセスする経路が存在しない
　（列そのものを持たない設計）
・実技試験の評価は、★書き出しから90日で自動的に削除する
・操作の記録を保存する
```

### 3-5 ★9月15日に渡す版について

- ★「機械で総当たりして確かめている」の1行は、いま**書けます**が、
  食い違いが33件残っています
