# RULING 143 — 公演を 作る流れと、料金

```yaml
ruling: 143
date: 2026-09-21
extends: 裁定その141（公演の運営）
related: その83（合言葉は人数で閉じる）／その99（合言葉は押したときに作る）
         ／その107（15〜17歳）／その110（返金の根拠）
```

---

## 1. WHERE

```yaml
入口: 行事 → 「＋ 公演を 作る」
一覧: 公演の本番は、行事の一覧にも自動で出る（「公演」の札つき）。開くと公演へ
考え方: 公演は行事の1件ではなく、稽古と配役を持つ別のまとまり。入口だけ行事に置く
```

## 2. FLOW（4段）

```yaml
1_公演: 題名・作品・稽古のはじまり・本番の日・会場
2_配役: 役を足す。A・B（ダブルキャスト）。キャストは後から入れてよい
3_招く:
  合言葉: 押したときに作る（開いただけでは作らない。裁定その99）
          いまの上限の人数になったら自動で閉じる（裁定その83）
  名簿から: 学校の中の方を招く
  15〜17歳: 保護者のひとこと（裁定その107）／15歳未満: 入れない
4_香盤表: 場面を足す →「●を つける」で役ごとに●
順番: 前後してよい。公演のホームに「つぎに すること」を出す（済みの印つき）
```

## 3. PRICE

```yaml
tiers:          # キャストとスタッフを合わせた人数
  15人まで: 0円
  40人まで: 20,000円
  120人まで: 50,000円
  300人まで: 100,000円
  note: 「ご相談」は置かない（窓口を設けない）

when_to_pay:
  作るとき: 払わない（作るのは無料）
  ★16人目を招こうとしたとき: はじめて払う画面が出る
  上の段へ: 差額だけ
form:
  公演ごとの1回払い（Stripe mode=payment）。自動更新なし
  期間: 本番の最後の日＋30日まで
refund:
  稽古が始まる前にやめる: 全額
  稽古が始まったあとにやめる: 残りの月数ぶんを月割り
  reason: 年払いの B案（裁定その110）と同じ考え。自社の損害で算定する
  人数が減っても: 返さない（段は上限であって、使った人数の料金ではない）
school: 学校の契約（教室プラン）の中の公演は 0円
after_end:
  出演者: 記録は本人に残る
  運営: 香盤表・出欠を PDF で書き出せる。新しい稽古は置けない

legal:
  特商法の表示に、公演の段・期間・返金を足す（料金ページと最終確認画面）
  請求書・領収書: インボイスの登録が決まってから（坂本さん待ち・裁定74）
```

## 4. PERMISSION

```yaml
新しいできこと: koen（公演を作る・配役・招く・料金）
  見本では gyoji か master を持つ方に出している（仮）
  学校が役職に渡す（裁定その75）
```

## 5. MOCK（2026-09-21）

```yaml
PC・iPad（運営）:
  行事 → ＋ 公演を 作る → 配役を 決める → 出演者を 招く → 香盤表（●を つける）
  公演の料金（段・差額・支払う → 1度たずねる）
  公演の運営：稽古がまだ無いときは「つぎに すること」
  ★ブラウザで 作る〜支払う〜香盤表まで 通した（エラー0）
```

## 6. VERIFY

```yaml
Q1: 作るだけではお金がかからない
Q2: 15人までは払う画面が出ない
Q3: 16人目を招こうとしたときに、差額が出る
Q4: 合言葉が、画面を開いただけでは作られない
Q5: 上限の人数で合言葉が閉じる
Q6: 本番が行事の一覧に出て、開くと公演へ行く
Q7: 学校の教室プランの中では、料金画面が出ない（0円）
Q8: 期間が終わったあと、出演者の記録が1件も消えない
```
