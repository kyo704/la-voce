## 2. Q2 PDF の方針 → ★PDFを作る仕組みを入れない

```yaml
決定: ★ブラウザの印刷を使う（HTML＋印刷用のCSS → 「PDFとして保存」）
理由:
  ① ★日本語のフォントを埋め込むのが重い（サーバで作る PDF の 最大の難所）。
     ブラウザなら 見ている人の環境のフォントで出る
  ② ★新しい依存を入れない（Vercel の実行時間・容量・費用が増えない）
  ③ ★台帳に「作った PDF」を置かない＝個人のものを増やさない
  ④ 26日で作るなら、★印刷用のCSS 1枚のほうが確実
作り方（Code へ）:
  各帳票の画面を 1つ作る（香盤表／稽古の一覧／出欠／当日の進行／呼ぶ方の一覧／出演料／参加費）
  @media print で: 画面の飾り・操作のボタンを消す／A4 横（香盤表）・A4 縦（ほか）／
    ページの上に 公演名と日付／表の見出しを 各ページで繰り返す（thead）
  ★出した紙は「そのときの姿」。あとで変えても紙は変わらない（画面にその1文を出す）
やらないこと: サーバでの PDF 生成／PDF をファイルとして保管する／電子署名
```
