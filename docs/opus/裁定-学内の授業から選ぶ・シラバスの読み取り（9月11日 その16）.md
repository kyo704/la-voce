# §1 ★★① 学内の 授業から 選ぶ

★**★空きコマの 仕組み ぜんぶが、★★学生が 時間割を 入れることに 乗っています。**

```

　★→ ★★空きコマが 集まらない。★★日程の 自動組みが 動かない。
　★→ ★★教室機能の いちばん 大きな 売りが、★死にます。
```

★**★音大生は 学期はじめに 30コマ ほど 打ちます。**
★**★手で 打つと 5分。★選ぶだけなら 1分。★★この差が、機能の 生死です。**

★**★私の 評価 ── ★★教室機能の 中で、★上から 3つに 入る 価値が あります。**

```

　★仕様シート SPEC_WHERE
```

★**★★条件 ── ★選ぶのは 端末の 中だけ。★選んだ結果を サーバへ 送りません。**

```
　★① ★学校の 授業の 一覧を、★★端末に 落とします（★学科ごと・年度ごと）

```

# §2 ★★② シラバスの 自動読み取り

## 2-1 ★★まず、言葉を 分けます

```
　★シラバス　★★授業の 中身の 説明（★到達目標・評価・毎回の内容）
　★時間割表　★★曜日・コマ・教室・担当・対象学科

　★★要るのは ★時間割表です。★シラバスでは ありません。
　★→ ★シラバスを 読んでも、★曜日と コマが 書いていないことが あります
```

## 2-2 ★★技術的に できるか ── ★「1校ずつなら できる。全部は できない」

```
　★PDF・Excel から 表を 取り出す　★★できます
　★★ただし
　　　★書式が ★学校ごとに 全部 違います
　　　★★そして ★毎年 変わります
　　　★学務システムの 中（★ログインの 奥）に あることが 多いです

　★→ ★★「1校ごとに 半日かけて 型を 作れば、その後は 自動」が 現実です
　★→ ★★「どの学校でも 自動」は ★できません
```

## 2-3 ★★そして、★もっと 大事な 理由で ★やりません

```
　★★間違えたときの 損が 大きいです。

　　★時間割を 1コマ 読み間違える
　　　→ ★空きコマが 1つ ずれる
　　　→ ★★先生が そこに レッスンを 入れる
　　　→ ★★★学生が 来られない

　★★これは 実害です。★「ちょっと ずれた」で 済みません。
```

★**★そして この製品の 作法に 反します。**

```
　★★「確かめられないことを 出さない」
　★→ ★AI が 読み取った 時間割を、★誰も 確かめずに 学生の 画面に 出す。
　★→ ★★これは、★声の 予報を 出すのと ★同じ形です。
```
