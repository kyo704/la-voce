
# §3 ★「くらべる」が 有料で 何を 見せるか（★実際に 動きます）

★**見本の 中の 記録（90日ぶん・作りもの）で、★3つの 結果が 出ます。**

| 分けかた ／ しぼり | 日数 | ひらき | どの門で 止まるか |
|---|---|---|---|
| 声の 出来（◎と△）・4週 | 10日／10日 | 0.76 | ★**3つとも 通る → 1文が 出ます** |
| 声の 出来（◎と△）・3か月 | 28日／36日 | 0.32 | ★門②で 止まる（★日数は 足りたが ひらきが 小さい） |
| **できごとの 前と後**・3か月 | 57日／33日 | 0.61 | ★**3つとも 通る**（★1つ 選んだとき） |
| **曲で しぼる**（冬の旅） | 12日／9日 | 0.70 | ★門①で 止まる（★曲で 絞ると 日数が 減ります） |

★**★いちばん 見ていただきたいのは、これです。**

```
　★「できごとの 前と後」で、★1つだけ 選んだとき　→ ★門③ 0.50　→ ★通ります
　★★もう1つ 足したとき　　　　　　　　　　　　　→ ★門③ 0.62　→ ★★通らなくなります
　　　　　　　　　　　　　　　　　　　　　　　　　　（★ひらきは 0.61 のまま）

　★★これが「たくさん 調べたぶんの 補正」の 実物です。
　★★たくさん 選ぶほど、★言えることが 減ります。★増えません。
```

★**ほかの アプリは、★選べる数が 増えると「見つかること」が 増えます。**
★**うちは 逆です。★これを 画面で 見せられるように しました。**

# §5 ★Code へ ── ★2つ 注意

## 5-1 ★「できごと」は 本人が 印を つけた日です

```
　★見本では「留学から 帰った」1つだけ 入れてあります（★作りもの）
　★本番では ★本人が 記録に 印を つけます（★引っ越し・留学・治療 など）
　★★アプリが 勝手に「できごと」を 見つけません。★推測しません
```

## 5-2 ★門③の 式は 仮です

```
　★見本　0.50 ＋ 0.12 ×（選んだ数 − 1）
　★→ ★★これは「増えると 厳しくなる」ことを 見せるための 仮の式です
　★→ ★本番では、★多重比較の 正しい 補正を 使ってください
　　　 （★Benjamini–Hochberg か Bonferroni。★どちらにするかは 別に 決めます）
　★→ ★★見本の 数字を そのまま 実装しないでください
```

★**そして 変えないこと。**

```
　✕ p 値・確率・％を 画面に 出す
　✕「効いた」「原因」「〜のせいで」
　◯「一緒に 出ています」
　◯ 通らないあいだは「まだ、はっきりした 差は 見えていません」
　◯ 門①は「10日の うち 7日 たまりました」（★進んだ側から 書く）
　✕ ★「あと3日」（★禁止事項）
```
