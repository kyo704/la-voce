# 1. 他社が、どこで線を引いているか（17本・公式ヘルプ確認）

| 型 | 中身 | 該当 |
|---|---|---|
| **C 機能の種類** | 分析機能そのものが有料 | **15/17** ★最頻 |

| **E 広告を消す** | 日本勢に多い | 4/17 |
| **A 期間** | 履歴が◯か月まで | **3〜4/17** |
| **D 書き出し** | エクスポートが有料 | **実質 1/17** |

# 2. ★実測の数字（RevenueCat 2026 ／ Adapty 2026）

## 2-1 転換率

```
インストール→課金（35日）　全体 ★2.0%　／　★健康・フィットネス 2.9%（最高）
　　　　　　　　　　　　　　　★上位25%は 6.2% 超
体験→課金　　　　　　　　　健康・フィットネス ★37.7%（上位25%で51.4%）
```

★**健康・フィットネスは、全カテゴリで最も課金される分野です。**分野の選択は有利です。

## 2-2 ★★ここが、いちばん大事です ── 体験期間なしの課金画面

**Adapty 2026、10,000本以上の課金画面の実測です。**

| 出し方 | インストール→課金 |
|---|---|
| **登録の途中で出す ＋ ★体験期間あり** | **1.35%** ★最高 |
| あとから出す ＋ 体験期間あり | 0.89% |
| **登録の途中で出す ＋ ★体験期間なし** | **0.82%** ★最低 |
| あとから出す ＋ 体験期間なし | 0.76% |

```
★★いま決まっているのは
　　・体験期間を作らない（9月6日・判断1）
　　・登録直後に課金を勧める（9月6日・課金の心理）

　→ ★★実測では、4通りのうち ★最も転換率の低い組み合わせです。
　　 ★1.35% と 0.82%。★1.6倍の差があります。
```

★Adapty は明記しています。
　「登録の途中で体験期間なしの課金画面を出すのは、**長期の価値が最も低い**」

## 2-3 体験期間の日数（★決め直す場合の材料）

```
体験→課金　　17〜32日 ★42.5%　／　5〜9日 37.4%　／　4日以下 ★25.5%
　　　　　　　★長いほうが、★約70%高い

★ランダム化した実験（Frontiers in Psychology 2025、n=680,588、190か国）
　　3日 vs 7日 →　総課金率 ★+20.9%（p<0.01）
　　　　　　　　　★7日群は、年額加入と再課金も有意に多い

健康・フィットネスの採用　5〜9日が ★54%（最多）／ 4日以下 29%
```

★★**「14日」は、データ上いちばん良い側にあります。**
　★9月6日に「体験期間を作らない」と決めましたが、
　★★これは、実測と正面からぶつかっています。**再考の材料として、お出しします。**

## 2-4 解約 ── ★どこで落ちるか

```
健康・フィットネス　月額の初回更新率 ★57%　→ ★初月で43%が落ちます
　　　　　　　　　　年額の初回更新率 ★25%

★年額の解約の ★35%が「契約1か月目」に起きています。
　　→ ★「1年使って飽きた」ではなく ★「買った直後に後悔した」

★Androidでは、解約の ★31%が決済の失敗（＝やめたかったわけではない）
　　→ ★カードの再試行を実装するだけで、取り返せます
```

## 2-5 価格

```
健康・フィットネスの中央値　月額 $9.99　／　年額 $39.94
　　★年額は、月額×12 に対して ★約67%引き（＝月額換算で1/3）が相場

★収益の68%が年額。★2つのプランを並べる形が60%（どちらもカテゴリ最高）
```

```
うちの価格　月額 ¥580　／　年額 ¥5,800
　　★年額は月額×12（¥6,960）に対して ★17%引き。
　　★★相場（67%引き）より、★ずっと浅いです。
　　→ ★年額を選ぶ理由が、いまは弱いです。
```

## 2-6 ★日本の数字

```
1年後のLTV中央値　★日本 $23.4　／　米国 $19.9
価格指数　　　　　★日本は米国の 0.8倍
解約率　　　　　　★国別で、日本が ★世界で最も低い
クレジットカード保有率　★85%（JCB 2025年度調査・n=3,500）
```

★★**日本は「安く売っても、続けてくれるので回収できる」市場です。**
　★¥580 という判断は、この意味で理にかなっています。

★そして **A/Bテストで最も勝率が高いのは、ローカライゼーション（62.3%）**でした。
　★見た目や文言の変更は 34.6%、価格の変更は 45.5%（どちらも半分以下）。
　★**日本語の作り込みが、いちばん効きます。**

## 2-7 ★個人開発の現実

```
リリース1年後の月間収益（全カテゴリ中央値）　★約 $72
2年以内に累計 $1,000 に届くアプリ　　　　　  ★約20%
2年以内に累計 $10,000 に届くアプリ　　　　　 ★約5%
```

# 4. ★以上を踏まえた、私の推し（★訂正版）

```
無料　★機能の種類は、ぜんぶ。★入力は無制限
　　　★振り返れるのは ★直近3か月
　　　★★全データの書き出しは、無料（★法律上、ここは動かせません）
　　　★受診用サマリーも、無料のまま

有料　★全期間の振り返り　＋　レパートリーの書き出し　＋「前も、こうでした」
```

★**「期間で切るのは標準ではない」と分かった上で、なお推す理由は3つです。**

```
1  ★いちばん近い Bearable が、この形です（30日→60/90/365日）。
　　★症状トラッカーという、同じ性質の製品です。

2  ★取り上げになりません。★1日目から全部さわれます。
　　★炎上した3件（Strava×2・MyFitnessPal）は、★全部「取り上げ」でした。

3  ★4か月目に、★自分が書いたものにぶつかります。
　　★他人のデータではありません。★いちばん強い課金の瞬間です。
```

★**そして、2つだけ、決め直しをお願いしたいことがあります。**

```
① ★年額の割引を、深くしてください
　　いま　¥5,800（月額×12 に対して 17%引き）
　　相場　★67%引き　→　うちなら ★¥3,480 前後
　　★せめて ★¥4,800（31%引き）まで下げないと、年額を選ぶ理由がありません。
　　★★健康・フィットネスは、収益の68%が年額です。★ここが薄いのは効きます。

② ★体験期間なし ＋ 登録直後の課金画面は、★実測で最悪の組み合わせです
　　1.35%（体験あり）vs 0.82%（体験なし）
　　★★14日の体験期間を、★もう一度ご検討ください。
　　★ランダム化実験でも、7日 > 3日 で総課金率 +20.9% でした。
```

★①②は、**私の意見ではなく、実測の数字です。**
　★決めるのは運営者ですが、**数字は先に見ておいてください。**
