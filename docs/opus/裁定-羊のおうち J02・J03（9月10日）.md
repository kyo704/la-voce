# §2 家具27点を、7か所に 割り当てます

★**足りないぶんは、★新しく 描くのでは なく、★まず 数え直してください。**

## 2-1 やってほしいこと（★先に これ）

```
　27点を、次の 5つに 分けて 一覧に してください。

　　① どこに 置いても おかしくない（例：鉢植え・時計）
　　② 掛けるもの（かべ 向き）
　　③ 座るもの（いす 向き）
　　④ 置くもの（とだな・つくえ・ゆか 向き）
　　⑤ どこにも 当てはまらない

　★この一覧が 無いと、何点 足りないのかが 決まりません。
```

## 2-2 決めごと（★描き足す前に）

```
　★1か所につき、最低 2点。★7か所 × 2点 ＝ 14点が 下限です。
　　（1点だと「選ぶ」ことに なりません。★選べないものは、置く意味が ありません）

　★27点あるので、★数の上では 足ります。
　★足りないとすれば、★偏りです（かべ向きが 10点、いす向きが 0点、など）。

　★★足りない ところだけ 描き足します。★全部を 描き直しません。
```

## 2-3 「とだな」に 絵が 1点も 無い件

```
　★とだな 向き（置くもの）が 0点なら、★3点 描き足してください。

　　・小さな 鉢植え
　　・重ねた 楽譜
　　・木の 小箱

　★どれも「置く」だけの もので、動きません。
　★★顔を 付けないでください（羊いがいに 顔を 作らない）。
```

# §3 J03「とびら」12点の 行き先

```
　★とびらは「おうちの 見た目」の 一部です。★おくスロットに 入れません。
　★入れると、7か所が 8か所に なり、★毎回 1つ 空きます。

## 3-2 置き場所

```
　★★おうちの 外観の 部品として、★<b>まど と 同じ 扱い</b>に します。

　　いまの 7か所　まど／かべ左／かべ右／とだな／いす／つくえ／ゆか

　★合わせて 8か所。★とびらにも 12点 あるので、選べます。

```
　★まども とびらも、★<b>部屋の 形そのもの</b>です。動かせません。
　★家具は 動かせます（帰国後に 自由配置を 考えます）。
　★→ ★動かせないものと、動かせるものを、★同じ 仕組みに 入れないでください。

```
　★いまの 見本の 部屋の絵に、とびらは 描いていません。
　★★これは「無い」ではなく「まだ 描いていない」です。

　★見本の 部屋は 仮です（9月10日「古い機能の扱い・訂正」§8-5）。
　★★Code に 部屋を 描かせないでください。
