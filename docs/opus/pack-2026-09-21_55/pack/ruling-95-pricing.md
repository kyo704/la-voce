# RULING 95 — pricing & expansion

```yaml
ruling: 95
date: 2026-09-18
supersedes: 価格と課金の正（2026-09-08）§1 の一部
reason: 製品が「声楽家向け記録アプリ」から「音楽家向け」に広がった
```

---

## 1. WHY_CHANGE

```yaml
2026-09-08時点の製品:
  - 記録アプリ ＋ 羊の着せかえ
  - 想定利用者: 声楽家のみ

2026-09-18時点の製品:
  - 記録 ＋ 分析 ＋ マッチング ＋ ポートフォリオ ＋ 公開ページ ＋ 羊
  - 想定利用者: 音楽家全般（伴奏を探す人・探される人すべて）

gap:
  - マッチングとポートフォリオに値段がついていない
  - しらべる（声の分析）は器楽奏者に価値がない
  - 器楽・ピアニストが払う理由が羊しかない
```

---

## 2. MATCHING_IS_FREE

```yaml
decision: マッチングは永久に無料

free_forever:
  - 募集を出す
  - 応募する
  - 切る（3種）
  - 通報する
  - 成立後のやりとり
  - アプリの中のポートフォリオ

reason: |
  ネットワーク効果を持つ機能は人数が価値。
  課金の壁を置くと壁の手前で止まる。
  歌い手が有料・伴奏者が無料 → 伴奏者が集まらない
  両方有料 → 人が集まらない → 機能しない
  参考: Finch / Duolingo とも中核は無料

do_not:  # 課金した人が有利になる形を作らない
  - 応募できる数の制限
  - 先に見られる（有料は24時間早く）
  - 上に表示される
  - 相手のプロフィールを詳しく見られる
  reason: |
    伴奏を探す学生と、それを狙う年長者。
    お金を出せるのは後者。課金で優位に立てる設計は加害者に武器を渡す
```

## 4. GROUP_RECRUITMENT

```yaml
decision: 作る。ただし第2段（1対1が動いてから）

changes_required:
  募集を出す:
    add: 何人 採るか（人数）
  応募を選ぶ:
    change: 複数選べる。「あと N人」を表示
    remove: 「決めると、ほかの応募は閉じます」（1人のときだけ）
  成立後:
    add: 全員が見える場所

structural_change:
  before: 1対1
  after:  N対1
  impact: 守りの設計が変わる

safety_for_groups:
  problem: |
    1対1なら相手を切れば終わる。
    団体は20人の中に1人だけ危ない人がいても、
    切ってもその人は同じ本番に参加する。練習室で顔を合わせる
  required:
    - 主催が誰か分かる（団体名・代表者名）
    - 成立後も個別に切れる
    - 通報が主催にも届く
    - 団体の募集は団体だけが出せる
  reason_last_item: 個人が「20人募集」を出せると、なりすましの温床になる

org_verification:
  who_can_post_group: 団体として登録した利用者のみ
  fields: 団体名 / 代表者名 / 活動地域 / 連絡先（運営のみ閲覧）
  note: 個人アカウントでは人数を1人より大きくできない

staging:
  1: 1対1のマッチング（設計済み・未実装）
  2: 団体の募集
  reason: 1対1が動かないうちに団体を作ると、守りの検証が二重になる
  opus_recommend: 第2段を後にする
```

## 5. PORTFOLIO_QUALITY

```yaml
decision: 有料の中核にするなら、いまの作りでは足りない

current:
  - 経歴
  - 録画
  - 公開範囲
  - 紙出力

add:
  appearance:
    what: 見た目を選べる
    was: 裁定その70で「将来追加」にしたもの
    now: 有料の中核なので前倒し
    options: 3〜4種（落ち着いた / 明るい / 古典的 / 簡素）

    what: 印刷して見劣りしない組版

  recordings_order:
    what: 録画の並べ方
    options: 本番順 / 曲目順 / 自分で並べ替え
  english:
    what: 英語版
    why: 欧州の音楽院に出すなら英語のポートフォリオが要る
    note: 「世界で使う準備 3.0」と同じ工事。画面の文字を1か所に集める作業に含める

why_this_matters: |
  応募するとき相手は経歴を見る。
  公開ページを持っている人のほうが信頼される。

  経歴を整えた手間への対価
```
