# 2. ★販売の文言の差し替え（★初版から変更なし）

★**この3つの差し替えは、★予報の有無と関係ありません。**
　★理由が別だからです（★因果を言っている／証明したと言っている）。**そのまま有効です。**

| # | 現行 | ★差し替え |
|---|---|---|
| 1 | グラフと相関分析で、**感覚を裏付けます** | **あなたの感覚と、あなたの記録を、並べて置きます** |
| 2 | 前日の過ごし方が今日の声に**どうつながるか**を可視化します | **前の日に書いたことと、今日の声を、並べて見られます** |
| 3 | …**傾向を分析します** | **書いたことの、並び方をお見せします** |

### なぜこう直すか

```
1 「裏付ける」　→ ★証明したことになります。条件を通ったものしか言えません
2 「どうつながるか」→ ★因果です。うちが言えるのは「一緒に出ている」まで
3 「分析します」　→ ★結論を約束しています

★3つとも「私たちが何をするか」→「★あなたが何を見られるか」に主語を移しています。
★主語が利用者なら、★こちらは何も約束しません。
```

## ★掃き出してほしい語

```
可視化／裏付け／証明／わかります／明らかにします
相関分析（★記事の側でだけ使う）
最適な／あなたに合った／おすすめの
改善／良くなる
★★予測／予報／目安／明日　←★★予報が消えたので、★1つ残らず消してください
```

★**最後の行が、第2版で足したところです。**
　★「明日」に触れる文言が1つでも残っていると、★消えた機能の説明になります。

# 6. coreFillNote ── ★まだ届いていません

★**121行のファイルは、★受け取っていません。**★届き次第、判定します。

★私を待たずに判定できる基準：

```
① 追いかけているか
　　◯ 開いた人にだけ、その場で見せる　→ ★表示。残してよい
　　✕ 通知／バッジ　　　　　　　　　　→ ★催促。消す

② 遅れている含みがあるか
　　✕ 「まだ4日ぶんです」　→ ◯ ★「4日ぶん たまりました」
　　✕ 「あと6日で出せます」→ ◯ ★「10日ぶんで、出せるようになります」
　　✕ 「3項目が未記入」　　→ ◯ ★言わない（★＋のまま置く）

③ 置き場所
　　✕ ホームの目立つ枠　→ ★毎日「まだ書いていない」を見せることになります
　　◯ 記録画面の中　　　→ ★書きに来た人にだけ、その場で見えます
```

★✕が1つもなければ、**戻して構いません。**
