# 第3部　★価格と、言葉

## §3-1 ★「お試し」という語は、使えません（3つの理由）

```
① ★体験期間14日と ぶつかります（★どちらも「お試し」になります）

③ ★景表法　★有料の機能を「お試し」と呼ぶと、★無料と誤認されるおそれがあります
```

## §3-2 ★言葉の案（★坂本さんのお気持ちに近いもの）

坂本さんが避けたいのは「**返す**」の重さだと思います。**衣裳部屋の言葉で言い換えられます。**

