## 1. 決定

```yaml
つたえる（公開ページ・紙の型・英語）:
  ★年6,000円（月あたり500円）  ← 年3,600円（月300円）から
  ★学生は 年3,000円（月あたり250円）
    条件: ★契約している学校の名簿にいる学生に限る（個人の学生プラン 月490円 と同じ条件）
    確かめ方: ★台帳を見るだけで自動で決まる（人の手は要らない）
      ①その人が どこかの契約校の名簿に「在籍中」として載っている
      ②その人が 在籍を確かめることに同意している（sql/02 の同意の仕組み）
    ★学校には伝わらない（誰が個人で払っているかを学校は知らない）
    ★学校が契約していない学生は 対象外（自己申告も 学生証の確認もしない）
  未経過月の返金: 500円／月（学生は250円）
変えないもの:
  別の形（デザイン）を足すとき: 1型 480円（買い切り）。14日間は無料で選び直せる
  紙の型（6種）: つたえるの中
```

## 2. なぜ変えるか

```yaml
月300円では 余裕が無い: 配信・保管・お問い合わせの受け口・独自の住所は、使われるほど費用がかかる
月500円の位置づけ: 自分でドメインとサーバを借りると 年5,000〜10,000円＋作る手間
  → ★安さの理由が説明できる値段
★安すぎる値段は 価値を下げる: 「お金がかかるものが 安く手に入る」と言うなら、
  1/50 の値段では かえって信じてもらえない
```

## 3. お金の無い人への手当て（★値段を下げる代わりに）

```yaml
学生を半額にする: ★いちばんお金が無く、★いちばんページが要るのが学生（オーディション・売り込み）
  仕組みは 個人の契約と同じ（学校の名簿にいることを確かめる。★学校には伝わらない）
紙の型は つたえるの中のまま（印刷して配るだけなら 費用がほとんどかからない）
```
