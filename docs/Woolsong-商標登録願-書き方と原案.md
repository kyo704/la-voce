## 0. なぜ1区分にしたか

**お金の話ではなく、順番の話です。**

```
出願は今すぐ出す（先願主義。出願日を押さえる）
登録料は、教室の収益が立ってから払う（2027年4月ごろ）
```

**★「登録を待つ」と「出願を遅らせる」は、まったく別の話です。**
出願を遅らせると、その間に他人が同じ名前を出願できます。
出願さえ出しておけば、登録料はあとから払えばよい。だから出願だけ先に出します。

**第9類（ダウンロード型アプリ）を落としたのは、
いまダウンロード型を出す予定がないからです。**
App Store / Google Play への配布は凍結中で、実体は
ブラウザで使う PWA、つまり第42類です。

```
第42類だけにすると
　出願料      20,600円 →  12,000円
　登録料(5年)  34,400円 →  17,200円
```

**★第9類は、ネイティブアプリを出すと決めた時点で、別途出願します。**
そのときは出願日が新しくなります。それが唯一の代償です（§8 で詳しく）。

## 1. 全体の流れと、お金の出ていく日

```
① 願書を作る（A4・1枚。tm/商標登録願_Woolsong.pdf が原案）
② 特許印紙 12,000円ぶんを貼る（★消印しない）
③ 特許庁へ書留で郵送             ← 出願日はこの日
④ 数週間後、電子化手数料の請求（2,400円＋800円×枚数＝約3,200円）→ 振込
⑤ 平均6.5か月 審査（2025年のファーストアクション平均）
⑥ 登録査定 → ★30日以内に登録料
⑦ 登録
```

```
2026年 9月    12,000円     ← 今年出ていくのは、ここと
2026年 9〜10月 約3,200円    ← ここだけ。合計 約15,200円
2027年 4月ごろ 17,200円     ← 5年分納の前期。教室の収益で払う
2032年 4月ごろ 17,200円     ← 後期。払わなければ、そこで権利が消える
```

**★5年分納にすると、10年一括（32,900円）より総額は 1,500円 高くなります。**
それでも分納を勧めるのは、**2027年4月に手元にある現金**の話だからです。

## 2. 区分と、指定役務

```
【第４２類】
電子計算機用プログラムの提供，電子計算機のプログラムの設計・作成又は保守
```

**★区切りは全角カンマ「，」です。読点「、」ではありません。**

### なぜこの2つか

```
電子計算機用プログラムの提供（42X11）
  → SaaS・ASP。「ダウンロードさせずに使わせる」形。★Woolsong の本体そのもの

電子計算機のプログラムの設計・作成又は保守（42P02）
  → 教室・大学向けに作り込む場合。受託の形をとったときに効く
```

**★「サーバーの記憶領域の貸与」は、あえて入れていません。**
料金は増えませんが、これは「他人に保管場所を貸す」役務です。
Woolsong がサーバーに記録を置くのは、サービスに付随する動作であって、
保管場所を貸しているわけではありません。
**使っていない役務は、3年後に他人から取消を請求できます（不使用取消審判）。**
実際に使う2つだけにしておくのが、いちばん強い形です。

**★第44類（医療・健康相談）は絶対に入れないでください。**
権利としては魅力的に見えますが、
**「医療に近いことをする事業者」だと、自分で宣言する**ことになります。
これまでこの製品が守ってきた線（疑い・リスク・早期発見という語を使わない）と矛盾します。

**第41類（オンラインの教育・記事）は、いまは要りません。**
「学ぶ」の有料記事を本格的に売るときに、追加で出願できます。

## 4. 願書のひな型（第４２類のみ）

**A4縦・横書き。`tm/商標登録願_Woolsong.docx` が、この形で出来ています。**

```
【特許印紙】
（12,000円ぶんを貼付。★消印しない）

【書類名】       商標登録願
【整理番号】     WS-001
【提出日】       令和8年9月◯日
【あて先】       特許庁長官殿
【商標登録を受けようとする商標】
                 Ｗｏｏｌｓｏｎｇ
【標準文字】
【指定商品又は指定役務並びに商品及び役務の区分】
【第４２類】
【指定商品（指定役務）】 電子計算機用プログラムの提供，
                         電子計算機のプログラムの設計・作成又は保守
【商標登録出願人】
【住所又は居所】 山梨県甲府市長松寺町１−２２
【氏名又は名称】 坂本　響
【電話番号】     ０８０−９３６０−８９４３
```

```
・★項目の順序と【 】の表記は、特許庁の様式どおりに
・押印は不要です（2021年から原則廃止）
・★【標準文字】と書くと、書体を問わない権利になります
   ロゴの形で守りたいときは別の出し方ですが、★今回は標準文字で十分です
・商標の欄には「Woolsong」とだけ書きます
   ★カタカナ「ウールソング」を併記しない（別の商標として扱われます）
```

### ★カタカナを併記しない理由

**「Woolsong」と「ウールソング」を1つの願書に並べると、
「二段併記」という別の商標になり、審査でも権利範囲でも扱いが変わります。**

**英字だけで出願すれば、称呼「ウールソング」も自動的に保護の対象になります。**
片仮名を別に取りたければ、後日もう1件出す形です。

## 6. ★出国前に、必ず決めておくこと

**10月中旬に日本を出ると、坂本さんは商標法上の「在外者」になります。**
在外者は、原則として日本国内の代理人を通してしか手続ができません
（商標法77条2項 → 特許法8条）。

```
出願（9月）        まだ日本にいる  → 自分で出せる
登録料の納付       在外者          → ★ここが問題になる可能性
拒絶理由への応答   在外者          → ★同上
```

**★出国前に、知財総合支援窓口で必ず聞いてください（無料）。**

```
□ 在外者になったあと、登録料の納付は誰が、どうやってするのか
　 （国内に住所のある「商標管理人」を、いま立てておく必要があるか）
□ 拒絶理由通知が届いたとき、イタリアから応答できるのか
□ 第42類だけで出す場合、第9類を空けておくリスクはどのくらいか
□ 指定役務の書き方は、これで通るか（願書は既に作ってあります）
```

**これは自分で判断できる範囲を越えています。必ず人に聞いてください。**

## 7. 出願したあと

```
数週間後   電子化手数料の請求（2,400円＋800円×枚数）→ 振込
1〜2か月   出願番号の通知
平均6.5か月 審査 → 登録査定 または 拒絶理由通知
登録査定後 ★30日以内に登録料 17,200円（5年分納・前期）
```

```
参考（特許庁の2025年の数字）
　ファーストアクションまでの平均   6.5か月
　早期審査を使った場合             1.9か月
　登録率                           87.5%
　代理人を立てずに出願した割合     24.6%
```

**拒絶理由通知が来ても、終わりではありません。**
意見書か補正書で応答できます。**そのときは弁理士に相談してください。**

**★登録料を30日以内に払わないと、出願そのものが失効します。**
出願日の利益も失われ、最初からやり直しになります。
2027年4月ごろに 17,200円 が要ることを、忘れないでください。

## 8. 第9類を空けることの、本当のリスク

**正直に書きます。ここは断定できません。**

```
起こりうること
　誰かが第9類で「Woolsong」を出願し、登録される
　→ ネイティブアプリを出すときに、その名前を使えなくなる

起こりにくい理由
　「Woolsong」は造語で、J-PlatPat の称呼検索で0件だった
　第42類で登録されていれば、第9類の類似判断でも考慮される
　（第9類のソフトウェアと第42類のSaaSは、実務上そこそこ近い関係にある）

★ただし「考慮される」は「必ず止まる」ではありません
```

**このリスクの大きさは、知財総合支援窓口で聞いてください（§6）。**
そのうえで「やはり第9類も要る」と言われたら、
出願は分けずに、いま2区分で出すほうが安全です。**判断材料は窓口にあります。**

## 9. ★出願日から6か月の意味

**この出願日から6か月以内なら、EUと中国でも「この日に出願した」ことにできます**
（パリ条約の優先権）。

```
2026年 9月◯日   日本で出願
    ↓  ★この6か月が、EUと中国の席を押さえている期間
2027年 3月◯日   ここまでにEU・中国へ出せば、9月◯日の出願として扱われる
```

**中国は、外国のブランドを先回りして出願する例が多い国です。**
**この6か月のうちに、中国だけは弁理士に相談してください。**
イタリアにいる期間と重なるので、**日本にいるうちに、誰に頼むかだけ決めておく**のが安全です。
