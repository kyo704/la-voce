## Woolsong プライバシーポリシー

版　privacy-ja-2026-09-v1
制定日　★★（公開する日を入れてください）

Woolsong（以下「本サービス」）は、声を使う方の体調の記録をお預かりします。
記録には、健康に関するものが含まれます。
どのようにお預かりし、何に使い、どこまで守るのかを、以下にお示しします。

読みやすさを優先して書いていますが、内容は
個人情報の保護に関する法律（以下「法」）に沿ったものです。

---

### 1　わたしたちについて

```
事業者    Woolsong（坂本 響）
所在地    お問い合わせいただければ、遅滞なくお答えします
連絡先    woolsong.app@gmail.com
```

本サービスは、個人が運営しています。

---

### 2　お預かりする情報

**あなたが入力するもの**

```
・お名前または表示名、メールアドレス
・体調の記録
　　睡眠時間、のどの状態、声を使った時間、むくみ、
　　本番の翌日かどうか、その日の活動と強さ、など
・既往症（一覧からお選びいただくもの）
・常用薬、アレルギー
・健康に関する自由記述
・レッスンの予定と出欠（教室・学校でお使いの場合）
・年齢の区分（15歳未満／15〜17歳／18歳以上）

　　★生年月日は、お預かりしません。
　　　年齢の区分だけをお聞きし、それ以外は記録しません。
```

**自動で記録されるもの**

```
・ログインの日時
・アプリの利用に伴う技術的な記録（エラーの記録など）
```

**外から取り込むもの**

```
・お住まいの地域の気温・湿度（お住まいの地域をご指定いただいた場合）
```

---

### 3　何に使うか（利用目的）

```
1  あなたの記録を保存し、あなたに見せるため
2  あなたの記録から、不調と関係の深い要因を統計で示すため
3  教室・学校でお使いの場合、レッスンの予定と出欠を管理するため
4  本サービスの不具合を見つけ、直すため
5  お問い合わせにお答えするため
6  本サービスの改善のため、個人を特定できない形にしたうえで集計するため
```

上記以外の目的には使いません。
目的を追加するときは、事前にお知らせし、必要な場合はあらためて同意をいただきます。

---

### 4　健康の記録について（要配慮個人情報）

体調の記録のうち、**既往症（逆流性食道炎・声帯結節などの持病）に関するもの**は、
法律上「要配慮個人情報」にあたります。
これをお預かりするには、あらかじめご本人の同意が必要です（法20条2項）。

**いただいた記録は、すべて要配慮個人情報に準じて取り扱います。**

同意は、いつでも撤回できます。撤回の方法は、第11項に記載しています。

---

### 5　だれが見られるか

```
本サービスは、あなたの体調の記録を
あなた以外の方が参照する機能を持ちません。
教室・学校でお使いの場合も同じです。
```

教室・学校の指導者・運営者に伝わるもの

```
・あなたの表示名
・あなたの職業
・レッスンの予定
・レッスンをやったかどうか
・あなたが送った連絡（欠席、遅れます）
```

本サービスは、教室・学校の指導者・運営者、および他の利用者が
次のものを参照する機能を持ちません。

```
・体調の記録
・既往症、服薬、その他の健康に関する情報
・月経周期の記録
・本サービスが示す分析の結果
・記録の中の、自由に書ける欄
```

**運営者について**

不具合の調査のために、運営者（坂本 響）が記録に触れることがあります。
そのときは、必要な範囲に限り、目的が終われば見ません。
調査のために体調の記録そのものを読む必要が生じた場合は、
あらかじめご本人にご連絡します。

### 8　自由に書ける欄について

体調の記録には、ご自身で自由に書ける欄があります。

その欄に、診断名やお薬の名前を書かれた場合、
それも要配慮個人情報として、同じようにお預かりします。

持病については、自由記述ではなく、一覧からお選びいただくことをおすすめします。
あとから「持病の記録だけを消したい」とご希望いただいたときに、
確実にお応えできるためです。

---

### 9　どのくらい保存するか

```
アプリの中        あなたが削除するまで
バックアップの中  削除後、最大30日。その後、自動的に消えます
```

削除をご希望の場合、アプリからはすぐに見えなくなり、記録も消えます。
安全のために取っているバックアップには最大30日残り、その後、自動的に消えます。
**バックアップから復元することになった場合も、削除された記録は元に戻しません。**

法令で保存が義務づけられているもの（取引の記録など）は、
削除のご依頼をいただいても、法定の期間、保存します。
現在、そのような記録はお預かりしていません。

### 10　統計への利用

本サービスは、記録から「不調と関係の深い要因」を統計で示します。

```
あなたに示す統計    あなたの記録だけを使います

サービス改善のための集計
　　個人を特定できない形にしたうえで行います
　　人数が少ないと個人が分かってしまうため、
　　一定の人数に満たない集計は、そもそも作りません
```

あなたの記録が、他の方に示される統計に使われることはありません。

```

　　　　　　　（「今日」「ノート」「分析」の各画面）

書き出す      「もっと ＞ アカウント ＞ データの書き出し」から、

消す          「もっと ＞ アカウント ＞ アカウントの削除」から、
　　　　　　　いつでも削除できます

同意をやめる  「もっと ＞ 設定 ＞ プロフィール・記録項目 ＞
```

同意の状態とは関わりなくできます。

これらのほか、法の定めにより、利用目的の通知、開示、訂正、
利用の停止、消去、第三者提供の停止をご請求いただけます（法32条〜35条）。
