# La Voce ／ 続けてもらうための設計（理論と、課金への導線）

**Claude Sonnet 5 へ。これは新しい機能を足す文書ではありません。**

**すでに散らばっている機能の「なぜ」を1本にまとめ、
判断に迷ったときの基準にするための文書です。**

理由の書いていない機能は、あとで「不要では」と削られます。
**この文書に載っている機能を、簡潔化の名目で削らないでください。**

読む順番：統合実行ルート v4 → 記録と分析の順番設計.md → 本書。

---

## 0. 結論

```
① ★手応え（毎回）と 発見（月1回）を分ける。
   発見を早めることはできない。手応えは1秒で返せる。

② ★滞在時間を伸ばさない。目標は「40秒で閉じてもらう」こと。
   暇な時間を取りに行かず、すでにある習慣にくっつける。

③ 割引をしない。代わりに ★3ゲートを通った「最初の1件」を無料で開く。
   値引きではなく、その人自身の証拠で転換する。

④ ★罪悪感を作らない。悪い日のデータが最初に失われる。
```

---

## 1. 前提：8割は離れる

健康アプリ全体では、**初回で7〜8割が戻らず、30日後に残るのは3〜4%**です。

La Voce は職業特化で、先生経由で広がり、記録が仕事に直結するので、
**30日後に15〜25%、90日後に8〜15%**を見込んでいます。

**それでも8割は離れます。これは前提であって、失敗ではありません。**

**設計の目標は「全員を引き止める」ことではありません。**
**効く人に確実に届き、離れた人が戻ってこられることです。**

## 2. 脱落する5つの地点と、対策の在りか

| # | いつ | なぜ落ちるか | 対策 | どこにあるか |
|---|---|---|---|---|
| 1 | Day 0-1 | 記録画面が重い | かんたん／しっかりの切り替え（★既定はかんたん） | ルート G2-8 |
| 2 | Day 2-7 | 記録しても何も返らない | 即時フィードバック／保存直後の羊とポイント | ルート G2-9・10 ／ 本書 §3 |
| 3 | **Day 7-30** | **3ゲートの沈黙** | **進捗ドット／「この分析を強くする」カード／週次の振り返り** | 表示規約 部品F ／ ルート G2-11 |
| 4 | Day 30+ | 調子が良いと記録の理由が消える | 羊のおうち／レッスン前後・本番前後の導線 | 羊のおうち仕様 ／ レッスンモードの解体 §5・§6 |
| 5 | **随時** | **★調子が悪い日に記録しなくなる** | **悲しい顔を作らない／催促しない／1タップで終わる** | 羊の表情 §2-1 ／ レッスンモードの解体 §11 |

**3が最大の関門です。**正しさと引き換えに、分析が何も言わない期間が続きます。

**5がいちばん深刻です。**落ち込んでいる日は記録したくない。
**そしてその日のデータこそが、この製品の全部です。**

## 3. ★手応えと発見を分ける

### 3-1｜発見は早められない。手応えは1秒で返せる

```
発見   3ゲートを通った関係。★月に1回で十分。盛らない
手応え 入力した瞬間に返る反応。★毎回いる
```

**手応えに統計は要りません。**その場で言える本当のことで足ります。

```
発話時間 45分 と入れた瞬間
  →「直近14日で3番目に長い日です」

湿度 38% と入れた瞬間
  →「あなたが記録した中で、いちばん乾いています」

睡眠 5時間30分 と入れた瞬間
  →「直近14日の中央値は6時間45分です」

保存した瞬間
  → 羊が笑う ＋「7日つづいています」
```

**特徴**

```
・★計算が軽い（並べ替えと中央値だけ。3ゲートは要らない）
・★初日から出せない項目は、出さない（「まだ比べられません」でよい）
・★良し悪しを言わない。順位と位置だけ
・★1つの項目につき1行。並べない
```

**「3番目に長い」は判定ではなく事実です。** だから3ゲートの外で出せます。
**ただし「長いから悪い」とは絶対に書かないこと。**

### 3-2｜★「今日の1つ」

**開いたときに、自分についての小さな事実を、1つだけ出します。**

```
┌──────────────────────────────┐
│ 8月の記録は、7月より4日多くなっています。   │
└──────────────────────────────┘
```

```
・★1つだけ。フィードにしない。並べない
・毎回違うものを出す（直近7日に出したものは出さない）
・★記録の「量」や「継続」についての事実を優先する
   → 中身についての事実は3ゲートの領域
・出すものが無い日は、★何も出さない（無理に作らない）
```

**1つだけ、というのが効きます。**2つ出した瞬間に、読み飛ばす対象になります。

## 4. ★滞在時間を伸ばさない

### 4-1｜目標は「40秒で閉じてもらう」こと

**短い動画と暇な時間を奪い合ったら、必ず負けます。だから戦いません。**

滞在時間を伸ばそうとすると、こうなります。

```
記録が面倒になる → 通知が増える → 罪悪感が出る → 悪い日のデータが消える
```

**全部、この製品を壊す方向です。**

```
★「1日あたりの滞在時間」を目標にしないでください。
★「セッション長」を伸ばす施策を作らないでください。
```

### 4-2｜暇な時間を取りに行かず、習慣にくっつける

```
レッスンが終わった直後の90秒     ← レッスンモードの解体 §5
次のレッスンの30分前              ← 同 §6
本番の翌朝、起きたとき
寝る前
```

**決まった時間に短く入る。**レッスンモードを解体して「レッスンの前後」に
置き直したのは、この理由です。

### 4-3｜計測するもの

```
○ ★声の出来が低い日の記録率     ← いちばん重要（記録と分析の順番設計 §7）
○ 記録1回あたりの所要時間（★短くなるほど良い）
○ Day 7 / 30 / 90 の継続率
○ 「最初の1件」に到達した人の割合
✗ 1日あたりの滞在時間
✗ 1日あたりの起動回数
```

## 5. ★最初の1件を無料で開く（課金への導線）

### 5-1｜しくみ

**3ゲートを初めて通った関係を、無料ユーザーにも1件だけ全部見せます。**

```
┌──────────────────────────────┐
│ 食後就寝までの時間と、翌朝の声              │
│                                            │
│ 2時間未満の翌朝は、2時間以上の翌朝に        │
│ くらべて声の調子の記録が低めでした。        │
│                                            │
│ 2時間未満 31回 ／ 2時間以上 24回           │
│ 差の大きさ 中程度                          │
│ ──────────────────────────  │
│ これはあなたの最初の発見です。              │
│ プレミアムにすると、ほかの関係も見えます。  │
│                     [ くわしく見る ]        │
└──────────────────────────────┘
```

**値引きではなく、その人自身の証拠で転換します。**
「払えば何か見えるかもしれない」ではなく、「**現に見えた。もっと見たい**」。

**そして製品がタイミングを決めるので、価値が出た瞬間ちょうどに勧誘できます。**

### 5-2｜実装の条件

```ts
interface FirstInsight {
  userId: string
  unlockedAt: string
  featureKey: string     // どのカードを開いたか
  // ★1人につき1件だけ。2件目は開かない
}
```

```
・★1人につき1件だけ。永久にその1件は見られる
・★モーダルで覆わない。そのカードの場所に、そのまま出す
・★周期・食事と就寝からは選ばない
   → 要配慮情報を「おまけ」に使わない。ほかの関係から選ぶ
・複数が同時に通ったら、★n がいちばん多いものを選ぶ（いちばん確かなもの）
・founder には出さない（全部見えているため）
```

**3つ目を省略しないでください。** 周期の分析を販促に使うのは、
この製品が守ってきた線の外側です。

### 5-3｜★やらないこと

```
✗ 初月割引
   最初の1か月は、この製品がいちばん役に立たない期間です。
   何も出ない月に払わせて、2か月目に解約されます。
   そして ¥680 の半額は ¥340。動機になりません。
   ★値引きの効果はないのに「安い製品」の印象だけ残ります。

✗ 30日間の無料トライアル
   切れる頃にやっと1件出る、という最悪のタイミングです。

✗ 期間限定セール
✗ 友だち紹介でポイント（★ポイントは記録に対してのみ）
```

## 6. 年払い

**これは筋の通った割引です。**

```
月払い ¥680 × 12 = ¥8,160
年払い ¥6,800（★2か月分無料）
```

**この製品は、効果が出るまでに数か月かかります。**
年払いは、**その時間軸に合意した人**が選ぶものなので、
値引きではなく前提の一致です。

**★年払いでも、途中解約時の記録は消しません。**

## 7. ★禁止事項

```
1.  ★連続記録が途切れたときに、失う演出をしない
2.  ★記録がない日に催促の通知を送らない
3.  ★ランダム報酬・ガチャを作らない
4.  他人との比較・ランキングを作らない
5.  ★滞在時間・起動回数を目標にしない
6.  即時フィードバックで良し悪しを言わない（順位と位置だけ）
7.  「今日の1つ」を2つにしない
8.  ★初月割引・期間限定セールをしない
9.  ★「最初の1件」を周期・食事と就寝から選ばない
10. 「最初の1件」を2件目に広げない
11. ★悲しい顔・がっかりした顔を作らない
12. 久しぶりに開いた人に、不在を指摘しない
```

**12について：** 2か月ぶりに開いた人の画面は、
**7日連続で使っている人の画面と同じ**でなければいけません。
記録は全部残っていて、羊はふつうに笑っている。**それだけです。**

## 9. Sonnet への依頼のコツ

**この文書に書いてあることの多くは、
「作らない」「増やさない」「伸ばさない」という形をしています。**

実装中に、次を思いつくはずです。

```
・連続記録が途切れそうなときに通知する
・記録した項目数に応じてボーナスを出す
・「今週のあなたの順位」を出す
・初月半額のキャンペーンを作る
・分析画面をもっと見てもらうために、開いたときに全部展開する
```

**5つとも §7 で禁止しています。**
どれも「継続率を上げるため」という正しい動機から出てきます。

**迷ったときの基準は1つです。**

```
★その施策は、調子が悪い日に記録する人を増やしますか？ 減らしますか？
　→ 減らすなら、継続率が上がっても、作らない。
```
