# 第2部 ── 書き出す・退会の 同居問題（★最終の 見立て）

## 8. 何が同居しているか

`components/VocalTracker.jsx:22741` の1枚のカードです。

```
┌─ アカウント ───────────────┐
│ ┌─ データを書き出す ───────┐ │
│ │ （説明2〜3行）              │ │
│ │ ［データを書き出す］         │ │
│ │ ［記録の控えを開く（印刷・PDF）］│ │
│ └───────────────────┘ │
│ 🗑 アカウントを削除する      →  │
│ ⇥ ログアウト                   │
└──────────────────────┘
```

題は「アカウント」。中に、書き出し・控え・退会・ログアウトの4つ。

## 9. 見本は どう しているか

見本の もっと は、**1つの平らな箱**です。見出しも区切りもありません。

```
設定 ›
毎日、聞いてほしいこと      5つまで ›
通っている ところ            2つ ›
アカウント ›                 ← ★シートが開く
プラン                      無料 ›
学ぶ ›
書き出す（CSV・JSON） ›
同意を とりけす ›
退会する ›
```

添える1行 ──「**法律の 行き先を、この 1か所に 集めています。**」

そして「アカウント」を押すと、別のシートが開きます ──
`SH['account']` = メールアドレス／パスワードを 変える／端末を 見る／**ログアウト**。

★見本の答えは、はっきりしています。

- **書き出す・同意・退会** … もっとの一覧の行。それぞれ独立した画面へ。
- **ログアウト** … 「アカウント」シートの中。もっとの直下ではない。

つまり見本では、この4つは**同じ器に入っていません**。

## 10. アプリの いまの 形

`lib/moreMenu.js` の `MORE_ROWS` は、すでに見本どおりです。

```
書き出す（CSV・JSON）   group: "じぶんの記録"
同意を とりけす         group: "じぶんの記録"
退会する               group: "じぶんの記録"  danger: true
アカウント             sheet: true   ← 別のシート
```

`lib/recordSheets.js` の `ACCOUNT_ROWS` も見本どおりです ──
メールアドレス／パスワードを 変える／ログアウト。

★つまり**新しい一覧は、もう正しい形になっています**。
同居しているのは、その下に残っている**古いカード1枚**だけです。

## 11. ★ここが 難しいところ（★ご判断が要る 理由）

このカードは `inMore("じぶんの記録")` で出し分けています。

```js
function inMore(section) {
  if (!layoutV2) return undefined;          // ★門の外 … いつも 出る
  return moreSection === section ? undefined : "none";
}
```

- 門の**外**（38名の方）… このカードが、もっとの画面にそのまま出ています。
  一覧の形にはなっていません。**このカードが唯一の入口です**。
- 門の**中**（坂本さん）… 一覧から「じぶんの記録」を選んだときに出ます。

★だから、このカードを消すと、**38名の方の退会・書き出し・ログアウトの
入口が同時に消えます**。

「古い機能を隠すな、仕分けろ」の仕分けで言えば ──

| 仕分け | 当てはまるか |
|---|---|
| ①消す | ★門の外の方の入口が消えるので、**そのままでは不可** |
| ②見せ方を変える | ○ 中身は正しい。器の分け方だけが違う |
| ③引っ越す | ○ ログアウトだけをアカウントのシートへ移す |
| ④経路ごと消す | × 退会も書き出しも法律上必要な道です |

## 12. ★私の 最終の 見立て

**②と③の組み合わせ**を勧めます。順番は次のとおりです。

### 第1段（★いますぐできる・門の中だけ）

門の中（`layoutV2`）のときだけ、カードを2つに割ります。

- カード1「じぶんの記録」… 書き出す／記録の控え／同意をとりけす／退会する
- ログアウトは、**アカウントのシートへ移す**（`ACCOUNT_ROWS` にもう入っています）

★門の外は、1文字も変わりません。

### 第2段（★門を広げるときに、まとめて）

門の外の方が新しい一覧に移るときに、古いカードごと消します。
それまでは残します。

★理由は、38名の方の画面を、退会の入口ごと変えないためです。
順序を守るなら、入口の増設が先で、古い入口の撤去はあとです。

### ★第1段でも手を付けないほうがよいもの

「記録の控えを開く（印刷・PDF）」── 見本にありません。
書き出すの調べ（㋖）で「見本より多いところ」として挙げたものです。
場所を動かすと、どこへ行ったか分からなくなります。いまの場所に残します。
