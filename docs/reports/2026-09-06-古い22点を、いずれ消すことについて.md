## ① ご質問1 ── 設計は、変わります。3つ変わります

**はい、変わります。しかも、良い方向に変わります。**

### 変わり方1　★22点ぶんの絵を描く案が、消えます

以前お出しした案2（22点ぶんの PNG を描く）は、**やらなくてよくなりました。**
いずれ消すものに、絵を22枚描くのは、無駄です。

★これで、選択肢が2つに減ります。

### 変わり方2　★★順番が、いちばん大事になります

**「先に配る。あとで消す。」**この順にすると、消す日に何も起きません。
逆にすると、消す日が「取り上げの日」になります。

```
★良い順　　1. 代わりの品を、先に配る（★増えるだけ。減らない）
　　　　　　2. 店から下ろす（★もう売らない）
　　　　　　3. しばらく置く
　　　　　　4. 絵を描く処理を消す（★このとき、誰も何も失わない）

★悪い順　　1. 絵を描く処理を消す（★その場で羊から消える）
　　　　　　2. お詫びとお知らせ
　　　　　　3. 代わりの品を配る
```

**同じ場所に着きますが、途中がまったく違います。**
★良い順なら、**お詫びが要りません。**「増えました」で済みます。

### 変わり方3　★「消す」を、3つに分けて考えます

**この3つは、まったく別のことです。**

```
①店から下ろす　　　　もう売らない　　　　★いつでも、安全にできます
②絵を描く処理を消す　SheepCharacter の中の22個の分岐
　　　　　　　　　　 ★持っている方の羊から、その品が消えます
③持ちものの記録を消す character_inventory の24行
　　　　　　　　　　 ★★これは、してはいけません
```

★★**③は、しないでください。**

この企画の決まりです。
「受け取ったものは取り上げない」「書いたものを消さない」。
**24行を残しても、費用はかかりません。**
消して得られるものは、何もありません。

★①と②だけで、「一本化」は達成できます。

## ③ ご質問2 ── 3人の方への対応

### ★まず、確かめていただきたいことがあります

**24行の内訳が、まだ分かりません。**

いただいた数（hat_straw が3人、ほかの21点が1人ずつ、合計24行）から、
**こう推測しています。**

```
1人　　22点ぜんぶをお持ち（★ためしに全部買われた方かもしれません）
2人　　麦わら帽子だけ
```

★もしそうなら、**話はとても小さくなります。**
　★麦わら帽子には、そのまま同じものがあります。
　★★お2人は、何も失いません。

**どなたが何をお持ちか、確かめる照会を出しました**
（`supabase/2026-09-08-古い22点-誰が何を持っているか.sql`）。
★試験にご協力の方（is_tester）かどうかも、一緒に見ます。

### ★対応の案

**案あ：先に配って、あとで消す（★おすすめ）**

```
1. 20点について、代わりの品を、その方の持ちものに足す（★無料）
   ★増えるだけです。★何も減りません
2. お知らせは「増えました」。★お詫びではありません
3. 店から下ろす
4. しばらく置いてから、絵を描く処理を消す
   ★このとき、代わりを既にお持ちなので、何も失われません
```

**お箸とフォークの2点は、どうするか。**

```
案あ-1　この2点だけ、絵を残す（★消さない）
　　　　★22点のうち20点が消えれば、一本化はほぼ達成できます
　　　　★残り2つのために、分岐を2つ残すだけです
案あ-2　217点に、食器の持ちものを2点足す
　　　　★絵が2枚要ります
案あ-3　消して、その方にお知らせする
　　　　★★取り上げになります。★おすすめしません
```

★★わたしは **案あ-1** を推します。
　★2つ残すだけで、**誰からも何も取り上げずに済みます。**
　★「ぜんぶ消す」ことより、「誰も損しない」ことのほうが大事だと思います。

### ★身につけたままの方（1人）について

**帽子を身につけておられる方が、1人いらっしゃいます。**

絵を描く処理を消すと、**その方の羊から、帽子が消えます。**
気づかないうちに、姿が変わります。

★代わりを配るときに、**身につけている状態も一緒に移してください。**
　`character_equipped.hat` が古い鍵なら、
　`character_equipped.wardrobe.hat` に、新しい鍵を入れます。

★★ただし、**同じ絵ではありません。**
　★古い麦わら帽子は SVG、★新しいものは絵です。★見た目は変わります。
　★「同じ帽子が、描き直されました」という説明が要ります。
