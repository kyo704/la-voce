## 3. 部品（9種）

**この9種以外の図を作らないでください。** 増やしたくなったら質問してください。

### A｜数値ヒーロー ＋ スパークライン

**使う場面**：今日のスコア、中央値など、1つの数字が主役のとき。

```
・数字 36px / 単位と補足 13px --ink-2
・★右に直近14日のスパークラインを添える（96×26px、点は最新のみ）
・スパークラインに軸・目盛りを付けない
```

**数字だけでは「今日が良い日なのか」が分かりません。**
推移を横に添えるだけで、同じ数字が読めるようになります。

### B｜内訳の横棒

**使う場面**：コンディションスコアの内訳、当てはまった日数。

```
・高さ5px、角丸3px、下地 --track、塗り --s2
・★全部同じ色。値によって色を変えない
・ラベル左・数値右、数値は太字
・並び順は固定（★値の大小で並べ替えない。毎回順番が変わると読めない）
```

### C｜1次元の点列（今日の位置）

**使う場面**：直近N日の中で今日がどこか。**今のリング表示の置き換え。**

```
・横軸はスコア。点ひとつが1日
・過去の日は --muted、今日は --s1 で少し大きく、上にラベル
・目盛りは3〜4本だけ
```

**リングは「7／9日中」しか言えませんが、点列は
順位と散らばりを同時に見せます。**
良い日と悪い日がどれくらい離れているかが分かります。

### D｜推移の線＋強調点

**使う場面**：声の調子、食後就寝までの時間など、日ごとの推移。

```
・線は --s1、太さ1.8px、不透明度0.3（線は補助。主役は点）
・点は半径3.2px、面の色で1.8pxの縁取り（重なっても数えられる）
・★本番・レッスンの日だけ --s2 にして半径4.8px
   → 色と大きさの両方で区別する（色だけに頼らない）
・目盛り線は --grid、横だけ。縦の目盛り線は引かない
・★基準線を引かない。引くなら「あなたの中央値」を破線 --ink-3 で
```

### E｜2群のドットプロット（★判定が出たとき）

**使う場面**：3ゲートを通った群間比較。

```
・1日ぶんの点を全部描く（重なりは縦に±4pxずらす）
・点は不透明度0.45、面の色で1.6pxの縁取り
・★各群の中央値を縦線で示し、数値を直接ラベルする
・軸は下に1本。ラベルは「低い ← → 高い」
・★棒グラフにしない
```

**平均の棒2本にすると、差が実際より確かなものに見えます。**
点を全部出すと重なりが見え、「2時間未満でも良かった日はある」が伝わります。
**効果量が中程度、というのはそういう意味です。**

### F｜進捗ドット（★判定できないとき）

**使う場面**：件数が足りていない全ての分析カード。

```
・9px の丸を10個。たまった分だけ --s2、残りは --track
・★「今日の記録」の点と同じ形にそろえる
・文言は「◯日分たまりました。あと◯日で傾向を出せます。」
・★「データがありません」と書かない
```

### G｜期間の帯＋点（横並び）

**使う場面**：周期など、繰り返す期間どうしの比較。

```
・行は直近6件まで。横軸は「何日目か」（★日付ではない）
・帯は --band、高さ8px、角丸4px
・点は --s1（ふつう以上）／ --muted（低い）
・★この図に解釈の文章を添えない
```

**並べれば、本人が自分で気づきます。教えないでください。**

### H｜小さく並べる（単位が違うもの）

**使う場面**：カロリーと体重など、縦軸の単位が違うものを一緒に見るとき。

```
・★1枚に2つの縦軸を重ねない（交点の位置が軸の取り方で変わる）
・x軸だけ揃えて、上下に分けて並べる
・それぞれの縦軸は実際の目盛りのまま

**今のサイトが既にこの形を選んでいます。正しい判断なので、変えないでください。**

### I｜散布図（相関を出すとき）

```

```

**③を「関係なし」と書かないでください。**

```

# 付録　★3ゲートとは何か（★この規約の本文ではありません）

## 3つのゲート（★数値は確定。勝手に緩めないこと）

```
① 件数　　　各群 n ≥ 10、かつ両群が揃っている
② 効果量　　|Hedges' g| ≥ 0.4
　　　　　　（相関で語る場合）|ρ| ≥ 0.3
③ 多重比較　BH-FDR で q < 0.10
```

★**3つを全部通ったときだけ**、文章で語ってよい、という決めです。

## なぜ件数だけでは足りないのか（★実装の側の覚え書きから）

> 「良い日にも悪い日にも白米」は、件数の問題ではありません。効果量がゼロなのに
> 文章を出したことが問題です。n が100あっても出してはいけません。
> 文章で語るものは、①件数 ②効果量 ③多重比較 の3つを全部通ったときだけ出します。

## 通らなかったときは、消さずに置き換える

> 条件を満たさないとき、このレイヤーは必ず「あと◯で何が見えるか」を返します。
> 呼び出し側は、何も表示しないのではなく、この message を出してください。

★これが、★規約 §5 の「① 待機 → F（進捗ドット）」と対応しています。
