## 一 ★違い ── ★**枝の 中身が 入れ替わって いる だけ** です

`lib/roomStage.js`。★どちらも 同じ 引数（箱の 幅・高さ・比）を 取ります。

```js

  if (w / h >= a) return { w: w,     h: w / a };  // ★横長の 箱 … 幅を 合わせる
  return              { w: h * a, h: h };         // ★縦長の 箱 … 高さを 合わせる
}

export function stageFit(boxW, boxH, aspect) {    // ★収める（contain）
  if (w / h >= a) return { w: h * a, h: h };      // ★横長の 箱 … 高さを 合わせる

}
```

★★★2行が、★そのまま 入れ替わって います。

| | 箱より | 余白 | 切れる |
|---|---|---|---|
| `stageSize` | ★大きい（覆う）| 出ない | ★出る |
| `stageFit` | ★小さい（収める）| ★出る | 出ない |

★★比が ぴったり 合う 箱では、★2つは **同じ 値**を 返します。
★★いまの 端末が それ です（★実測 390×278.56 ── ★どちらも 同じ）。
