## 2. ★では、なぜ見えないのか（2つあります）

```

```

### ㋑ プランの値段の札は、★坂本さんには出ません

プランの節が出る条件は `subscribed !== true && paidGateApplies` です。

`paidGateApplies` は `!mayViewSummary(...)`。
そして `mayViewSummary` は、★`NEXT_PUBLIC_GATE_TEST_USER_IDS` に
載っている方には **true** を返します（=門がかからない）。

```js
const only = gateAppliesTo(userId, env);
if (only === false) return true;   // ★一覧に居ない → 門はかからない
```

★`/api/version` は `gateTestIds: true, counts: 2` と返しています。
坂本さんがその2名のどちらかなら、★**プランの札そのものが出ません**。

★これは不具合ではありません。試す方に門をかけない、という決めです。
