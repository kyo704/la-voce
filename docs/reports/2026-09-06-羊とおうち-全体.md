## 1. 何ができるようになったか

**動きが5つになりました。**

| 名前 | いつ出るか | どこで |
|---|---|---|
| still（止まる） | ほかのどれでもないとき | おうち・庭 |
| walk（歩く） | 歩いているとき | おうち・庭 |
| sleep（眠る） | 寝ているとき | おうち |
| celebrate（喜ぶ） | 喜んでいるとき | 庭 |
| farm（畑にいる） | 畑仕事のとき | 庭 |

5つとも、実際に画面から呼ばれていることを、試験で確かめています。
作ったのに呼ばれていない動きは、ありません。

**おうちと庭の羊が、着せかえの羊になりました。**
217点の服が、歩いても眠っても、体と一緒に動きます。
門が閉じている方には、これまでどおり SVG の羊が出ます。

**壁と床に、写真のような絵を敷けるようになりました。**
インテリア第1便（壁10・床9）です。

## 2. 途中で見つけて、直したこと

**① 画面に2匹いると、片方の動きが消えていました。**

庭の画面では、着せかえの見本と、おうちの羊が、同時に出ています。
動きの名前が同じだったので、あとから描かれたほうの定義が、
先のものを上書きしていました。止まっている羊（移動0）の定義が勝つと、
見本の「歩かせてみる」が、その場で止まって見えます。
名前に動きを混ぜて、分けました。試験でも見張っています。

**② 絵はあるのに、店に無い材質が17点ありました。**

第1便の19点のうち、17点は、どのお客さまも選べない状態でした。
店に並べ、9か国語の名前を付けました。
wall_american と floor_american の2点は、もとから店に在ります。
絵が付いただけなので、新しいものには数えていません。
数えると、もとからお持ちの方から取り上げてしまいます。

**③ 店の見本が、17点とも同じ四角でした。**

色を持たない材質だったので、全部おなじ灰色の四角に見えていました。
どれを買うのか選べません。絵そのものを見本にしました。

## 3. 決めたこと（変えたいところがあれば、1行で直せます）

- **値段は90ポイント**にしました。いまの壁と床が70〜90なので、
  その一番上に合わせています。lib/character.js の cost です。
- **寝ているときも、服は着たままです。**
  寝ると脱げる羊は、不具合に見えます。
  ただし、寝姿の絵はまだ無いので、立ったまま静かに息をしている形です。
  ここは実機で見ていただきたいところです。
- **すわって本を読む姿は、着せかえの羊では出ません。**
  絵が無いためです。止まっている姿になります。
  なお、本は着せかえの品として、ご自分で持たせられます。
- **汗をかく姿は、失われていません。**
  汗は畑仕事と必ず一緒に出るものだったので、farm に含まれています。

## 4. 門について

着せかえも内装も、kyo0703opera@gmail.com だけにお見せしています。
門の判定は VocalTracker に1か所だけ置き、下へ渡す形にしました。
2か所で判定すると、片方だけ直す日が来ます。

門が閉じているあいだは、店にも並べていません。
買えるのに敷けない、が起きないようにするためです。

**Vercel の Production で、この環境変数がまだ要ります。**

```
NEXT_PUBLIC_WARDROBE_USER_IDS = 99b695d8-ae90-43a5-9767-a8d073a4003d
```

これが入っていないと、門は開きません。

## 5. 見ていただきたいところ

1. 庭で「歩かせてみる」を押して、見本の羊が歩くか
2. おうちで、羊が眠るときに服を着たままか
3. 庭で、畑にいるときの動き
4. 店の「壁」「床」で、17点の見本が絵になっているか
5. 壁と床を買って敷いたとき、絵が敷きつめられるか

動きの大きさは lib/sheepWardrobe.js の MOTIONS で、1か所で直せます。
「もう少し大きく」「もう少しゆっくり」は、そこの数字だけです。
