## ① 家具が動かせない ── ★直しました。配信済みです（`eaa3b8b`）

原因は 2つでした。どちらも、羊を 92 → 140 に大きくしたときに 表に出ました。

### 1つめ ── ★羊が、下の家具の指を 受け止めていた

羊には、押したときの動きが 1つも ありません。飾りです。
けれど 重ね順は 7000台（`sheepZIndex`）で、家具（3000〜4000台）より 前にいます。

→ 立ち姿と 寝姿の 両方に `pointerEvents: "none"` を 入れました。
　指は 羊を すり抜けて、下の家具に とどきます。

### 2つめ ── ★「うごかす」の 押しどころが、床材・壁材の 後ろに 隠れていた

`UI_CHROME_Z = 10` は、場面の要素が 1〜6 だった頃の 数です。
コードの中に、こう 書いてありました。

```
// 場面の要素は front(6) を超えてはいけない（超えると羊を横切る）。
const UI_CHROME_Z = 10;
```

内装を 入れたときに、★この約束が 破れていました。
内装の帯は 500〜9100、羊は 7000台です。10 は、そのどれよりも 後ろです。
（内装は `pointerEvents:none` なので、★押せてはいました。★見えないだけでした。）

→ 数を `lib/sheepInteriorV2.js` へ 移し、★荷物の帯から 数える形に しました。
　`SCENE_MAX_Z = 9100`（最大の帯 90）／`UI_CHROME_Z = 9200`。
　新しい帯が 届いても、ここが 勝手に 追いつきます。

### 見張り

`sheep-interior-v2.test.js` に 4件 足しました。
「操作ボタンが 場面より前」「羊が 指を すり抜ける（★立ち姿と寝姿の 2つ）」
