## 1. 色

### 1-1｜★色は今のサイトの値をそのまま使う

**新しい色を1つも作りません。** 下の値は、実際の画面の画素から抜き出したものです。
**近い色に置き換えたり、明るさを調整したりしないでください。**

```css
:root{
  --bg:#F7F2E6;        /* 地色 */
  --card:#FFFDF8;      /* カードの面 */
  --card-2:#F7F2E6;    /* チップの面 */
  --border:#E5DDC7;    /* 枠線 */
  --grid:#E5DDC7;      /* 目盛り線 */
  --track:#E5DDC7;     /* 棒の下地 */

  --ink:#261913;       /* 本文 */
  --ink-2:#6D5D50;     /* 補助 */
  --ink-3:#76665A;     /* 目盛り・注記 */

  --wine:#840C24;      /* ブランド色（ロゴ・ボタン） */
  --s1:#840C24;        /* 系列1 = ワイン */
  --s2:#BF8722;        /* 系列2 = 山吹（今のスコアの棒の色） */
  --s3:#447862;        /* 系列3 = 深緑（今の体重の線の色） */
  --s2-pale:#DFC28D;   /* 山吹の淡いほう（既にサイトにある値） */
  --ok:#739E67;        /* スコアの数字に使われている緑 */
}
```

**すでにサイトにある3色を、そのまま系列色に昇格させただけです。**
ワインはロゴとボタン、山吹はスコアの棒、深緑は体重の線。
**新しい色が増えないので、画面がばらけません。**

### 1-2｜★色を増やさず、形で区別する

系列が3つを超えるとき、**4色目を作らないでください。**
代わりに次のどれかを使います。

```
・白抜きの丸（塗りなし＋1.4pxの輪郭）
・丸の大きさを変える（3.2px と 4.8px）
・直接ラベルを添える
・図を分ける（小さく上下に並べる）
```

見本では「低い日」を**白抜きの丸**、「今日」を**塗りつぶし**にしています。
**色は1つのまま、形だけで区別しています。**

これは色覚多様性への対応でもあります。**色だけに意味を持たせない**という原則は、
色を増やさない方針と同じ方向を向いています。

### 1-3｜★夜のモードは、いま決めません

夜の面の上では、`#840C24` は暗すぎて読めません。
**しかし、私が勝手に明るい色を作るべきではありません。**

```
・夜のモードは、坂本さんが色を決めてから実装する
・★それまでは昼のモードだけを作る
・勝手に明度を上げた「近い色」を作らないこと
```

### 1-4｜★使ってはいけない色の使い方

```
✗ 赤・黄・緑の信号色（色そのものが判定になる）
✗ メーターの「危険ゾーン」の塗り分け
✗ 値の大小で色を変える
✗ 上の6色以外の色をデータに使う
✗ 同じ色の明るさ違いを勝手に作る
```

**信号色は3ゲートを迂回します。** 文章を出していなくても、色が言っています。

## 7. ★禁止事項

```
1.  立体のグラフを作らない（3D棒・3D円・奥行きのある面）
2.  円グラフ・ドーナツで割合を出さない（角度は比較しにくい）
3.  赤・黄・緑の信号色を使わない
4.  メーターに危険ゾーンを塗らない
5.  値の大小で色を変えない
6.  文献の基準線・目標線を引かない（★目標カロリーの破線を含む）
7.  1枚のグラフに2つの縦軸を重ねない
8.  散布図に回帰直線を引かない
9.  3ゲートを通っていないカードに解釈の文章を出さない
10. 図の中に解釈の文章を書き込まない（文章はカードの本文だけ）
11. 「データがありません」と書かない（Fの進捗ドットにする）
12. 棒グラフの縦軸を0以外から始めない
13. 系列の並び順を値によって入れ替えない
14. ブランド色 --wine をデータの色に使わない
15. 影でカードを浮かせない（線で囲う）
16. ★勝手に新しい色を作らない（明るさ違いも含む）
```
