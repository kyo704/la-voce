## 2. ★「両方拾う」が、なぜ必須だったか

裁定のとおり両方拾いました。調べてみると、**これ以外に正解がありません**でした。

`lessons` に生徒が届く道は2つあります。

| 決まり | 当たり方 |
|---|---|
| `Ops-visible lessons (org-based)` | `org_id is not null` かつ `auth.uid() = student_id` |
| `Teacher and student can view lessons` | `teacher_student_links` 経由（`link_id`）。org_id の条件なし |

★そして、個人指導のレッスンは **`student_id` を持ちません**。

```js
// components/VocalTracker.jsx handleCreateLesson

`student_id` が入っていません。

つまり `.eq("student_id", userId)` だけで引くと、個人指導の方には**1件も出ません**。
空の画面になり、エラーも出ません。誰も気づきません。

見張りが、この前提そのものも毎回確かめます。
将来 `student_id` も入れるようになったら、その1本が落ちます。落ちて正しいです。

### ㋓ `org_events` は日づけを1つ持つか ── ★はい（紙のうえ）

```
id / org_id / target_group / event_date / start_time / end_time /
kind / title / previous_date / withdrawn_at / updated_at

★★ただしこれは**紙**です。台帳ではありません。
