## 一 ★★答え ── ★部屋を 触らずに 直せます。★しかも 数が ぴたりと 合います

```

　★★壁の 広さでは なく、★**掛けられる 範囲**の 1.5倍。

## 四 ★どこまで 広げるか

| 帯 | 動ける 幅 | いまの | 壁の 中か |

　★★数を 書き写さず、★**床の 線から 引きます**。

### ★1つ、★見て いただきたい こと

★壁の ものは `top` が **上の 端**です（`transform: translate(-50%, 0)`）。
★絵は 320×320。★幅を 14％ ほどで 描くと、★高さは 20％ ほど に なります。

```

top = 52（案）　　　　 → 下の 端は 約 72％ … ★半分 以上 床に かかります
```

★★★つまり **いまでも すでに 床に かかって います**。★案が 初めてでは ありません。
★★「壁の ものが 床に 降りる」ことを 許すか どうかは、★お決め です。

```

★★私は ㋐ です ── ★裁定 その71 の 追補と 同じ 考え方 で。
　★★「★枠の 外にも 置けます。★禁じません」。
　★★置けなく するのでは なく、★置ける ように して、★あとは お客さまが 決める。
