# ★「出席」「休講」は、★どの 画面の どこに 出るか

全65行 / 末尾は「　★★その ときは、★お手数ですが レッスンを 1つ お作りください。」

★★★いま 出るのは **1か所 だけ** です。

## ★手順

```
★1 アプリを 開く
★2 いちばん 下の 帯の「きょう」を 押す
★3 ★上のほうに「きょう おしえる ○人」の 帯が 出て いれば、そこ です
★4 その 帯の 中に、★生徒さんの お名前が 1行ずつ 並んで います
★5 ★お名前の 右に、★小さな 札が 3つ 並んで います
　　★★★出席 ／ 休み ／ 休講
```

## ★★出る ための 条件 ── ★3つ とも そろった とき

```
★① きょう レッスンが ある こと
　　★★きょうの ぶんが 0件 なら、★帯そのものが 出ません。
★② ご自分が **教える 側** で ある こと
　　★★`teaching`（きょう おしえる）の 帯 だけ に 出ます。
　　★★習う 側の 行には、★出欠の 札は 出ません。
★③ まだ つけて いない こと
　　★★つけた あとは「済　出席」の ように、★字だけに 変わります。
　　★★押した 直後の 3秒だけ「もどす」が 出ます。
```

## ★つけた あとの 見え方

```
★押す 前 …… ［出席］［休み］［休講］  ← ★3つの 札
★押した 直後 …… ［もどす］          ← ★3秒 だけ
★3秒 過ぎたら …… 済 出席            ← ★字だけ
```

★★★「よろしいですか」は 出ません。★押した その場で 変わります。
　★★間違えても、★もう一度 押せば 直せます。

## ★★出ない ところ（★念のため）

```
★運営の 画面 …… ★まだ 出ません。★出欠の 画面を いま 作って います。
★記録の 画面 …… ★出ません。★あそこは ご自分の 記録 です。
★レッスンの 帯 …… ★「実施した ／ しなかった」が 出ます。
　★★★これは **別の 画面** です。★言葉も 変えて いません。
　★★あちらは「何回 やったか」を 数える ところ です。
　★★こちらは「その日 来たか」を 見る ところ です。★問いが ちがいます。
```

## ★確かめて いただきたい こと

```
□ ★「きょう」に、きょうの レッスンが 出て いますか
□ ★お名前の 右の 札が、★「出席 ／ 休み ／ 休講」に なって いますか
　　★★もし「来た ／ 休み ／ 中止」の ままなら、★まだ 届いて いません
□ ★1つ 押して みて、★「済 出席」に 変わりますか
□ ★もう一度 押して、★消せますか
```

★★★もし「きょう おしえる」の 帯が 出て いない ときは ──
　★★きょうの レッスンが 0件 か、★教える 側の 行が 無い ときです。
　★★その ときは、★お手数ですが レッスンを 1つ お作りください。
