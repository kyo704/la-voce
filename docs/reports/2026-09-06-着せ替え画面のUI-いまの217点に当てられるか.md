## ⑤ 保存先について（★第3段から要ります）

コーデとお気に入りは、**どこかに残さないと意味がありません。**
いまの `profiles.character_equipped` は「いま着ているもの」1つだけです。

いちばん軽いのは、**同じ列の中に足す**やり方です。

```
character_equipped = {
  hat: "...", garment: "...", ... ,          ← いま着ているもの（変えません）
  wardrobe: { ... },                          ← いま着ているもの（変えません）
  outfits:   [ { id, label, worn, createdAt } ],   ← ★足す（上限20）
  favorites: [ "coatWinterDuffle", ... ],          ← ★足す
  worn30d:   { "coatWinterDuffle": 4, ... }        ← ★足す
}
```

**表を作らずに済みます。SQLも要りません。**
`character_equipped` は jsonb で、すでに書き込む道があります
（`handleEquipWardrobe`）。**いちばん壊れにくい形です。**

★上限20を超えたら、古いものから消す——ではなく、
　**「いっぱいです。どれかを消してください」と伝える**ほうが良いと思います。
　黙って消すのは、この企画の決まり（★取り上げない）に反します。
