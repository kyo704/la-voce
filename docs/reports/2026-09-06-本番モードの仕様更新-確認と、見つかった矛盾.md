## ② ★★ここが大事です ── ACWR は、もう動いています

**「作らない」ではなく、「消す」作業になります。**

コードを確かめました。ACWR は**すでに実装され、利用者に出ています。**

```
components/VocalTracker.jsx:887   computeDailyLoad（活動ごとの重み）
components/VocalTracker.jsx:3102  computeActivityBlockLoad
components/VocalTracker.jsx:3128  computeDayLoadFromActivities
components/VocalTracker.jsx:6945  acwrSeries（★A/C の比を、日ごとに出している）
components/VocalTracker.jsx:7891  分析の系列の1つ「発声負荷（ACWR）」
```

**さらに2か所で、利用者に約束しています。**

**（1）28日つづけた方への「ごほうび」になっています。**

```js
{ days: 28, label: "発声負荷バランス（ACWR）" }
```

3日・7日・14日・28日と、記録を続けると開くものが増えていく作りで、
**28日目に開くのが、この ACWR です。**
消すと、**28日つづけた方に渡すものが、無くなります。**

**（2）「声の予報」の材料になっています。**

```js
// 07. 発声負荷（ACWR）の日次系列。声の予報の「前日発声負荷」predictor にも使う。
const prevAcwr = acwrSeries[prevD] ? acwrSeries[prevD].acwr : null;
```

ACWR を消すと、**声の予報から説明変数が1つ抜けます。**
予報そのものを作り直すか、止めるかの判断が要ります。

## ⑥ 消す範囲について、お決めいただきたいこと

### 判断1　ACWR を、どこまで消しますか

```
案あ  ぜんぶ消す
      ★28日のごほうびが無くなる。★声の予報も作り直しが要る
案い  比（A/C）だけ消し、★日ごとの負荷は残す

★★実装からは、**案い**を推します。

### 判断2　声の予報を、どうしますか

```
案あ  止める　　　★required copy と合う。★28日の方への説明が要る
