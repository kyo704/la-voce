# ★壁を 高く、★床を 広く できるか（★調べだけ・★直して いません）

全137行 / 末尾は「★★動かす 量（★どれだけ 伸ばすか）を お決めいただいてから 動きます。」

## 答え ── ★できます。★ただし **1つ だけ 壊れます**

★★壊れるのは「置いた ものが 動かない」という 保証 そのもの では ありません。
★★**すでに 置いて ある ものの 見え方**です。

## 一 ★いまの 数

`lib/sheepInteriorV2.js`

```
FLOOR_BOTTOM_PCT = 48        ★床が 舞台の 下 48％
WALL_HEIGHT_PCT  = 100 - 48  ★壁は 上 52％
WALL_BAND        = [5, 40]   ★壁の ものを 置ける 帯
FLOOR_BAND       = [60, 97]  ★足もとを 置ける 帯
SHEEP_WANDER     = { centerTop: 80, rangeTop: 10 }  ★羊は 70〜90 を 歩く
```

`components/CharacterHome.jsx`

```
FURNITURE_FLOOR_TOP = 98     ★家具の 既定の 足もと
WALL_BAND_MIN_TOP   = 14
WALL_BAND_MAX_TOP   = 58
```

★★**床の 線は「上から 52％」の ところ**です（100 − 48）。

## 二 ★Q1 ── ★数を 変える だけで 済むか

★★**済みません。★5つ 要ります。**

| 直す もの | いま | わけ |
|---|---|---|
| `FLOOR_BOTTOM_PCT` | 48 | ★本体 |
| `FLOOR_BAND` | [60, 97] | ★足もとの 帯。★床の 線と 一緒に 動かす |
| `SHEEP_WANDER.centerTop` / `rangeTop` | 80 / 10 | ★羊が 歩く 帯。★床の 上を 歩かせる |
| `FURNITURE_FLOOR_TOP` | 98 | ★家具の 既定の 足もと |
| `WALL_BAND` ／ `WALL_BAND_MIN_TOP` ／ `WALL_BAND_MAX_TOP` | [5,40] ／ 14 ／ 58 | ★壁の ものの 帯 |

★★★`FLOOR_BOTTOM_PCT` **だけ**を 動かすと、
　★床の 色の 帯は 動きますが、★羊も 家具も **その ままの 高さ**に 残ります。
　★★羊が 床の 上を 歩かなく なります。

★★★もう 1つ、★見落としやすい ところ ──

```
CharacterHome.jsx:2284  stageBleed(roomBoxW, roomBoxH, STAGE_ASPECT, FLOOR_BOTTOM_PCT)
CharacterHome.jsx:2900  bottom: `${FLOOR_BOTTOM_PCT - 26}%`
見本 2本の CSS       background: linear-gradient(… 48.219% …)
```

★★見本の `48.219%` は「★床の 高さ ÷ 部屋の 高さ」です。★裁定 §2-5 が
　★「部屋の 寸法が 変われば、★この 数も 変えます」と 書いて います。
★★**見本 2本も 一緒に 直します。**★片方だけ 直すと、また 2つに なります。

## 三 ★★Q2 ── ★すでに 置いて ある ものは どう なるか

★★**動きます。★見え方だけ が。**

★★しまって ある 値は「★舞台に 対する ％」です。★床に 対する ％では ありません。
　★★だから、★床の 線を 動かしても、★家具の 数は **1つも 変わりません**。
　★★変わるのは **床の 線の ほう**です。

```
いま      家具の 足もと 82％ ／ 床の 線 52％  → ★床の 上に 立って います
床を 広げる（48 → 56）と
          家具の 足もと 82％ ／ 床の 線 44％  → ★床の 上。★けれど 壁から 遠く なります
壁を 伸ばす（48 → 40）と
          家具の 足もと 82％ ／ 床の 線 60％  → ★★床の 手前に 寄り、★狭く 見えます
```

★★★**「浮く」「沈む」は 起きません。**★家具は 床の 帯（60〜97）の 中に あり、
　★床の 線（44〜60）より 下 だからです。
★★けれど **壁ぎわに 寄せた もの**は、★床の 線が 動いた ぶん だけ
　★★壁から 離れて／壁に めり込んで 見えます。

★★★★壁の もの（絵・時計・窓）は、★もっと はっきり 出ます。
　★★`WALL_BAND` は [5, 40]。★床の 線（52）より ずっと 上 なので、
　　★床の 線を 動かしても 当たりません。
　★★けれど **壁の 下端**が 動きます。
　　★壁を 伸ばす（48 → 40）と、★壁の 下端は 52 → 60。
　　★★40 に 掛けた 絵は、★いままで 壁の 真ん中 でした。
　　★★あとは 壁の 上の ほうに 見えます。★**掛け直したく なります。**

## 四 ★Q3 ── ★危ない ところ

| 危なさ | 何 | 起きる こと |
|---|---|---|
| ★小 | 床の 色の 帯 | ★数を 変える だけ |
| ★小 | 舞台の 余白の 色（`stageBleed`）| ★同じ 数を 渡して います。★自動で 揃います |
| ★中 | 羊が 歩く 帯 | ★合わせ忘れると、★羊が 床から 外れます |
| ★中 | 家具の 既定の 足もと | ★合わせ忘れると、★新しく 置いた ものだけ ずれます |
| ★★大 | **すでに 掛けて ある 壁の もの** | ★壁の 中での 高さが 変わります。★掛け直しに なります |
| ★中 | 見本 2本の CSS の `48.219%` | ★忘れると、★見本と 実機が また 分かれます |
| ★小 | `CharacterHome.jsx:2900` の `FLOOR_BOTTOM_PCT - 26` | ★この `26` が どこから 来たのか **書かれて いません**。★調べが 要ります |

★★★**いちばん 大きいのは、★お客さまの 手が 入った ところ**です。
　★★壁に 何かを 掛けた 方は、★掛け直しに なります。
　★★いま 掛けて いる 方が 何人 いるかは、★台帳に 尋ねれば 分かります。
　　（`character_equipped.interiorPositions` に `wallart` の 鍵が ある 方）
　★★★**0人 なら、★危なさは ほとんど ありません。**

## 五 ★安全に 進める 順

```
1 ★台帳に 尋ねる ── ★壁に 何かを 掛けて いる 方は 何人か
2 ★どれだけ 動かすか を 決める（★例：48 → 52）
3 ★5つの 数を **一度に** 直す（★1つずつ 直すと、途中の 姿が 壊れます）
4 ★見本 2本の CSS も 同じ 日に 直す
5 ★道具で 測る ── ★床の 線・羊の 足もと・家具の 足もとの 3つ
6 ★見張りを 足す ── ★★数どうしの 関わりが 崩れたら 落ちる
     れい：FLOOR_BAND[0] > 100 - FLOOR_BOTTOM_PCT（★足もとは 床の 線より 下）
7 ★見た目は 未確認の まま 報告し、★坂本さんに 撮って いただく
```

★★6が 大事 です。★いまは **5つの 数が 別々に 置かれて いて**、
　★「どれと どれが 揃って いる べきか」が どこにも 書かれて いません。
　★★次に 誰かが 1つだけ 動かすと、★また 静かに ずれます。
　★★動かす いま が、★それを 結ぶ いちばん 安い 時 です。
