## 4. 裁定 §2-3 について

> ★とだな 向き（置くもの）が 0点なら、★3点 描き足してください。
> ・小さな 鉢植え ・重ねた 楽譜 ・木の 小箱

★**家具27点の 中では 0点ですが、むかしのかぐ に 4点 あります。**
　下限（2点）は 越えています。

★★ただし、Opus が 挙げた 3点は「**とだな の 上に 置くもの**」に
　読めます。いまの 4点は「**とだな そのもの**」です。役が ちがいます。

★いまの 品で「上に 置くもの」に あたるのは、**3点**です。
　石油ランプ（showa_01）／真空管ラジオ（showa_11）／トロフィー（wallart_11）。
　★どれも `placement: tabletop` です。

★★どちらの 意味かで、要る 絵が 変わります。
　㋐「とだな そのもの」なら ── **要りません**（4点 あります）
　㋑「とだな の 上に 置くもの」なら ── **いまは 3点**。下限は 越えます。

## 5. お尋ねしたいこと（★2つ）

**① 天井の 照明 7点を、どう しますか。**

　家具の 6点（麻のシェード・琺瑯のペンダント・白い球・透かし彫り・
　裸電球・ステンドの傘）と、むかしのかぐ の 1点（洋燈のシャンデリア）です。

- ㋐ **9か所目「てんじょう」を 足す**（★7点 あるので 選べます）
- ㋑ 8か所に 入れず、当面 出さない
　　★★ただし、いま 天井に 吊るしておられる方が いるかもしれません。
　　★裁定 §4 ⑤（1点も 取り上げない）に 触れます。私は 数えられません。
- ㋒ 「ゆか」に 混ぜる（★天井の ものが 床に 立ちます。おすすめしません）

★私の 案は ㋐ です。★8か所が 9か所に なるだけで、
　「毎回 1つ 空く」問題は 起きません（★7点 ある ため）。

**② 縁側（showa_19）1点を、どう しますか。**

　`placement: structure` で、これ1点だけです。
　まど・とびら と 同じ「部屋の 形」に 近い ものですが、
　1点しか ないので、置き場所には できません（★下限2点）。

- ㋐ 当面 出さない（★①㋑ と 同じ 心配が あります）
- ㋑ 「ゆか」に 入れる
- ㋒ Opus に お尋ねいただく

　まど と 同じ「動かせない・部屋の 形そのもの」の 扱いです。

　品の 鍵に 日本語が 入っていない こと（★言葉を 直しても 鍵が 動かない）を
