## ③ ひとつにまとめる件 ── 何が引っかかるか

**見た目をそろえるだけなら、すぐできます。**
ショップの「装備する」の画面を、着せかえと同じ形（分類のタブ＋押すだけ）に
することは、101点ぜんぶについて、絵を1枚も描かずにできます。

**引っかかるのは、古い22点を羊に出すところです。**

古い22点は、**PNG の絵がありません。**
SheepCharacter という部品の中に、1点ずつ SVG で手描きされています。
`equipped.hat === "hat_straw"` のときこの図形を描く、という書き方が22個
並んでいます。絵のファイルではないので、絵の羊には貼れません。

道は3つです。

**案1：古い22点を、217点に引きあげる**
新しいほうが、同じところを広く覆っています（帽子6→61、服10→97、持ち物6→47）。
ただし、**買ってくださった方から取り上げることになります。**
持っている扱いのまま隠す、ポイントをお返しする、などの手当てが要ります。
絵は1枚も要りません。

**案2：22点ぶんの PNG を描く**
いちばんきれいですが、絵が22枚要ります。

**案3：お部屋の羊を SVG に戻す**
古い22点は見えます。217点が、お部屋では見えなくなります。

わたしのおすすめは **案1** です。取り上げにならないよう、
「持っている扱いは残す」を必ず付けます。

## ④ 歩き方 ── 昨日のわたしの説明が、まちがっていました

昨日わたしは「服を着ると脚が隠れるから、脚の動きは使えない」と申しました。
**ちがいました。絵をひらいて確かめました。**

**絵の羊には、そもそも脚がありません。**
sheep_body.png は、もこもこの体が地面に接していて、
その下に小さな足の楕円が2つあるだけです。脚という部分が描かれていません。
服は関係ありませんでした。まちがったことを申しました。

**SVG の羊の歩きは、こうなっています。**
`leg-l` と `leg-r` という2つのかたまりがあり、それぞれ棒の脚と
ひづめの楕円を持っています。つけ根を軸に、左右が逆向きに20度ずつ、
0.62秒で振れます。腕も14度、逆向きに振れます。
図形が部品に分かれているので、こういうことができます。

**絵の羊で採れる道**

**案A：お部屋の羊を SVG に戻す**
ほんものの脚の動きが戻ります。217点が、お部屋で見えなくなります。
絵は要りません。すぐできます。

**案B：脚の絵を描き足す**
体の後ろに脚を2本置いて、交互に振ります。
ただし、いまの体は地面に接する形なので、**体の下側も描き直しが要ります。**
絵が要ります。

**案C：脚なしのまま、歩きらしくする（絵は要りません）**
いまの動きは、上下に同じだけ弾む形です。だから跳ねて見えます。
歩きに見せるには、左右で非対称にします。
進む向きへ少し傾け、体を左右にゆらし、着地で少しつぶれ、
その上下を、進む速さと合わせます。
絵は1枚も要りません。**いちばん早く、たしかに良くなります。**

**案D：2枚の絵を入れかえる（昔ながらのやり方）**
右足前・左足前の2枚を交互に出します。脚が無くても歩いて見えます。
実際に絵を測りました。**足の2つは、y=935 より下では分かれています**
（左 x364〜479／右 x544〜659）。ただしそれより上は体と一体なので、
そのまま動かすと輪郭が裂けます。足まわりの描き直しが要ります。

**靴については、きれいに分かれていました。**
靴の絵は左右2つが x=511 のあたりで離れています。
**靴をはいているときだけ**なら、絵を足さずに左右を交互に動かせます。

**おすすめの順**
まず**案C**（絵が要らず、今日中にできます）。それをご覧いただいてから、
まだ足りなければ案Bか案Dで絵を起こす、という順が無駄がありません。

## ⑤ 表情9点について

**README には「実装済み」とありますが、このリポジトリには入っていません。**
確かめました。

- 9枚の絵は、public/ のどこにもありません
- 表情を呼んでいるコードも、ありません
- 置き場所は ~/Desktop/docs:/羊-表情9点＋生成コード（git の外）です

**それより大事なことがあります。別の羊です。**

表情9点の羊は、粘土のような立体の絵です。
着せかえの羊は、平たい、やわらかい色の絵です。
**同じ羊ではありません。**顔の形も、体の作りもちがいます。
README の座標（左目 458,416 など）は、あちらの羊のためのものです。

**そして、着せかえの217点は、平たいほうの羊に合わせて描かれています。**
測りました。和服の絵は x224〜799・y506〜889。
体の絵は x224〜799・y490〜951。ぴったり中に納まっています。
**土台の羊を立体のほうに差し替えると、217点ぜんぶが合わなくなります。**

**採れる道**

**案ア：表情は、いまは使わない**
217点を守ります。何もしません。

**案イ：gen.py を、平たい羊の顔に当て直す**
gen.py は「目と口を消して、描き直す」道具です。
元の絵と座標を変えれば、平たい羊でも9つの表情を作れます。
座標の測り直しと、絵の作り直しが要ります。217点はそのまま使えます。

**案ウ：立体の羊に乗りかえる**
表情は手に入りますが、217点を捨てることになります。

わたしのおすすめは、いまは**案ア**、落ち着いてから**案イ**です。

なお README の最後の一行は、そのとおりだと思います。
「体調・スコアには連動させないこと。羊が元気ないと、利用者は責められたと感じます。」
これは、いまの作りとも合っています。ポイントは記録したことに出しており、
数字の良し悪しには出していません。
