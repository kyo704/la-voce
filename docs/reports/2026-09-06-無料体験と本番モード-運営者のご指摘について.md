## ① 先に、前提のことを1つ

**「無料体験」は、作らないと決まっています。**
2つの文書に、2回書かれています。

```
docs/opus/lavoce-価格と課金の正（9月4日・確定）.md §1-2
　　✕ 30日の猶予　　✕ 7日の体験　　✕ どんな体験期間も、作りません

docs/opus/lavoce-価格と課金の正（9月6日・確定）.md §2
　　・体験期間を作らないこと
```

★理由も書かれています。

> ★★そして、★取り上げなくて済みます。
> 　★9月4日の決まり ── ★一度あげたものを、取り上げない。
> 　★**体験期間は、★終わる日に、必ず取り上げます。**
> 　★この形なら、★取り上げる日が来ません。

★ですので「①今すぐ14日間／②本番の2週間前から」という2案は、
　★この決まりより**前**のもの、あるいは**別の流れ**で出てきたものだと思われます。

★★どちらが正か、お確かめください。
　★決まりのほうが生きているなら、**①も②も作りません。**
　★決まりを変えるのであれば、それは価格の正を書き換える話になります。

**以下は、「もし体験期間を作るとしたら」という前提でお答えします。**

---

## ② ご指摘は、問題です。★しかも、もっと深いです

**はい、問題視すべきです。**そして、**②を選んでも解決しません。**

### 「前も、こうでした」は、2回目の本番から動きます

この機能は、**過去にご自身が書いたことを出し直す**ものです。
出し直すには、**先に1回、書いてあることが要ります。**

```
1回目の本番   ★記録される。★比べる相手がいない
2回目の本番   ★ここで初めて「前も、こうでした」が出る
```

つまり——

```
①今すぐ14日間        本番が無ければ、何も起きない　　　（ご指摘のとおり）
②本番の2週間前から   本番が1回あっても、★比べる相手がいない
```

**②でも、本当の価値は出ません。**

### 声を使うお仕事の、本番の間隔

本番と本番のあいだは、**数週間から数か月**です。
**2週間の窓に、2回の本番が入ることは、まずありません。**

★★つまり、**どんな長さの体験期間でも、この機能は見せられません。**
　★14日を30日にしても、同じです。
　★①を外して②だけにしても、同じです。

**体験期間という道具では、この機能は伝わりません。**

---

## ③ では、どうするか

**ご指摘は、体験期間を作らないという決まりを、別の角度から裏づけています。**

### ★お勧めする形

**「記録は無料。比べるところだけ、売る。」**

これは、すでにある決まりそのものです。

```
★記録は取り上げない。★見方だけを売る。
★★本人が書いた数を、そのまま見せる画面は、★期間を問わず無料。
★★こちらが計算した数を見せる画面は、★売ってよい。
```

本番モードを、この線で切ります。

| | 無料 | 有料 |
|---|---|---|
| 本番の日を登録する | ★無料 | |
| 「あと n日」の帯 | ★無料 | |
| D-1／D-0／D+1 の羊のことば | ★無料 | |
| D+1 のひとつの質問と、その保存 | ★無料 | |
| **「前も、こうでした」（過去との比較）** | | ★有料 |
| **今週と先月を並べて見せる** | | ★有料 |

### ★なぜ、この切り方なのか

**（1）決まりに、そのまま合います。**
本番の日も、D+1 の答えも、**ご本人が書いたもの**です。
「前も、こうでした」は、**こちらが並べ直したもの**です。

**（2）★★これがいちばん大事です ── 記録が、無料で貯まります。**

いまの案（本番モードを丸ごと有料）だと、こうなります。

```
本番の日を登録できない（有料だから）
　　↓
過去の本番が、1つも貯まらない
　　↓
いつ買っても「比べる相手がいません」と出る
　　↓
★永遠に、価値が出ない
```

**買わないと貯まらないのに、貯まっていないと買う理由が無い。**
★出口がありません。

無料で登録できれば、**使っているうちに、勝手に貯まります。**
2回目の本番が来たとき、初めて「前も、こうでした」が出せます。
**そのときに、買っていただけばよいのです。**

**（3）取り上げる日が、来ません。**
体験期間と違い、**無料の部分は、ずっと無料のままです。**

## ④ ご提案の2案について

```
案あ  ①を選んだ方にも、本番日の登録を強く促す
案い  ①自体を、選択肢から外す
```

**どちらも、②の理由で効きません。**
登録を促しても、**比べる相手が無いことは変わらない**からです。

★また案あは、「催促しないこと」という決まりにも触れます
　（価格の正 §1-4）。
