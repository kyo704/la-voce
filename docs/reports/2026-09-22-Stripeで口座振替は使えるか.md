## 一 ── 答え

★★★**使えません。**

Stripe の「口座振替（bank debits）」に 並んで いるのは、★この 6つ だけ です。

| 決済手段 | 国 |
|---|---|
| ACH ダイレクトデビット | US |
| Bacs ダイレクトデビット | GB |
| BECS ダイレクトデビット | AU |
| BECS ダイレクトデビット | NZ |
| プレオーソリデビット | CA |
| SEPA デビット | 欧州 |

★★**日本の 口座振替は ありません。**

★文書に こう 書いて あります ──
「新しい 口座振替手段を リクエストされる 場合は、お問い合わせください」
★★つまり「まだ 無い」です。★設定で 出て くる ものでは ありません。

## 二 ── では 日本で 何が 使えるか

| 決済手段 | 通貨 | 毎月の 自動の 引き落としに 使えるか |
|---|---|---|
| カード | ほぼ すべて | ★**使えます**（サブスクリプション・Invoicing とも） |
| 銀行振込（`customer_balance`） | JPY | ★**半分だけ**。★下を ご覧ください |
| コンビニ決済（`konbini`） | JPY | ★`send_invoice` の ときだけ |
| PayPay | JPY | ★サブスクリプションは **使えません** |
| Link ／ Apple Pay ／ Google Pay | ほぼ すべて | ★使えます（★中身は カード） |

### ★★銀行振込の「半分だけ」の 意味

★Invoicing でも サブスクリプションでも 使えます。★ただし ──

```
「請求書 と サブスクは send_invoice の 回収方法 のみに 対応」
```

★★`charge_automatically`（★自動で 引き落とす）は **できません**。
★★★つまり「請求書を 送る → 学校が 自分で 振り込む」形 だけ です。
　★毎月 ひとりでに 落ちる 形には なりません。
