## §2 ★-webkit-text-size-adjust: 100% ── ★入れないでください

★これが、いちばん大事な訂正です。

```
text-size-adjust の意味
　　auto（既定）  ★端末の文字の拡大に、★従う
　　100%          ★★従わない。★等倍に固定する
```

★名前から「100%に整える」と読めますが、★逆です。
　★★「拡大するな」という指示です。

```
Android      ★いま auto なので、OS の文字サイズに★従っています
　　　　　　  ★★100% を入れると、★その日から従わなくなります

iOS          ★横に長い文章を勝手に大きくするのを止める指示です
　　　　　　  ★設定 ＞ 画面表示と明るさ ＞ 文字サイズ とは、★無関係です
```

★★いま globals.css に、この指定は★1つもありません（確認済み）。
　★このままにしてください。★足すと、Android の方が困ります。

## §3 ★iOS は、rem では追従しません

★ここも、★はっきり書きます。

```
Android Chrome  ★OS の文字サイズ → ★ウェブの文字に、そのまま効きます
iOS Safari      ★★OS の文字サイズ（Dynamic Type）は、
                　★ふつうのウェブページには★効きません
```

★iOS で追従させるには、★指定の書き方が1つだけあります。

```css
html {
  /* ★★これだけが、iOS の「文字サイズ」を拾えます。 */
  font: -apple-system-body;
  /* ★font: は書体もまとめて上書きするので、★書体は戻します。 */
  font-family: var(--font-body), system-ui, sans-serif;
}
```

★★これを入れないと、★iPhone の方には、何も変わりません。
　★そして、お客さまの多くは iPhone です。

## §4 ★いまの作り ── ★足を引っ張っているのは、ここです

```css
:root { --base: 16px; }        /* app/globals.css:110 */
html  { font-size: var(--base); }
```

★`html` の文字サイズを、★16px と★決め打ちしています。
★★これがあると、★ブラウザや OS の設定は、★上書きされて消えます。

★アプリの中にも、大きさの設定がすでにあります。

```
[data-scale="large"]  --base: 20px
[data-scale="xlarge"] --base: 24px
```

★★つまり「アプリの設定」と「OS の設定」が、★取り合っています。
　★いまは、★アプリの側が勝っています。★OS の設定は、届いていません。

### 直す形

```css
:root {
  /* ★倍率にします。★大きさそのものは、OS と端末から来ます。 */
  --scale: 1;
  --tap: 44px; --gap: 12px; --line: 1.7;
}
[data-scale="large"]  { --scale: 1.25; --tap: 56px; --gap: 16px; --line: 1.75; }
[data-scale="xlarge"] { --scale: 1.5;  --tap: 64px; --gap: 20px; --line: 1.8; }

html {
  font: -apple-system-body;                     /* ★iOS の設定を拾う */
  font-family: var(--font-body), system-ui, sans-serif;
  font-size: calc(100% * var(--scale));         /* ★端末の既定 × アプリの倍率 */
}
```

★★これで、★2つが取り合わず、★かけ算になります。
　★OS で大きくしている方が、アプリでも大きくすると、★もっと大きくなります。
　★それが、望まれている動きです。

## §5 ★手の量

```
固定の px で書いた文字     ★254 か所（components ＋ app）
すでに rem で書いた文字     68 か所
```

★254 か所を、★16 で割って rem にします（16px → 1rem）。
★★機械的にできますが、★機械だけでは危ないところがあります。

```
★入力欄の 16px は、★下げないこと
　　→ iOS は、16px 未満の入力欄に触ると★画面を勝手に拡大します
　　→ globals.css の input/select/textarea は、★px のままにします

★線の太さ・角の丸み・余白の px は、★文字ではありません
　　→ fontSize だけを直します。★padding や borderRadius は触りません
```
