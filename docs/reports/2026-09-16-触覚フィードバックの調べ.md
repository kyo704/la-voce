## Q1　`navigator.vibrate` は 使えるか

| どこ | 使えるか | 中身 |
|---|---|---|
| Android Chrome / Edge / Samsung | ○ | 画面に 貼った アプリでも 効きます |
| Android Firefox | ○ | 同上 |
| **iOS Safari（iPhone・iPad）** | **×** | `navigator.vibrate` が **そもそも ありません** |
| iOS の Chrome・Edge・Firefox | × | 中身は すべて Safari と 同じ 仕掛けです |
| PC の Chrome / Edge | 印だけ ○ | 呼べますが、揺れる 部品が ありません。黙って 何も しません |

★★ここに 落とし穴が 1つ あります。
　★`"vibrate" in navigator` が 真でも、**揺れるとは 限りません**。
　★PC は 真を 返して、何も しません。「有る」は「効く」では ありません。

★★Android で 呼ぶ ときの 決まり（いずれも お求めの 制約と 合います）──
　・利用者が 触った あとでしか 効きません（Chrome の 決まり）。
　　★「予告なしの 発火は 禁止」は、**ブラウザ側が すでに 守って います**。
　・画面が 見えて いる ときだけ 効きます。
　・10ms は 端末により 丸められます。感じない 端末が あります。
