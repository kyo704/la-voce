### ★いちばんありそうな理由

★`NEXT_PUBLIC_` で始まる変数は、★**組み立てのときに埋め込まれます**。

- ★「Redeploy」で **Use existing Build Cache** を選ぶと、
  ★前の組み立てをそのまま使うので、★新しい値が入りません
- ★Production ではなく Preview／Development に入れた場合も入りません

★お確かめいただきたいこと ──

```
1  Vercel → Settings → Environment Variables
   NEXT_PUBLIC_GATE_TEST_USER_IDS の行の「Environments」に
   ★Production の印が付いているか

   ★「Use existing Build Cache」の ★チェックを外す
3  終わったら https://woolsong.app/api/version で
   ★gateTestIds が 3 になっているか
```

★3にならないうちは、何をしても有料の面は出ません。
