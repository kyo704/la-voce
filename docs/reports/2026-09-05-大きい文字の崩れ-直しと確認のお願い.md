## §2 直したこと

### ③ 「教室に参加する」が画面の外（★いちばん重い）

```
原因  ★flex と grid の子は、★既定では中身より小さくなれません
　　　★中身が長いと、★箱を押し広げ、★となりを画面の外へ押し出します
直し  ★min-width: 0 を渡しました。★縮めるようになります
```

★★shrink-0 を付けてある部品（タブなど）は、★これでは縮みません。
　★意図して固定してあるものは、そのままです。

### ② 分析の見出しが2〜4行に折り返す

```
直し  ★見出しに上限を置きました
　　　　h1・h2 … 30px まで
　　　　h3・h4 … 24px まで
```

★★私は、ここで1つ間違えました。★書いておきます。

```
はじめ書いたもの   h1, h2, h3, h4 { font-size: calc(1em * 倍率) }
起きること         ★何も効きません
理由               ★Tailwind の text-lg（クラス）のほうが、
　　　　　　　　　  ★h3（要素）より強いためです
直したこと         ★[data-scale] を頭に付けて、強さを上げました
　　　　　　　　　  ★そして、★倍率ではなく★上限（px）にしました
```

★上限にした理由 ── ★倍率だと、★元の大きさが読めないので、確かめられません。
　★上限なら、★何が起きるか、★見なくても分かります。

### ② 声の予報の本文が、何行にもなる

```
★行数ではなく、★幅の問題でした。★2列の中に入っています。
直し  ★狭い画面（640px 未満）で、★大きい設定のときだけ、★1列にします
```

### ④ 暦の数字が重なる

```
★7つ並ぶ升目の幅は、★画面の1/7で決まっています。
★数字だけ大きくしても、★升目は広がりません。★重なります。
直し  ★暦の中だけ、★倍率を打ち消しました
```

### ④ ノートのタブが2行に折り返す

```
★折り返すと、★どこまでが1つの名前か分からなくなります。
直し  ★折り返しを止め、★入れ物を横に流します
　　　★「まだ続く」と読めます
★レッスンの役割の帯（学ぶ／教える）にも、同じ直しを入れました
```

### そのほか

```
★切れない長い文字（アドレス・記号の列）を、折り返させました
```

### ★ふつうの設定では、1つも効きません

★上の直しは、★すべて `[data-scale]` が付いているときだけです。
★倍率が「ふつう」の方の見た目は、★1つも変わりません。

## §3 ★入れていないもの ── グラフが小さいまま

★ご報告の「グラフが、まったく大きくならない」は、★直していません。
★理由を書きます。

```
★グラフは、★文字ではありません。★絵です。
　★中の数字だけを大きくすると、★線と重なります。
　★絵ごと大きくすると、★横にはみ出します。
★★どちらも、★見ないと決められません。
```

★そして、★これは別の仕事です。

```
□ グラフの入れ物を、★幅いっぱいに伸ばす（viewBox にする）
□ 目盛りの数字だけ、★別に大きさを決める
□ ★横に長いグラフは、★横に流せるようにする
　　★見積もり 半日〜1日
```

★★先に、★§4 を見ていただきたいです。
　★見出しと幅が直ると、★グラフの見え方も変わります。
　★そのうえで、★まだ小さいと感じられるかを、★教えてください。
