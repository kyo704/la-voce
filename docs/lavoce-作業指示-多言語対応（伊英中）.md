## 2. ★訳してはいけない日本語（これを間違えると壊れます）

**日本語の文字列が、画面の文字ではなく「保存される値」や
「計算の鍵」になっている箇所があります。**

### 2-1｜活動の種類（★最も危険）

```js
// components/VocalTracker.jsx:736
const ACTIVITY_LOAD_WEIGHT = { "休養": 0, "自主練習": 1.0,
                               "レッスン": 1.2, "リハーサル": 1.3, "本番": 1.6 };
// :1356
const ACTIVITY_BLOCK_KINDS = ["自主練習", "レッスン", "リハーサル", "本番"];
// :3035
const ACTIVITY_CHART_COLORS = { "休養": ..., "本番": ... };
```

この「本番」は **`entries.activity_type` に保存されている値**であり、
**発声負荷の重みを引く鍵**でもあります。

★訳した瞬間に、過去の全記録が引けなくなり、負荷の計算が壊れます。

### 2-2｜そのほか、保存される日本語

| 定数 | 保存先 | 状態 |
|---|---|---|
| `ACTIVITY_*`（本番・休養ほか） | `entries.activity_type` / `activity.kind` | ★訳さない |
| `VOICE_TYPES`（ソプラノほか） | `profiles.voice_type` | ★訳さない |
| `NUTRITION_PHASES`（維持・増量・減量） | `profiles.nutrition_phase` | ★訳さない |

### 2-3｜正しい形は、もう在ります

```js
{ key: "休養", icon: Moon, labelKey: "activityRest" }   // ← これ
{ key: "gerd", label: "逆流性食道炎" }                    // ← これも良い形
const NUTRITION_PHASE_KEYS = { "維持": "phaseMaintain", ... };  // ← これも
```

**保存する値（key）と、画面に出す文字（labelKey）を分ける。**
③の用語辞書も、この形の上に載せました。
**同じ分け方を、残りにも広げるだけです。新しい発明は要りません。**

★`GOAL_TAGS` と `CONDITION_OPTIONS` は既に key/label が分かれています。
　label だけを翻訳キーに置き換えれば済みます。

### 2-4｜手順（1箇所ごとに、必ずこの順で）

```
① その日本語が、どこかに保存されているか調べる
     grep でその文字列を探し、DBの列名の近くに出ないか見る
② 保存されている  → ★訳さない。labelKey を足して、表示だけ差し替える
③ 保存されていない → t() に通す
④ 翻訳キーが無ければ、★9言語ぶん足す（it/en/zh だけ足さない）
```

## 3. ★先にやること：用語の統一

**翻訳を広げる前に、言葉のズレを片付けてください。**

`labelResonanceScore` が、3言語で少しずつ違う意味になっています。

| 言語 | いまの語 | 直訳すると |
|---|---|---|
| ja | 声の出来（0〜10） | 声の仕上がり |
| it | Resa della voce (0–10) | 声の「出力・成果」 |
| zh | 嗓音状态（0〜10） | 声の「状態」 |

この項目は、2026-08-28 に「同じ数字が2つの名前で呼ばれている」
問題が出たところでもあります（声の出来／声の響きスコア）。

```
□ ★日本語の呼び名を1つに決める（坂本さんの判断）
□ 決めた意味に合わせて it / en / zh を直す
□ 用語表を docs/ に残す。★以後、翻訳はこの表に従う
```

**ズレたまま3言語に広げると、あとで3倍直すことになります。**

---

## 4. ★2つに分かれている仕組みを、1つに寄せる

いま、言語の切り替えが**2系統**あります。

| | 仕組み | 対象 |
|---|---|---|
| ① | `createTranslator` ＋ `localStorage["la-voce-language"]` ＋ もっとの選択メニュー | アプリ本体 |
| ② | 各ページが自前の `LANGS` 表を持ち、`?lang=` で切替 | `app/page.js` と理論ページ4つ |

②は5ファイル（`page.js` / `vocal-theory` / `announcer-theory` /
`voice-actor-theory` / `performer-theory`）にあります。

```
□ ②を①に寄せる。★自前の LANGS 表を残さない
□ 入口（app/page.js）で選んだ言語が、ログイン後も続くこと
□ ?lang= は当面のあいだ受け付ける（配ったリンクが死なないため）
```

★寄せないまま進めると、**同じ決めごとが2か所にある**状態が固定します。
　このリポジトリが繰り返してきた壊れ方です。
