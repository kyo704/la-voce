## 決めごと

- ★**手で書きません。** `supabase/AUDIT_full_schema_vs_repo.sql` の出力を、そのまま貼ります。
- ★**編集しません。** 直したくなったら、直すのは本番のほうです。
- ★**消しません。** 古い写しは、いつ何が変わったかを答えるために要ります。
- ファイル名は `YYYY-MM-DD.md`。★**1日に何度取っても構いません**（`-2` を付けてください）。

## 読み方

★**「いまどうなっているか」に答えるのは、常にいちばん新しい写しです。**
`schema.sql` ではありません。
